# FP 소환 자동 판매 (1.4.1)

**판매 화면에 보이는 서번트·경험치 카드·포우 카드 중 잠금이 아닌 칸을 모두 선택해 판매합니다. 시작 전에 판매 화면의 필터 설정을 꼭 확인하세요.**

무엇을 팔지는 게임 판매 화면의 필터로 미리 정합니다. FGA는 필터와 정렬을 읽거나 바꾸지 않습니다. 종류·별 수·NEW! 여부로 대상을 제한하지 않으므로, 필터에 보이는 고등급 카드나 육성한 카드도 잠금이 아니면 대상입니다.

## 설정

**시험 모드는 베타 전용**입니다. 정규판은 시험 모드 스위치·설명을 표시하지 않으며, 저장된 시험 모드 설정과 관계없이 자동 판매를 켜면 실제 판매합니다. 실제 판매 허용 조건(KR·JP, 잠금 템플릿)을 만족하지 않으면 판매 없이 정지합니다. 베타는 시험 모드가 기본으로 켜져 있습니다.

| 항목 | 기본값 | 동작 |
|---|---|---|
| 자동 판매 켜기 | 꺼짐 | 서번트칸 가득 참에서 판매 화면으로 이동합니다. |
| 시험 모드 (최종 확인에서 취소, 베타 전용) | **켜짐** | 최종 확인창에서 왼쪽 취소를 누르고 원래 배너에서 재소환합니다. 두 번째 가득 참에서 정지합니다. 끄면 실제 판매합니다. |

## 동작과 보호 규칙

서번트칸 가득 참 경고에서 서번트 단어를 확인하고 판매 화면의 서번트 탭으로 이동합니다. 개념예장칸 등 다른 경고에서는 판매하지 않습니다. 5→6→7열 순환을 최대 두 번 눌러 7열을 맞춥니다.

한 화면의 행 기준점을 카드 테두리에서 한 번 찾고 고정 열 간격으로 격자를 만듭니다. 종류 라벨이 없어도 실제 카드가 있으면 읽습니다. 완전히 보이는 아래 행도 평가하며 빈 슬롯은 선택하지 않습니다.

다음 조건을 모두 만족한 칸만 한 번 누릅니다.

- 카드가 실제로 있습니다.
- 자물쇠 또는 `잠금 중` / `ロック中` 표시가 없습니다.
- `選択不可`, `グランドサーヴァント`, `PARTY`, `仮加入` / `仮加入サーヴァント` 표시가 없습니다.
- 청록색 선택 테두리가 **미선택(false)** 으로 판독됩니다. 이미 선택됐거나 애매하면 누르지 않습니다.

잠금을 풀지 않습니다. 잠금 템플릿이 없으면 베타는 시험 모드만 허용하고 정규판은 판매 없이 정지하며, 시험 모드에서는 잠금 판별 불가 칸도 선택할 수 있습니다. 이 수는 **잠금 판별 안 됨 N칸**으로 따로 표시합니다. 실제 판매에서 잠금 판별 불가는 선택하지 않습니다. 실제 판매는 검증된 KR·JP와 잠금 템플릿이 모두 있을 때만 허용합니다.

누른 뒤 선택 확인은 기다리지 않습니다. 스크롤은 평가한 행보다 한 행 적게, 한 번에 최대 560px(1440p)로 제한하고 끝점에서 멈춰 관성을 억제합니다. 겹쳐 본 칸은 청록색 테두리로 이미 선택됐음을 확인하고 건너뜁니다. 한 번에 최대 999칸입니다. 겹친 다음 쪽에서 눌렀던 칸이 여전히 미선택이면 `tap-rejected`로 기록하고 선택 수에서 한 번 빼며, 다시 누르지 않습니다. 목록 내 행·열로 같은 카드를 추적하며 같은 화면 위치도 연속으로 누르지 않습니다.

행 위치가 이전 쪽과 ±12px(1440p) 이내로 두 번 연속 같거나, 새로 누를 칸이 없는 쪽이 다섯 번 연속이면 목록 끝으로 봅니다. 끝의 작은 바운스 때문에 계속 스크롤하지 않습니다.

선택 수가 있으면 두 모드 모두 **결정 → 최종 확인창 검증**까지 진행합니다. 시험 모드는 **왼쪽 취소**, 실제 판매는 **변환 → 완료 닫기**를 누릅니다. 시험 모드는 변환을 누르지 않으며 취소 후 판매 화면 복귀를 확인합니다. 선택 수가 0이면 결정을 건너뜁니다. 버튼 템플릿을 찾지 못하면 정지합니다.

그다음 판매 화면 닫기 → 공방 → MENU → 소환으로 돌아와 처음 기억한 제목 이미지를 제자리에서 비교합니다. 다르면 **왼쪽 화살표를 최대 10번** 누르며 비교합니다. 제목과 FP 표시, 소환 버튼 템플릿을 모두 확인해야 재소환합니다. 공방 도착, MENU, 소환 화면, 배너 제목 탐색 실패를 구분해 정지합니다. 여러 FP 배너의 제목 영역까지 같으면 다른 FP 배너로 돌아갈 수 있습니다.

시험 모드는 팔지 않았으므로 재소환 때 두 번째 가득 참 경고가 뜹니다. 여기서 **판매 흐름·배너 복귀·재소환까지 확인** 안내와 선택 수(+ 잠금 판별 불가 수)를 보여 주고 종료합니다. 두 번째 경고가 확인되지 않으면 성공으로 처리하지 않고 판매 흐름 오류로 정지합니다.

판매 수가 0인데 다시 가득 참 경고가 뜨면 더 팔 것이 없어 정지합니다. 화면 진입·7열 전환·격자 판독·실제 판매 진행의 정지 안내는 각각 구분되며 시험 모드 상태와 선택 수를 표시합니다.

## 처음 시험할 때 (베타)

1. 게임 판매 화면에서 팔 대상만 보이도록 필터를 확인합니다.
2. FP 실행 화면에서 **자동 판매 켜기**와 **시험 모드 (최종 확인에서 취소)**를 켭니다.
3. FP 소환을 시작하고 가득 참 후 판매 화면의 선택 결과를 확인합니다.
4. 선택 수와 잠금 판별 불가 수, 잠금·제외·이미 선택된 칸의 보호를 확인합니다. 최종 확인창에서 왼쪽 취소를 누르고, 배너 복귀·재소환 뒤 두 번째 가득 참에서 종료되는지 확인합니다.
5. 결과가 맞을 때만 시험 모드를 끕니다. 게임에서 선택을 모두 해제하고 필터를 다시 확인한 뒤 시작합니다.

## 진단 로그

태그는 `FpSell`입니다. 칸마다 다음 한 줄과 쪽 요약, 스크롤, 정지 이유를 남깁니다.

```text
page=2 r3c4 present=true lock=Unlocked excluded=false selected=false decision=select
```

`page`는 0부터, `r/c`는 1부터입니다. `present`는 카드 존재, `lock`은 잠금 상태, `excluded`는 금지 표시, `selected`는 선택 상태입니다. `?`는 판별 불가입니다. `rows=[...]`는 평가한 행의 y 좌표(1440p), `distance=`는 스크롤 거리입니다.

수동 정지에도 `final-summary pages=… taps=… rejected=… selected=…`를 남깁니다. `tap-rejected`는 게임이 선택을 거부한 카드이며 누른 수와 최종 선택 수가 달라질 수 있습니다.

## 화면 전환 대기 (beta.11 / 1.4.0)

칸 선택과 겹침 스크롤 속도는 그대로입니다. 판매·배너 복귀 구간의 고정 대기는 beta.9에서 0.5초씩 늘렸고, 버튼을 찾기 전에 **1초 안정화 대기**를 한 뒤 최대 약 2초 동안 새 화면에서 템플릿을 찾습니다. 원래 FGA의 FP 소환 반복(처음 10회·매일 무료·계속 소환 확인 0.3초, 연출 3초, 반복 0.5초)은 자동 판매 ON/OFF와 관계없이 **원래 값**입니다.

| 동작 | 값 |
|---|---|
| 판매 버튼 뒤 | 기존 1.0초 + 판매 화면 로딩 2.0초 |
| 탭·열 전환·결정·취소·완료 닫기 뒤 | 1.0초 |
| 변환 뒤 | 기존 1.0초 + 0.3초 |
| 왼쪽 화살표 뒤 | 1.2초 |
| 칸 선택 뒤 스크롤 | 0.7초 |
| 화면 도착 확인 (`awaitScreen`) | 0.5초 간격·20초 상한 |
| 소환 아이콘 누른 뒤 | 고정 5초 대기, 이후 최대 15초 동안 소환 화면 확인 (다시 누르지 않음) |

판매 화면 닫기 뒤 공방 제목과 MENU 뒤 소환 아이콘은 각각 3초 확인하며, 신호가 없으면 해당 이동 버튼만 한 번 다시 누릅니다. 소환 아이콘은 로딩 중 재탭하지 않고 15초 안에 소환 화면이 안 나오면 `summon` 사유로 정지합니다. FP 소환·결정·취소·변환은 재탭하지 않습니다.

거부된 칸(`tap-rejected`)은 목록이 움직이지 않은(행 위치 ±12px) 쪽에서 같은 화면 위치의 칸에만 판정합니다. 스크롤을 건너는 구간과 잠금·제외 칸은 판정하지 않으며, 선택 수는 누른 수에서 확정 거부 수를 뺀 값입니다.

배너 복귀 정지는 `stop step=bannerReturn reason=workshop/menu/summon/title`로 남기며 영어·한국어 안내도 각각 구분합니다. 종료 요약 `final-summary`는 스크립트 종료 처리에서 한 번만 출력합니다.

## 재소환 (1.4.1)

판매 또는 베타 시험 모드 취소 후 원래 FP 배너로 돌아오면 **처음 소환과 같은 원본 FGA 경로**로 누릅니다. 일반 소환은 소환 위치 → 0.3초 → 확인 위치, 매일 무료 소환은 처음 무료 소환 위치 → 0.3초 → 계속 위치입니다. 별도 확인창 이미지 검사는 하지 않습니다. 배너 제목·FP 표시·소환 버튼 확인과 왼쪽 최대 10번 탐색은 유지합니다.

베타 시험 모드는 재소환 뒤 두 번째 가득 참 알림에서 `SellDryRunDone`으로 끝납니다. 정규판은 시험 모드 없이 실제 판매합니다.

실제 판매 직후에도 가득 참이면 다시 판매합니다. 더 선택할 칸이 없어 선택 수가 0이면 `InventoryFullNothingToSell`로 정지합니다. 별도의 판매 직후 가득 참 정지는 없습니다.
