# FP 소환 자동 판매

**서번트칸이 가득 차면 판매 화면에서 잠금이 아닌 카드를 모두 선택해 판매하고, FP 배너로 돌아와 소환을 이어 갑니다. 시작 전에 게임 판매 화면의 필터를 꼭 확인하세요.**

무엇을 팔지는 게임 판매 화면의 필터로 정합니다. FGA는 필터와 정렬을 읽거나 바꾸지 않으며, 종류·별 수·NEW! 여부로 대상을 제한하지 않습니다. 필터에 보이는 카드는 자물쇠가 없으면 모두 대상입니다. **파티 편성·그랜드·임시 가입 서번트는 시작 전에 게임 필터로 제외하세요.** 해당 문구는 검사하지 않습니다. KR·JP 서버에서만 동작합니다.

FP 소환은 **배너 화면에서 시작하세요.** 소환 결과 화면에서는 FP로 자동 판별하지 않습니다.

## 설정

| 항목 | 기본값 | 동작 |
|---|---|---|
| 자동 판매 켜기 | 꺼짐 | 서번트칸이 가득 차면 판매 화면으로 이동해 판매합니다. |
| 시험 모드 (베타 전용) | 켜짐 | 결정만 누른 뒤 최종 확인창에서 즉시 멈춥니다. 변환하거나 재소환하지 않습니다. |

정규판에는 시험 모드가 없고, 자동 판매를 켜면 실제로 판매합니다. 베타에서 시험 모드를 끄면 실제 판매합니다.

## 처음 시험할 때 (베타)

1. 게임 판매 화면에서 팔 카드만 보이도록 필터를 확인합니다.
2. FP 실행 창에서 **자동 판매 켜기**와 **시험 모드**를 켭니다.
3. FP 소환을 시작하고, 가득 찬 뒤 판매 화면에서 선택된 카드를 확인합니다.
4. **결정** 뒤 최종 확인창에서 즉시 멈추는지 확인합니다. 창에 표시된 대상을 직접 확인한 뒤 취소하세요.
5. 결과가 맞을 때만 시험 모드를 끕니다. 게임에서 선택을 모두 해제하고 필터를 다시 확인한 뒤 시작하세요.

## 동작과 보호 규칙

- 서번트칸 가득 참 경고일 때만 판매합니다. 개념예장칸 등 다른 경고에서는 판매하지 않습니다.
- 판매 버튼을 누른 뒤 열 수와 무관하게 카드 프레임이 읽히기를 기다립니다. 서번트 탭은 진입할 때 한 번 확인하고, 7열로 맞춘 뒤 스크롤하며 선택합니다. 제목은 확인하지 않으며 선택 중 그리드를 잃으면 멈춥니다.
- 한 페이지의 카드 선택을 마친 뒤 스크롤바 아래 끝 박스에 손잡이가 있으면 추가 스와이프 없이 목록 탐색을 끝냅니다. 레일이 없으면 한 페이지만 처리합니다. 행이 그대로인 것만으로 종료하지 않으며, 거부된 탭 추론과 새 탭 없는 5페이지·전체 500페이지 한도는 유지합니다.
- 다음 조건을 모두 만족한 칸만 누릅니다: 카드가 있음 / 자물쇠가 없음 / 아직 선택되지 않음. `잠금 중` 등 문구와 파티·그랜드·임시 가입 여부는 검사하지 않습니다.
- 잠금을 풀지 않으며, 잠금 여부가 애매한 칸은 실제 판매에서 선택하지 않습니다.
- 실제 판매는 고정 위치로 **결정 → 1초 → 변환 → 1초 → 완료 창 닫기 → 4초**를 진행합니다. 최종 대화상자를 검사하지 않습니다. 시험 모드는 결정 직후 `SellDryRunDone`으로 멈춥니다.
- 선택이 0장이면 결정·변환·배너 복귀 없이 즉시 판매할 카드 없음으로 멈춥니다.
- 판매 화면 → 공방 → MENU → 소환으로 돌아와 처음 기억한 배너를 찾아(왼쪽 화살표 최대 10번) 소환을 이어 갑니다. 같은 제목의 FP 배너가 여럿이면 다른 배너로 돌아갈 수 있습니다.
- 완료 창 뒤 판매 화면 왼쪽 위 닫기를 한 번 누르고 4초 기다린 뒤 MENU로 갑니다. 공방 제목 확인이나 닫기 재시도는 하지 않으며 MENU 확인은 유지합니다.
- 버튼이나 화면을 찾지 못하면 어디서 멈췄는지 구분해 안내하고 정지합니다.

## 진단 로그

태그는 `FpSell`입니다. 칸마다 존재·잠금·선택 여부와 결정을 한 줄로 남기고, 종료할 때 `final-summary`를 남깁니다.

```text
page=2 r3c4 present=true lock=Unlocked selected=false decision=select
```

`?`는 판별 불가입니다. 게임이 선택을 거부한 카드는 `tap-rejected`로 기록하며 선택 수에서 빠집니다.
