# FP 소환 자동 판매 (1.4.0-beta.4)

FP 소환 도중 **서번트칸이 가득 차면** 판매 화면에서 설정한 종류만 골라 판매하고, 처음 시작한 배너로 돌아와 소환을 이어 갑니다. KR과 JP 모두 지원합니다. 기능은 **기본 꺼짐**입니다.

## 설정 (FP 실행 화면, "자동 판매" 항목)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 자동 판매 켜기 | 꺼짐 | 켜기 전에는 기존처럼 가득 참에서 멈춥니다. |
| 1★ 서번트 | 켜짐 | |
| 2★ 서번트 | 켜짐 | |
| 3★ 서번트 | 꺼짐 | |
| 4★ 서번트 | 꺼짐 | |
| 4★ 경험치 카드 | 꺼짐 | |
| 5★ 경험치 카드 | 꺼짐 | |
| NEW!만 판매 | 켜짐 | 이번에 새로 얻은 것만 고릅니다. 육성한 서번트를 보호합니다. |
| 시험 모드 (선택만) | **켜짐** | 켜 두면 선택까지만 하고 **확인을 누르지 않고 멈춥니다.** 시험 모드는 기본으로 켜져 있습니다. 시험 모드로 선택 결과를 확인한 뒤 끄면 실제 판매합니다. |

5★ 서번트, 개념예장, 커맨드 코드는 판매 대상이 아닙니다.

## 동작

1. 소환 중 서번트칸 가득 참 경고가 뜨면 경고 문구의 **서번트 단어**를 찾습니다(KR "서번트칸", JP "サーヴァント枠"). 단어가 없으면(개념예장칸 등) 판매하지 않고 멈춥니다.
2. 판매 화면이 7열이 아니면 아이콘 크기 전환을 최대 2번 눌러 7열로 맞춥니다.
3. 화면을 위에서부터 훑으며 설정한 종류·NEW! 조건에 맞는 칸만 선택합니다. 칸을 한 번 누른 뒤 최대 약 1.5초 동안 새 화면을 여러 번 읽어 선택됐는지 확인하고, 확인되지 않으면 **같은 칸을 다시 누르지 않고** 멈춥니다. 선택 여부는 칸 테두리의 청록색만 보고 판별하며(카드 그림은 보지 않음), 애매하면 선택 여부를 모르는 것으로 보고 누르지 않습니다. 별 수는 별 줄 템플릿으로 읽고, 스크롤한 화면처럼 템플릿이 맞지 않으면 **별 한 개씩 오른쪽부터 세어** 읽습니다. 마지막 별 다음 칸이 확실히 비어 있지 않으면 별 수를 모르는 것으로 보고 누르지 않습니다. 끝까지 스크롤한 뒤 선택 수를 기록합니다.
4. 시험 모드면 여기서 멈춥니다. 아니면 **확인 → 변환 → 닫기**로 판매하고, 다빈치 공방 → MENU → 소환에서 처음 배너를 다시 열어 소환을 계속합니다.

## 선택하지 않는 칸

다음 중 하나라도 보이면 시험 모드에서도 선택하지 않습니다.

- 자물쇠 아이콘, `잠금 중` / `ロック中`
- `選択不可`(선택 불가), `グランドサーヴァント`
- `PARTY`(편성 중)
- `Servant`·`Exp. UP` 라벨이 없는 칸(`Status UP` 등)
- 종류, 별 수, NEW! 여부를 확실히 읽지 못한 칸

잠금을 풀거나 잠금 상태를 바꾸지 않습니다.

## 종료 안내

| 안내 | 뜻 |
|---|---|
| 시험 모드 완료 | 선택만 했고 판매하지 않았습니다. 선택 수, 종류별 수, "잠금 판별 안 됨" 칸 수를 함께 보여 줍니다. |
| 직전 판매 수가 0이며 서번트칸이 다시 가득 참 | 더 팔 것이 없어 멈췄습니다. |
| 서번트칸 경고가 아님 | 개념예장칸 등입니다. 판매하지 않고 멈췄습니다. |
| 원래 FP 배너를 찾지 못함 | 소환 전에 멈췄습니다. |
| 소환 중 알려진 화면을 오래 확인하지 못함 | 알 수 없는 화면이 계속되어 멈췄습니다. |
| 판매 화면에 들어가지 못함 | 판매 버튼, 제목 또는 서번트 탭을 찾지 못했습니다. 판매하지 않았습니다. |
| 판매 화면을 7열로 바꾸지 못함 | 아이콘 크기 전환이 되지 않았습니다. 판매하지 않았습니다. |
| 누른 칸이 선택된 것으로 확인되지 않음 | 누른 뒤 약 1.5초 안에 선택이 확인되지 않았습니다(또는 선택 중 판매 화면을 잃었습니다). 같은 칸을 다시 누르지 않았습니다. 판매하지 않았습니다. |
| 판매 진행 단계에서 정지 | 결정, 변환 또는 닫기 단계가 확인되지 않았습니다. 이미 판매되었을 수 있으니 게임 화면을 확인하세요. |

판매 단계에서 멈추는 안내(위 네 가지)에는 **시험 모드 켬/끔**과 **선택된 칸 수**가 함께 표시됩니다.

## 소유자 시험 절차 (시험 모드 먼저)

시험 모드는 기본으로 켜져 있습니다. 시험 모드로 선택 결과를 확인한 뒤 끄면 실제 판매합니다.

1. FP 실행 화면에서 **자동 판매 켜기**와 **시험 모드 (선택만)**를 켭니다. NEW!만 판매와 종류 스위치를 확인합니다.
2. FP 소환을 시작하고 서번트칸이 가득 찰 때까지 기다립니다.
3. 판매 화면에서 선택 테두리가 설정한 종류에만 붙었는지 확인합니다. FGA가 "시험 모드 완료"로 멈춥니다.
4. 선택 수와 종류별 수, "잠금 판별 안 됨" 수를 확인합니다. 실제 판매 확인은 누르지 않습니다.
5. 게임에서 **선택 모두 해제**로 되돌립니다.
6. 결과가 맞으면 시험 모드를 끄고 다시 시도합니다. 실제 판매는 시험 모드가 꺼져 있을 때만 일어납니다.

## 진단 로그 (logcat)

시험 모드든 실제 판매든 판매 화면을 훑는 동안 **칸마다 한 줄**, 그리고 정지할 때 **정지 단계와 이유**를 남깁니다. 태그는 `FpSell`입니다.

```
adb logcat -s FpSell
```

한 줄 예: `page=2 r3c4 kind=Servant stars=1(strip 1:0.0/2:0.0 slots 0.83,0.4,0.0,0.0,0.0) new=true(0.93) lock=Unlocked excluded=false selected=false decision=select`

- `page`는 스크롤 쪽 번호(0부터), `r`/`c`는 그 화면의 줄·열(1부터)입니다.
- `stars`는 읽은 별 수, `strip`은 별 줄 템플릿의 상위 두 점수, `slots`는 오른쪽부터 별 칸별 점수입니다. `new`는 NEW! 판독과 점수입니다.
- `decision`은 `select` 또는 `skip:` 뒤에 이유(`not-new`, `stars-unknown`, `already-selected`, `locked`, `excluded`, `category-off`, `new-unknown`, `selection-unknown`, `kind-unknown`, `lock-unknown`, `gridTop`, `gridBottom`)입니다. 화면 위·아래 가장자리에 걸쳐 NEW! 표시가 잘릴 수 있는 칸(`gridTop`, `gridBottom`)은 읽지 않고 선택하지 않습니다.
- 정지할 때는 `stop step=Selection reason=... selected=N dryRun=true` 줄이 남습니다.

## 알아 둘 점

- 아이콘 크기 전환 버튼은 게임 화면 왼쪽 아래에 있으며 FGA 재생 버튼에 가려질 수 있습니다. 가려지면 전환이 되지 않고 멈춥니다. 게임의 아이콘 크기 설정이 바뀔 수 있습니다.
- JP 배너 복귀는 점 줄(두 줄) 대신 **배너 제목 이미지**를 기준으로 찾습니다. 찾지 못하면 최대 60번 넘긴 뒤 멈춥니다.
- 판매 확인·변환·완료 버튼은 소유자가 제공한 화면으로만 확인했습니다. 실제 판매 결과는 직접 확인해 주세요.
