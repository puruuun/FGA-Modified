# FP 소환 자동 판매 (1.4.0-beta.6)

**판매 화면에 보이는 서번트·경험치 카드·포우 카드 중 잠금이 아닌 칸을 모두 선택해 판매합니다. 시작 전에 판매 화면의 필터 설정을 꼭 확인하세요.**

예: ★1~★3, 서번트만. 잠금·선택 불가·그랜드·PARTY 칸은 고르지 않습니다.

무엇을 팔지는 게임 판매 화면의 필터로 미리 정합니다. FGA는 필터와 정렬을 읽거나 바꾸지 않습니다. 종류·별 수·NEW! 여부로 대상을 제한하지 않으므로, 필터에 보이는 고등급 카드나 육성한 카드도 잠금이 아니면 대상입니다.

## 설정

| 항목 | 기본값 | 동작 |
|---|---|---|
| 자동 판매 켜기 | 꺼짐 | 서번트칸 가득 참에서 판매 화면으로 이동합니다. |
| 시험 모드 (선택만) | **켜짐** | 선택 결과를 남기고 확인 전에 정지합니다. 끄면 실제 판매합니다. |

## 동작과 보호 규칙

서번트칸 가득 참 경고에서 서번트 단어를 확인하고 판매 화면의 서번트 탭으로 이동합니다. 개념예장칸 등 다른 경고에서는 판매하지 않습니다. 5→6→7열 순환을 최대 두 번 눌러 7열을 맞춥니다.

한 화면의 행 기준점을 카드 테두리에서 한 번 찾고 고정 열 간격으로 격자를 만듭니다. 종류 라벨이 없어도 실제 카드가 있으면 읽습니다. 완전히 보이는 아래 행도 평가하며 빈 슬롯은 선택하지 않습니다.

다음 조건을 모두 만족한 칸만 한 번 누릅니다.

- 카드가 실제로 있습니다.
- 자물쇠 또는 `잠금 중` / `ロック中` 표시가 없습니다.
- `選択不可`, `グランドサーヴァント`, `PARTY` 표시가 없습니다.
- 청록색 선택 테두리가 **미선택(false)** 으로 판독됩니다. 이미 선택됐거나 애매하면 누르지 않습니다.

잠금을 풀지 않습니다. 잠금 템플릿이 없으면 시험 모드만 허용하며, 시험 모드에서는 잠금 판별 불가 칸도 선택할 수 있습니다. 이 수는 **잠금 판별 안 됨 N칸**으로 따로 표시합니다. 실제 판매에서 잠금 판별 불가는 선택하지 않습니다. 실제 판매는 검증된 KR·JP와 잠금 템플릿이 모두 있을 때만 허용합니다.

누른 뒤 선택 확인은 기다리지 않습니다. 스크롤은 평가한 행보다 한 행 적게, 한 번에 최대 560px(1440p)로 제한하고 끝점에서 멈춰 관성을 억제합니다. 겹쳐 본 칸은 청록색 테두리로 이미 선택됐음을 확인하고 건너뜁니다. 한 번에 최대 999칸입니다.

목록 끝에서 시험 모드는 **선택 수 + 잠금 판별 안 됨 수**를 보여 주고 정지합니다. 실제 판매는 확인→변환→닫기를 진행합니다. 공방→MENU→소환으로 돌아온 뒤 처음 기억한 제목 이미지를 제자리에서 비교하고, 다르면 **왼쪽 화살표를 최대 10번** 누르며 비교합니다. 제목과 FP 소환 버튼이 모두 확인돼야 소환을 이어 갑니다. 제목을 찾지 못하면 `BannerNotFound`로 정지합니다. 여러 FP 배너의 제목 영역까지 같으면 다른 FP 배너로 돌아갈 수 있습니다.

판매 수가 0인데 다시 가득 참 경고가 뜨면 더 팔 것이 없어 정지합니다. 화면 진입·7열 전환·격자 판독·실제 판매 진행의 정지 안내는 각각 구분되며 시험 모드 상태와 선택 수를 표시합니다.

## 처음 시험할 때

1. 게임 판매 화면에서 팔 대상만 보이도록 필터를 확인합니다.
2. FP 실행 화면에서 **자동 판매 켜기**와 **시험 모드 (선택만)**를 켭니다.
3. FP 소환을 시작하고 가득 참 후 판매 화면의 선택 결과를 확인합니다.
4. 선택 수와 잠금 판별 불가 수, 잠금·제외·이미 선택된 칸의 보호를 확인합니다. 시험 모드는 확인을 누르지 않습니다.
5. 결과가 맞을 때만 시험 모드를 끕니다. 게임에서 선택을 모두 해제하고 필터를 다시 확인한 뒤 시작합니다.

## 진단 로그

태그는 `FpSell`입니다. 칸마다 다음 한 줄과 쪽 요약, 스크롤, 정지 이유를 남깁니다.

```text
page=2 r3c4 present=true lock=Unlocked excluded=false selected=false decision=select
```

`page`는 0부터, `r/c`는 1부터입니다. `present`는 카드 존재, `lock`은 잠금 상태, `excluded`는 금지 표시, `selected`는 선택 상태입니다. `?`는 판별 불가입니다. `rows=[...]`는 평가한 행의 y 좌표(1440p), `distance=`는 스크롤 거리입니다.
