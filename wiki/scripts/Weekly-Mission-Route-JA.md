# ウィークリーミッション自動周回

**今週のウィークリーミッションを最小APで満たすクエストと回数を計算し、メイン画面から章とマップを辿って全ルートを実行します。使用するバトル設定とAP回復アイテム設定を事前に確認してください。**

JP・KRサーバー向けの機能で、インターネット接続が必要です。実際のゲーム内のミッション進行状況は読み取りません。

## 始め方

1. ゲームの**メイン画面**を開きます。左上に `공지` / `お知らせ` がある画面です。クエストパネルや章一覧から開始しないでください。
2. FGA再生ボタン → 実行画面左下の **ウィークリーミッションクリア** を押します。
3. 実行画面の**右側にウィークリーミッションパネル**が開きます（同じボタンをもう一度押すと折りたたまれます）。パネルが開いている間、左側の **周回設定** 項目は非表示になり、閉じると保存値を変えずに元へ戻ります。左側のバトル設定・AP回復アイテム・アイテム・絆設定をそのまま使用します。
4. **ダウンロード** を押します。ミッション・章・敵構成のダウンロード段階と進行バーが表示されます。今週分のキャッシュがある場合はすぐにルートが表示されます。
5. 手動ミッションにはチェックボックスがなく、保存されていた過去の選択も無視されます。チェックを外したミッションは元の順番の位置にグレー表示で残ります。すでに達成済みのミッションなどはチェックを外して計算から除外してください。初期値はすべてオンで、サーバー・週ごとの選択はアプリ再起動後も保持され、新しい週になるとリセットされます。選択を変更するとルートが再計算され、**−/+ 回数** も新しい計算値に戻ります。
6. 合計APとクエストごとの回数を確認したあと、共通の **OK** を押します。パネルが開いていて回数が残ったルートがあればウィークリールートを実行し、ルートが空の場合は **実行するクエストがありません** と表示して実行しません。パネルを折りたたんでいる場合は通常どおりバトルを開始し、キャンセルすると何も操作しません。

**その他の設定 → バトル → ウィークリーミッション自動化機能を使用** は初期値オンです。オフにするとバトル実行画面のウィークリーミッションボタンが非表示になります。

章・クエスト候補は **その他の設定 → その他 → ウィークリークエスト追跡設定** でサーバー別にオン・オフできます。章名の `+` を押すとフリークエストを展開します。初期値はすべてオンで、章をオフにしても個別のクエスト選択状態は保持されます。データがない場合は、先に実行画面で該当サーバーのデータをダウンロードしてください。ミクトランと奏章Ⅰ〜Ⅳは非対応のため一覧に表示されません。

## 確認ウィンドウと計算

**宝物庫・初級**（10 AP）も候補に含まれます。敵構成がキャスター9体固定のため他の難易度の代わりに初級のみを使用し、ルートでは常に最後に訪れます。**ウィークリークエスト追跡設定 → 曜日クエスト** でオフにでき、探索テストにも含まれます。

他のクエストが終わるとお知らせボタンでメイン画面を確認し、**メイン → カルデアゲート → 曜日クエスト → 黄色の宝物庫・初級パネル** の順に移動します。ゲートを押した後に閉じるのを待ち、一覧内の曜日バナーを探して押した後、閉じるとデイリークエストパネルのアンカーを合わせて待ちます（右側のタイトルやイベント背景は不使用）。一覧から**上から最初に見つかる黄色いパネル**（色相38〜52°、彩度0.80以上）を初級とみなし、名前を読み取らずタップします（名前・APは `map.log` 記録用のみ読み取り）。黄色いパネルがなければ下にスクロールし、最後まで見つからなければ中断します。赤色の種火・緑色の修練場や `CLEAR`・`NEW!`・`∞` パネルは色判定に使いません。キャンペーン中で表示APが異なっていても色で判別し、最終周回後には曜日クエスト一覧に戻ります。

| 項目 | 説明 |
|---|---|
| 今週のミッション | チェックしたミッションだけを計算します。完了済みのミッションはチェックを外してください。一部の進行度は回数で調整します。 |
| チェックを外したミッション | 今週の一覧の元の位置にグレー表示で残り、再度オンにできます。手動ミッションにはチェックボックスがありません。 |
| ルート | 章 / スポット / クエスト名 / AP / 回数および合計APです。回数0のクエストは実行しません。 |
| 候補設定 | ウィークリークエスト追跡設定でオフにした章・クエストはルート計算から除外されます。 |
| 手動 | ドロップミッションなど計算できない条件です。ご自身で達成してください。 |
| 除外対象 | **非対応の章:** ミクトラン（war 311）は階層切り替え方式が異なるため、奏章Ⅰ〜Ⅳ（war 402〜405）は運営方針により除外しています。ルート候補・探索テスト対象・ウィークリークエスト追跡設定・章一覧のいずれにも表示されません（JP・KR共通）。平安京（307）・トラオム（310）はメイン・インタールードの章として対応しています。 |
| バトル設定 | 左側の一覧で選んだ設定を使用します。異なる敵構成でも動作する設定を選んでください。 |

繰り返し可能なメインストーリーのフリークエストのみを計算し、冬木の1回限定 `危険地帯` のような `afterClear=close` クエストは除外します。敵特性・クラス・サーヴァントクラス・特定の敵・クエストクリア・クエスト特性条件に対応しており、非対応や達成可能な候補がない場合は手動として表示します。合計ミッションは個別条件を達成する過程で合わせて満たされます。

KRの候補・名前・APはKRデータを使用し、**KRの敵構成はJPデータ基準**です。同じクエストIDでJPとKRのAPが異なる場合は除外します。計算用データはサーバー・週ごとにアプリキャッシュへ保存され、Atlas Academyから章バナー・マップサイズ・スポット座標を取得してキャッシュします。

## 自動移動とバトル

### 一覧探索と章への移動

- JPはメイン・レコード **1 / 1.5 / 2** を辿ります。KRは **1 / 1.5** を辿り、2部の章はメイン画面の一覧から探します。平安京（307）・トラオム（310）はメイン・レコードではなくメイン画面最下部の金色 **メイン・インタールード**（`メイン・インタールード` / `메인·인터루드` / KRホーム **메인 인터루드**）ボタン内にあるため最後に訪れます。
- 章バナーはAtlasバナーの内側ボタン画像で探します。一覧探索ではオリジナルFGAのスクロールバー上下端の基準画像を狭い領域で読み取り、すでに到達している方向をスキップして1ページ一覧ではスワイプしません。端が確認できない場合は下→上の順に各方向最大14回探索します（背景アニメーションで端判定を取り消したり中央レールの有無で推測したりしません）。想定された一覧から外れた場合や見つからない場合は安全にスキップ・中断します。
- 章バナーからマップに入った直後とターミナルへ戻った直後は各3秒待機します。平安京はマップが4枚ありフリークエストは `30702` にありますが、別のマップが開いている場合はスポット名確認で弾いてスキップします（マップ切り替え方法は推測しません）。

### マップの縮小と位置計算

すべての章で共通の幾何ベース位置計算方式を使用します。

- **最小ズーム確認**: 章に入ったら2本指ピンチで最小ズームまで縮小し、2回連続で倍率1.0のまま変化がなくなるまで確認します（最大6回）。ジェスチャーが拒否されたり確定できない場合はその章をスキップします。
- **端への位置合わせと縦移動**: 最小ズームのマップは画面幅に合うため（`倍率 = 画面幅 ÷ マップ幅`、縦移動範囲 = `マップ高さ × 倍率 − 720`、拡大比率許容範囲 0.45〜1.0 で22:9画面にも対応）、X座標を保ったまま上端・下端から押せるスポットは該当の端へ、それ以外は近い端へ長くドラッグして停止を確認します。中央付近のスポットは端から1回最大180pxずつドラッグし、毎回前後画面を比較して位置を累積します（100px以上の重なりを維持、最大16回）。測定失敗時は端へ戻って1回再試行し、それでも失敗すると `map movement did not converge` でスキップします。
- **遮蔽領域の回避と早期タップ**: マスター肖像画のひし形・レベル/AP・プレゼント/ミッション吹き出し・MENUなどの固定UI領域から720p基準で12px以上の余白を確保し、上下端からも60px以上内側の安全な位置を選びます。移動中の再確認でアイコン中心が遮蔽領域から4px以上離れ、上下端60px以上内側にあれば即座にタップし（`reason=early`）、そうでなければ目標原点まで移動してからタップします（`reason=converged`）。16:9などで安全な行がない場合は移動範囲内で最も隠れにくい位置へ動かし、見えている部分（領域と逆方向最大30px、4px以上離隔）をタップします。タップ可能な点がまったくない場合のみ `spot out of reach` でスキップします。

### クエストパネルの読み取りと選択

- スポットを押す際は座標より25px上のアイコン中心を優先し、隠れていれば見えている部分または隠れていないスポット座標を押し、すべて隠れていれば押しません。スポットを押してもパネルが出ない場合は1秒後に同じ点をもう一度押し、それでも出なければ `no panel after spot tap` として記録します。
- クエストパネルは **Free Quest表示** を画面の広い帯域で探して**先に読み取り**ます。一致（Match）ならドラッグせずそのまま進み、表示切れや不一致のときだけパネル内のボタンがない場所で上から下へ1回ドラッグして読み直します。それでも一致しない場合はパネルを閉じて（最大3秒ずつ最大3回タップ、失敗時1回復旧試行）、画面端60px以内のスポットは内側・画面中央付近へ寄せて（動かせない場合は安全範囲や逆方向を確認）もう一度だけ試します。編成制限のあるミッションクエストは絶対に押さず、上がミッションクエストなら下のフリークエストも確認します。
- 名前は4方式（2・3・4倍拡大、二値化と元のグレースケール）で読み取り、サーバーの**全フリークエスト名辞書**（スポットに2つ以上フリークエストがある場合はそのスポットの候補一覧）と照合します。珍しい漢字やハングルパッチムの誤読は、最大2文字かつ長さ1/3以内・次点候補より2文字以上近い・2回の読み取り一致をすべて満たす場合のみ補正します。
- スポット拡大時に表示される**スポット名ラベル**も第2確認に使います。クエスト名が読み取れれば **クエスト名だけで単独判定** を行い（`by=quest-name` / 複数候補スポットでは `by=quest-name-spot`）、目標と異なればスポット名が合っていても採用しません。クエスト名がまったく読み取れない場合のみ、スポット名一致・単一フリークエスト・Free Quest表示・文字幅一致のすべてを満たせば採用します（`by=spot-name+cells`）。APはログ記録のみで判定には使わず、Match以外は絶対にタップしません。

### バトルと復帰

- バトル・サポート選択・AP回復は既存のFGAフローを使用します。回数制限のみクエストごとに一時上書きして終了時に復元し、果実の使用数はルート全体で1度差し引かれます。
- 最終バトル後に連続出撃ダイアログを閉じたあとは、マップへの読み込みのため **さらに5秒待ってから** 次のクエストへ進みます。同じ章の次のクエストはパネルを閉じてマップを再探索し、別の章へは `ターミナル` / `터미널` と必要に応じ `閉じる` / `닫기` で戻ります。

## 終了と確認内容

終了時にクエストごとの **予定回数 / 実行回数 / 完了・見つからず・中断・未実行** と手動ミッションを表示します。バトル中にAP不足・敗北・撤退・ユーザー停止などで止まった場合、残りのルートは実行しません。

メイン画面でない場合は何も押さず、メイン画面からの開始を案内します。データ取得失敗時は通信・Atlas接続を、ルート計算失敗時は有効な章数を減らして再試行してください。詳細な手順はログで確認できます。

```text
adb -s 127.0.0.1:5555 logcat -s WeeklyRoute
```

## 探索テストモード（ベータ専用）

APを消費せずに全章のマップでクエストを見つけられるか実ゲームで点検する**ベータ専用**モードです（正式版では非表示になり、診断ファイルも保存されません）。

- **使用場所**: ウィークリーミッションパネル上部の **探索テスト（AP消費なし）** チェックボックス（オンでルート一覧の代わりに範囲選択を表示）。**すべてのメインストーリーフリークエスト / 選択した章 / ウィークリークエスト追跡設定でオンにしたクエスト** から選べ、サーバー別の **すでに成功したクエストをスキップ** も使えます（ミクトラン・奏章は除外）。ログには `mode=probe` が付きます。
- **動作と安全性**: メイン画面から開始し、実ルートと同じ移動・マップ合わせ・パネル判定まで実行しますが、**Matchでもクエストパネルは絶対に押さず**パネルを閉じて次へ進みます。途中で止めた場合はそこまでの結果を保存し、未到達は `未実行` と表示します。
- **結果と診断ファイル**: 状態（成功 / マップ位置合わせ失敗 / スポットタップ後にパネルなし / パネル不一致 / 章が見つかりません / 未実行。一度でもパネルを開いた後の失敗は `panel_mismatch`、最初から安全な点がない場合は `spot out of reach`）と所要時間をサマリーおよび `diagnostics/weeklyRoute/probe/` のCSVに記録します。成功ごとに2倍拡大の証拠PNG（`diagnostics/weeklyRoute/<実行番号>/evidence/q<クエストID>.png`）、パネル不一致（1実行最大8枚）・探索失敗（最大100枚）・中断時の診断PNG、実行ごとの単一 `map.log` も保存されます。CSVと証拠フォルダをPCへ移し、下記コマンドでHTML照合表（`spot-name+cells` 優先表示）を作成できます。

```text
py -3 tools/weekly-audit/contact_sheet.py probe-JP-<日時>.csv <証拠フォルダー> -o audit.html
```

## 注意事項と制限

- 未開放の章は必ず **ウィークリークエスト追跡設定** でオフにしてから実行してください。Atlasデータと実ゲームの敵構成に差がある場合があるため、実際のウィークリーミッション進捗はゲーム内で確認してください。
- 画面比率やフォントの違いによりスポット・パネルの判読根拠が不足する場合は、推測タップを行わず安全にスキップします（`spot out of reach`、`map not recognized`）。新しい端末や画面比率では短いルートやベータの **探索テストモード** で事前にご確認ください。
