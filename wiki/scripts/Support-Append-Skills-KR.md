# 서포트 어펜드 스킬 판독

선호 서번트의 어펜드 스킬 5칸이 **레벨 10인지** 확인해 서포트를 고릅니다. 각 칸의 `10`은 레벨 10을 요구하고 `x`는 검사하지 않습니다. 1~9레벨을 따로 지정하는 기능은 아닙니다.

## 설정

1. 전투 설정의 **서포트 선택 → 서번트 선호**에서 서번트를 고르고, 일반 스킬 최대 레벨 3칸을 설정합니다.
2. **어펜드 스킬 판독**을 켭니다(기본 꺼짐).
3. 왼쪽부터 어펜드 1~5번 칸을 `10 / x`로 정합니다.

예를 들어 `x / 10 / x / x / 10`은 2번과 5번 칸만 레벨 10이면 통과합니다. 잠긴 칸은 10으로 치지 않습니다. 토글을 꺼도 칸 설정은 보존되고 복사·내보내기·가져오기에 포함됩니다. 5칸이 모두 `x`이거나 선호 서번트가 없으면 어펜드 화면으로 전환하지 않습니다.

## 선택 순서

1. 일반 표시에서 서번트·일반 스킬·스코어·보구 레벨·예장·친구 조건을 먼저 확인합니다. 하나라도 실패하면 어펜드 확인은 건너뜁니다.
2. 조건에 맞는 후보가 있으면 상단 **스킬 전환** 버튼을 눌러 어펜드 5칸을 검사합니다.
3. 검사 뒤 버튼을 두 번 눌러 일반 표시로 되돌립니다.
4. 통과한 후보를 선택하고, 통과하지 못하면 다른 서번트를 찾습니다.

화면 전환이나 복구를 확인하지 못하면 서포트를 고르지 않고 중단합니다. 조건을 꼭 지키려면 서포트 선택 실패 시 **첫 번째 서포트 선택** 대체 동작을 쓰지 마세요. 선호 조건을 우회할 수 있습니다.

## 참고

- KR·JP 화면의 숫자와 표시 아이콘 템플릿을 기준으로 읽으며, 흐리거나 해상도가 낮으면 읽지 못해 후보를 건너뛸 수 있습니다.
- 실제 기기에서의 화면 전환 속도는 환경에 따라 다를 수 있습니다.
