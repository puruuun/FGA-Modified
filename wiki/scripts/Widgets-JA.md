# ホーム画面ウィジェット

ホーム画面にFGAのウィジェットを2つ配置できます。1つはFGAサービスを開始・停止する1x1ウィジェットで、もう1つは収集したアカウントのAPを表示するアカウント情報ウィジェットです。どちらも初期設定は濃い紺色のカードデザインで、[ウィジェット設定](#widget-settings)からライトテーマや背景の透明度を変更できます。

**KR（韓国）・公式JP（日本）サーバーを対象としています。** アカウントAPデータはAndroid 10以上で[ログ収集](Gains-Tracker-JA.md)を有効にし、アカウントを1回以上収集すると表示されます。

## ウィジェットを追加する

1. ホーム画面の空きスペースを長押しして **ウィジェット** を開きます。
2. 一覧から **FGA** を探し、**FGAサービス** または **アカウント情報** をホーム画面へドラッグして配置します。

アカウント情報ウィジェットはアカウント選択の手順なしですぐに追加されます。以前のバージョンで配置したウィジェットでも収集済みの全アカウントが表示されます。

## FGAサービスウィジェット（1x1）

最初は従来と同じ1x1サイズです。横方向に約2マス（2x1）まで広げられ、**ログ収集ボタンを表示** をオンにすると2マス幅では左側にログ収集ボタン、右側にサービスボタンが並んで表示されます。1マス幅ではサービスボタンのみ表示されます。

サービス停止中は円の中の ▶ と **OFF**、実行中は ■ と強調色の **ON** が表示されます。サービスが開始または停止するたびに両方のウィジェットに状態が反映されます。

- **OFFからタップすると** FGAが開き、メイン画面の **実行** ボタンとまったく同じ順序（保存フォルダ → 通知権限 → 他のアプリの上に重ねて表示権限 → ユーザー補助サービス → 画面キャプチャの許可 → サービス開始）を1回実行し、ログ収集がオンの場合は最後にログ収集VPNも開始します。
- FGAをアカウントダッシュボード・ログ・その他の設定画面に開いたままにしていても、まずメイン画面へ移動して開始手順を実行します。初期設定が必要な場合は開始要求を破棄し、すでに実行中のサービスに対して開始要求を再実行することはありません。
- 不足している権限があれば通常どおり案内ダイアログが表示されます。サービスが開始するとFGA画面は自動で閉じ、元の画面に戻ります。開始に失敗したり画面キャプチャの許可をキャンセルしたりするとFGA画面はそのまま残ります。
- **ONからタップすると** FGAを開かずにサービスを停止します。ログ収集は既存のルール（設定の **サービス停止時にログ収集を停止**）に従って一緒に停止します。

## アカウント情報ウィジェット（標準4x1、3x1まで縮小可能）

**ログ収集ボタンを表示** をオンにすると、右側に **アカウント情報 | ▲▼ | ログ収集 | サービス** の順で表示されます。ログボタンはサービスボタンと同じサイズで、鍵アイコンで区別されます。アカウント情報が切れないよう、幅が250 dp未満の場合はログボタンを非表示にします。一般的な3x1（約200 dp）では非表示になります。左右の余白は約22 dpで、情報と ▲▼ の間にも間隔を設けています。

左側にはアカウントカードが1枚表示されます。カードと開始／停止ボタンの間の **▲ / ▼ ボタン** でアカウントを切り替えます。**▼ は次のアカウント、▲ は前のアカウント** で、端まで来ると反対側の端へ戻ります（循環）。どのアカウントを表示しているかはウィジェットごとに記憶され、15分更新や新規データ保存で再描画されても見ていたアカウントがそのまま維持されます。見ていたアカウントが削除された場合は最初のアカウントに戻ります。現在のアカウントが先頭に表示され、残りは最後にデータを収集した時刻が新しい順になります。右側の開始／停止ボタンは固定されています。

アカウントは1度に1つずつ表示されます。アカウントが1つしかない場合は ▲ / ▼ ボタンは表示されません。名前やAP、バーがカードの角丸に付かないよう左側に余白を取っています。

| 表示 | 意味 |
| --- | --- |
| アカウント名 | 手動で変更した名前が優先されます。 |
| 右側の灰色の `たった今` / `N分前` / `N時間前` / `N日前` | このアカウントのデータを最後に収集してからの経過時間です。1アカウント表示時のみ表示されます。 |
| `57 / 142` | 保存されたデータから現在時刻に合わせて計算した現在APと最大APです。 |
| `全回復 午後 8:23` | APが全回復する時刻です。すでに全回復している場合は **AP全回復** と表示されます。 |
| バー | 現在AP / 最大AP の割合です。 |

- 時刻は端末の言語と12/24時間制設定に従います。画面の色はシステムテーマではなく[ウィジェット設定](#widget-settings)のテーマに従います。初期値は濃い紺色です。
- 狭い幅でもAPと全回復時刻が一緒に収まるよう文字サイズを縮小します。ボタン欄が幅を取るため、幅が狭いほど文字は小さくなります。
- 表示中のアカウントカードの情報や余白をタップすると、そのアカウントのダッシュボードが開きます。▲ / ▼ でアカウントを切り替えた後も、現在表示中のアカウントが開きます。
- APは1 APあたり5分で回復する計算で、メイン画面のアカウントカードと同じ値です。

### すべてのアカウントを1行に

**ウィジェット設定 → 表示方式** を **すべてのアカウントを1行に** に変更すると、▲ / ▼ ボタンなしでアカウントが同じ幅の列として横に並んで表示されます。列の並び順は1アカウントずつ表示の順序（現在のアカウント、続いて最近収集した順）と同じです。

- 各列には上から **名前**（太字、長ければ省略記号）、**AP 現在 / 最大**（大きく太字）、その下に緑色の **全回復時刻**（すでに全回復していれば **AP全回復**）が表示されます。バーはありません。
- ウィジェット幅に収まる数だけ列を表示し、残りのアカウントは表示しません。サービスボタンのみオンのスマートフォン4x1（約272 dp）では2アカウント、5x1（約350 dp）では3アカウントが表示されます。ログ・サービスボタンを両方オンにした4x1では約292 dpから2アカウントが表示され、それより狭いと1アカウントが表示されます。1列あたり約76 dp以上を確保します。1アカウントずつ表示と異なり、「たった今 / N分前」などのデータ経過時間は表示されません。
- 高さが低い場合は3行が収まるよう余白と文字サイズを縮小します。最小高さ40 dpでは右側のボタンにアイコンのみ表示され、ボタンのサイズと丸い形はどの高さでも変わりません。
- アカウント列をタップすると、そのアカウントのダッシュボードが開きます。

### 更新タイミング

- アカウント情報ウィジェットが1つでも配置されていれば15分ごとに再計算します。すべて削除すると定期更新は停止します。
- ログ収集がアカウントの新しいデータを保存すると即座に更新します。
- 再起動やアプリのアップデートを行うと配置済みウィジェットを再描画します。**エミュレータやスマートフォンが自動起動をブロックして読み込み表示のまま残る場合は、FGAを1度開いてください。** アプリ起動時にも配置済みウィジェットを再描画します。
- バッテリー節約機能がFGAのバックグラウンド処理を制限すると、15分更新が遅れることがあります。

### データが古くなっている場合

AP値は最後に収集したデータを基に経過時間だけで計算したものです。ログ収集をオンにしたままゲームへログインしなかった場合、その間に消費または回復したAPは反映されません。正確な値が必要な場合は、1アカウント表示ウィジェットの**データ経過時間**（たった今 / N分前）を確認し、ゲームに再度アクセスして新しいデータを取得してください。

### アカウントデータなし

収集したアカウントがない、ログ収集をオフにしている、またはAndroid 10未満の場合は左側に **アカウントデータなし** と表示され、タップするとFGAが開きます。右側の開始／停止ボタンはそのまま使えます。アカウントを再度収集するかログ収集をオンに戻すと、アカウント情報が再び表示されます。

APが全回復した際に通知を送る機能はありません。

## ウィジェット設定

**その他の設定 → その他 → ウィジェット設定** で、2つのウィジェット（1x1サービスウィジェットとアカウント情報ウィジェット）の見た目を変更します。値を変更するとホーム画面に配置されたウィジェットが即座に再描画されます。

| 設定 | 選択肢 | 初期値 |
| --- | --- | --- |
| **背景の透明度** | 0%から100%まで10%単位 | 0%（不透明、従来デザイン） |
| **テーマ** | ダークテーマ / ライトテーマ | ダークテーマ（従来の紺色） |
| **表示方式** | アカウントを1つずつ（上下で切り替え） / すべてのアカウントを1行に | アカウントを1つずつ（従来デザイン） |
| **名前の横にサーバー（KR/JP）を表示** | オン / オフ | オフ |
| **サービス開始/停止ボタンを表示** | オン / オフ | オン |
| **ログ収集ボタンを表示** | オン / オフ | オン |

- **ログ収集ボタンを表示** の初期値は現在オンです。以前に手動でオフまたはオンにしていた場合はその値が維持されます。
- **サービス開始/停止ボタンを表示** をオフにするとアカウント情報ウィジェットのサービスボタンが消え、そのスペースまでアカウント領域が広がります。
- **名前の横にサーバー（KR/JP）を表示** をオンにすると、アカウント名の横に小さな `KR` / `JP` 表示が付きます。どちらの表示方式にも適用されます。
- 透明になるのはカード背景だけです。文字、APバー、▲ / ▼ ボタン、開始／停止ボタンは透明度にかかわらずそのまま見えます。1x1サービスウィジェットはボタン枠自体がカードなのでその背景が透明になり、アイコンとON/OFF文字はそのまま見えます。
- ライトテーマは白いカードに暗い文字を使い、全回復時刻は白背景でも読み取れるようより濃い緑色で表示します。バーの色は同じで、開始／停止ボタン欄も明るい色になります。
- 角丸は透明度にかかわらずAndroid 10以降で維持されます。

## ウィジェットからログ収集を開始・停止する

**その他の設定 → その他 → ウィジェット設定 → ログ収集ボタンを表示** をオンにし、ログ収集機能もオンにしているAndroid 10以降の端末で利用できます。ログ収集中は鍵アイコン（メイン画面の **ログ収集を開始** ボタンと同じアイコン）と **ON** が黄色い背景で表示されます。収集を開始または停止すると両方のウィジェットが更新されます。

- **ONからタップすると** FGA画面を開かずに即座にログ収集を停止します。
- **OFFからタップすると** 現在バージョンの収集同意、証明書準備、VPN権限がすべて揃っていればFGA画面を開かずに収集を開始します。
- 同意や権限が欠けている場合はFGAが開き、メイン画面のログ収集ボタンと同じ 同意 → 証明書確認 → VPN許可（FGA VPN方式のみ） → 開始 の手順を実行します。証明書がない場合はログ収集設定の証明書案内画面へ移動します。
- 実際に収集開始に成功するとFGA画面が閉じます。同意やVPN許可をキャンセルした場合や証明書がない場合は、案内された画面がそのまま残ります。
