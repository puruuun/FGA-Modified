# そのターンの攻撃順の直接指定

通常カードと宝具を含む3枚の選択順をそのターンだけ固定します。

## 設定方法

1. 使用するバトル設定の **コマンド → Attack** を開きます。
2. **宝具前に選択するコマンドカード枚数** の横にある **Direct cards**（通常カードの直接指定）ボタンを押します。
3. **Fix the attack order for this turn**（このターンの攻撃順を直接指定）をオンにします。
4. 1番目・2番目・3番目の攻撃（`Attack 1`〜`3`）それぞれについて、**Buster**、**Arts**、**Quick**、サーヴァント1〜3の宝具（`Servant 1–3 NP`）、または **Unselected**（未選択）から選びます。
5. 色が足りないときに他のカードで補いたい場合は、**Fill missing and unselected cards by priority**（カード不足・未選択カードを優先順位で代替）にチェックを入れます。初期値はオフで、直接指定をオフにすると無効化されます。1か所でも **Unselected**（未選択）を選ぶと自動的にチェックが入り外せなくなります。未選択の枠をすべて戻すと再び切り替えられるようになります（元のチェック状態は保持されます）。
6. **Save**（保存）を押して表示された順番を確認したあと、**次のターン（同じウェーブ）** または **次のウェーブ** でコマンドに追加します。

直接指定を有効にしている間は、従来の宝具ボタンと「宝具前に選択するコマンドカード枚数」の代わりに指定した3枚を使用します。再度ボタンを開いてトグルをオフにすると、同じ画面の通常設定に戻ります。**閉じる** を押してキャンセルすると変更は反映されません。次に新しく攻撃設定を開くときは通常方式で始まるため、必要なターンでのみオンにしてください。

## コマンド文字列の書式

`&` の後ろに正確に3文字を指定します。代替をオンにしたターンは `&` の直後に `?` を1文字付けます（`&?b4a`）。`?` 自体は攻撃枠ではなく、残りのルールは同じです。従来の `&b4a` は代替なしでそのまま実行されます。`b/a/q` はそれぞれ **Buster / Arts / Quick**、`4/5/6` は **現在の前衛1/2/3番サーヴァントの宝具**、`p` は **Unselected**（未選択、優先順位で埋める枠）です。`p` を含むコマンドには必ず `?` が必要で（`&?bp4`）、`&bp4` はエラーとして拒否されます。通常カードの所持サーヴァントは別途制限されないため、特定サーヴァントのカードを生成するスキルを使う場合はそのスキルを先に設定してください。

```text
&ba4,&bba,&b5a,#,
```

| コマンド | 選択順 |
|---|---|
| `&ba4` | Buster → Arts → 前衛1番 宝具 |
| `&bba` | Buster → 別の Buster → Arts |
| `&b5a` | Buster → 前衛2番 宝具 → Arts |
| `&a4b` | Arts → 前衛1番 宝具 → Buster |
| `&4ba` | 前衛1番 宝具 → Buster → Arts |
| `&?bp4` | Buster → 未選択（優先順位） → 前衛1番 宝具 |
| `&?pp4` | 未選択 → 未選択 → 前衛1番 宝具 |
| `&?ppp` | 3枚すべて優先順位 |

従来通り `,` がターン区切り、`#,` がウェーブ区切りです。既存のスキルは `&` の前に置きます。たとえば `ab&b5a` はスキル a・b を使用したあとに固定攻撃を実行します。大文字の `B/A/Q` 入力は小文字に正規化されます。`WB`・`RB` などの相性指定はこの書式では使えません。

固定攻撃はそのターンの最後のコマンドでなければなりません。同じターン内で通常の宝具コマンドや `n1/n2` と併用すると解釈エラーで停止します。同じ宝具を2回指定したり、3枚より短い・長いコマンドも拒否されます。前に置かれた無動作 `0` は従来通り無視されます。

## 選択ルールと制限

- 現在のカード画面を認識し、必要な3枚をすべて確定させてからタップします。同じ色の中では **WEAK → 通常 → RESIST** の順に選び、相性が同じなら左から選びます。すでに選んだ通常カードは除外されます。
- スタンなどで使用できない通常カードは除外されます。代替をオフにした状態で指定色が足りない場合、代替をオンにしても使用可能な通常カード自体が足りない場合、または通常カードの種別を読み取れない場合は、**最初の1枚もタップせずに停止**します。指定した宝具の前衛位置が空の場合も停止します。
- 通常の直接指定ではカード・サーヴァント優先順位は適用されません。代替をオンにすると、不足した通常カードの枠だけに現在のウェーブおよび選択中の1番目・2番目設定のカード・サーヴァント優先順位が適用されます。どちらの方式でも Brave Chains 選択・優先順位逆転（カード再配列）・追加の自動宝具は適用されません。次のターンの通常攻撃は従来通りに動作します。
- 既存のスキル自動使用および共通シャッフル設定は維持されます。スキルとシャッフル後の実際の手札から指定された種類を探します。スキルで整えた手札を維持したい場合は共通シャッフル条件も確認してください。
- **宝具ゲージ・宝具封印・使用可能状態を新たに読み取る機能ではありません。** 通常の宝具実行と同じく、使用する宝具が撃てる状態になるようスキルや NP チャージを設定してください。
- 1番目・2番目どちらの開始条件コマンドでも使用でき、`.fga` のコピー・エクスポート・インポートにもコマンド文字列が含まれます。

## カード不足・未選択カードを優先順位で代替

チェックを入れると、まず3枠全体で手札に存在する指定色を先に確保します。同じ色は WEAK → 通常 → RESIST の順、相性が同じ場合は画面の左から確保します。複数の枠が同じ色を指定している場合は、前の枠が最も条件の良いカードを先に確保します。その後、空いているすべての通常カード枠（**Unselected** 枠および色が不足した枠）を枠の順番通りに、残った手札へ既存のカード・サーヴァント優先順位を適用して一括で埋めます。未選択の枠が、後ろの色指定枠に必要なカードを奪うことはありません。宝具枠と確保済みカードの位置は入れ替わりません。

たとえば `&?b4a`（Buster → 前衛1番 宝具 → Arts）で、手札に Arts 1枚・Quick 4枚があり、優先順位が Buster > Arts > Quick の場合は **Quick → 前衛1番 宝具 → Arts** になります。最後の Arts を先に確保するため、前の代替枠がその Arts を取ってしまうことはありません。同じ手札でも `&b4a` はタップせずに停止します。

たとえば `&?pa4` で Arts が1枚しかない場合、その Arts は2番目の枠に確保され、1番目の枠は残りのカードのうち優先順位が最も高いカードになります。使用可能なカードが足りない場合はタップせずに停止します。

このチェックはそのターンにだけ保存されます。編集・コピー・`.fga` エクスポート／インポート、1番目・2番目の設定すべてで保持されます。チェックを外して保存すると `?` が取り除かれ、新しい攻撃ではオフから始まります。**閉じる** を押すと変更は適用されません。

読み取れなかった通常カード、不完全・重複した手札、使用可能なカード不足、空いている指定宝具枠は代替されません。`"Could not prepare the fixed attack … No cards were selected. Check the hand and deployed Servants."`（固定攻撃 … に必要なカードを確認できなかったため、カードは選択していません。）が表示された場合は、手札と前衛サーヴァントを確認し、指定色や代替設定を調整してください。不正なコマンドはコマンド書式を修正する必要があります。宝具の使用可能状態は新たに読み取りません。

優先順位で埋めた枠が1つでもある攻撃（未選択または色不足）は、診断ログの `FGA.DirectCards` に要求コマンドと最終的な3枚の順番を1回記録します。
