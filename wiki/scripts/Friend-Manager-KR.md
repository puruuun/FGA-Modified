# 프렌드 관리

**로그 수집으로 받은 친구 목록에서 일반·이벤트·관위 편성의 서번트와 육성 상태를 모아 보고, 친구 이름·서번트·예장·레벨·미접속 기간으로 걸러 볼 수 있는 화면입니다.** 게임을 조작하거나 설정을 바꾸지 않고 읽기만 합니다.

열기: **더 많은 옵션 → 추가 기능 → 프렌드 관리** (**로그 수집** 바로 아래). **로그 수집 사용**이 켜진 Android 10 이상에서만 표시되며, 스위치를 끄면 사라집니다(저장된 친구 목록은 삭제되지 않음). [로그 수집 (KR)](Gains-Tracker-KR.md)을 먼저 설정해야 합니다.

## 목록 채우기

1. 로그 수집을 켠 상태에서 게임을 시작합니다.
2. 게임의 **메뉴 → 친구&팔로우**를 한 번 엽니다. 이때 받은 친구 목록으로 목록 전체를 새로 만듭니다.
3. 아직 목록이 없으면 화면에 같은 안내가 표시됩니다.

친구 목록은 **계정을 식별할 수 있고 그 계정의 저장 상태가 있을 때만** 저장합니다. 두 번째 계정을 처음 수집한다면 로그 수집을 켜고 게임을 시작해 로그인 상태를 저장한 뒤 **메인 메뉴를 한 번 방문**하고 친구&팔로우를 열어 주세요. 계정을 알 수 없는 응답은 다른 계정의 목록을 덮어쓰지 않습니다. 이미 저장된 계정의 목록은 현재 표시 중인 계정과 달라도 해당 소유자에게 저장하며, 현재 계정은 바꾸지 않습니다.

이후 퀘스트의 서포트 선택 화면을 열거나 전투가 끝날 때 받은 서포트 목록에서 **친구**인 사람의 서번트가 반영됩니다. 응답에서 계정이 확인되면 새 친구도 추가하고, 계정 정보가 없으면 현재 계정 목록에 이미 있는 친구만 갱신합니다. 친구가 아닌 서포트는 저장하지 않습니다. 친구를 정리하거나 새로 친구가 된 경우에는 **친구&팔로우**를 다시 열어 목록을 갱신하세요. 목록에서 사라진 친구와 친구 신청 중인 사람은 새 목록에 포함되지 않습니다. 계정마다 따로 보관합니다.

## 화면 구성

제목 아래 **계정 선택**에는 친구 목록이 저장된 계정의 이름, **Lv N · 친구 N · 갱신 N분(시간·일) 전**, 서버 태그(**KR / JP**)가 표시됩니다. 현재 계정에 목록이 있으면 그 계정으로 시작하고, 없으면 가장 최근에 갱신한 목록을 보여 줍니다. 계정이 여러 개면 눌러서 바꾸고, 하나면 메뉴 없이 정보만 표시합니다.

그 아래 적용 중인 필터 칩이 표시됩니다. 갱신 시각(계정 선택 줄)은 마지막으로 친구&팔로우를 연 시각이며, 로그인 열과 같게 분 / 시간 / 일로 표시합니다. 한 줄이 서포트 서번트 한 칸이며, 최근에 접속한 친구 순서입니다. 스크롤해도 표의 제목 행은 위에 남습니다.

| 이름 | 스킬 | 어펜드 | 예장 | 로그인 |
| --- | --- | --- | --- | --- |
| 첫 줄 서번트 이름, 둘째 줄 `Lv120 보5 · 친구 이름` | 세 스킬 `a/b/c` | `5/5/5/-/-`처럼 다섯 개를 이어 표시 (잠금은 `-`, 칸이 좁으면 자동 줄바꿈) | 예장 이름 바로 뒤에 최대 돌파 시 **최대**와 `Lv100`을 같은 줄에. 관위 편성은 CE1·CE3을 각각 한 줄에, 아래에 인연 효과 | 마지막 접속 후 경과 시간 `N분` / `N시간` / `N일` |

서번트·친구 이름과 예장 이름은 넘치면 말줄임표로 줄입니다. 어펜드는 칸 너비에 맞게 줄바꿈하고, 관위 편성은 두 예장 줄과 인연 효과 라벨 높이에 맞춥니다. 예장은 이름이 먼저 줄어들고 **최대**·Lv는 이름 옆에 남습니다. **로그인**은 접속 기록이 없으면 `–`입니다. 예장이 없으면 **예장 없음**입니다. 이름 칸의 `보N`은 보구 레벨입니다.

일반·이벤트 편성에서 관위 서번트인 서포트 칸은 서번트 이름 옆에 작은 **관위** 배지가 표시됩니다. 관위 정보는 로그 수집을 켠 상태에서 게임의 **친구&팔로우**를 다시 열면 채워집니다. 공식 JP와 KR 모두 받은 데이터에 따라 표시하며, KR에 관위 서번트가 도입된 뒤에도 같은 방식으로 갱신합니다.

**관위 편성**은 관위전·특수 퀘스트용으로 받은 별도 편성입니다. 일반·이벤트 편성의 관위 배지와 별개로 선택합니다. CE1과 CE3의 예장 이름·최대 돌파 표시·레벨을 두 줄에 보여 주며, 그 아래 **인연: NP 차지 / 인연: 기본 효과 / 인연: 없음**을 표시합니다. 인연 예장이 장착되어 있고 NP 차지로 설정된 경우 **NP 차지**, 인연 예장이 있고 해당 설정이 없으면 **기본 효과**, 인연 예장이 없으면 **없음**입니다. 관위 편성도 최근 접속 순이며, 같은 친구의 관위 칸은 자리 번호순입니다. 서포트 목록 응답에 관위 편성이 포함된 때만 저장된 관위 편성을 갱신합니다.

행을 누르면 바로 아래에 **친구 코드**와 복사 버튼, **친구 Lv N · 클래스 칸 · 편성 N · M/d HH:mm**(마지막 접속, 기기 현지 시간)이 펼쳐집니다. 클래스 칸은 서포트 클래스 칸(전체, 세이버 … 버서커, 엑스트라)이고, 편성은 해당 친구의 일반 또는 이벤트 편성 중 몇 번째인지입니다. 복사 버튼은 숫자만 복사합니다. 코드를 아직 모르면 표시하지 않습니다. 다시 누르면 접힙니다.

이름과 서번트 클래스는 Atlas 공개 목록에서 가져오고, KR에 없는 JP 항목은 JP 목록으로 보완하며, 아직 없는 번호는 `#번호`로 표시합니다. 서번트 아이콘은 표시하지 않습니다.

## 필터

목록 위 칩 줄의 첫 칩 **필터**(조정 아이콘)를 누르면 화면 위에서 전체 너비의 필터 패널이 열립니다. 넓은 화면에서는 항목을 두 열로 배치하고, 좁은 화면에서는 세로로 스크롤합니다. 편성 칩과 적용 중인 조건 칩이 이어지며, 조건 칩을 누르면 해당 조건만 해제합니다. 편성 칩은 항상 표시됩니다.

- **편성**에서 **일반 편성 / 이벤트 편성 / 관위 편성**을 고릅니다. 바꾸면 서번트·예장 선택이 풀립니다.
- **친구 이름**은 이름 일부로 검색하며 영문 대소문자를 구분하지 않습니다.
- **서번트**는 선택한 편성에 있는 서번트를 칸 수와 함께 표시합니다. **(세이버) 이름**처럼 클래스가 이름 앞에 붙으며, 이름과 클래스 모두 검색됩니다. 한국어·일본어 클래스 이름을 사용하고, 아직 알려지지 않은 클래스는 Atlas 원문으로 표시합니다.
- **서번트 레벨**은 방향 **이상 / 이하**와 레벨 **전체 / 80 / 90 / 100 / 120**을 따로 고릅니다. 예: **100 이상**은 레벨 100 이상, **100 이하**는 레벨 100 이하인 칸이 표시되며 기준과 같은 레벨도 포함합니다. 필터 칩에는 **100 이하**처럼 표시되고, **전체**일 때는 방향과 상관없이 모든 레벨이 표시됩니다.
- **예장**은 여러 개를 선택할 수 있고 **확인**으로 선택 창을 닫습니다. 선택한 예장 중 하나라도 장착한 칸이 표시됩니다. 관위 편성은 CE1·CE3을 검사하며 인연 예장은 예장 선택과 돌파 조건에서 제외합니다. **인연 보너스** 아래 칼데아 티타임을 맨 앞에, 이어 빌린 서포트의 인연을 20% 올리는 예장을 이름순으로, 나머지도 이름순으로 표시합니다.
- **예장 돌파**는 **전체 / 최대 돌파만 / 최대 돌파 아님**입니다. 예장을 골랐다면 선택한 예장 중 하나가 해당 돌파 상태여야 합니다. 예장을 고르지 않았다면 그 칸의 예장 중 하나가 해당 상태면 됩니다. 예장 없는 칸은 **전체**에서 표시됩니다.
- **최종 로그인**은 **전체 / 미접속**입니다. **미접속**에서는 **− / +** 버튼으로 **0–99**를 정하고 단위는 **분 / 시간 / 일** 중에서 고릅니다. 마지막 접속 후 N × 단위 이상인 칸이 표시되며, 기본값은 3일입니다. 이전 화면 상태의 범위 밖 숫자는 0–99로 제한합니다. 접속 기록이 없는 친구는 **전체**에서 표시됩니다.

이전의 **관위 서번트만** 스위치는 제거되었습니다. 관위 편성은 편성 선택에서 고르고, **최대 돌파만**은 **예장 돌파**의 세 가지 선택 중 하나로 옮겨졌습니다.

**초기화**는 일반 편성·빈 친구 이름·모든 서번트·모든 예장·돌파 전체·레벨 전체·전체 접속(미접속 기본값 3일)으로 되돌립니다. **N칸 보기**는 현재 조건의 칸 수를 표시하며 패널을 닫습니다.

## 개인정보

- 친구 이름·친구 코드·서포트 정보는 **이 기기 안**(앱 전용 저장소)에만 보관하고 어디로도 전송하지 않습니다. 프로필 메시지는 읽지도 저장하지도 않습니다.
- 로그나 Chaldea 파일 내보내기에는 들어가지 않습니다.
- **로그 수집 데이터 삭제** 또는 계정별 삭제를 하면 그 친구 목록도 함께 지워집니다.
- 계정 대시보드 위쪽의 **프렌드 아이콘**(친구 목록을 받은 계정에만 표시)을 누르면 그 계정이 선택된 상태로 프렌드 관리가 열립니다.
- 계정 대시보드의 프로필에는 친구 목록을 받은 뒤부터 **친구 상한: 현재 친구 수/상한**(예: 139/145)이 표시됩니다. 받기 전에는 상한만 표시합니다.
