# 서포트 보구 레벨 판독 — 0.5.1

## 설정

1. [정규 릴리즈 0.6.0](https://github.com/puruuun/FGA-Modified/releases/tag/v0.6.0)의 `FGA-mod-0.6.0-arm.apk`를 설치합니다. 기존 수정판과 같은 패키지·서명을 사용합니다.
2. 전투 설정에서 서포트 선택 방식을 **선호**로 정하고 **서번트 선호**를 엽니다.
3. **보구 레벨 판독**을 켭니다. 설정은 어펜드 스킬 설정보다 위에 있습니다.
4. **최소 보구 레벨**을 1~5 중 선택합니다. Lv.3을 선택하면 Lv.3·4·5가 통과하고 Lv.1·2는 탈락합니다.

판독 토글은 처음에는 꺼져 있으며, 최소 레벨의 초기 선택은 Lv.5입니다. 끄더라도 선택한 최소 레벨은 유지됩니다. 기존 설정을 가져오면 토글은 꺼진 상태로 시작합니다. 설정 복사·내보내기·가져오기에 포함됩니다.

원하는 서번트 이미지나 예장·친구 이름 조건과 함께 사용할 수 있습니다. 보구 레벨 조건만 사용하는 것도 가능합니다. 친구 전용 제한은 기존 **친구만** 설정을 따릅니다.

이 필터는 **선호 선택** 모드에 적용됩니다. 기존 실패 시 대체 동작을 **첫 번째 서포트 선택**으로 설정하면 선호 조건을 우회할 수 있습니다. 조건을 반드시 지키려면 대체 동작은 **수동 선택**으로 설정하세요.

## 동작 순서

후보를 찾으면 서번트·일반 스킬·스코어·예장·친구 이름·보구 레벨 등 일반 조건을 먼저 확인합니다. 이 중 하나라도 실패하면 다음 후보나 다음 페이지를 찾고, 해당 후보의 어펜드 판독은 하지 않습니다.

일반 조건이 모두 통과한 후보에서만 어펜드 스킬 조건을 마지막으로 확인합니다. 어펜드가 켜져 있으면 표시 전환 → 판독 → 일반 표시로 복원 후 선택합니다. 어펜드가 실패하면 표시를 복원하고 다음 후보의 일반 조건부터 확인합니다. 기존 화면이 어펜드 표시로 시작한 경우에는 일반 스킬 검사를 위해 먼저 일반 표시로 정리하는 기존 동작을 유지합니다.

스코어 +62·보구 레벨 검사는 어펜드보다 앞에서 실행됩니다. 0.5.1은 이 순서를 유지하고 보구 레벨 판독 실패 시의 재검사를 개선합니다.

## 인식 방법

- 기존 서포트 행 찾기로 후보 위치를 구하고, 보구명 영역 안에서 `Lv.`를 찾습니다. 숫자의 가로 좌표를 고정하지 않습니다.
- 찾은 `Lv.`와 숫자만 잘라 기존 Tesseract와 앱에 포함된 영문 모델로 읽습니다. 보구 전용 OCR 설정은 기존 선물함 OCR과 분리합니다.
- 기존 판독이 성공하면 즉시 사용합니다. 실패한 경우에만 기존 기준 이미지를 여러 크기로 검색하고 확대율·밝기 기준이 다른 전처리로 다시 읽습니다.
- 재검사는 신뢰도가 높은 결과 두 개 이상이 같은 레벨을 가리킬 때만 통과합니다. 다른 레벨이 함께 높은 신뢰도로 읽히거나 위치가 모호하거나 숫자가 잘렸으면 통과시키지 않습니다.
- 확정된 `Lv.1`~`Lv.5`를 설정한 최소 레벨과 비교합니다. 계속 불확실하면 다음 서포트를 찾습니다.

새 OCR 엔진·서버·모델이나 서번트별 예외는 추가하지 않았습니다. 기존 한국·영문 기준 이미지를 그대로 사용하며 일본 서버는 기존 영문 기본값을 사용합니다. 어펜드·스코어 설정이나 설정 파일 형식을 바꿀 필요가 없습니다.

## 검증 재현

검증 도구는 `tools/verify_support_np_images.py`입니다. OpenCV 4.11.0, Pillow, Tesseract 5.5.1을 사용하는 tesserocr가 설치된 Python 환경에서 16장 원본을 같은 폴더에 두고 실행합니다.

```sh
python -m pip install -r tools/np-level-vision-requirements.txt
python tools/verify_support_np_images.py --input-dir /path/to/screenshots --report np-image-results.json
```

기존 5장만 검사하려면 `--initial-only`를 추가합니다. tesserocr가 사용하는 Tesseract는 5.5.1이어야 합니다. 운영체제에 따라 별도 native Tesseract 설치가 필요할 수 있습니다.

## 현재 확인 범위

- 같은 OpenCV·Tesseract 버전과 실제 앱 언어 데이터를 사용하는 데스크톱 이미지 검증입니다. Android 앱 내부 OCR이나 실제 FGO 자동 선택의 성공을 뜻하지 않습니다.
- 흰색·노란색 표시, Lv.1~5, 긴 보구명의 작은 글자, 강화 화살표, 다른 스크롤 위치를 포함합니다. 다른 화면 비율·서버·단말기는 추가 확인이 필요합니다.
- 재검사 설정은 제공 자료의 실패를 분석해 정했습니다. 별도의 미사용 자료에 대한 독립 검증은 아닙니다. 두 OCR 결과가 일치해도 모든 상황에서 오류가 없어지는 것은 아니며, 모든 화면에서 100%를 보장하지 않습니다.

현재 정규 버전 0.6.0도 같은 보구 판독 개선을 포함합니다. 기존 Obtainium 설정으로 업데이트할 수 있습니다.
