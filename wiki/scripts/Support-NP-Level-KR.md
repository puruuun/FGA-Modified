# 서포트 보구 레벨 판독 — 0.5.0

## 설정

1. [정규 릴리즈 0.5.0](https://github.com/puruuun/FGA-Modified/releases/tag/v0.5.0)의 `FGA-mod-0.5.0-arm.apk`를 설치합니다. 기존 수정판과 같은 패키지·서명을 사용합니다.
2. 전투 설정에서 서포트 선택 방식을 **선호**로 정하고 **서번트 선호**를 엽니다.
3. **보구 레벨 판독**을 켭니다. 설정은 어펜드 스킬 설정보다 위에 있습니다.
4. **최소 보구 레벨**을 1~5 중 선택합니다. Lv.3을 선택하면 Lv.3·4·5가 통과하고 Lv.1·2는 탈락합니다.

판독 토글은 처음에는 꺼져 있으며, 최소 레벨의 초기 선택은 Lv.5입니다. 끄더라도 선택한 최소 레벨은 유지됩니다. 기존 설정을 가져오면 토글은 꺼진 상태로 시작합니다. 설정 복사·내보내기·가져오기에 포함됩니다.

원하는 서번트 이미지나 예장·친구 이름 조건과 함께 사용할 수 있습니다. 보구 레벨 조건만 사용하는 것도 가능합니다. 친구 전용 제한은 기존 **친구만** 설정을 따릅니다.

이 필터는 **선호 선택** 모드에 적용됩니다. 기존 실패 시 대체 동작을 **첫 번째 서포트 선택**으로 설정하면 선호 조건을 우회할 수 있습니다. 조건을 반드시 지키려면 대체 동작은 **수동 선택**으로 설정하세요.

## 동작 순서

후보를 찾으면 서번트·일반 스킬·스코어·예장·친구 이름·보구 레벨 등 일반 조건을 먼저 확인합니다. 이 중 하나라도 실패하면 다음 후보나 다음 페이지를 찾고, 해당 후보의 어펜드 판독은 하지 않습니다.

일반 조건이 모두 통과한 후보에서만 어펜드 스킬 조건을 마지막으로 확인합니다. 어펜드가 켜져 있으면 표시 전환 → 판독 → 일반 표시로 복원 후 선택합니다. 어펜드가 실패하면 표시를 복원하고 다음 후보의 일반 조건부터 확인합니다. 기존 화면이 어펜드 표시로 시작한 경우에는 일반 스킬 검사를 위해 먼저 일반 표시로 정리하는 기존 동작을 유지합니다.

스코어 +62 검사는 이전 버전에서도 어펜드보다 앞에서 실행됐습니다. 이번 버전에서는 보구 레벨 검사를 앞선 일반 조건에 추가했고, UI의 스코어 토글도 어펜드 설정 앞으로 옮겼습니다.

## 인식 방법

- 기존 서포트 행 찾기로 후보의 위치를 구합니다.
- 보구명 영역 내부에서 `Lv.` 기준 이미지를 검색합니다. 숫자의 가로 좌표를 고정하지 않습니다.
- 찾은 `Lv.`와 숫자만 잘라 확대·이진화·테두리 처리를 합니다.
- 기존 Tesseract 5.5.1 및 앱에 포함된 `eng.traineddata`로 한 줄을 읽습니다. 보구 전용 OCR 설정은 기존 선물함 OCR과 분리합니다.
- 높은 신뢰도로 읽힌 `Lv.1`~`Lv.5`만 유효한 레벨로 인정합니다. 위치가 모호하거나 숫자가 잘렸거나 판독 신뢰도가 부족하면 해당 후보를 통과시키지 않습니다.

새 OCR 엔진·서버·모델을 추가하지 않았습니다. 기준 이미지는 720p이며 한국 서버와 일본 서버 화면의 글자 크기 차이를 구분합니다. 영어 이미지 폴더를 공통 기본값으로 사용하는 기존 자산 규칙을 따릅니다.

앱과 같은 처리 설정과 배포할 기준 이미지를 사용한 로컬 실험입니다.

제공 이미지에서 확인 가능한 보구 레벨은 **한국 서버 4/4, 일본 서버 8/8, 전체 12/12로 100%** 일치했습니다. 같은 표시를 정규화 방법만 바꾸어 반복한 24회 검사를 24개의 서로 다른 자료로 해석하지 않습니다.

12개 표시를 두 화면 정규화 순서로 검사한 24개 판독이 모두 일치했습니다. 각 결과에 최소 레벨 1~5를 적용하는 120개 조건 비교와 `Lv.`를 제외한 실제 보구명 조각 24개의 판독 불가 결과도 통과했습니다. 화면 상단의 일부 잘린 2개 행은 기준 위치를 수동 지정하며, 나머지 10개 표시는 기존 편성 확인 버튼에서 행 위치를 자동 계산합니다.

기준 이미지는 위 자료 중 143344·134749에서 추출했습니다. 두 장을 제외한 다른 세 장의 7개 표시도 함께 검증합니다. 원본 플레이어 화면은 저장소에 올리지 않고 익명 보구명 영역만 `docs/reference-images/`에 보관합니다.

검증 도구는 `tools/verify_support_np_images.py`입니다. OpenCV 4.11.0, Pillow, Tesseract 5.5.1을 사용하는 tesserocr가 설치된 Python 환경에서 실행합니다.

```sh
python -m pip install -r tools/np-level-vision-requirements.txt
python tools/verify_support_np_images.py --input-dir /path/to/screenshots --report np-image-results.json
```

tesserocr의 Tesseract 버전이 5.5.1인지 확인해야 합니다. 운영체제에 따라 별도 native Tesseract 설치가 필요할 수 있습니다.

### 현재 확인 범위

- 현재 실물 자료는 Lv.1·Lv.5입니다. Lv.2·3·4 및 한국 서버 Lv.1의 실제 화면 판독은 추가 검증이 필요합니다. 최소 레벨 비교·문자열 검증 로직은 1~5 전체를 자동 테스트합니다.
- 이 검증은 데스크톱에서 같은 OpenCV·Tesseract 버전과 실제 앱 언어 데이터를 사용한 실험입니다. Android 앱 내부에서 실행한 OCR이나 실제 FGO 자동 선택의 성공을 뜻하지 않습니다.
- 흰색·노란색 표시, 보구명 길이, 강화 화살표, 스크롤 위치가 다른 사례를 포함합니다. 다른 화면 비율·서버·실제 기기는 추가 확인이 필요합니다.
- 보구명 조각의 음성 테스트는 Lv.2~4를 서로 구분하는 실제 이미지 테스트를 대신하지 않습니다.

0.5.0은 정규 릴리즈입니다. 기존 Obtainium 설정으로 업데이트할 수 있습니다.
