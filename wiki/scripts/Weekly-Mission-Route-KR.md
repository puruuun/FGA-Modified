# 주간 미션 자동 주회

**이번 주 주간 미션을 최소 AP로 채울 퀘스트와 횟수를 계산하고, 메인 화면에서 장·지도를 찾아 전체 경로를 실행합니다. 사용할 오토 스킬 설정과 사과 보충 설정을 먼저 확인하세요.**

JP·KR 서버에서 동작하며 인터넷 연결이 필요합니다. 실제 게임 안의 미션 진행도는 읽지 않습니다.

## 시작하는 방법

1. 게임의 **메인 화면**을 엽니다. 왼쪽 위에 `공지` / `お知らせ`가 보이는 화면입니다. 퀘스트 판이나 장 목록에서는 시작하지 마세요.
2. FGA 재생 버튼 → 실행 창 왼쪽 아래의 **주간 미션 클리어**를 누릅니다.
3. 실행 창 **오른쪽에 주간 미션 패널**이 열립니다(같은 버튼을 한 번 더 누르면 접힙니다). 주간 패널이 열려 있는 동안 왼쪽의 **제한** 항목은 숨겨지고, 패널을 접으면 저장값 변경 없이 다시 보입니다. 왼쪽의 오토 스킬 설정·AP 회복·아이템·인연 설정은 그대로 사용합니다.
4. **불러오기**를 누릅니다. 미션·장·적 구성을 불러오는 단계와 진행 막대가 표시됩니다. 이번 주 캐시가 있으면 바로 경로가 나타납니다.
5. 수동 미션은 체크박스가 없으며 이전에 저장된 선택도 무시합니다. 체크를 푼 미션은 원래 순서 위치에 회색으로 남습니다. 이미 완료한 미션 등은 체크를 해제해 계산에서 제외하세요. 지원 미션의 기본값은 모두 체크이고 서버·주차별 선택은 앱을 다시 열어도 유지되며 새 주가 되면 초기화됩니다. 체크를 바꾸면 경로가 다시 계산되고 **−/+ 횟수**도 새 계산값으로 돌아갑니다.
6. 총 AP와 퀘스트별 횟수를 확인한 뒤 공용 **확인**을 누릅니다. 패널이 열려 있고 남은 횟수가 있으면 주간 경로를 실행하며, 경로가 비어 있으면 실행하지 않고 **실행할 퀘스트가 없습니다**를 표시합니다. 패널을 접어 두었다면 일반 전투로 시작하며, 취소를 누르면 아무 동작도 하지 않습니다.

**더 많은 옵션 → 배틀 → 주간 미션 자동화 기능 사용**은 기본 켜짐입니다. 끄면 전투 실행 창의 주간 미션 클리어 버튼을 숨깁니다.

장·퀘스트 후보는 **더 많은 옵션 → 고급 → 주간 퀘 추적 설정**에서 서버별로 켜고 끌 수 있습니다. 장 이름의 `+`를 누르면 프리 퀘스트가 펼쳐집니다. 기본값은 모두 켜짐이며, 장을 꺼도 개별 퀘스트 선택은 유지됩니다. 데이터가 없으면 먼저 실행 창에서 해당 서버 데이터를 내려받으세요. 믹틀란과 주장 Ⅰ~Ⅳ는 지원하지 않아 목록에 나오지 않습니다.

## 확인 창과 경로 계산

**보물창고 초급**(10 AP)도 후보에 들어갑니다. 적 구성이 캐스터 9체로 고정돼 있어 다른 난이도 대신 초급만 쓰며, 경로에서는 항상 마지막에 방문합니다. **주간 퀘 추적 설정 → 요일 퀘스트**에서 끌 수 있고 탐색 시험에도 포함됩니다.

다른 퀘스트를 마친 뒤 공지 버튼으로 메인 화면을 확인하고 **메인 → 칼데아 게이트 → 요일 퀘스트 → 노란색 보물창고 초급 판** 순서로 이동합니다. 게이트를 누른 뒤 닫히기를 기다리고, 목록의 요일 배너를 찾아 누른 뒤 닫힘과 요일 퀘스트 판 기준점을 함께 확인합니다(오른쪽 제목·이벤트 배경 미사용). 목록에서 **위부터 가장 먼저 보이는 노란색 판**(색상 38–52°, 채도 0.80 이상)을 초급으로 보고 이름을 읽지 않은 채 누르며(이름과 AP는 `map.log` 기록용으로만 읽음), 노란 판이 없으면 아래로 스크롤하고 끝까지 없으면 중단합니다. 빨간 종화·초록 수련장과 `CLEAR`·`NEW!`·`∞` 판은 색 판정에 쓰지 않습니다. 캠페인으로 표시 AP가 달라도 색으로 찾고, 마지막 주회 뒤에는 요일 퀘스트 목록으로 나옵니다.

| 항목 | 설명 |
|---|---|
| 이번 주 미션 | 체크한 미션만 계산합니다. 이미 끝난 미션은 체크를 해제하세요. 일부 진행분은 횟수로 조절합니다. |
| 체크 푼 미션 | 이번 주 목록의 원래 자리에 회색으로 남으며 다시 켤 수 있습니다. 수동 미션은 체크박스가 없습니다. |
| 경로 | 장 / 지점 / 퀘스트 이름 / AP / 횟수와 총 AP입니다. 횟수 0인 퀘스트는 돌지 않습니다. |
| 후보 설정 | 주간 퀘 추적 설정에서 끈 장·퀘스트는 계산에서 제외합니다. |
| 수동 | 드롭 미션 등 계산할 수 없는 조건입니다. 직접 진행하세요. |
| 제외 대상 | **미지원 장:** 믹틀란(war 311)은 계층 전환 방식이 달라, 주장 Ⅰ~Ⅳ(war 402~405)는 운영 정책으로 제외했습니다. 경로 후보·탐색 시험·주간 퀘 추적 설정·장 목록 어디에도 나오지 않습니다(JP·KR 공통). 헤이안쿄(307)·트라움(310)은 메인 인터루드 장으로 지원합니다. |
| 전투 설정 | 왼쪽 목록에서 선택한 오토 스킬 설정을 씁니다. 여러 적 구성을 무리 없이 도는 설정을 고르세요. |

반복 가능한 메인 스토리 프리 퀘스트만 계산합니다. 후유키의 1회성 `危険地帯`처럼 `afterClear=close`인 퀘스트는 제외합니다. 적 특성·클래스·서번트 클래스·특정 적·퀘스트 클리어·퀘스트 특성 조건을 지원하며, 지원하지 않거나 도는 후보가 없으면 수동으로 뺍니다. 합계 미션은 개별 조건을 도는 과정에서 함께 채워집니다.

KR 후보·이름·AP는 KR 데이터를 쓰며, **KR 적 구성은 JP 데이터 기준**입니다. 같은 퀘스트 ID의 JP AP와 KR AP가 다르면 제외합니다. 계산용 데이터는 서버·주차별로 앱 캐시에 저장되며, Atlas Academy에서 장 배너와 지도 크기·지점 좌표를 내려받아 캐시합니다.

## 자동 이동과 전투

### 목록 탐색과 장 진입

- JP는 메인 레코드 **1 / 1.5 / 2**를 찾습니다. KR은 **1 / 1.5**를 찾고 2부 장은 메인 화면 목록에서 찾습니다. 헤이안쿄(307)·트라움(310)은 메인 레코드가 아니라 메인 화면 맨 아래 금색 **메인 인터루드**(`メイン・インタールード` / `메인·인터루드`) 버튼 안에 있어 경로 마지막에 방문합니다.
- 장 배너는 Atlas 배너의 안쪽 버튼 그림으로 찾습니다. 목록을 찾을 때는 원본 FGA의 스크롤바 위·아래 끝 기준 이미지를 작은 영역에서 확인해 이미 도달한 방향을 건너뛰며, 한 페이지 목록은 스와이프하지 않습니다. 끝이 확인되지 않으면 아래→위 순으로 방향마다 최대 14회 스와이프하며(배경 애니메이션으로 끝 판독을 취소하거나 가운데 레일 유무로 추정하지 않음), 못 찾거나 목록을 벗어나면 해당 장을 건너뜁니다.
- 장 배너에서 지도에 들어간 직후와 터미널로 나온 직후에는 3초씩 기다립니다. 헤이안쿄는 지도가 4장이고 프리 퀘스트는 `30702`에 있으며, 다른 지도가 열려 있으면 지점 이름 검증에서 걸러져 건너뜁니다(지도 전환 UI는 추측하지 않음).

### 지도 축소와 위치 계산

모든 장이 동일한 기하 기반 위치 계산 방식을 사용합니다.

- **최대 축소 확인**: 장에 들어가면 핀치로 지도를 최소 줌까지 축소하며, 핀치 두 번이 연속으로 배율 변화가 없을 때까지(최대 6번) 확인합니다. 제스처가 거부되거나 확정하지 못하면 그 장을 건너뜁니다.
- **끝에 붙이기와 세로 이동**: 최소 줌 지도는 화면 폭에 맞으므로(`배율 = 화면 폭 ÷ 지도 폭`, 세로 이동 범위 = `지도 높이 × 배율 − 720`, 확대 비율 허용 0.45~1.0으로 22:9 지원), 지점의 x 좌표를 유지하면서 위·아래 끝에서 눌릴 수 있는 지점은 해당 끝으로, 아니면 가까운 끝으로 길게 끌어 멈춤을 확인합니다. 가운데 지점은 끝에서 한 번에 최대 180px씩 끌며 전후 화면 비교로(100px 이상 겹침 유지) 위치를 누적합니다(최대 16회 드래그). 실패 시 끝으로 돌아가 한 번 다시 시도하고, 그래도 안 되면 `map movement did not converge`로 건너뜁니다.
- **가림 영역 회피와 조기 탭**: 마스터 초상화 마름모·레벨/AP·선물/미션 말풍선·MENU 등 고정 UI 영역과 720p 기준 12px 이상 여백을 두고, 위·아래 가장자리에서도 60px 이상 안쪽인 안전한 위치를 고릅니다. 이동 중 재확인에서 아이콘 중심이 가림 영역에서 4px 이상 떨어져 있고 위아래 60px 이상 안쪽이면 곧바로 탭하며(`reason=early`), 그렇지 않으면 목표 위치까지 이동한 뒤 탭합니다(`reason=converged`). 16:9 등에서 안전한 행이 없으면 이동 범위 내 가장 덜 가려지는 위치에서 보이는 부분(구역 반대 최대 30px, 4px 이상 여백)을 누르며, 탭 가능한 점이 전혀 없을 때만 `spot out of reach`로 건너뜁니다.

### 퀘스트 판 읽기와 선택

- 지점을 누를 때는 지점 좌표보다 25px 위인 아이콘 중심을 먼저 시도하고, 가려졌으면 보이는 부분 또는 가려지지 않은 지점 좌표를 누릅니다. 모두 가려졌으면 누르지 않습니다. 지점을 눌렀는데 판이 안 뜨면 1초 뒤 같은 점을 한 번 더 누르고, 그래도 없으면 `no panel after spot tap`으로 기록합니다.
- 퀘스트 판은 **Free Quest 표시**를 화면의 넓은 띠에서 찾은 뒤 **먼저 읽습니다**. Match면 드래그 없이 바로 진행하고, 잘렸거나 일치하지 않을 때만 판 내부 버튼 없는 곳에서 위→아래로 한 번 드래그해 다시 읽습니다. 그래도 맞지 않으면 판을 닫고(최대 3초씩 3번 탭, 실패 시 1회 복구 시도) 지점을 화면 안쪽·가운데로 옮겨 한 번 더 시도합니다. 미션 퀘스트 등 파티 제한 퀘스트는 절대 누르지 않으며, 위 판이 미션 퀘스트면 아래 프리 퀘스트도 검사합니다.
- 이름은 4가지 방식(2·3·4배 확대, 이진화·원본 그레이스케일)으로 읽어 서버의 **전체 프리 퀘스트 이름 사전**(지점에 프리 퀘스트가 2개 이상이면 해당 지점 후보 목록)과 대조합니다. 희귀 한자·받침 오독은 최대 2글자·전체 길이 1/3 이하·차순위 후보보다 2 이상 가까움·2회 판독 합의를 모두 만족할 때만 보정합니다.
- 지점을 눌러 확대 표시되는 **지점 이름표**도 두 번째 확인으로 씁니다. 퀘스트 이름이 읽히면 **퀘스트 이름이 단독으로 판정**(`by=quest-name`, 지점 후보 2개 이상이면 `by=quest-name-spot`)하며, 이름이 목표와 다르면 지점 이름이 맞아도 거부합니다. 퀘스트 이름이 전혀 안 읽힐 때만 지점 이름 일치·Atlas 단일 프리 퀘스트·Free Quest 표시·이름 너비 일치를 모두 만족할 때 인정합니다(`by=spot-name+cells`). AP는 로그 기록용이며 판정에는 쓰지 않습니다. Match가 아니면 절대 누르지 않습니다.

### 전투 진행과 복귀

- 전투·서포트 선택·AP 회복은 일반 FGA 흐름을 그대로 씁니다. 퀘스트별 횟수 제한만 임시로 적용했다가 종료 시 원래 값을 복원하고, 사과는 전체 경로에서 실제 사용한 만큼 한 번 차감합니다.
- 마지막 전투 뒤 연속 출격 창을 닫으면 지도로 돌아오는 로딩을 위해 **5초 더 기다린 뒤** 다음 퀘스트를 찾습니다. 같은 장의 다음 퀘스트는 판을 닫고 지도를 다시 맞추며, 다른 장은 `터미널` / `ターミナル` 및 필요 시 `닫기` / `閉じる`로 돌아갑니다.

## 종료 요약과 문제 해결

종료 시 각 퀘스트의 **계획 / 실제 / 완료·못 찾음·중단·미실행**과 수동 미션을 보여 줍니다. 전투 중 AP 부족·전멸·퇴각·사용자 정지 등으로 멈추면 남은 경로는 이어 가지 않습니다.

메인 화면이 아니면 아무것도 누르지 않고 시작 화면 안내를 띄웁니다. 데이터 불러오기 실패 시 인터넷·Atlas 연결을, 경로 계산 실패 시 켠 장 수를 줄여 다시 시도하세요. 상세 진행 단계는 로그에서 확인할 수 있습니다.

```text
adb -s 127.0.0.1:5555 logcat -s WeeklyRoute
```

## 탐색 시험 모드 (베타 전용)

AP를 쓰지 않고 모든 장의 지도에서 퀘스트를 찾을 수 있는지 실제 게임에서 점검하는 **베타 전용** 모드입니다(정규판에서는 숨겨지며 진단 파일도 남기지 않습니다).

- **사용 위치**: 주간 미션 패널 위쪽 **탐색 시험(AP 소모 없음)** 체크(켜면 경로 대신 범위 선택 표시). **모든 메인 스토리 프리 퀘스트 / 선택한 장 / 주간 퀘 추적 설정에서 켠 퀘스트** 중 고를 수 있고, **이미 성공한 퀘스트 건너뛰기**도 서버별로 지원합니다(믹틀란·주장 제외).
- **동작과 안전**: 메인 화면에서 시작해 실제 경로와 동일하게 이동·지도 맞추기·지점 탭·판 판정까지 수행하지만, **Match여도 퀘스트 판은 절대 누르지 않고** 닫은 뒤 다음 퀘스트로 넘어갑니다. 중간에 멈추면 그때까지의 결과만 저장하고 나머지는 `미실행`으로 남깁니다.
- **결과와 진단 파일**: 상태(`성공` / `지도 맞추기 실패` / `지점 탭 후 판 없음` / `판 불일치` / `장 못 찾음` / `미실행`, 한 번이라도 판을 연 뒤 실패는 `panel_mismatch`, 처음부터 안전한 탭 점이 없으면 `spot out of reach`)와 소요 시간을 요약 창과 `diagnostics/weeklyRoute/probe/` CSV에 기록합니다. 성공마다 2배 확대 증거 PNG(`diagnostics/weeklyRoute/<실행번호>/evidence/q<퀘스트ID>.png`)를 남기며, 실패·판 불일치(실행당 최대 8장, 탐색 시험 실패 최대 100장)·중단 화면과 실행당 1개의 `map.log`도 저장합니다. CSV와 증거 폴더를 PC로 옮겨 아래 명령으로 HTML 대조표(`spot-name+cells` 상단 정렬)를 만들 수 있습니다.

```text
py -3 tools/weekly-audit/contact_sheet.py probe-JP-<시각>.csv <증거 폴더> -o audit.html
```

## 주의 및 한계

- 아직 해금하지 않은 장은 반드시 **주간 퀘 추적 설정**에서 끄고 실행하세요. Atlas 데이터와 실제 게임의 적 구성 차이로 미션이 부족할 수 있으므로 실제 주간 미션 진행도는 게임에서 직접 확인하세요.
- 화면 비율이나 글꼴 차이로 지점·판 판독 근거가 충분하지 않으면 추측 탭 대신 안전하게 건너뜁니다(`spot out of reach`, `map not recognized`). 새 기기나 다른 화면 비율에서는 짧은 경로나 베타 **탐색 시험 모드**로 먼저 확인하세요.
