# 주간 미션 클리어 — 1.6.0-beta.1

**이번 주 주간 미션을 가장 적은 AP로 채우는 퀘스트와 횟수를 계산하고, 그 첫 퀘스트를 열어 둔 퀘스트 판에서 반복 실행합니다. 이번 베타는 1단계입니다. 장 목록·지도 이동은 하지 않으며, 경로의 첫 퀘스트 하나만 돌립니다.**

KR·JP 서버에서만 동작하고 인터넷이 필요합니다. 베타 전용 기능이며 정규판(1.5.0)에는 없습니다.

## 시작하는 방법

1. 게임에서 **돌릴 퀘스트의 지점을 눌러 퀘스트 판을 엽니다.** 확인 창에 나온 경로의 **첫 퀘스트**가 퀘스트 판의 **맨 위**에 있어야 합니다. 맨 위가 편성 조건이 있는 미션 퀘스트라면 FGA가 정지합니다.
2. FGA 재생 버튼을 누릅니다. 설정 창 왼쪽 아래의 **주간 미션 클리어** 버튼을 누릅니다. (JP·KR 서버에서만 보입니다.)
3. 이번 주 미션 데이터를 내려받아 경로를 계산하고 **경로 확인 창**을 띄웁니다.
4. 창에서 전투 설정을 고르고, 필요하면 횟수나 장을 조정한 뒤 **첫 퀘스트 실행**을 누릅니다.

## 경로 확인 창

| 항목 | 설명 |
|---|---|
| 이번 주 미션 | 게임의 주간 미션 목록(서버 언어)입니다. |
| 수동 미션 | 계산하지 못하는 미션입니다(예: 재료·피스 획득). 경로에 들어 있지 않으니 직접 채우세요. |
| 경로 | 퀘스트별 `장 / 지점 / 퀘스트 이름 · AP`와 횟수입니다. 횟수는 0부터 직접 바꿀 수 있습니다. 맨 아래에 **총 AP**가 표시됩니다. |
| 장 선택 | 아직 열지 않은 장은 끄세요. 끄면 경로를 다시 계산합니다. 기본은 모두 켬입니다. |
| 제외됨 | 믹틀란(Lostbelt No.7)은 지도가 층 버튼으로 바뀌어 항상 제외합니다. |
| 전투 설정 | 퀘스트를 돌 때 쓸 기존 FGA 전투 설정입니다. 광역 연사 설정을 고르세요. |

계산은 주간 미션마다 "필요한 수 이상"을 채우는 **정수 최소 AP**입니다. 반복 가능한 메인 스토리 프리 퀘스트(메인 레코드 1 · 1.5 · 2)만 후보입니다. 후유키의 `위험지대`처럼 한 번만 할 수 있는 퀘스트와 이벤트·미션 퀘스트는 뺍니다. 적 처치 수는 소환된 적을 빼고, "일부 보스 제외" 문구가 있는 미션은 그 규칙을 따릅니다.

지원하는 미션 조건은 **적 특성, 적 클래스, 서번트 클래스, 특정 적, 퀘스트 클리어(횟수), 퀘스트 특성 조건**입니다. 그 밖의 조건은 모두 수동으로 분리합니다. "이번 주 마스터 미션을 모두 클리어" 미션은 다른 미션을 채우면 저절로 달성되므로 경로에 넣지 않습니다.

KR은 같은 퀘스트 ID의 **JP 적 구성**으로 계산합니다(창에 "KR 적 구성은 JP 데이터 기준"이 표시됩니다). KR에 있는 퀘스트만 후보이고, KR과 JP의 AP가 다른 퀘스트는 뺍니다.

## 1단계가 하는 일

확인을 누르면 **경로에서 횟수가 1 이상인 첫 퀘스트**만 실행합니다.

1. 열려 있는 퀘스트 판의 맨 위 판을 읽습니다. 아무것도 누르지 않고 다음 세 가지를 확인합니다.
   - **Free Quest 표시**가 있는 프리 퀘스트일 것
   - **AP**가 경로의 AP와 같을 것(숫자를 읽어 대조)
   - **퀘스트 이름의 길이**가 경로의 이름과 비슷할 것
2. 모두 맞으면 기존 FGA 전투를 **정한 횟수**만큼 실행합니다. 서포트 선택, 전투, 연속 출격, AP 회복(사과 사용·대기·정지)은 기존 FGA 설정을 그대로 따릅니다. 정한 횟수는 기존 `실행 횟수 제한`으로 들어가고 끝나면 꺼집니다.
3. 하나라도 맞지 않으면 아무것도 시작하지 않고 이유를 알려 줍니다.

**이름 확인의 한계**: 앱에 일본어·한국어 문자 인식 데이터가 없어서 이름 글자를 읽지는 못합니다. 대신 이름 글자가 차지하는 **가로 길이**로 글자 수를 추정해 비교합니다. 길이가 크게 다른 퀘스트는 걸러내지만 같은 길이의 다른 퀘스트까지 구별하지는 못합니다. 그래서 AP와 Free Quest 표시를 함께 보며, **확인 창에 나온 이름과 열어 둔 퀘스트 판의 이름이 같은지는 직접 확인하세요.**

## 데이터와 캐시

- 데이터는 Atlas Academy의 공개 데이터입니다(`api.atlasacademy.io`).
- 처음 한 번(주마다) 약 14초가 걸립니다(JP, 296개 퀘스트). 같은 주에는 저장해 둔 결과로 바로 열립니다. 다음 주 월요일 0시(JST) 이후 처음 실행하면 새로 내려받습니다.
- 저장하는 것은 계산에 쓰는 작은 결과(몇 MB)뿐이며 앱 캐시 폴더에 둡니다. 계산 자체는 20밀리초 안팎입니다.

## 정지 메시지

| 메시지 | 뜻과 대처 |
|---|---|
| 퀘스트 판을 찾지 못했습니다 | 퀘스트 판이 열려 있지 않습니다. 퀘스트 판을 연 뒤 다시 시작하세요. |
| 맨 위 판이 프리 퀘스트가 아닙니다 | 맨 위가 미션 퀘스트(편성 조건)이거나 다른 화면입니다. 경로의 퀘스트가 맨 위에 오도록 연 뒤 다시 시작하세요. |
| 판의 AP를 읽지 못했습니다 | AP 숫자가 가려졌습니다. 화면을 가리는 것이 없는지 확인하세요. |
| 판의 AP는 N이지만 ...의 AP는 M입니다 | 다른 퀘스트의 판입니다. 경로의 퀘스트 판을 여세요. |
| 판의 퀘스트 이름이 ...와 맞지 않아 보입니다 | 이름 길이가 다릅니다. 경로의 퀘스트 판을 여세요. |
| 주간 미션 데이터를 불러오지 못했습니다 | 인터넷 연결이나 Atlas Academy 접속을 확인하세요. |
| 경로를 계산하지 못했습니다 | 계산 한도를 넘었습니다. 장 선택으로 후보를 줄여 보세요. |

전투가 시작된 뒤의 정지(AP 부족, 패배 등)는 기존 FGA 전투와 같습니다.

## 진단 로그

태그는 `WeeklyRoute`입니다. 베타에서도 INFO 로그를 기록합니다. 데이터 불러오기(주 번호, 후보 수, 시간, 뺀 퀘스트와 이유), 확인한 경로, 퀘스트 판 읽기 결과(Free 여부, AP, 이름 길이, 판정)와 정지 이유를 남깁니다.

```text
adb -s 127.0.0.1:5555 logcat -s WeeklyRoute
```

## 알려진 한계

- 1단계는 퀘스트 하나만 실행합니다. 장 목록·지도 이동과 여러 퀘스트 연속 실행은 다음 단계입니다.
- 퀘스트 판 읽기는 JP·KR 16:9 캡처로 검증했습니다(자료 3장: JP Free 퀘스트, JP 미션 퀘스트가 맨 위, KR Free 퀘스트). 16:9보다 넓은 화면(18:9 초과)의 좌표와 AP 숫자 읽기의 다른 값은 아직 확인하지 못했습니다.
- Atlas의 적 구성과 게임의 실제 적이 다르면 미션이 덜 채워질 수 있습니다. 진행도는 게임의 주간 미션 화면에서 직접 확인하세요.
- 믹틀란은 항상 제외합니다. 지도가 둘 이상인 다른 장은 다음 단계에서 다룹니다.
