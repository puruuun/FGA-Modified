# 전투 로그

메인 화면의 **로그**에서 전투 종료 기록을 최신순으로 확인합니다. 폭이 840dp 이상인 넓은 화면에서는 왼쪽에 목록, 오른쪽에 선택한 기록의 상세를 함께 보여 줍니다. 처음에는 가장 최근 기록이 선택되며, 선택한 기록을 삭제하면 가장 최근 기록으로 넘어갑니다. 좁은 화면에서는 카드를 누르면 종료 화면과 같은 상세 요약이 열립니다. 수집 중인 **스크립트 밖 변화**가 있으면 **진행 중** 표시로 맨 위에 나타나고 변화마다 갱신됩니다.

카드는 두 줄로 표시합니다. 첫 줄은 설정 이름·작고 옅은 계정 이름과 오른쪽 종료 일시, 둘째 줄은 주회 수·평균 턴·**추적됨**·종료 이유입니다. 스크립트 밖 카드의 둘째 줄은 해당 기간에 처음 등장한 순서대로 **선물함 · 미션** 같은 출처를 표시합니다. 진행 중인 기간은 **진행 중 ·**으로 시작하며, 출처가 길면 한 줄 끝에서 줄임표로 표시합니다. 전투 카드는 회색이며, 스크립트 밖 카드는 별도 색을 유지합니다. 두 종류 모두 선택했을 때만 같은 테두리가 붙습니다.

로그 수집으로 기록된 전투 카드는 제목 왼쪽에 열쇠 아이콘이 표시되며, 화면 인식만으로 기록된 전투 카드는 아이콘 없이, 스크립트 밖 변화와 진행 중 카드는 기존의 양방향 화살표 아이콘으로 표시됩니다.

전투 스크립트가 끝났을 때 완료한 주회가 1회 이상이면 한 건을 자동으로 저장합니다. 주간 미션 경로가 끝날 때 표시하는 전투 종료 요약도 저장합니다. **일시정지 중 상태 확인 화면**과 **0회 주회**는 기록하지 않습니다.

기록에는 당시의 전투 설정 이름, 종료 시각·이유, 주회 수·제한, 사과 사용량·제한, 최소·평균·최대 턴 수, 전체·평균 전투 시간, 개념예장 드롭 수와 전멸·턴 제한 퇴각 횟수가 담깁니다. 종료 이유는 저장할 때의 언어로 남습니다.

**재료**는 재료 카운트를 켜서 집계된 항목이 있을 때, **인연포인트**는 인연 추적 기능을 켰을 때만 상세 화면에 표시합니다.

[로그 수집 (KR)](Gains-Tracker-KR.md)의 VPN이 실행 중이었다면 카드에 **추적됨**이 붙습니다. 상세의 **획득량 (로그 수집)**에서 서버 응답 기준 아이템·QP·마스터 EXP·서번트별 인연, 과일과 그 밖의 사용한 아이템(스톰 포드, 티팟 등) 사용량, 접힌 전투별 내역을 확인합니다. 획득·사용 타일은 화면 폭에 맞춰 줄바꿈하며 아이템은 아이콘·짧은 이름·개수, 재화는 아이콘·개수로 표시합니다. 타일을 누르거나 길게 눌러도 팝업은 열리지 않으며, 화면 읽기 도구에는 이름과 개수를 제공합니다. 이미지 실패 시 이름으로 대체합니다. KR 데이터에 아직 없는 아이템은 KR 데이터가 갱신될 때까지 일본어 이름으로 표시합니다. 아이콘은 화면에 표시할 때 없는 파일만 Atlas의 공개 HTTPS 서버에서 한 번 내려받아 앱 내부에 영구 보관합니다. 이후에는 저장된 파일을 사용하며 계정 데이터를 전송하지 않습니다. 추적하지 못한 전투가 있으면 누락 안내가 표시됩니다. 추적 기록이 없는 로그는 기존 요약만 표시합니다.

**스크립트 밖 변화** 상세에서는 합계와 펼친 출처별 내역에 QP·성정석·프렌드 포인트 등 재화의 증감을 부호와 자릿수 구분으로 표시합니다. 프렌드 포인트만 변해도 기록이 시작되거나 진행 중 기록에 이어집니다. 프렌드 포인트 소환의 사용량과 응답에 포함된 새 서번트·개념예장은 **소환** 내역에서 확인합니다. 서포트 사용 보상처럼 다른 경로로 받은 프렌드 포인트는 해당 응답의 출처에 집계합니다.

상단 **삭제** 옆의 **필터 아이콘**을 누르면 날짜·프로필·획득 자원·로그 보관 개수를 설정하는 창이 열립니다. 날짜는 **오늘 / 7일 / 30일 / 전체** 또는 **기간 지정**에서 시작일과 종료일을 고릅니다. 기간은 기기의 현지 날짜와 기록의 종료 시각을 기준으로 하며 양 끝 날짜를 포함합니다. 프로필은 **전체** 또는 보관된 로그에 등장하는 프로필 이름(이름이 없으면 **#계정 ID**)으로 고릅니다. 선택한 프로필의 전투·스크립트 밖 기록만 표시하며, 계정 ID가 없는 기록(로그 수집을 끄고 실행한 기록, 프로필 정보가 없는 예전 기록)은 **전체**에서 보이며, 그런 기록이 하나라도 있으면 프로필 목록 끝에 나타나는 **프로필 없음**을 고르면 그 기록만 표시합니다. 선택한 프로필(또는 **프로필 없음**)의 기록이 없으면 **전체**를 표시합니다. 회전이나 화면 복원 후 기록을 읽는 동안에도 선택한 프로필을 기억하며, 해당 프로필의 기록이 나타나면 필터를 다시 적용합니다. 프로필은 날짜·자원 조건과 함께 적용되며, 자원 선택 목록도 선택한 날짜와 프로필의 기록을 따릅니다. 자원은 이 기록에 등장하는 이름과 아이콘 중에서 고르고, 해당 자원을 획득한 두 종류의 기록을 표시합니다. 프렌드 포인트도 QP와 같은 방식으로 자원 목록에 표시하며, 스크립트 밖 기록은 해당 자원을 획득한 내역이 있을 때 필터에 나타납니다. **적용**을 누르면 조건이 반영됩니다. 필터가 켜져 있으면 아이콘에 작은 표시와 목록 위 한 줄 요약이 나타나며 **해제**로 초기화합니다. 필터와 설정 중인 조건은 회전해도 유지되고, 결과가 없으면 필터 안내를 표시합니다.

**로그 보관 개수 (종류별)**는 **50 / 100 / 200** 중에서 고르며 기본·최대는 **200**입니다. 이전에 저장된 **500**이나 지원하지 않는 값은 **200**으로 처리하며, 기존 로그 정리가 실행되면 종류별 최신 200건을 넘는 오래된 기록은 삭제됩니다. 전투 기록과 스크립트 밖 기록에 각각 같은 한도를 적용하고 설정을 저장합니다. 현재 기록 수보다 작은 한도로 줄일 때는 확인 창을 거친 뒤 가장 오래된 기록부터 지웁니다. 확인을 취소하면 보관 설정과 기록은 그대로 유지됩니다. 이후 한도를 초과하면 오래된 기록부터 지웁니다. 상단 **삭제**를 눌러 선택 모드에 들어간 뒤 체크하고 **선택 삭제**를 누릅니다. **전체 삭제**는 필터에 가려진 기록까지 모두 지우며, 두 동작 모두 확인 창을 거칩니다. **취소**는 선택을 버립니다. 진행 중 기록도 지울 수 있으며 이후 새 변화부터 새 기간이 시작됩니다. 삭제한 기록은 복구할 수 없습니다. Chaldea 내보내기는 **더 많은 옵션 → 추가 기능**에서 사용합니다.

계정별 최신 활동은 메인 화면의 계정 카드를 눌러 **계정 대시보드 → 최근 활동**에서도 확인합니다. 자원 타일은 모두 같은 높이로, 종료 시 보유량·무료/유료 구분을 아이콘 오른쪽의 둘째 줄에 표시합니다.

**더 많은 옵션 → 저장소 → 로그 아이콘 데이터 다운로드**에서 재료·재화·과일 아이콘을 미리 받을 수 있습니다(서포트 이미지 추출과는 별개). 첫 다운로드는 약 15 MB이며 이벤트 아이템은 제외합니다. 이미 받은 파일은 로그와 대시보드가 함께 사용합니다. [아이콘 준비와 진행 표시](Default-Support-Images-KR.md)
