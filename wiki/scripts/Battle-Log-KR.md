# 전투 로그

메인 화면의 **로그**에서 전투 종료 기록을 최신순으로 확인합니다. 폭이 840dp 이상인 넓은 화면에서는 왼쪽에 목록, 오른쪽에 선택한 기록의 상세를 함께 보여 줍니다. 처음에는 가장 최근 기록이 선택되며, 선택한 기록을 삭제하면 가장 최근 기록으로 넘어갑니다. 좁은 화면에서는 카드를 누르면 종료 화면과 같은 상세 요약이 열립니다. 수집 중인 **스크립트 밖 변화**가 있으면 **진행 중** 표시로 맨 위에 나타나고 변화마다 갱신됩니다.

카드는 두 줄로 표시합니다. 첫 줄은 설정 이름·작고 옅은 계정 이름과 오른쪽 종료 일시, 둘째 줄은 주회 수·평균 턴·**추적됨**·종료 이유입니다. 전투 카드는 회색이며, 스크립트 밖 카드는 별도 색을 유지합니다. 두 종류 모두 선택했을 때만 같은 테두리가 붙습니다.

전투 스크립트가 끝났을 때 완료한 주회가 1회 이상이면 한 건을 자동으로 저장합니다. 주간 미션 경로가 끝날 때 표시하는 전투 종료 요약도 저장합니다. **일시정지 중 상태 확인 화면**과 **0회 주회**는 기록하지 않습니다.

기록에는 당시의 전투 설정 이름, 종료 시각·이유, 주회 수·제한, 사과 사용량·제한, 최소·평균·최대 턴 수, 전체·평균 전투 시간, 개념예장 드롭 수와 전멸·턴 제한 퇴각 횟수가 담깁니다. 종료 이유는 저장할 때의 언어로 남습니다.

**재료**는 재료 카운트를 켜서 집계된 항목이 있을 때, **인연포인트**는 인연 추적 기능을 켰을 때만 상세 화면에 표시합니다.

[로그 수집 (KR)](Gains-Tracker-KR.md)의 VPN이 실행 중이었다면 카드에 **추적됨**이 붙습니다. 상세의 **획득량 (로그 수집)**에서 서버 응답 기준 아이템·QP·마스터 EXP·서번트별 인연, 과일 사용량과 접힌 전투별 내역을 확인합니다. 획득·사용 타일은 화면 폭에 맞춰 줄바꿈하며 아이템은 아이콘·짧은 이름·개수, 재화는 아이콘·개수로 표시합니다. 타일을 길게 누르거나 누르면 이름을 볼 수 있고 이미지 실패 시 이름으로 대체합니다. 아이콘은 Atlas의 공개 파일만 내려받아 앱 내부에 캐시하며 계정 데이터를 전송하지 않습니다. 추적하지 못한 전투가 있으면 누락 안내가 표시됩니다. 추적 기록이 없는 로그는 기존 요약만 표시합니다.

목록 위의 **오늘 / 7일 / 30일 / 전체**와 **획득 자원** 필터를 함께 사용할 수 있습니다. 기간은 현지 날짜로 오늘을 포함하며 종료 시각 기준입니다. 자원은 보관된 수집 기록에 등장하는 이름 중에서 고르고, 해당 자원을 획득한 두 종류의 기록을 표시합니다. 필터는 회전해도 유지되며 결과가 없으면 필터 안내를 표시합니다.

앱 내부에 최근 **200건**을 보관하며, 초과하면 가장 오래된 기록부터 지웁니다. 상단 **삭제**를 눌러 선택 모드에 들어간 뒤 체크하고 **선택 삭제**를 누릅니다. **전체 삭제**는 필터에 가려진 기록까지 모두 지우며, 두 동작 모두 확인 창을 거칩니다. **취소**는 선택을 버립니다. 진행 중 기록도 지울 수 있으며 이후 새 변화부터 새 기간이 시작됩니다. 삭제한 기록은 복구할 수 없습니다. Chaldea 내보내기는 **메인 → 도구**에서 사용합니다.
