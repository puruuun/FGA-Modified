# 전투 로그

메인 화면의 **로그**에서 전투 종료 기록을 최신순으로 확인합니다. 폭이 600dp 이상인 넓은 화면(태블릿, 가로 방향, BlueStacks)에서는 왼쪽에 목록, 오른쪽에 선택한 기록의 상세를 함께 보여 줍니다. 처음에는 가장 최근 기록이 선택되며, 선택한 기록을 삭제하면 가장 최근 기록으로 넘어갑니다. 좁은 화면에서는 카드를 누르면 종료 화면과 같은 상세 요약이 열립니다.

전투 스크립트가 끝났을 때 완료한 주회가 1회 이상이면 한 건을 자동으로 저장합니다. 주간 미션 경로가 끝날 때 표시하는 전투 종료 요약도 저장합니다. **일시정지 중 상태 확인 화면**과 **0회 주회**는 기록하지 않습니다.

기록에는 당시의 전투 설정 이름, 종료 시각·이유, 주회 수·제한, 사과 사용량·제한, 최소·평균·최대 턴 수, 전체·평균 전투 시간, 개념예장 드롭 수와 전멸·턴 제한 퇴각 횟수가 담깁니다. 종료 이유는 저장할 때의 언어로 남습니다.

**재료**는 재료 카운트를 켜서 집계된 항목이 있을 때, **인연포인트**는 인연 추적 기능을 켰을 때만 상세 화면에 표시합니다.

앱 내부에 최근 **200건**을 보관하며, 초과하면 가장 오래된 기록부터 지웁니다. 각 카드의 **기록 삭제** 버튼이나 목록 위 **전체 삭제**를 누르면 확인 창을 거쳐 삭제합니다. 삭제한 기록은 복구할 수 없습니다.
