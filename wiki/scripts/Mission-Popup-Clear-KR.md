# 연속 출격 전 미션 팝업 지우기

퀘스트가 끝난 뒤 화면 위쪽 가운데에 뜨는 미션 달성 팝업이 너무 많이 쌓이면, 다음 전투가 시작된 뒤에도 남아 오른쪽 위의 웨이브·턴 표시를 가릴 수 있습니다. 이 기능을 켜면 연속 출격 창에서 **연속 출격**을 누르기 전에 팝업이 뜨는 자리를 정한 시간 동안 빠르게 연타해 팝업을 미리 지웁니다.

## 설정 방법

**더 많은 옵션 → 배틀**에서 설정합니다. 전역 설정이므로 모든 전투 설정에 함께 적용됩니다.

| 항목 | 설명 |
|---|---|
| 연속 출격 전 미션 팝업 지우기 | 기능을 켜고 끕니다. 기본값은 꺼짐입니다. |
| 연타 시간 | 팝업 자리를 연타할 시간(1~60초)을 정합니다. 기본값은 10초이며, 위 스위치가 켜져 있을 때만 바꿀 수 있습니다. |

## 동작 방식

- **연속 출격 창에서만 동작합니다.** 다른 화면이나 전투 중에는 연타하지 않습니다.
- 연타 위치는 화면 위쪽 가운데(미션 팝업 자리) 한 곳뿐입니다.
- 팝업이 떠 있는지 따로 확인하지 않으므로, **팝업이 없는 주회에도 매번 설정한 시간만큼 주회 시간이 늘어납니다.**
- 한 번에 10회씩 묶음으로 누른 뒤 경과 시간을 확인합니다. **미세 조정**에서 클릭 대기 시간 등을 길게 설정한 경우에는 설정한 시간보다 최대 약 1~2초 정도 더 걸릴 수 있습니다.
- 연타가 끝나면 새 화면에서 연속 출격 버튼을 다시 찾습니다.
  - 연속 출격 버튼이 있으면 평소와 같이 연속 출격을 누릅니다(부스트 아이템 설정 포함).
  - 연타 뒤 연속 출격 버튼이 보이지 않으면 아무 버튼도 누르지 않고 메인 루프로 돌아갑니다. 같은 연속 출격 창에서 다시 버튼을 찾더라도, 이미 한 번 연타했다면 다시 N초를 연타하지 않고 바로 연속 출격을 누릅니다.
- 연타하는 도중에도 정지 요청이 들어오면 즉시 멈춥니다.

## 주의

- 스위치가 꺼져 있을 때는 연타·추가 대기·추가 화면 확인 없이 기존과 똑같이 동작합니다.
- 서버(한국·일본)와 화면 비율(16:9·21:9 등)에 관계없이 화면 위쪽 가운데를 누릅니다.
