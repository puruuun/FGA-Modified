# サポート一覧フィルター

ログ収集がオンのとき、ゲームがサーバーから受け取るサポート一覧から、条件に合わないサポートを除いて表示させる機能です。条件に合うサポートがいない人は一覧から外れ、残る人のそれ以外のサーヴァント枠は空き枠として表示されます。スクリプトのサポート選択（画面判定とタップ）は変わらず、フィルターはゲームが表示する一覧を減らすだけです。

フィルターは一つで、自分で切り替えます。スクリプトの開始や終了でフィルターは変わらないので、スクリプトで回すときも手動でプレイするときも同じフィルターが適用されます。

## オンにする方法

この機能は常に使え、オン・オフのスイッチはありません。再生ボタンのメニューの**サポートフィルター**のチェックボックスでそのつど切り替えます（初期値はオフ）。メニューとボタンはログ収集がオンのときだけ表示されます。**その他のオプション → 追加機能 → サポート一覧フィルター**にはプロファイルだけがあります。

- ログ収集がオフのとき: 戦闘メニューにサポートフィルターは表示されず、何も絞り込みません。サポート一覧は受け取ったままゲームに渡ります。
- ログ収集がオンのとき: 戦闘メニュー（戦闘設定を選んで戦闘を始める再生ボタンのメニュー）下部のボタン列に**サポートフィルター · オン/オフ**ボタンが加わります。サポート選択画面で再生ボタンを押して開いたとき（サポート画像メーカーのボタンも表示されるメニュー）も同じ戦闘設定リストのメニューなので、ボタンがあります。週間ミッションのボタンが表示される条件とは無関係です。フレンドポイント召喚、ルーレット、プレゼントボックスなど他のスクリプトのメニューにはボタンもパネルも表示されず、これまでと同じ見た目です。

## 再生ボタンのメニューで使う

**サポートフィルター**を押すと右側にフィルターパネルが開きます。週間ミッションのパネルと同じ場所を使うので、開くのはどちらか一方です。フィルターパネルは左の戦闘設定の一覧と同じ幅で、最後に開いていたかどうかが記憶され、次にメニューを開いたときも同じ状態で開きます（週間ミッションのパネルを開くと、フィルターパネルは閉じたものとして記憶されます）。下の**週間ミッションクリア**ボタンと**サポートフィルター**ボタンは同じ見た目で、開いているパネルのボタンが強調されます。開いていても周回の上限（回数・素材・礼装）は中央に表示されたままです。週間ミッションのパネルを開いたときは、週間ルートが周回の上限を使わないため、これまでどおり上限の項目は隠れます。ボタンは戦闘メニューにだけあり、パネルには次が表示されます。

- **サポート一覧フィルターのチェックボックス**: 中央の列のオプションと同じチェックボックスです（行のどこを押しても切り替わります）。オンにするとその時点からフィルターが適用され、オフにするとすぐ止まります。状態はアプリを再起動しても残ります。
- **条件の取り込み元**: 今の条件をどこから取り込んだか（戦闘設定の名前またはプロファイル名）。
- **適用中のすべての条件**: サーヴァント（選んだ霊基の見た目を含む）、礼装と最大解放、スキル、アペンド、宝具レベル、最終再臨、クラススコア+62、グランドの条件（グランドサーヴァント、グランドスコア+16、絆礼装の効果、通常・報酬礼装の両方に一致）、フレンドのみ。設定した条件だけが1行ずつ表示されます。
- **取り込み**の行の**スクリプト**ボタン: 左の一覧で選択中の戦闘設定のサポート条件をコピーします。その設定のサポート選択モードに関係なく条件だけを取り込みます。戦闘設定が選択されていないときは押せません。戦闘設定に保存されている霊基の見た目は取り込みません。
- **取り込み**の行の**プロファイル**ボタン: 保存したプロファイルの条件（霊基の見た目を含む）をコピーします。プロファイルがないときは押せません。
- **フィルター結果**の行: 前回受け取ったサポート一覧にフィルターがしたこと（例:「フィルター結果: 20人中6人を表示」）、または「変更なし」。

**スクリプト**も**プロファイル**も条件を**コピー**します。後でその戦闘設定やプロファイルを変えても今のフィルターは変わらないので、変えた内容を使うにはもう一度取り込んでください。再生ボタンのメニューでは条件を編集できません。編集はプロファイルの画面で行います。

### 切り替えた後はサポート一覧を更新してください

ゲームはサポート一覧をまだ持っていないときだけサーバーに一覧を要求します。サポート選択画面を一度開いた後にフィルターを切り替えたり条件を読み込んだりした場合は、ゲームでサポート一覧を**更新**すると新しいフィルターの一覧が表示されます。FGAがゲームに一覧を要求させることはありません。

## プロファイル

**その他のオプション → 追加機能 → サポート一覧フィルター**の**プロファイル**で条件の組を保存できます。プロファイルは戦闘設定とは別に保存され、戦闘設定のエクスポート（.fga）には含まれません。

- **プロファイルを追加**: 名前を付けて空のプロファイルを作り、すぐ編集画面を開きます。
- プロファイルを押すと編集画面が開きます。戦闘設定のサポート優先画面と同じ項目ですが、スクリプトだけが使う項目（宝具画像、フレンド名、フレンド申請）はありません。グランドの項目（グランドサーヴァント、グランドスコア+16、選択する絆礼装の効果、通常礼装＆報酬アップ礼装の両方に一致）はフィルターが適用するので、プロファイルにもあります。**戦闘設定から条件を取り込む**で戦闘設定の条件をプロファイルにコピーすることもできます。
- **有効なフィルターにする**: そのプロファイルの条件を今のフィルターにコピーします（再生ボタンのメニューの**プロファイルを読み込む**と同じです）。
- 右のメニューで**名前を変更**、**削除**ができます。プロファイルを削除しても、すでに今のフィルターにコピーした条件は残ります。

戦闘設定のサポート優先画面は、この機能とは関係なく以前と同じです（フィルターの説明、**フィルター適用**の表示、**霊基の見た目**の項目はありません）。**霊基の見た目**はプロファイルの編集画面でだけ選び、そこでは各条件の横に**フィルター適用**または**画面判定のみ**も表示されます。そのため**スクリプト**で取り込んだ条件に霊基の見た目は含まれず、霊基の見た目は**プロファイル**からだけ取り込めます。

## フィルターが適用する条件

設定した条件を**すべて**満たすサーヴァント枠だけが残ります。

| 条件 | フィルターでの判定 |
|---|---|
| サーヴァント優先 | 選んだサーヴァントのいずれか。空なら任意のサーヴァント |
| 霊基の見た目 | サーヴァントごとに選んだ見た目（第1段階、第2段階、第3段階、最終、霊衣N）のいずれか。選ばなければすべての見た目 |
| 最終再臨 | 最終再臨したサーヴァント |
| スキル最大レベル | 選んだスキルがレベル10 |
| アペンドスキル | 選んだアペンドがレベル10 |
| 宝具レベル | 設定したレベル以上 |
| クラススコア+62 | そのサーヴァントのクラスのクラススコアボード（1〜9番のボード）がすべて解放済み。クラスが分からないサーヴァントは一致しない |
| 礼装優先 / 最大解放 | 選んだ礼装のいずれか（最大解放をオンにするとその礼装が最大解放） |
| グランドサーヴァント | グランドサーヴァントの枠だけが一致。通常のサポート枠は同じサーヴァントでも一致しない |
| グランドスコア+16 | そのサーヴァントのクラスのグランドボード（16マス）がすべて解放済み。セイバー〜バーサーカーはそれぞれのクラスの、シールダー・ルーラー・アヴェンジャー・ムーンキャンサーはエクストラⅠの、アルターエゴ・フォーリナー・プリテンダー・ビーストのクラスはエクストラⅡのグランドボードを見る。クラスが分からないとフィルターは止まる（下記）。そのグランドボードがない人は一致しない |
| 選択する絆礼装の効果 | NPチャージ: 絆礼装があり、効果をNPチャージに切り替えている。通常効果: 絆礼装があり、切り替えていない。判定をスキップする: 見ない |
| 通常・報酬礼装の両方に一致 | グランドサーヴァントの通常礼装枠と報酬アップ礼装枠の両方に選んだ礼装（最大解放をオンにするとそれぞれ最大解放）。オフならどちらか一方 |
| フレンドのみ | フレンドでない人は一覧から外す |

スクリプトと同じく、最終再臨・スキル・アペンドはサーヴァント優先を1騎以上選んだときだけ適用されます。宝具レベルとクラススコア+62はサーヴァント優先を選んだときだけ表示され、最後のサーヴァントを外すとオフになります。グランドの条件もスクリプトと同じ範囲で適用されます。グランドサーヴァントとグランドスコア+16はサーヴァント優先があるときだけ、絆礼装の効果と両方に一致はさらに礼装優先もあるときだけ適用されます。

**画面判定のみ**の条件（フレンド名、サーヴァント名＋宝具による再臨の区別、サポートのクラスタブ）はフィルターでは適用しません。

### グランドサーヴァントの表示

条件に合うグランドサーヴァントがいる人は一覧に残り、**その人のほかのグランドサーヴァントのうち、条件に合わないものは表示されません**。クラスごとにグランドサーヴァントを置いている人でも、条件に合うグランドサーヴァント（1騎とは限りません）だけが残るので、ほかのクラスタブにはその人のほかのグランドサーヴァントが出ません。この規則はグランドの条件をオンにしていないときも同じです。たとえばサーヴァント優先だけを選んだ場合、残る人のグランドサーヴァントのうち、そのサーヴァントでないものは表示されません。グランドサーヴァントの枠は空き枠にせず、一覧から外します。ただし、同じ人が条件に合う通常のサポート枠にも置いているグランドサーヴァントは、グランドの一覧に残ります。グランドサーヴァントをオンにすると通常のサポート枠は一致しないため、残る人の通常のサーヴァント枠は空き枠になります。スクリプトもグランドのラベルがない行は選びません。

**グランドの条件は、受け取った一覧にグランドサーヴァントがいるときだけ適用します。** グランドサーヴァント、グランドスコア+16、絆礼装の効果、通常・報酬礼装の両方一致の4つの条件は、受け取ったサポート一覧に誰もグランドサーヴァントを置いていなければ、その一覧には適用せず、ほかの条件だけで判定します。このときパネルの結果の行の下に「この一覧にはグランドサーヴァントがいないため、グランドの条件は適用しませんでした」と表示されます。KRのサポート一覧にはまだグランドの枠が来ないため、今のKRではグランドの条件は適用されません。サーバー名ではなく受け取った一覧で決めるので、KRにグランドが来ればそのときから同じ規則が適用されます。

### 条件に合う人がいないとき

条件に合う人が一人もいないときは、一覧の最初の一人をサーヴァントなし（すべての枠を空き枠にし、グランドサーヴァントもなし）で残します。サポート一覧が完全に空になると、ゲームのサポート画面がボタンに反応しなくなるためです。結果の行はそのまま「N人中0人を表示」です。残った人には選べるサーヴァントがいないので、一覧を更新するか条件を変えてください。

## フィルターが止まる場合

切り替えがオンでも次の場合はフィルターが動作せず、パネルに赤字で理由が表示されます。

- **ゲームのIDと対応付けられない項目**: 自作の画像など、どのサーヴァント・礼装か分からない画像が条件にあると、欲しいサポートまで隠してしまうおそれがあるため、フィルターは動作しません。該当する項目が表示されます。組み込みの画像と**画像の取得**で取得した画像は対応付けられます。
- **クラススコア+62かグランドスコア+16がオンで、選んだサーヴァントのクラスが分からない**: クラススコアボードと対応付けられるクラスは、セイバー・アーチャー・ランサー・ライダー・キャスター・アサシン・バーサーカー・シールダー・ルーラー・アルターエゴ・アヴェンジャー・ムーンキャンサー・フォーリナー・プリテンダー・ビーストと、JPのボード9に含まれる2つのビーストクラス（Atlasの beastEresh と unBeastOlgaMarie）です。グランドスコア+16も、そのクラスのグランドボードを見つけるために同じクラスを知る必要があります。それ以外のクラスのサーヴァントを選んでクラススコア+62かグランドスコア+16をオンにすると、そのサーヴァントのサポートをすべて隠すことになるため、フィルターは動作せず該当するサーヴァントが表示されます。
- **クラススコア・グランドスコアの条件に必要なサーヴァント一覧がない**: サーヴァントのクラスを知るには端末にサーヴァント一覧が必要です。フレンド管理、アカウント状況、画像の取得でダウンロードされます。フィルターが一覧をダウンロードすることはありません。
- サポート一覧の応答の形が想定と違う場合は、受け取ったままゲームに渡します。
- ログ収集がオフのときはフィルターは動作しません。

## 安全な範囲

- ゲームがサーバーへ送る内容は変更せず、新しいリクエストも送りません。
- 変わるのはサポート一覧の応答だけです。条件に合うサーヴァント枠とそれ以外の内容は受け取ったままです。
- ログ収集がオフ、または切り替えがオフのときは、サポート一覧も受け取ったままゲームに渡します。
- 霊基の見た目の値の対応（第1段階〜最終、霊衣）はまだ実機で確認中です。

## 以前のバージョンからの変更

戦闘設定ごとの**サポート一覧フィルター**スイッチと「優先モードでのみ動作」の規則はなくなりました。アップデート時に一度だけ次のように移されます。

- 手動プレイ用フィルターの条件は今のフィルターの条件として残り、**マイフィルター**というプロファイルとしても保存されます。
- 手動プレイ用フィルターのスイッチの状態が切り替えになります。
- 戦闘設定のスイッチの値は消え、それ以外のサポート設定はそのままです。以前にエクスポートした.fgaファイルもそのまま取り込めます。
