# サポート一覧フィルター

ログ収集がオンのとき、ゲームがサーバーから受け取るサポート一覧から、条件に合わないサポートを除いて表示させる機能です。条件に合うサポートがいない人は一覧から外れ、残る人のそれ以外のサーヴァント枠は空き枠として表示されます。スクリプトのサポート選択（画面判定とタップ）は変わらず、フィルターはゲームが表示する一覧を減らすだけです。

## どこでオンにするか

- **戦闘設定 → サポート → 優先サーヴァント画面** の一番上の **サポート一覧フィルター** スイッチ：この戦闘設定でスクリプトが動いている間に適用されます。初期値はオフです。
- **その他の設定 → 追加機能 → サポート一覧フィルター (手動プレイ)**：スクリプトを使わず手動でプレイするときのフィルターです。戦闘設定と同じ項目を別に保存し、専用のスイッチ（初期値オフ）があります。**戦闘設定から条件を取り込む** ボタンで、戦闘設定ひとつのサポート条件をコピーできます。
- **プレイボタンのメニュー**：手動プレイ用フィルターのスイッチと条件の要約1行があります。編集は追加機能の画面で行います。

戦闘設定のフィルターは、その設定のサポート選択モードが **優先** のときだけ動作します（スクリプトがこれらの条件を読むモードです）。一番上を選択・手動などほかのモードでは、オフと同じです。手動プレイ用フィルターには選択モードはありません。

スクリプトの実行中は、その戦闘設定のスイッチだけが適用され、手動プレイ用フィルターは適用されません。スクリプトが終わると手動プレイ用フィルターに戻ります。ログ収集がオフのときはフィルターは動作せず、画面に案内が出ます。

スイッチの下の **前回の一覧** の行は、最後に受け取ったサポート一覧でフィルターが行ったこと（残った人数とサーヴァント枠数）、または「変更なし」を表示します。

## フィルターが適用する条件

各条件の横に **フィルター適用** または **画面判定のみ** が表示されます。設定した条件を **すべて** 満たすサーヴァント枠だけが残ります。

| 条件 | フィルターでの判定 |
|---|---|
| 優先サーヴァント | 選んだサーヴァントのいずれか。空ならどのサーヴァントでも可 |
| 霊基の見た目（新項目） | サーヴァントごとに選んだ見た目（第1段階、第2段階、第3段階、最終、霊衣N）のいずれか。選ばなければすべての見た目 |
| 最終再臨 | 最終再臨済み |
| スキル最大レベル | 選んだスキルがレベル10 |
| アペンドスキル | 選んだアペンドがレベル10 |
| 宝具レベル | 設定したレベル以上 |
| クラススコア+62 | そのサーヴァントのクラスのクラススコアがすべて解放済み。クラスが分からないサーヴァントは一致しない |
| 優先礼装 / 最大解放 | 選んだ礼装のいずれか（最大解放オンならその礼装が最大解放） |
| フレンドのみ | フレンドでない人は一覧から除く |

最終再臨、スキル、アペンドは、スクリプトと同じく優先サーヴァントを1騎以上選んだときだけ適用されます。宝具レベルとクラススコア+62は優先サーヴァントを選んだときだけ画面に表示され、最後のサーヴァントを外すとオフになります。そのため、サーヴァントを選んでいない設定ではこの2つも適用されません。

**画面判定のみ** の条件（フレンド名、サーヴァント名＋宝具の画像、サポートのクラスタブ、グランドサーヴァント、グランドスコア+16、絆礼装の効果）はフィルターでは適用せず、これまでどおりスクリプトが画面を見て判定します。グランドの条件をオンにした戦闘設定は、残りの条件だけでフィルターされます。

## フィルターが動作しない場合

- **ゲームのIDと対応付けられない項目**：自作の画像など、どのサーヴァント・礼装か分からない画像を選ぶと、欲しいサポートまで隠してしまうおそれがあるため、その設定のフィルターは動作しません。画面に該当項目が表示されます。標準の画像と **画像の取得** で取得した画像は対応付けられます。
- **クラススコアの条件がオンで、選んだサーヴァントのクラスが分からない**：現在クラススコアのボードと対応付けられるのは、セイバー・アーチャー・ランサー・ライダー・キャスター・アサシン・バーサーカー・アヴェンジャー・ムーンキャンサー・アルターエゴ・フォーリナー・プリテンダーの12クラスだけです。それ以外のクラス（ルーラー、シールダー、ビーストなど）のサーヴァントを選んでクラススコア+62をオンにすると、そのサーヴァントのサポートをすべて隠すことになるため、フィルターは動作せず、画面に該当サーヴァントが表示されます。
- **クラススコアの条件に必要なサーヴァント一覧がない**：サーヴァントのクラスは端末にあるサーヴァント一覧から求めます。一覧はフレンド管理、アカウント状況、画像の取得でダウンロードされます。フィルターが一覧をダウンロードすることはありません。
- サポート一覧の応答の形が想定と違う場合は、受け取ったままゲームに渡します。

## 安全範囲

- ゲームがサーバーへ送る内容は変更せず、リクエストを追加することもありません。
- 変わるのはサポート一覧の応答だけです。条件に合うサーヴァント枠とそれ以外の内容は受け取ったままです。
- すべてのスイッチがオフなら、サポート一覧も受け取ったままゲームに渡します。
- 霊基の見た目の値の対応（第1段階〜最終、霊衣）は、まだ実機で確認中です。

以前の実験機能（ログ収集設定の「サポート一覧フィルター (実験)」）はなくなりました。そこで選んだサーヴァントと礼装は手動プレイ用フィルターへ一度だけ移され、スイッチはオフの状態で始まります。
