# FGA (Card Count) 두 서번트 조건 모드

## 설치·업데이트

릴리스의 `FGA-Modified-0.2.0-arm.apk`를 받으세요.

- [수정판 저장소](https://github.com/puruuun/FGA-card-count)
- [0.2.0 릴리스](https://github.com/puruuun/FGA-card-count/releases/tag/v0.2.0)

공개 저장소의 릴리스에서 APK를 받을 수 있습니다.

앱 이름은 **FGA (Card Count)**, 아이콘은 초록색 **Quick**, 패키지는 `io.github.fate_grand_automata.cardcount`입니다. 앞서 배포한 개인 수정판과 같은 패키지·서명을 사용하고 버전 코드를 올려 업데이트 설치할 수 있습니다. 공식 FGA·공식 CI판은 별도 앱이므로 설정은 `.fga`로 내보내 가져오세요.

Android 7 이상 ARM 기기(arm64-v8a / armeabi-v7a)를 지원합니다. 기존 수정판 업데이트에서는 두 번째 조건이 기본적으로 꺼져 있어 기존 단일 조건 설정이 유지됩니다.

## 설정 방법

1. **Battle Configs → 사용할 설정 → 커맨드 시작 조건**에서 **커맨드 카드 개수 선택 모드** 토글을 켭니다. 끄면 기본 모드로 실행합니다.
2. 카드 개수 모드에서는 첫 번째 대상과 필요한 일반 카드 수를 지정합니다. 카드 수는 설정값 이상입니다.
3. 두 번째 대상도 사용할 경우 **두 번째 조건: 대상 서번트**에서 서번트를 고르고 필요한 카드 수를 지정합니다. **사용 안 함**을 고르면 단일 조건으로 동작합니다.
4. 최대 대기 턴을 설정합니다. **0 = 무제한**입니다.
5. 커맨드 시작 조건 박스에는 위 항목만 표시됩니다. 분기별 커맨드·우선순위는 원래 설정 박스에서 편집합니다. **스팸 모드(스킬·보구 자동 사용)는 기존 공통 설정 한 곳에서만 편집**하며 어느 조건으로 시작하든 동일하게 적용합니다.

| 설정 위치 | 카드 개수 모드에서의 표시 |
|---|---|
| 기존 커맨드 박스 | 기존 항목을 1번째 설정의 커맨드 편집으로 표시하고 아래에 2번째 설정 추가 |
| 기존 카드 우선순위 항목 | 기존 항목을 1번째 카드·서번트 우선순위로 표시하고 아래에 2번째 설정 추가 |
| 기존 스팸 모드 | 공통 설정 하나만 표시 |
| 기존 셔플 박스 | 두 조건에 공통인 카드 셔플 설정 하나만 표시 |

기본 설정과 첫 번째 설정을 중복 표시하지 않습니다. 두 번째 분기 항목은 두 번째 대상을 선택했을 때 나타납니다. 기본 모드에서는 기존 설정만 표시합니다. 각 커맨드의 요약과 우선순위 상태를 해당 위치에서 확인할 수 있습니다.

기존 기본 설정과 첫 번째 설정은 동일한 저장값을 사용합니다. 두 번째 커맨드·우선순위는 별도로 저장되며 첫 번째 커맨드가 자동 복사되지 않습니다. 모드 토글을 끄거나 두 번째 대상을 사용 안 함으로 바꿔도 저장된 설정은 보존됩니다. 이전 버전의 첫 번째 스팸·셔플 설정이 공통 설정으로 유지되며, 이전의 두 번째 스팸·셔플 설정은 더 이상 사용하지 않습니다.

대기 중 일반 공격에는 첫 번째 우선순위를 사용합니다. 파티·서버·서포트·자동 적 지정·스킬과 보구 자동 사용·카드 셔플은 공통입니다. 이전의 긴 조건 설명 문장은 설정 화면에서 삭제했습니다.

## 첫 턴 조건 부족 시 셔플 후 재검사

공통 **카드 셔플 → 사용 조건 → 첫 턴 커맨드 시작 조건 불만족**을 선택합니다. 커맨드 카드 개수 선택 모드가 켜져 있어야 동작합니다.

1. 전투 첫 턴(첫 웨이브 첫 턴)의 일반 카드를 인식하고 설정한 시작 조건을 검사합니다.
2. 첫 번째나 두 번째 중 하나라도 충족되면 셔플하지 않고 해당 설정의 커맨드를 시작합니다. 동시에 충족하면 첫 번째가 우선입니다.
3. 두 조건 모두 부족하면 스킬 화면으로 돌아가 마스터 3번 스킬로 셔플을 한 번 시도합니다. 두 번째 조건을 사용하지 않을 때는 첫 번째 조건만 확인합니다.
4. 셔플 후 새 카드로 두 조건을 다시 검사합니다. 충족된 설정의 커맨드를 **같은 턴에 처음부터** 시작합니다.
5. 새 카드도 부족하면 그 새 카드로 일반 공격하고 다음 턴으로 넘깁니다. 이후에는 셔플 없이 시작 조건을 계속 검사합니다.

셔플 자체는 대기 턴 수에 더하지 않습니다. 실제 일반 공격으로 넘겼을 때만 대기 턴 수가 증가합니다. 첫 턴에만 전투당 최대 한 번 시도하며 다음 주회에서 초기화됩니다. 셔플 전에 이미 충분하면 사용하지 않습니다. 커맨드가 시작된 뒤에도 이 옵션으로 다시 셔플하지 않습니다.

마스터 3번 스킬이 카드 셔플인 마술예장을 장착해야 합니다. 카드 인식이 불명확하면 셔플 전·후 각각 같은 손패에서 최대 세 번 확인하고, 계속 실패하면 공격·커맨드를 실행하지 않고 중단합니다. 셔플 후 재검사에서도 첫 번째 조건의 우선순위를 유지합니다.

새 옵션은 첫 턴으로 고정되어 웨이브 숫자 설정을 표시하지 않습니다. **없음**, **효과있는 카드 없음**, **보구와 맞는 카드 없음**은 그대로 유지됩니다. 기존 두 자동 조건은 지정한 커맨드 웨이브에서 커맨드가 시작된 뒤 동작합니다. 기본 모드에서 새 옵션을 선택해도 시작 조건 셔플은 사용하지 않습니다.

## 선택 규칙

두 조건을 같은 카드 화면의 인식 결과로 검사합니다. 각 조건의 개수는 서로 다르게 설정할 수 있습니다.

두 조건 모두 2장 이상인 예시:

| 첫 번째 A | 두 번째 B | 동작 |
|---|---|---|
| 2장 이상 | 2장 미만 | A용 커맨드·우선순위 시작 |
| 2장 미만 | 2장 이상 | B용 커맨드·우선순위 시작 |
| 2장 이상 | 2장 이상 | 첫 번째 A용 설정만 시작 |
| 2장 미만 | 2장 미만 | 일반 공격으로 넘기고 다음 턴 검사 |

B의 카드가 더 많아도 A가 조건을 만족하면 A를 선택합니다. **하나를 선택한 뒤에는 전투가 끝날 때까지 고정**합니다. B로 시작한 뒤 다음 턴에 A 카드가 늘어도 전환하지 않습니다. 다음 주회에서는 다시 두 조건을 검사합니다.

대기 중에는 예약 스킬·보구·Spam과 기존 자동 셔플을 보류합니다. 새 첫 턴 셔플 옵션만 위 순서로 예외 적용합니다. 웨이브가 바뀌어도 계속 대기합니다. 조건이 충족된 동일 턴에 스킬 화면으로 돌아가 선택된 커맨드의 처음부터 실행합니다.

## 웨이브·턴 이동

실제 **2웨이브 3턴**에 조건을 만족한 예시:

| 선택한 커맨드 위치 | 실제 실행 위치 |
|---|---|
| 1웨이브 1턴 | 2웨이브 3턴 |
| 1웨이브 2턴 | 2웨이브 4턴 |
| 2웨이브 1턴 | 3웨이브 1턴 |

선택한 설정의 웨이브별 카드 우선순위·브레이브 체인과 공통 Spam·기존 자동 셔플의 사용 웨이브는 커맨드 기준 웨이브를 따릅니다. 새 셔플 옵션은 기다리기 전 전투 첫 턴에만 적용합니다. 실제 턴 통계에는 기다린 턴도 포함됩니다. 이동한다고 게임에 웨이브가 추가되는 것은 아니므로 뒤쪽 커맨드가 실행되지 않을 수 있습니다.

## 예외 처리

- 같은 서번트를 두 조건에 지정하면 오류를 표시하고 시작을 중단합니다.
- 한 대상이 사망·이탈하면 남아 있는 다른 조건으로 계속 기다립니다. 두 대상 모두 없으면 중단합니다.
- 스턴 등 사용 불가 일반 카드와 보구 카드는 개수에서 제외합니다.
- 카드 소유자나 종류가 불명확하면 같은 턴에서 최대 세 번 확인하고, 계속 실패하면 추가 공격 없이 중단합니다. 이 경우 카드 화면에서 뒤로 돌아간 뒤 다시 실행하세요.
- 대기 제한을 설정하고 그만큼 공격을 넘긴 뒤에도 부족하면 중단합니다. 마지막 허용 대기 이후 조건을 만족한 손패는 시작할 수 있습니다.
- 조건 이전에 전투가 끝나면 커맨드 미실행을 기록하고 다음 주회에서 초기화합니다.

## 보구 + 일반 카드 2장

각 설정에 대상의 보구 하나를 지정하고, 필요 카드 수를 2장 이상, Cards before NP를 0, Brave Chain을 With NP로 설정하세요. 추가 보구가 끼어들지 않도록 공통 스팸 모드에서 NP Spam도 확인하세요.

시작 조건은 보구 게이지나 사용 가능 여부까지 검사하지 않습니다. 스킬이 카드 셔플·변환·교체를 일으키면 실제 카드가 바뀔 수 있어 최신 카드로 선택합니다. 시작 조건을 다시 적용하거나 이미 쓴 스킬을 반복하지 않습니다.

## 검증 범위

- 실행 로직 82개·설정 저장 14개 등 **96개 테스트**가 통과했습니다. 서포트 어펜드 스킬 관련 검증도 포함합니다.
- 첫 턴 셔플 후 A/B/동시 충족, 미달 시 새 카드로 대기 공격, 대기 턴 수, 이후 턴·웨이브의 중복 셔플 방지, 다음 주회 초기화, 셔플 전·후 인식과 화면 복귀 실패 처리를 검증합니다.
- 공통 스팸·셔플 설정의 두 분기 적용과 기존 저장키·내보내기·가져오기 호환, 기본 모드·단일 조건 호환, A/B/동시 충족·대기, 독립 개수, 대상 사망, 선택 고정·초기화, 별도 커맨드·카드·서번트 우선순위·브레이브 체인을 검증합니다.
- 이번 UI 수정판의 앱 컴파일과 ARM APK 빌드, 서명·패키지·버전·업로드 파일 해시를 확인했습니다.

**실제 기기의 설정 화면 시각 검수, FGO 이미지 인식률, 스킬 화면 복귀 및 실제 전투 동작은 아직 검증하지 않았습니다.**

서포트 어펜드 스킬의 설정과 한국·일본 화면 이미지 검증은 [어펜드 스킬 안내](Support-Append-Skills-KR.md)를 확인하세요.

원본 기준은 공식 FGA **v3059**, 커밋 `e138a15273dee9cac342833ee2d8aee93d8ae700`입니다. 버전 코드 `3064`는 개인 수정판 업데이트용이며 공식 v3064를 의미하지 않습니다.

## 소스 빌드

JDK 21과 Android SDK 37을 준비하고 다음을 실행합니다.

```sh
FGA_VERSION_CODE=3064 FGA_VERSION_NAME=0.2.0 ./gradlew :scripts:test :prefs:testCiUnitTest :app:compileDebugKotlin :app:assembleCi
```

두 번째 실행 설정은 동일한 Battle Config 안의 `secondary_` 키들에 저장합니다. 별도 설정 파일을 만들지 않으므로 복사·내보내기·가져오기·삭제에 함께 포함됩니다.
