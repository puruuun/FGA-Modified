# サーヴァント条件モード

指定した前衛サーヴァント（最大3対象）の通常カード条件を満たしたときだけコマンドを開始するモードです。

## 設定方法

1. **バトルの設定 → <使用する設定> → Command start**（コマンド開始条件）で **Command card count mode**（コマンドカード枚数選択モード）トグルをオンにします。オフにすると **Basic mode**（基本モード）で実行します。
2. カード枚数モードでは、最初の対象を選んだあと **Start conditions**（開始条件）の行を追加して条件を作成します。1行は `[Any/B/A/Q ▾] − N +` の形式で、`N` は 1〜5 枚です。
   - **Any**（全体）は対象サーヴァントの使用可能な通常カードの合計枚数、B/A/Q はそれぞれ Buster・Arts・Quick の枚数です。同じ色は1回しか追加できず、色チップ（B：赤、A：青、Q：緑）をタップすると未使用の色へ切り替えられます。
   - **Add condition**（条件追加）は、未使用の最初の色を1枚として行を追加します。`✕` で行を削除でき、行が1つだけのときは `✕` が非表示になります。
   - 行が2つ以上ある場合のみ、見出しに **AND / OR** トグルが表示されます。行の下には `"Start when Buster 2+ and Arts 1+"`（Buster 2枚以上かつ Arts 1枚以上で開始）のような1行要約が表示されます。
3. 2番目の対象も使う場合は、**Second condition: target Servant**（2番目の条件: 対象サーヴァント）からサーヴァントを選び、同じように条件行を個別に構成します。**Not used**（使用しない）を選ぶと単一条件で動作します。
   - 3番目の対象である **3番目の条件: 対象サーヴァント** は、**2番目の条件を使用中のときだけ**表示されます。同様に条件行を構成でき、2番目の条件を **Not used** に戻すと3番目の条件行は隠れ、実行時もオフとして扱われます（保存値は保持されます）。
   - 確認順は **1番目 → 2番目 → 3番目** で、最初に条件を満たした設定から開始します。使用中の対象のうち2つ以上に同じサーヴァントを指定すると開始できません。
   - 3番目の対象をオンにすると、コマンド3とカード優先順位3（スキルメーカー含む）もあわせて表示されます。オンにしない場合は従来の動作と通知のままです。
4. **Maximum skipped turns**（最大待機ターン）を設定します。**0 = Unlimited**（無制限）です。
5. Command start 枠には上記項目のみが表示されます。分岐ごとのコマンドと優先順位は元の設定欄で編集します。**リピートモード（スキル・宝具の自動使用）は従来の共通設定1か所のみで編集**し、どの条件で開始しても同じ設定が適用されます。

| 設定場所 | カード枚数モードでの表示 |
|---|---|
| 従来のコマンド枠 | 既存項目を 1番目設定のコマンド編集（Edit command for setting 1）として表示し、下に 2番目設定を追加 |
| 従来のカードの優先順位項目 | 既存項目を 1番目のカード・サーヴァント優先順位（Card and Servant priorities for setting 1）として表示し、下に 2番目設定を追加 |
| 従来のリピートモード | 共通設定を1つだけ表示 |
| 従来のコマンドシャッフル枠 | 条件共通のコマンドシャッフル設定を1つだけ表示 |

基本設定と1番目設定は重複表示されません。2番目の分岐項目は2番目の対象を選択したときに表示されます。基本モードでは従来の設定のみが表示されます。各コマンドの概要や優先順位の状態はその場所から確認できます。

従来の基本設定と1番目設定は同じ保存値を使用します。2番目・3番目のコマンドと優先順位は別々に保存され、1番目のコマンドが自動コピーされることはありません。モードトグルをオフにしたり対象を Not used に変えても、保存された設定は保持されます。

待機中の通常攻撃には1番目の優先順位を使用します。パーティー、ゲームサーバー、サポート、ターゲットの自動選択、リピートモード、コマンドシャッフルは共通です。

## 1ターン目の条件未達成時にシャッフルして再判定

共通の **コマンドシャッフル → タイミング → Start condition not met on first turn**（1ターン目のコマンド開始条件を満たしていない場合）を選択します。**Command card count mode** がオンになっている必要があります。

1. バトルの1ターン目（ウェーブ1・ターン1）の通常カードを認識し、設定した開始条件を判定します。
2. 1番目・2番目・3番目のいずれかを満たしていれば、シャッフルせずに該当設定のコマンドを開始します。同時に満たした場合は番号の若い方が優先されます。
3. いずれも条件を満たさない場合、スキル画面に戻ってマスタースキル3番でシャッフルを1回試みます。2番目の条件を使わない場合は1番目の条件だけを確認します。
4. シャッフル後、新しい手札で条件をもう一度判定します。条件を満たした設定のコマンドを**同じターンで最初から**開始します。
5. 新しい手札も条件不足の場合は、その手札で通常攻撃を行って次のターンへ進みます。以降のターンではシャッフルせず開始条件の確認を続けます。

シャッフル自体は待機ターン数に加算されません。実際に通常攻撃でターンを進めたときだけ待機ターン数が増えます。1ターン目にのみ1戦闘につき最大1回試行し、次の周回でリセットされます。シャッフル前にすでに条件を満たしていれば使用しません。コマンドが開始された後も、このオプションで再びシャッフルすることはありません。

マスタースキル3番がカードシャッフルの魔術礼装を装備している必要があります。カード認識が不鮮明な場合はシャッフル前後でそれぞれ同じ手札を最大3回確認し、それでも失敗した場合は攻撃・コマンドを実行せず停止します。シャッフル後の再判定でも1番目の条件が優先されます。

この新しいオプションは1ターン目に固定されているため、ウェーブ数の設定は表示されません。**使用しない**、**WEAKカードがない場合**、**宝具使用サーヴァントのカードがない場合** はそのまま残ります。従来の2つの自動条件は、コマンド開始後に指定されたコマンドウェーブで動作します。基本モードでこのオプションを選んでも開始条件シャッフルは実行されません。

## 選択ルール

カード枚数と色別枚数は、いずれも**その条件の対象サーヴァントが持つ使用可能な通常カードだけ**を数えます。他のサーヴァントのカード、スタンなどで使用できないカード、宝具カードは除外します。既存のカード認識結果を使って判定するため、新しい画面確認やタップは追加されません。

条件ごとに1つの **AND / OR** が、合計枚数および 0 より大きいすべての色別最小枚数に適用されます。

- **AND**: 合計枚数と、使用中のすべての色別最小枚数を満たす必要があります。
- **OR**: 合計枚数または使用中の色別最小枚数のうち、いずれか1つを満たせば開始します。
- 行がすべて空の場合は **Any 1枚** として扱います。Any 行がなく色別の行だけがある場合は、その色条件だけを確認します。色別の行がない場合は AND/OR いずれも合計枚数だけを確認します。初期値は **B/A/Q すべて 0、AND** なので、既存の設定や以前のエクスポートファイルはこれまで通りに動作します。

| Any | 結合 | B / A / Q 最小値 | 開始条件 |
|---|---|---|---|
| 2 | AND | 1 / 0 / 0 | 対象カード2枚以上 かつ Buster 1枚以上 |
| 2 | OR | 1 / 0 / 0 | 対象カード2枚以上 または Buster 1枚以上 |
| 1 | AND | 1 / 0 / 0 | **対象に Buster カードがあれば開始** |
| 2 | AND | 1 / 1 / 0 | 対象カード2枚以上、Buster 1枚以上、Arts 1枚以上をすべて満たす |
| 3 | OR | 1 / 1 / 0 | 対象カード3枚以上、Buster 1枚以上、Arts 1枚以上のいずれかを満たす |
| なし | AND | 2 / 0 / 0 | Any 行なしで Buster 2枚以上なら開始 |
| なし | OR | 2 / 0 / 2 | Buster 2枚以上 または Quick 2枚以上なら開始 |

**Any 1 + AND + Buster 1** は Buster が1枚あるだけで Any 1 を自動的に満たすため、色だけを要求する設定になります。Arts や Quick も同じ方法で指定できます。Any 行を削除すると合計枚数条件は使用されません。

待機通知やログには各対象の実際の色別枚数（例: **B1 A0 Q0**、Any 行がない場合は最小枚数を `-` として表示）が表示され、開始通知とログには選ばれた対象の色別枚数が表示されます。OR では表示されている最小枚数より少なくても色条件によって開始する場合があります。

各条件は同じカード画面の認識結果で判定します。条件ごとに異なる枚数を設定できます。

どちらの条件も2枚以上の例:

| 1番目 A | 2番目 B | 動作 |
|---|---|---|
| 2枚以上 | 2枚未満 | A 用のコマンド・優先順位で開始 |
| 2枚未満 | 2枚以上 | B 用のコマンド・優先順位で開始 |
| 2枚以上 | 2枚以上 | 1番目の A 用設定のみ開始 |
| 2枚未満 | 2枚未満 | 通常攻撃で進み、次のターンに判定 |

B のカードが多くても、A が条件を満たしていれば A を選びます。**一度選んだ設定はバトル終了まで固定**されます。B で開始したあと次のターンに A のカードが増えても切り替わりません。次の周回で再び各条件を判定します。

待機中は、予約されたスキル・宝具・リピートモード・従来の自動シャッフルを保留します。上記の1ターン目シャッフルオプションだけが例外として適用されます。ウェーブが切り替わっても待機を続けます。条件を満たした同じターンにスキル画面へ戻り、選ばれたコマンドを最初から実行します。

## ウェーブ・ターンのずれ

実際の **2ウェーブ 3ターン** で条件を満たした例:

| 選択したコマンド上の位置 | 実際の実行位置 |
|---|---|
| 1ウェーブ 1ターン | 2ウェーブ 3ターン |
| 1ウェーブ 2ターン | 2ウェーブ 4ターン |
| 2ウェーブ 1ターン | 3ウェーブ 1ターン |

選ばれた設定のウェーブ別カード優先順位・Brave Chains および共通のリピート・従来自動シャッフルの使用ウェーブは、コマンド基準のウェーブに従います。新しいシャッフルオプションは待機前のバトル1ターン目のみに適用されます。実際のターン統計には待機したターンも含まれます。位置がずれてもクエストのウェーブが増えるわけではないため、後半のコマンドが実行されない場合があります。

## 例外処理

- 同じサーヴァントを複数の有効な条件に指定すると、エラーを表示して開始せず停止します。
- 1つの対象が撃破・離脱しても、残っている他の条件で待機を続けます。すべての対象が場にいなくなると中断します。
- スタンなどで使用できない通常カードおよび宝具カードは枚数から除外します。
- カードの所持サーヴァントや種別が不明瞭な場合は同じターン内で最大3回確認し、それでも失敗すると追加攻撃せず停止します。この場合はカード画面から戻ってからやり直してください。
- 最大待機ターンを設定し、そのターン数だけ攻撃を進めても満たせない場合は停止します。最後の許容待機直後に条件を満たした手札は開始できます。
- 条件達成前にバトルが終了した場合は、コマンド未実行を記録して次の周回でリセットします。

## 宝具 + 通常カード2枚

各設定に対象の宝具を1つ指定し、必要カード枚数を2枚以上、**宝具前に選択するコマンドカード枚数**を `0`、**Brave Chains** を **宝具と同時に** に設定してください。余計な宝具が割り込まないよう、共通のリピートモードの **宝具:** 設定も確認してください。

開始条件は宝具ゲージや使用可否までは確認しません。スキルでカードシャッフル・変化・交代が起きると実際の手札が変わるため、最新の手札から選択します。開始条件を再適用したり、使用済みスキルを繰り返したりすることはありません。
