# ログ収集の初期設定

ログ収集を初めて有効にし、KR または JP サーバーの最初のデータを取得するまでの設定手順です。詳しい動作、アカウントダッシュボード、Chaldea エクスポート、データ削除については [ログ収集](Gains-Tracker-JA.md) をご覧ください。

!!! note "対応条件とセキュリティ"
    - **Android 10 以降**で公式 KR アプリ（`com.netmarble.fgok`）および root 端末の公式 JP アプリ（`com.aniplex.fategrandorder`）に対応しています。BetterFGO やデュアルアプリ・複製アプリには対応していません。
    - 通信はすべて端末内の読み取り専用プロキシ内でのみ処理され、アカウント情報やログイントークンを保存したり外部へ送信したりしません。
    - 証明書ファイルを保存するため、事前に **その他の設定 → ストレージ** で FGA フォルダーを指定しておくことを推奨します（[インストール案内](Installation-JA.md)）。

## 1. ログ収集を有効にして案内に同意する

1. **その他の設定 → 追加機能 → ログ収集** を開きます。
2. **ログ収集を有効にする** スイッチをオンにします。
3. **使用前の案内** を読み、**同意して使用** を押します（**キャンセル**するとオフのままになります）。

## 2. サーバー別の証明書を準備する

収集するサーバーに応じて証明書を準備します。両方のサーバーが準備できていれば、1 回の収集開始で同時に記録できます。

### KR サーバー（root 不要）

1. **KR サーバー → 証明書を作成** を押します。
   - 選択した FGA フォルダー内の `capture/fga-capture-ca.crt` に保存されます（フォルダーが使えない場合はシステム保存画面が開きます）。
2. **インストール方法 → セキュリティ設定を開く** を押します（見つからない場合は端末設定の検索欄で **CA 証明書** を検索してください）。
3. **セキュリティ → 暗号化と認証情報 → 証明書のインストール → CA 証明書** を選び、保存した `fga-capture-ca.crt` を選択します。
4. FGA に戻り、状態が **KR 証明書: CA 証明書としてインストール済み** になっているか確認します。

!!! warning "必ず CA 証明書としてインストールしてください"
    Wi-Fi 証明書など別の種別でインストールすると、ゲーム側が証明書を拒否して収集できません。

### JP サーバー（root 端末専用）

Android 10 以降で公式 JP アプリがインストールされている場合、**JPサーバー（root）** セクションが表示されます。

1. **root権限でJP証明書を自動インストールします** スイッチをオンにし、root 権限の確認ポップアップを許可します。
2. 状態が **JP 証明書: インストール済み** になっているか確認します。
3. すでに JP 版ゲームが起動していた場合は、一度完全に終了してから再起動してください。

!!! note "再起動後の JP 証明書"
    端末を再起動するとシステム CA のマウントは解除されますが、次回ログ収集を開始する際に自動で再インストールされます。

## 3. 接続モードを選択する

**接続 → 接続モード** から、利用環境に合った方式を 1 つ選びます。

| 接続モード | おすすめの環境 | 必要な準備 |
|---|---|---|
| **FGA VPN**（標準） | 他の VPN や広告ブロックアプリを併用しない場合 | 別アプリ・root 不要。初回開始時に Android の VPN 接続許可のみ行います。他の VPN と同時使用はできません。 |
| **外部アプリのプロキシ** | AdGuard などのローカル VPN アプリと併用する場合 | バッテリー最適化の除外、外部アプリへの `127.0.0.1:ポート`（標準 `8899`）登録、FGA の除外および FGO の HTTPS フィルタリング無効化が必要です。手順: [外部アプリのプロキシモード](Capture-AdGuard-JA.md) |
| **ルート** | root 端末で WireGuard などの個人 VPN と併用する場合 | root 権限の許可とカーネル対応（`nat REDIRECT`・`iptables owner`）が必要です。手順: [ルート収集モード](Capture-Root-JA.md) |

## 4. 収集を開始して初回データを確認する

次の 4 か所のいずれかから収集を開始できます。

- **ログ収集画面**: **接続** の **開始**（FGA VPN）または **収集をオン**（外部アプリのプロキシ・ルート）
- **メイン画面**: 右下の青い **ログ収集を開始** ボタン（実行中は黄色の **ログ収集を停止** に変化）
- **FGA サービスと同時開始**: 準備が整っていれば、メイン画面の **サービス開始** でも同時に開始されます。
- **ホーム画面ウィジェット**: ウィジェットのログ収集ボタン（[ホーム画面ウィジェット](Widgets-JA.md)）

収集をオンにした状態で **FGO を新しく起動** します（すでに起動中だった場合は一度終了して再起動、ルートモードではタイトル画面からの再接続など新しい通信から記録されます）。ログイン応答を受信すると、メイン画面上部にマスター名と AP を表示する **プロフィールカード** が現れます。

## つまずきやすい点

- **ゲームが証明書を拒否した警告が出る場合**: KR は **CA 証明書** としてインストールされているか（Wi-Fi 証明書ではないか）、外部アプリのプロキシではプロキシアプリ側で **FGO の HTTPS 復号（フィルタリング）をオフにしているか** 確認してください。
- **Wi-Fi では接続できるのにモバイルデータ（LTE/5G）で接続できない場合**: 収集中は FGO の通信が FGA を経由するため、端末設定で **FGA のモバイルデータ通信** が許可されているか確認してください。
- **収集データの活用先**: メイン画面の **プロフィールカード（アカウントダッシュボード）**、[戦闘ログ](Battle-Log-JA.md)、[フレンド管理](Friend-Manager-JA.md)、[Chaldea自動反映](Chaldea-Sync-JA.md) で確認・利用できます。
