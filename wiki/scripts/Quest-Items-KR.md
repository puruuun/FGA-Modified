# 티포트·스톰포드 자동 사용 — 0.9.2

## 사용하기

1. **더 많은 옵션 → 추가기능 → 티포트·스톰포드 자동 설정 사용**을 켭니다. 새 설정의 기본값은 꺼짐입니다.
2. 한국 또는 일본 서버를 선택하고 재생 버튼을 누릅니다.
3. 실행 창 오른쪽 **AP 회복과 제한 사이 → 아이템 자동 사용**에서 **스톰포드 사용**, **티포트 사용**을 각각 설정합니다.
4. 체크는 ON, 해제는 OFF입니다. 확인을 누르면 선택한 실행 설정으로 시작합니다.

두 선택은 서버별로 기억하며, 개별 전투 설정의 스킬 커맨드나 카드 우선순위에 넣는 설정이 아닙니다. 실행 창의 두 선택은 처음에는 해제돼 있습니다. 위 자동 설정 기능을 켠 경우에만 보이는 아이템을 실행 창에서 고른 ON/OFF로 맞춥니다. 스크립트 설정 파일을 다른 기기로 가져온 경우 실행 창에서 이 항목을 다시 선택하세요.

| 실행 창 선택 | 퀘스트 시작 직전 상태 |
|---|---|
| 둘 다 해제 | 스톰포드 OFF, 티포트 OFF |
| 스톰포드만 체크 | 스톰포드 ON, 티포트 OFF |
| 티포트만 체크 | 스톰포드 OFF, 티포트 ON |
| 둘 다 체크 | 스톰포드 ON, 티포트 ON |

자동 설정 기능이 꺼져 있으면 게임의 상태 검사·변경을 모두 생략합니다. 실행 창의 선택은 유지하며 회색으로 표시합니다. 기능을 켜면 실행 창의 선택을 적용합니다. 이전에 직접 저장한 사용·무시 선택은 유지하며, 선택하지 않은 설정은 기본 꺼짐입니다. 다른 서버에서는 현재 이 제어를 생략합니다.

## 동작

**서포트 선택 → 파티 선택 → 아이템 설정 → 퀘스트 시작** 순서입니다.

**1.0.2-beta.5부터 한국·일본 서버의 파티 확인 화면에서 바로 재생해도** 같은 파티 선택·아이템 검사·출발 과정을 거칩니다. 게임이 파티 확인을 표시하는 연속 주회에서도 검사합니다. 이미 아이템 설정창을 직접 열어 둔 경우에는 먼저 닫고 재생하세요.

동일하게 보이는 메인 버튼을 한 번 눌러 직접 전환형인지 설정창형인지 확인합니다. 직접 전환형이면 변경된 상태를 확인하고 요청한 최종 상태에 맞춥니다. 처음부터 원하는 상태였던 직접 전환형은 두 번째 클릭으로 복구합니다. 아이템은 퀘스트 시작 시 사용되므로 이 확인 클릭으로 소비하지 않습니다.

설정창형이면 **왼쪽 스톰포드 / 오른쪽 티포트**를 각각 확인하고 다른 상태인 항목만 변경합니다. 두 상태를 새 화면으로 확인한 뒤 **닫기**를 누르고, 파티 화면으로 돌아온 것까지 확인합니다. 변경이나 닫기를 확인하지 못하면 퀘스트 시작 전에 중단합니다. 수량 0·0/9 표시는 ON/OFF와 별개이며 상태 판독에 사용하지 않습니다.

아이템 버튼이 없는 파티 화면은 그대로 시작합니다. 하나만 제공되는 퀘스트에서는 보이는 아이템만 제어하고 제공되지 않는 아이템을 임의로 클릭하지 않습니다. 게임의 **빠른 연속 주회**가 파티 확인 화면을 생략하면 이미 맞춰 둔 설정을 그대로 사용하고, 파티 확인 화면을 거치는 시작에서 다시 검사합니다.

## 제공 화면 검증

한국 3장·일본 6장, **전체 게임 화면 9/9장(100%)**에서 표시 형태·아이템 종류·ON/OFF가 일치했습니다. 두 정규화 순서 **18회**, 확대 ON 버튼의 두 축소 배율, 버튼을 제거한 합성 화면 **12회**도 통과했습니다. 실행 창 이미지는 UI 배치 참고이며 상태 판독 검사 수에 포함하지 않습니다.

자동 코드 검사는 두 선택의 네 조합, 각 초기 상태, 직접 전환, 이미 열린 설정창, 지연된 응답, 상태 미확정·변경 실패·닫기 실패 때 시작 차단, 전체 무시를 포함합니다. 실제 Android/FGO 터치 조작과 긴 화면·다른 번역 화면은 아직 확인하지 않았습니다. 제공 자료 기준 100%이며 모든 기기·화면에서 100%를 보장하는 수치는 아닙니다.

```sh
python -m pip install -r tools/np-level-vision-requirements.txt
python tools/verify_quest_item_images.py \
  --input-dir /path/to/티포트 \
  --report quest-item-tests.json
```

[정규 릴리즈 0.7.0](https://github.com/puruuun/FGA-Modified/releases/tag/v0.7.0)에서 APK 하나를 설치하거나 Obtainium으로 업데이트하세요. [English guide](Quest-Items.md).

티포트·스톰포드 설정 과정에서 버튼을 누른 뒤마다 일반 대기 배율과 무관하게 0.1초를 추가로 기다립니다. 설정창 닫기도 포함합니다.

## 1.0.2-beta.5 수정과 회귀 검사

한섭 블루스택에서 설정창의 양쪽 OFF 버튼과 닫기는 인식했지만 제목을 인식하지 못해 출발 전에 멈추는 현상을 재현했습니다. 원본 캡처와 PC 창에서 축소된 캡처의 글자 가장자리 차이로, 기존 제목 이미지의 일치도가 0.878로 내려갔습니다(기준 0.90). 원본 한섭 제목 표본을 추가하고 기존 제목도 유지합니다. 버튼·제목·닫기 확인 기준은 낮추지 않았습니다.

저장된 UI 영역 표본으로 한국·일본의 기존 9개 경우와 새 원본/PC 화면 4개 경우를 다시 검사합니다. 전체 화면을 합성해 게임 화면이라고 간주하는 검사가 아니라, 저장된 좌표에 UI 영역만 배치한 픽셀 회귀 검사입니다. 설정창 제목·닫기·각 버튼을 가린 경우에는 미확정으로 처리하고, 파티 제목이 없으면 파티 시작 화면으로 처리하지 않는지도 확인합니다.

```sh
python tools/verify_quest_item_images.py --reference-crops --report quest-item-regression.json
```

중단 문구는 “스톰포드·티포트 설정 또는 설정창 닫기를 확인하지 못해 퀘스트 시작 전에 중단했습니다.”만 표시합니다.
