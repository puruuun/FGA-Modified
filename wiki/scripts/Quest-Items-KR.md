# 티포트·스톰포드 자동 사용

## 사용하기

1. **더 많은 옵션 → 추가기능 → 티포트·스톰포드 자동 설정 사용**을 켭니다. 새 설정의 기본값은 켜짐입니다.
2. 한국 또는 일본 서버를 선택하고 재생 버튼을 누릅니다.
3. 실행 창 오른쪽 **AP 회복과 제한 사이 → 아이템 자동 사용**에서 **스톰포드 사용**, **티포트 사용**을 각각 설정합니다.
4. 체크는 ON, 해제는 OFF입니다. 확인을 누르면 선택한 실행 설정으로 시작합니다.

두 선택은 서버별로 기억하며, 개별 전투 설정의 스킬 커맨드나 카드 우선순위에 넣는 설정이 아닙니다. 실행 창의 두 선택은 처음에는 해제돼 있습니다. 위 자동 설정 기능을 켠 경우에만 보이는 아이템을 실행 창에서 고른 ON/OFF로 맞춥니다. 스크립트 설정 파일을 다른 기기로 가져온 경우 실행 창에서 이 항목을 다시 선택하세요.

| 실행 창 선택 | 퀘스트 시작 직전 상태 |
|---|---|
| 둘 다 해제 | 스톰포드 OFF, 티포트 OFF |
| 스톰포드만 체크 | 스톰포드 ON, 티포트 OFF |
| 티포트만 체크 | 스톰포드 OFF, 티포트 ON |
| 둘 다 체크 | 스톰포드 ON, 티포트 ON |

자동 설정 기능이 꺼져 있으면 게임의 상태 검사·변경을 모두 생략합니다. 실행 창의 선택은 유지하며 아이템 블록 전체를 숨깁니다. 기능을 켜면 실행 창의 선택을 적용합니다. 이전에 직접 저장한 사용·무시 선택은 유지하며, 선택하지 않은 설정은 기본 켜짐입니다. 다른 서버에서는 현재 이 제어를 생략합니다.

## 동작

**서포트 선택 → 4초 → 파티 선택 → 1초 → 아이템 설정 → 1초 → 퀘스트 시작** 순서입니다. 파티 선택 자체의 1.2초·1초 대기는 유지합니다. 시작을 누른 뒤에는 기존대로 2초 대기 → 부스트 아이템 선택 → 스토리 스킵 준비 → 5초 대기를 거칩니다. 이 대기 순서는 모든 서버에 적용하며 일반 대기 배율을 따릅니다.

**1.6.7-beta.2부터 파티 확인 화면에서 바로 재생하는 시작은 지원하지 않습니다.** 서포트 선택에서 이어지는 시작 순서를 사용하세요. 이미 아이템 설정창을 직접 열어 둔 경우에는 먼저 닫고 재생하세요.

동일하게 보이는 메인 버튼을 한 번 눌러 직접 전환형인지 설정창형인지 확인합니다. 직접 전환형이면 변경된 상태를 확인하고 요청한 최종 상태에 맞춥니다. 처음부터 원하는 상태였던 직접 전환형은 두 번째 클릭으로 복구합니다. 아이템은 퀘스트 시작 시 사용되므로 이 확인 클릭으로 소비하지 않습니다.

설정창형이면 **왼쪽 스톰포드 / 오른쪽 티포트**를 각각 확인하고 다른 상태인 항목만 변경합니다. 두 상태를 새 화면으로 확인한 뒤 **닫기**를 누르고, 메인 아이템 버튼이 요청한 상태로 돌아온 것까지 확인합니다. 변경이나 닫기를 확인하지 못하면 퀘스트 시작 전에 중단합니다. 수량 0·0/9 표시는 ON/OFF와 별개이며 상태 판독에 사용하지 않습니다.

아이템 버튼이 없는 파티 화면은 그대로 시작합니다. 하나만 제공되는 퀘스트에서는 보이는 아이템만 제어하고 제공되지 않는 아이템을 임의로 클릭하지 않습니다. 게임의 **빠른 연속 주회**가 파티 확인 화면을 생략하면 이미 맞춰 둔 설정을 그대로 사용하고, 서포트 선택 뒤의 시작에서 다시 검사합니다.

## 고정 대기로 출발

파티 제목 이미지가 맞지 않아도 출발할 수 있도록 제목 확인과 최대 3초 재시도, 확인 뒤 2초 대기, 건너뛰기 로그를 제거했습니다. 모든 서버에서 위의 4초·1초·1초 순서로 진행합니다. KR·JP 외 서버와 자동 설정을 무시하는 경우에는 아이템 조작을 생략하지만 1초 대기는 유지합니다.

아이템 아이콘이나 ON/OFF 버튼이 없거나 불확실하면 아이템을 누르지 않고 시작을 진행합니다. 설정창 제목·닫기·양쪽 버튼 확인은 유지합니다. 실제 아이템 버튼을 누른 뒤 전환·복구·닫기 결과를 확인하지 못하면 기존 문구로 중단합니다.

저장 화면 기반 Android 검증과 실제 게임 검수는 구분합니다. 소유자가 다음 기능 수정과 함께 게임에서 새 시작 순서를 확인할 예정입니다.
