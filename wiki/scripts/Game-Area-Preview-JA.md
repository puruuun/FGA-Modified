# ゲームエリア

!!! note
    実験的機能です。メニュー名は **ゲームエリア（実験的機能）** で、**その他の設定 → 追加機能** の一番下にあります。

**その他の設定 → 追加機能 → ゲームエリア（実験的機能）** でゲーム画面の範囲を設定します。**デフォルト**、**カスタム**、自分で保存した設定のいずれかを選べます。Surface Duo専用項目は削除されており、以前にその項目を使っていた場合はデフォルトとして読み込まれます。既存のカスタム座標は保持されます。

## 分割画面での調整

### スクリーンショットから自動調整

JP・KRサーバーのメイン画面で **スクリーンショットから自動調整** を使えます。

1. FGAサービスと画面キャプチャをオンにし、ゲームをメイン画面にしておきます。ゲームのポップアップは閉じてください。
2. **その他の設定 → 追加機能 → ゲームエリア（実験的機能）** で **カスタム** を選んだあと、その下にある **スクリーンショットから自動調整** を押します。デフォルト・プリセット状態ではボタンが表示されません。
3. 既存のプレビュー線が一時的に非表示になり、1秒後に画面全体を読み取ります。お知らせとMENUボタンの位置・大きさから実際のゲーム映像の範囲を計算します。分割ウィンドウのタイトルバー・境界線や上下の紺色の余白は保存領域に含めません。
4. 結果ダイアログの左側・上部・右側・下部の値、ゲームサイズと倍率を確認し、ゲーム側のプレビュー線が映像の縁に沿っているか見ます。計算した領域を通常の読み取り経路に適用し、MENUが見えるかも再検査します。
5. **新しい設定として保存** を押すと **自動調整 MM-dd HH:mm** プリセットが新しく作成され、すぐ選択されます。既存のプリセットやカスタム値は変わりません。**キャンセル** すると保存せずに以前のプレビュー状態へ戻ります。

サービス・キャプチャが起動していない場合は先にサービスを開始するよう案内が出ます。JP・KR以外のサーバーは非対応案内が表示されます。お知らせ・MENUが見つからない場合、2つのボタンの倍率が異なる場合、領域を確定できない場合、またはMENU再検査に失敗した場合は保存しません。メイン画面でポップアップを閉じ、画面配置を維持したまま再試行してください。自動調整中はスクリプトを実行しないでください。

保存される値はウィンドウ全体ではなく **ゲーム映像そのものの余白** です。分割比率や向きを変えた場合は調整し直して保存してください。自動調整の結果が合わない場合は下記の手動設定を使用してください。

### 直接座標を合わせる

1. Androidの分割画面でFGOとFGA設定を並べて開きます。FGOのメニューやバトル画面など、実際のゲーム画像の縁が見える画面を使ってください。
2. FGAユーザー補助サービスをオンにし、**ゲームエリア（実験的機能） → カスタム** を選択します。
3. 左側・上部・右側・下部座標の下にある **エリアプレビュー** をオンにします。ユーザー補助サービスがオフの場合はスイッチが無効化され案内が表示されます。デバッグモードは不要です。
4. 座標を調整しながら **緑の線を実際のゲーム画像の縁** に合わせます。分割ウィンドウ全体や上部のタイトルバー、ゲーム外の青い模様まで含めないようにしてください。ボタンを長押ししている間も枠線が更新されます。数字をタップすると直接入力できます。
5. 調整が終わったら設定画面から戻ります。オフセットを変更した後に画面を出るとキャプチャ倍率が1回適用されます。ゲームエリア一覧から項目を選ぶか **リセット** を押しても即座に適用されます。サービスがオフの場合は次にオンにしたとき現在の設定を使います。実行中の画面キャプチャは既存の権限をそのまま使うため、再度キャプチャ許可を求めません。
6. ゲームを実行する画面配置をそのまま保ちます。**分割比率を変えた場合は保存した設定を選び直すか、カスタム座標を調整し直してください。** 配置自体が変わった場合も座標を新しい配置に合わせる必要があります。実行時の自動再調整や範囲警告はありません。

## 最小領域とリセット

ユーザー領域は画面ピクセル基準で **幅1280以上、高さ720以上** である必要があります。各座標の上限は画面サイズと反対側の余白から計算します。最小サイズに達すると対応する **+** ボタンが無効になり、直接入力した数値も許容範囲に制限されます。画面の幅または高さがこれより小さい場合、カスタム座標はすべて0のみ許可されます。

**リセット** はカスタムの4つの座標をすべて0に戻し、キャプチャ倍率を適用します。保存済み設定は削除しません。スクリプト実行中はゲームエリア設定を変更できません。

## 設定の保存・選択・削除

1. カスタムで座標を合わせたあと **設定を追加** を押します。
2. 名前を入力して決定します。初期名は **分割画面 N** です。
3. 保存した名前がゲームエリア一覧に追加されます。選択すると保存された4つの座標とキャプチャ倍率が適用されます。
4. 保存済み設定画面では座標を読み取り専用で確認し、**エリアプレビュー** をオンにできます。修正したい場合はカスタムで調整したあと新しい設定として追加してください。
5. **削除** を押すと選択した設定が削除され、デフォルトに戻ります。同じ名前で保存された別の設定は保持されます。

## 枠線と数値の意味

- **赤い線**: 4つの座標で設定したユーザー領域です。画面を反対側の横向きに回転させると、既存スクリプトと同じく左右基準が入れ替わります。
- **緑の線**: ユーザー領域の中でFGAが実際に認識してタッチするゲーム領域です。ゲーム画面比率に合わせて上下または左右の余白を除外するため、赤い線と異なる場合があります。
- **領域 / ゲーム / 比率**: ユーザー領域と実認識領域の幅×高さ（画面ピクセル）、実認識領域の横/縦比率です。

たとえば3040×1904のタブレットでは、左側1049・上部107・右側0・下部0は分割ウィンドウの大部分を含みますが、中央揃えのため緑の線が実際のゲーム画像より下にズレることがあります。同じ配置での実測値である左側1049・上部432・右側0・下部356はユーザー領域1991×1116を作ります。端末と配置ごとに値が異なるため、数値をそのままコピーするより緑の線を見て確認してください。

## 自動でオフになる場合

スイッチをオフにする、設定画面から出る、アプリが停止状態に入る、またはユーザー補助サービスが切れると枠線は消えます。**スクリプト開始時は画面判別キャプチャの前に消去され**、実行中はオンにできません。設定画面を再び開いてもプレビューはオフの状態です。

プレビューは画面表示機能であり、ゲームを操作したり座標を自動で合わせたりはしません。キャプチャ倍率と認識領域は選択したゲームエリア基準でまとめて計算され、追加権限は不要です。
