# 홈 화면 위젯

홈 화면에 FGA 위젯 두 개를 둘 수 있습니다. 하나는 FGA 서비스를 시작·중지하는 1x1 위젯이고, 다른 하나는 수집한 계정 하나의 AP를 보여 주는 계정 AP 위젯입니다. 두 위젯 모두 어두운 남색 카드 모양입니다.

**KR(한국)·JP(일본) 서버에서만 테스트했습니다.** 계정 AP 위젯은 Android 10 이상에서 [로그 수집](Gains-Tracker-KR.md)을 켜고 계정을 한 번 이상 수집한 경우에만 쓸 수 있습니다.

## 위젯 추가하기

1. 홈 화면의 빈 곳을 길게 눌러 **위젯**을 엽니다.
2. 목록에서 **FGA**를 찾아 **FGA 서비스** 또는 **계정 AP**를 홈 화면으로 끌어 놓습니다.
3. 계정 AP 위젯은 놓는 즉시 **계정 선택** 화면이 나옵니다. 수집한 계정 중 하나를 고르면 위젯이 추가됩니다.

## FGA 서비스 위젯 (1x1)

시작·중지를 한 번에 바꾸는 버튼 하나뿐입니다. 서비스가 멈춰 있으면 원 안의 ▶와 **OFF**, 실행 중이면 ■와 강조색 **ON**이 표시됩니다. 서비스가 시작되거나 멈출 때마다 모든 위젯이 바로 갱신됩니다.

- **OFF에서 누르면** FGA가 열리고 메인 화면의 **서비스 시작** 버튼과 똑같은 순서를 한 번 실행합니다. 저장 폴더 → 알림 권한 → 다른 앱 위에 표시 권한 → 접근성 서비스 → 화면 캡처 허용 → 서비스 시작 순서이고, 로그 수집이 켜져 있으면 마지막에 로그 수집 VPN도 시작합니다.
- 빠진 권한이 있으면 평소처럼 안내 창이 뜹니다. 서비스가 시작되면 FGA 화면이 저절로 닫혀 원래 보던 화면으로 돌아갑니다. 시작에 실패하거나 화면 캡처 허용을 취소하면 FGA 화면이 그대로 남습니다.
- **ON에서 누르면** FGA를 열지 않고 서비스를 중지합니다. 로그 수집은 기존 규칙(설정의 서비스와 함께 중지)에 따라 같이 멈춥니다.

## 계정 AP 위젯 (기본 4x1, 3x1까지 줄일 수 있음)

선택한 계정 하나에 묶여 있으며, 위젯마다 다른 계정을 고를 수 있습니다. 왼쪽은 계정 정보, 오른쪽은 1x1 위젯과 같은 시작·중지 버튼입니다.

| 표시 | 뜻 |
| --- | --- |
| KR/JP 표시, 계정 이름 | 서버 표시와 계정 이름(직접 바꾼 이름이 우선)입니다. |
| 방금 / N분 전 / N시간 전 / N일 전 + 새로고침 아이콘 | 이 계정의 데이터를 마지막으로 수집한 뒤 지난 시간입니다. |
| AP 현재 / 최대 | 저장된 데이터로 지금 시각에 맞춰 계산한 현재 AP입니다. |
| 완충 오후 9:41 (4:35) | AP가 가득 차는 시각과 남은 시간(시:분)입니다. 이미 가득 차 있으면 **AP 가득 참**으로 표시합니다. |
| 막대 | 현재 AP / 최대 AP 비율입니다. |

- 시각은 기기의 언어와 12/24시간제 설정을 따릅니다. 화면은 시스템의 밝은/어두운 테마와 관계없이 어두운 남색으로 표시됩니다.
- **새로고침 아이콘**을 누르면 저장된 데이터로 위젯을 다시 그립니다. 게임이나 서버에서 새로 받아 오지는 않습니다.
- 글자가 잘리지 않도록 위젯 폭이 좁아질수록 일부를 숨깁니다. 4x1보다 조금 좁으면 `AP` 글자를 숨기고, **3x1**로 줄이면 남은 시간 `(시:분)`과 새로고침 아이콘도 숨깁니다. 3x1보다 더 좁게 줄이면 `완충` 글자 없이 시각만 보여 줍니다. 이전 버전에서 3x2로 놓은 위젯도 같은 줄을 위쪽 가운데에 그려 계속 쓸 수 있습니다.
- 정보 부분을 누르면 그 계정의 대시보드가 열립니다.
- AP는 1 AP당 5분 회복으로 계산하며, 메인 화면의 계정 카드와 같은 값입니다. 서버에 접속하지 않습니다.

### 갱신 시점

- 위젯이 하나라도 있으면 15분마다 다시 계산합니다. 위젯을 모두 지우면 갱신도 멈춥니다.
- 로그 수집이 이 계정의 새 데이터를 저장하면 바로 갱신합니다.
- 배터리 절약 기능이 FGA의 백그라운드 작업을 막으면 15분 갱신이 늦어질 수 있습니다.

### 데이터가 오래되었을 때

AP 값은 마지막으로 수집한 데이터를 바탕으로 시간만 흘려 계산한 것입니다. 로그 수집을 켠 채 게임에 접속하지 않았다면, 그 사이에 쓰거나 회복한 AP는 반영되지 않습니다. 정확한 값이 필요하면 위젯의 **데이터 경과 시간**을 확인하고 게임에 다시 접속해 새 데이터를 받으세요.

### 계정 데이터 없음

계정을 삭제했거나, 로그 수집을 껐거나, Android 10 미만이면 위젯에 **계정 데이터 없음**이 왼쪽에 표시되고, 누르면 FGA가 열립니다. 오른쪽 시작·중지 버튼은 그대로 쓸 수 있습니다. 위젯과 계정의 연결은 자동으로 지우지 않으므로, 계정을 다시 수집하거나 로그 수집을 다시 켜면 바로 되살아납니다. 위젯을 홈 화면에서 지우면 연결도 함께 지워집니다.

로그 수집을 꺼 둔 상태이거나 수집한 계정이 없을 때 위젯을 놓으려 하면 **로그 수집으로 계정을 먼저 수집해 주세요**라는 안내가 나오고 위젯은 추가되지 않습니다.

AP가 가득 찼을 때 알림을 보내지는 않습니다.
