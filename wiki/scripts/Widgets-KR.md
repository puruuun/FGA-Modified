# 홈 화면 위젯

홈 화면에 FGA 위젯 두 개를 둘 수 있습니다. 하나는 FGA 서비스를 시작·중지하는 1x1 위젯이고, 다른 하나는 수집한 계정들의 AP를 보여 주는 계정 AP 위젯입니다. 두 위젯 모두 기본은 어두운 남색 카드 모양이고, [위젯 설정](#위젯-설정)에서 밝은 테마와 배경 투명도를 고를 수 있습니다.

**KR(한국)·공식 JP(일본) 서버를 대상으로 합니다.** 계정 AP 데이터는 Android 10 이상에서 [로그 수집](Gains-Tracker-KR.md)을 켜고 계정을 한 번 이상 수집하면 표시됩니다.

## 위젯 추가하기

1. 홈 화면의 빈 곳을 길게 눌러 **위젯**을 엽니다.
2. 목록에서 **FGA**를 찾아 **FGA 서비스** 또는 **계정 AP**를 홈 화면으로 끌어 놓습니다.

계정 AP 위젯은 계정을 고르는 과정 없이 바로 추가됩니다. 이전 버전에서 놓은 위젯도 수집한 모든 계정을 보여 줍니다.

## FGA 서비스 위젯 (1x1)

처음에는 기존과 같은 1x1 크기입니다. 가로로 약 두 칸(2x1)까지 늘릴 수 있고, **로그 수집 버튼 표시**를 켜면 두 칸에서 왼쪽 로그 수집 버튼과 오른쪽 서비스 버튼이 나란히 나타납니다. 한 칸에서는 서비스 버튼만 보입니다.

서비스가 멈춰 있으면 원 안의 ▶와 **OFF**, 실행 중이면 ■와 강조색 **ON**이 표시됩니다. 서비스가 시작되거나 멈출 때마다 두 종류의 위젯에 상태가 반영됩니다.

- **OFF에서 누르면** FGA가 열리고 메인 화면의 **서비스 시작** 버튼과 똑같은 순서를 한 번 실행합니다. 저장 폴더 → 알림 권한 → 다른 앱 위에 표시 권한 → 접근성 서비스 → 화면 캡처 허용 → 서비스 시작 순서이고, 로그 수집이 켜져 있으면 마지막에 로그 수집 VPN도 시작합니다.
- 빠진 권한이 있으면 평소처럼 안내 창이 뜹니다. 서비스가 시작되면 FGA 화면이 저절로 닫혀 원래 보던 화면으로 돌아갑니다. 시작에 실패하거나 화면 캡처 허용을 취소하면 FGA 화면이 그대로 남습니다.
- **ON에서 누르면** FGA를 열지 않고 서비스를 중지합니다. 로그 수집은 기존 규칙(설정의 서비스와 함께 중지)에 따라 같이 멈춥니다.

## 계정 AP 위젯 (기본 4x1, 3x1까지 줄일 수 있음)

**로그 수집 버튼 표시**를 켜면 오른쪽에 **계정 정보 | ▲▼ | 로그 수집 | 서비스** 순서로 표시됩니다. 로그 버튼은 서비스 버튼과 같은 크기이며 열쇠 아이콘으로 구분합니다. 계정 정보가 잘리지 않도록 폭이 250 dp 미만이면 로그 버튼을 숨깁니다. 일반적인 3x1(약 200 dp)에서는 숨겨집니다. 좌우 내용 여백은 약 22 dp이고, 정보와 ▲▼ 사이에도 간격을 둡니다.

왼쪽에는 계정 카드가 한 장 보입니다. 카드와 시작·중지 버튼 사이의 **▲ / ▼ 버튼**으로 계정을 바꿉니다. **▼는 다음 계정, ▲는 이전 계정**이고, 맨 끝에서 누르면 반대쪽 끝으로 돌아갑니다(순환). 어느 계정을 보고 있는지는 위젯마다 기억하며, 15분 갱신이나 새 데이터 저장으로 다시 그려도 보던 계정이 그대로 유지됩니다. 보던 계정이 없어지면 첫 번째 계정으로 돌아갑니다. 현재 계정이 맨 앞에 나오고, 나머지는 마지막으로 데이터를 수집한 시각이 최신인 순서입니다. 오른쪽 시작·중지 버튼은 고정되어 있습니다.

계정은 한 번에 하나씩 보입니다. 계정이 하나뿐이면 ▲ / ▼ 버튼이 나타나지 않습니다. 이름과 AP, 막대가 카드의 둥근 모서리에 붙지 않도록 왼쪽에 여백을 두었습니다.

| 표시 | 뜻 |
| --- | --- |
| 계정 이름 | 직접 바꾼 이름이 우선입니다. |
| 오른쪽 회색의 방금 / N분 전 / N시간 전 / N일 전 | 이 계정의 데이터를 마지막으로 수집한 뒤 지난 시간입니다. |
| 57 / 142 | 저장된 데이터로 지금 시각에 맞춰 계산한 현재 AP와 최대 AP입니다. |
| 완충 오후 8:23 | AP가 가득 차는 시각입니다. 이미 가득 차 있으면 **AP 가득 참**으로 표시합니다. |
| 막대 | 현재 AP / 최대 AP 비율입니다. |

- 시각은 기기의 언어와 12/24시간제 설정을 따릅니다. 화면 색은 시스템 테마가 아니라 [위젯 설정](#위젯-설정)의 테마를 따릅니다. 기본은 어두운 남색입니다.
- 좁은 폭에서도 AP와 완충 시각이 함께 보이도록 글자 크기를 줄입니다. 버튼 칸이 너비를 차지하므로 폭이 좁을수록 글자가 작아집니다.
- 보이는 계정 카드를 누르면 해당 계정의 대시보드가 열립니다.
- AP는 1 AP당 5분 회복으로 계산하며, 메인 화면의 계정 카드와 같은 값입니다.

### 모든 계정을 한 줄로 보기

**위젯 설정 → 표시 방식**을 **모든 계정을 한 줄로**로 바꾸면 ▲ / ▼ 버튼 없이 계정들이 같은 너비의 칸으로 나란히 표시됩니다. 칸 순서는 한 계정씩 보기의 순서(현재 계정, 그다음 최근 수집 순)와 같습니다.

- 각 칸은 위에서부터 **이름**(굵게, 길면 말줄임), **AP 현재 / 최대**(크고 굵게), 그 아래 초록색 **완충 시각**(이미 가득 차 있으면 **AP 가득 참**)입니다. 막대는 없습니다.
- 위젯 폭에 들어가는 만큼만 칸을 보여 주고 나머지 계정은 표시하지 않습니다. 서비스 버튼만 켠 휴대폰 4x1(약 272 dp)에서는 두 계정, 5x1(약 350 dp)에서는 세 계정이 보입니다. 4x1에서 로그·서비스 버튼을 함께 켜면 한 계정이 보입니다. 칸 하나는 약 76 dp 이상을 확보합니다.
- 데이터 경과 시간은 보이는 계정 중 가장 오래된 데이터 기준으로 한 번만 표시됩니다. 휴대폰에서는 버튼 위에, 넓은 위젯에서는 계정 칸과 버튼 사이에 표시됩니다.
- 높이가 짧으면 세 줄이 들어가도록 여백과 글자 크기를 줄입니다. 최소 높이 40 dp에서는 오른쪽 버튼에 아이콘만 표시됩니다.
- 계정 칸을 누르면 그 계정의 대시보드가 열립니다.

### 갱신 시점

- 계정 AP 위젯이 하나라도 있으면 15분마다 다시 계산합니다. 모두 지우면 주기 갱신이 멈춥니다.
- 로그 수집이 계정의 새 데이터를 저장하면 바로 갱신합니다.
- 재부팅하거나 앱을 업데이트하면 배치된 위젯을 다시 그립니다. **에뮬레이터나 휴대폰이 자동 시작을 막아서 로딩 표시가 남으면 FGA를 한 번 열어 주세요.** 앱이 시작될 때도 배치된 위젯을 다시 그립니다.
- 배터리 절약 기능이 FGA의 백그라운드 작업을 막으면 15분 갱신이 늦어질 수 있습니다.

### 데이터가 오래되었을 때

AP 값은 마지막으로 수집한 데이터를 바탕으로 시간만 흘려 계산한 것입니다. 로그 수집을 켠 채 게임에 접속하지 않았다면, 그 사이에 쓰거나 회복한 AP는 반영되지 않습니다. 정확한 값이 필요하면 위젯의 **데이터 경과 시간**을 확인하고 게임에 다시 접속해 새 데이터를 받으세요.

### 계정 데이터 없음

수집한 계정이 없거나, 로그 수집을 껐거나, Android 10 미만이면 왼쪽에 **계정 데이터 없음**이 표시되고, 누르면 FGA가 열립니다. 오른쪽 시작·중지 버튼은 계속 쓸 수 있습니다. 계정을 다시 수집하거나 로그 수집을 다시 켜면 계정 정보가 다시 표시됩니다.

AP가 가득 찼을 때 알림을 보내지는 않습니다.
## 위젯 설정

**더보기 → 고급 → 위젯 설정**에서 두 위젯(1x1 서비스 위젯과 계정 AP 위젯)의 모양을 바꿉니다. 값을 바꾸면 홈 화면에 놓인 위젯이 곧바로 다시 그려집니다.

| 설정 | 선택지 | 기본값 |
| --- | --- | --- |
| **배경 투명도** | 0%에서 100%까지 10% 단위 | 0% (불투명, 기존 모양) |
| **테마** | 어두운 테마 / 밝은 테마 | 어두운 테마 (기존 남색) |
| **표시 방식** | 계정 하나씩 / 모든 계정을 한 줄로 | 계정 하나씩 (기존 모양) |
| **이름 옆에 서버(KR/JP) 표시** | 켜기 / 끄기 | 끄기 |
| **서비스 시작/중지 버튼 표시** | 켜기 / 끄기 | 켜기 |
| **로그 수집 버튼 표시** | 켜기 / 끄기 | 켜기 |

- **로그 수집 버튼 표시**의 기본값은 이제 켜기입니다. 이전에 직접 끄거나 켠 적이 있으면 그 값이 유지됩니다.
- **서비스 시작/중지 버튼 표시**를 끄면 계정 AP 위젯의 서비스 버튼이 사라지고 그 자리까지 계정 영역이 넓어집니다.
- **이름 옆에 서버 표시**를 켜면 계정 이름 옆에 작은 KR / JP 표시가 붙습니다. 두 가지 표시 방식 모두에 적용됩니다.
- 투명해지는 것은 카드 배경뿐입니다. 글자, AP 막대, ▲ / ▼ 버튼, 시작·중지 버튼은 투명도와 관계없이 그대로 보입니다. 1x1 서비스 위젯은 버튼 칸 자체가 카드이므로 그 배경이 투명해지고, 아이콘과 ON/OFF 글자는 그대로 보입니다.
- 밝은 테마는 흰색 카드에 어두운 글자를 쓰고, 완충 시각은 흰 배경에서도 읽히도록 더 진한 초록색으로 표시합니다. 막대 색은 같고 시작·중지 버튼 칸도 밝은 색이 됩니다.
- 모서리는 투명도와 관계없이 Android 10 이상에서 둥글게 유지됩니다.

## 위젯에서 로그 수집 시작·중지

**더보기 → 고급 → 위젯 설정 → 로그 수집 버튼 표시**를 켜고, 로그 수집 기능도 켠 Android 10 이상 기기에서 사용할 수 있습니다. 로그 수집 중에는 열쇠 아이콘(메인 화면의 로그 수집 시작 버튼과 같은 모양)과 **ON**이 노란색 바탕에 표시됩니다. 수집을 시작하거나 중지하면 두 위젯 모두 갱신됩니다.

- **ON에서 누르면** FGA 화면을 열지 않고 즉시 로그 수집을 중지합니다.
- **OFF에서 누르면** 현재 버전의 수집 동의, 인증서 준비, VPN 권한이 모두 갖춰져 있으면 FGA 화면을 열지 않고 수집을 시작합니다.
- 동의나 권한이 빠져 있으면 FGA가 열리고 메인 화면의 로그 수집 버튼과 같은 동의 → 인증서 확인 → VPN 허용 → 시작 순서를 실행합니다. 인증서가 없으면 로그 수집 설정의 인증서 안내 화면으로 이동합니다.
- 실제 수집 시작에 성공하면 FGA 화면이 닫힙니다. 동의나 VPN 허용을 취소하거나 인증서가 없으면 안내된 화면이 그대로 남습니다.
