# 추가 기능 미세 조정

**더 많은 옵션 → 고급 → 추가 기능 미세 조정**에서 추가 기능별 고정 대기 시간과 템플릿 유사도 기준을 조금씩 바꿀 수 있습니다. 기본값에서는 기존 동작과 완전히 같습니다. 바꾼 값은 **다음 스크립트 실행부터** 적용되고, 실행 중인 스크립트에는 영향을 주지 않습니다.

## 구역

| 구역 | 대상 |
|---|---|
| 주간 미션 자동화 | 경로 이동, 배너·버튼 판별, 목록 스크롤바 |
| FP 자동 매각 및 배너 복귀 | 매각 화면 대기, 스크롤바·잠금 판별, 소환 대기 |
| 스킬 / 어펜드 레벨 | 선택·강화·취소·스킵 대기, 라벨·대화상자·패널 윤곽 판별 |
| 예장 자동 강화 | 강화 화면 대기, 추천 표시 판별 |
| 스톰 포드 / 찻주전자 및 퀘스트 시작 | 아이템 조작 후 대기, 재확인 간격, 아이템 상태·아이콘 판별 |
| 인연 추적 및 정지 | 인연 화면 대기, 인연 이미지 판별 |
| 추가 서포트 판독 | NP 이름·레벨, 점수, 스킬 표시, 예장 인연 효과 판별 |

Hakuno 셔플과 카드 우선순위는 대상이 아닙니다.

## 항목

| 항목 | 범위 | 기본값 | 설명 |
|---|---|---|---|
| 대기 배율 | 50~300% (10% 단위) | 100% | 구역의 고정 대기에 곱합니다. 전체 대기 배율이 원래 적용되던 대기에는 두 배율이 함께 적용됩니다. |
| 유사도 보정 | -0.05~+0.05 | 0.00 | 템플릿 판정 기준에 더하고 0.40~0.99로 제한합니다. 음수는 더 약한 일치도 허용합니다. |
| 아이템 조작 후 대기 | 50~1000ms | 100ms | 스톰 포드·찻주전자 탭 뒤 대기입니다. 구역 배율만 적용됩니다. |
| 아이템 재확인 간격 | 100~2000ms | 300ms | 아이템 상태를 다시 읽는 간격입니다. 재시도는 10회로 유지됩니다. |

## 바뀌지 않는 것

안전 확인 간격과 시간 제한, OCR 밝기 기준, 색상 규칙, 잉크 비율, 점수 차이, 좌표는 바꾸지 않습니다.

## 초기화

각 구역의 **기본값으로** 버튼은 그 구역만, **전체 기본값으로** 버튼은 모든 구역을 기본값으로 되돌립니다.

## 사용 팁

- 인식이 자주 실패하면 유사도 보정을 -0.01~-0.02씩 낮춰 보세요. 오인식이 생기면 다시 올리세요.
- 화면 전환이 느린 기기는 대기 배율을 먼저 올려 보세요.
