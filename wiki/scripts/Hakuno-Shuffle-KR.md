# 하쿠노 셔플

**게임의 스킬 사용 확인은 OFF**, FGA의 서번트 일반 카드 판독은 ON이어야 합니다. NP를 써서 카드를 다시 섞는 1스킬을 지정한 조건까지 반복합니다.

스킬 메이커에서 전열 1~3번의 **첫 번째 스킬 → Hakuno Shuffle**을 누르세요. 최소 횟수(기본 0), 최대 횟수(1~30, 기본 10), 전열 위치별 필요 카드 수(1~5장), 미달 시 전투 중단 여부를 정합니다. 조건은 추가·삭제할 수 있고 하나라도 충족하면 성공입니다. 스턴 카드는 세지 않습니다.

직접 입력은 `<스킬>{[최소-]최대:위치장수[|위치장수…][!]}`입니다. 스킬은 `a`·`d`·`g`만 씁니다.

- `a{8:13|22}`: 최대 8회, 전열 1번 3장 이상 **또는** 2번 2장 이상이면 종료합니다. 처음 손패가 맞으면 0회입니다.
- `a{2-8:13|22!}`: 최소 2회 쓰고 검사하며, 최대 8회에도 미달하거나 NP 부족·판독 실패면 전투를 중단합니다.
- `d{30:23}`: 전열 2번의 1스킬을 최대 30회, 전열 2번 일반 카드 3장 이상까지 사용합니다.

NP 부족 창은 닫고 전투 화면으로 돌아옵니다. 카드 판독은 같은 손패를 두 번 더 읽고도 실패하면 종료합니다. `!`가 없으면 미달이어도 남은 커맨드를 계속합니다. 전투 화면 복귀 실패나 일반 카드 판독 OFF는 항상 중단합니다.

이 토큰을 쓴 턴에는 마술예장 셔플을 추가로 쓰지 않습니다. 이후 일반 공격은 기존 카드 우선순위·브레이브 체인·보구 설정을 따릅니다. 실행 결과와 횟수, 전열별 카드 수는 `HakunoShuffle` 로그에서 확인하세요.
