# Chaldea 자동 반영

**로그 수집으로 모은 계정 데이터를 Chaldea의 `userdata.json`에 자동으로 써 넣습니다. Chaldea에서 수동으로 "가져오기"를 하지 않아도 됩니다.** 1단계에서는 아이템 계열만 반영합니다.

Shizuku로 Chaldea의 데이터 폴더(`/sdcard/Android/data/cc.narumi.chaldea/files/user/`)를 읽고 씁니다. KR 서버와 공식 JP 서버의 계정을 지원하며, **로그 수집**이 켜져 있어야 합니다. 기본값은 꺼짐입니다. 꺼져 있으면 FGA는 Shizuku 기능을 호출하지 않고(권한 요청, 연결, 서비스 실행 모두 하지 않음) 아무것도 하지 않습니다. Shizuku가 보내는 연결 정보를 받는 구성 요소(Provider)는 앱 설치 때부터 항상 켜져 있으며, 받기만 할 뿐 아무 동작도 하지 않습니다.

## 준비

1. 기기에 **Shizuku** 앱을 설치하고 실행합니다(무선 디버깅 또는 루트로 시작). Shizuku 13 이상이 필요합니다.
2. FGA의 **로그 수집** 화면에서 로그 수집을 켭니다.
3. 같은 화면 아래의 **Chaldea 자동 반영** 구역에서 **Chaldea에 자동으로 반영** 스위치를 켭니다.
4. 스위치를 켜면 Shizuku가 FGA의 권한을 묻는 창이 뜹니다. **허용**하세요. Shizuku가 아직 실행 중이 아니면 실행된 뒤에 창이 뜹니다. 창이 뜨지 않거나 결과가 돌아오지 않으면 FGA 화면으로 돌아올 때 다시 확인하며(스위치를 켤 때마다 최대 2번), 그래도 허용되지 않았다면 Shizuku 앱에서 FGA를 허용하세요.
5. Chaldea를 한 번 이상 실행해 `userdata.json`이 만들어져 있어야 합니다. 파일이 없으면 FGA는 새로 만들지 않고 "Chaldea 데이터 파일을 찾을 수 없습니다"를 표시합니다.

Chaldea의 **외부 저장소 사용** 설정을 켜서 데이터 위치를 바꾼 경우에는 지원하지 않습니다(기본 위치에 파일이 없으면 쓰지 않습니다). `userdata.json`이나 `.bak`이 16MB를 넘으면(보통은 1MB 정도입니다) 건드리지 않습니다. `cc.narumi.chaldea`와 `cc.narumi.chaldea.fdroid`가 둘 다 있으면 `userdata.json`이 더 최근에 바뀐 쪽을 쓰고, 상태 줄에 어느 쪽을 썼는지 표시합니다.

## 1단계에서 반영하는 것

| 반영함 | 반영하지 않음(다음 단계) |
|---|---|
| 아이템(QP, 성정석, 마나 프리즘, 레어 프리즘 포함) | 서번트 |
| 마술예장 레벨 | 개념예장 |
| 클래스 보드(칸 해방·강화) | 커맨드 코드 |
| 성별 | 서번트 코인 |

- 아이템은 Chaldea의 수동 가져오기와 같은 규칙으로 **덮어쓰기 병합**합니다. 값이 있는 항목만 덮어쓰고, 아무것도 지우지 않습니다.
- **게임에서 사라진 아이템은 Chaldea에 예전 값이 그대로 남습니다.** Chaldea의 수동 가져오기도 같습니다.
- 클래스 보드는 보드 하나를 통째로 바꿉니다. 다른 보드는 그대로 둡니다.
- Chaldea의 계획, 다른 사용자, FGA가 모르는 항목은 건드리지 않습니다. `itemsLeft`(남은 개수)도 쓰지 않습니다.

## 언제 반영하나

- 계정 데이터가 바뀐 뒤 **1분 동안 조용하면** 반영합니다. 같은 내용이면(마지막으로 반영한 내용과 같으면) 아무것도 하지 않고 Chaldea를 닫지도 않습니다.
- **스크립트가 실행되는 동안에는 반영하지 않습니다.** 스크립트가 끝나고 15초 뒤에 반영합니다. 그 사이에 스크립트가 다시 시작되면 취소합니다.
- **지금 반영** 버튼은 각 서버의 현재 계정을 바로 반영합니다(마지막 반영 내용과 같아도 씁니다). 스크립트가 실행되는 동안에는 누를 수 없습니다.
- FGA 프로세스가 시스템에 의해 멈춰 있으면 반영도 멈춥니다. 반영은 **최선을 다하는 방식**이며, FGA가 다시 화면에 나오면 대기 중이던 항목을 이어서 반영합니다.

## Chaldea가 켜져 있을 때

Chaldea는 쓰는 동안 자기 파일을 다시 저장하므로, **Chaldea가 완전히 꺼져 있을 때만** 씁니다.

- Chaldea가 **화면에 보이면**(전체 화면, 화면 분할, 떠 있는 창, 그 상태로 화면이 꺼진 경우) 절대 닫지 않고 기다립니다. 처음 10분은 1분마다, 그 뒤에는 5분마다 상태를 확인합니다.
- Chaldea의 상태를 알 수 없을 때도 닫지 않고 쓰지도 않습니다("Chaldea 상태를 알 수 없습니다").
- Chaldea가 **뒤에서 실행 중**이면 시간을 잽니다. 정한 시간이 지나면 닫기 직전에 상태를 다시 확인한 뒤 강제 종료하고 반영합니다. 그 사이에 Chaldea가 다시 화면에 나오면 시간을 처음부터 다시 잽니다.
- 반영한 뒤 Chaldea가 그 사이 켜졌는지 다시 확인합니다. 켜졌으면 반영한 것으로 치지 않고 나중에 다시 반영합니다.

### 자동으로 닫는 시간

**Chaldea가 뒤에 있을 때 닫기**에서 **10분 후 / 30분 후 / 60분 후 / 닫지 않음** 중에서 고릅니다. 기본값은 30분입니다. **닫지 않음**을 고르면 FGA는 Chaldea를 절대 닫지 않고, Chaldea가 스스로 꺼질 때까지 기다립니다.

**지금 반영**은 Chaldea가 켜져 있으면 닫기 전에 확인 창을 띄웁니다. 확인한 뒤 상태가 바뀌었으면(예: 화면에 나타남) 다시 묻습니다.

## 새 사용자와 이어받기

Chaldea 사용자와 FGA 계정은 **친구 코드**로 짝을 찾습니다. Chaldea 사용자의 `lastImportId`가 계정의 친구 코드와 같으면 그 사용자에게 씁니다. 친구 코드가 아직 없는 계정은 반영하지 않습니다("계정을 확인할 수 없어…").

짝이 없으면:

- Chaldea 사용자가 **하나뿐이고 가져온 적이 없으며 데이터가 완전히 비어 있으면**(기본 사용자) 그 사용자를 이어받아 이름, 지역, 친구 코드를 채웁니다.
- 그 밖에는 **새 사용자**를 추가합니다. 이름은 `게임 닉네임 (KR)` 또는 `(JP)`, 지역은 계정 서버입니다. Chaldea에서 현재 선택된 사용자는 바꾸지 않습니다.
- 새 사용자를 만들거나 이어받는 것은 각 서버의 **현재 계정**뿐입니다. 예전에 로그인했던 다른 계정은 이미 짝이 있는 경우에만 반영합니다.
- 짝이 된 Chaldea 사용자의 지역이 게임 서버와 다르면 지역은 바꾸지 않고 상태 줄에 알려 줍니다.

## 백업

쓰기 전에 Chaldea의 원본 파일 **두 개(`userdata.json`과 `userdata.json.bak`)를 모두** FGA 앱 전용 폴더 `files/chaldea-backup/<패키지 이름>/`에 저장하고, 저장한 파일을 다시 읽어 확인한 뒤에만 씁니다. 백업에 실패하면 쓰지 않습니다. 백업은 폴더 하나에 두 파일이 원래 이름 그대로 들어 있습니다.

- `first-before-fga/`: FGA가 처음 받은 원본. 지우거나 바꾸지 않습니다.
- `backup-…/`: 최근 3개. 마지막으로 FGA가 쓴 내용과 같은 파일이면 새 백업을 만들지 않습니다.
- `inflight-base/`: 쓰는 도중에만 있는 폴더입니다. 쓰기가 확인되면 지웁니다.
- 로그 수집 데이터를 지워도 이 폴더는 지워지지 않습니다.

쓰는 중에 실패하면 `userdata.json`과 `userdata.json.bak`을 **각각 원래 내용으로** 되돌립니다. FGA가 쓰는 도중에 멈춘 경우에는 다음 반영 때 파일을 검사하고, `userdata.json`이 깨졌으면 백업으로 되돌립니다. 이때도 두 파일을 각자 원래 내용으로 되돌리며, 이미 원래 내용 그대로인 파일은 건드리지 않습니다. 되돌릴 수 없으면 다음 메시지가 나오고 백업 폴더는 지우지 않습니다.

- 복구를 확인하지 못하면 최대 3번까지 다시 시도합니다. 그 뒤에는 **모든 반영이 멈춥니다**(상태를 모르는 파일 위에 쓰지 않기 위한 의도된 안전 동작). 스위치를 껐다 켜거나 **지금 반영**을 누를 때까지 아무것도 쓰지 않고, 이유는 상태 줄에 표시하며, 백업은 그대로 남습니다.
- 쓰기가 끝난 것처럼 보여도 `userdata.json.bak`이 원래 내용도 새 내용도 아니면(쓰다가 멈춰 일부만 남은 경우) 중단된 것으로 보고 두 파일을 각자 원래 내용으로 되돌린 뒤 다시 반영합니다. 두 파일이 모두 확인된 뒤에만 백업 폴더(`inflight-base/`)를 지웁니다.

## 루트 기기

루트가 있는 기기에서는 Shizuku 없이도 루트로 같은 일을 합니다.

- 루트를 쓸 수 있으면 **자동으로 루트를 씁니다.** 루트와 Shizuku가 둘 다 가능하면 **루트가 우선**합니다. 루트를 쓰는 동안에는 Shizuku 권한 요청 창을 띄우지 않으며, 상태 줄에는 `권한: 루트`가 표시됩니다.
- **처음 한 번** Magisk나 KernelSU가 FGA에 루트 권한을 허용할지 묻습니다. 스위치를 켤 때(또는 Shizuku 없이 **지금 반영**을 누를 때) 뜹니다. KernelSU는 FGA를 허용 목록에 직접 추가해야 할 수 있습니다.
- Magisk는 FGA를 시작할 때마다 한 번 "루트 권한 허용됨" 토스트를 보여 줍니다. 거슬리면 Magisk의 슈퍼유저 목록에서 FGA의 알림을 끄면 됩니다.
- 루트로 쓴 뒤에도 Chaldea 파일의 소유자와 권한이 그대로인지 확인합니다. 바뀌었으면 원래대로 되돌리고, 되돌리지 못하면 "Chaldea 파일의 소유자나 권한이 바뀌어 되돌리지 못했습니다. 백업은 남아 있습니다."를 표시합니다.
- 스크립트가 실행되는 동안에는 루트 확인도, 루트 연결도 하지 않습니다.
- 루트가 없거나 허용하지 않았으면 위의 Shizuku 방식 그대로 동작합니다.

## 상태 줄 메시지

상태 줄은 서버(KR, JP)마다 **마지막 결과**를 따로 보여 줍니다. 두 서버에 결과가 있으면 줄이 둘이고(`KR: …`, `JP: …`), 하나뿐이면 한 줄입니다. 한 서버가 성공해도 다른 서버의 실패 메시지는 지워지지 않습니다. Shizuku 문제는 언제나 맨 먼저 하나만 보입니다.

| 메시지 | 뜻과 할 일 |
|---|---|
| 꺼져 있음 / 아직 반영할 내용이 없습니다 | 스위치가 꺼져 있거나 반영할 변경이 없습니다. |
| 마지막 반영 …: 아이템 N개, … | 성공. "Chaldea 사용자를 새로 만들었습니다", 지역 안내, 사용한 앱 이름이 덧붙을 수 있습니다. |
| 대기 중: 스크립트 실행 중입니다 | 스크립트가 끝나면 반영합니다. |
| 대기 중: Chaldea가 켜져 있습니다 | Chaldea를 닫거나 백그라운드로 보내면 이어서 진행합니다. |
| 대기 중: Chaldea가 N분째 뒤에 있습니다 | 정한 시간이 지나면 닫고 반영합니다. |
| Shizuku가 설치되어 있지 않습니다 / 실행 중이 아닙니다 | Shizuku를 설치하거나 시작하세요. 시작되면 이어서 반영합니다(재부팅 뒤에도 같습니다). |
| Shizuku가 아직 FGA를 허용하지 않았습니다 / 거부했습니다 | Shizuku 요청에서 또는 Shizuku 앱에서 허용하세요. |
| Shizuku 서비스에 연결할 수 없습니다 | 잠시 뒤 다시 시도합니다. |
| Chaldea 상태를 알 수 없습니다 | 닫지도 쓰지도 않고 기다립니다. |
| 반영 중에 Chaldea가 켜졌습니다 | 나중에 다시 반영합니다. |
| Chaldea 데이터 파일을 찾을 수 없습니다 | Chaldea를 한 번 실행하세요. |
| Chaldea 데이터 폴더에 접근할 수 없습니다 | Shizuku 권한을 확인하세요. |
| 알 수 없는 Chaldea 데이터 버전입니다 | 지원하지 않는 파일 형식이라 수정하지 않았습니다. |
| Chaldea 파일을 읽을 수 없어 수정하지 않았습니다 | `userdata.json`과 `.bak`이 모두 깨졌습니다. Chaldea에서 확인하세요. |
| 백업에 실패해 Chaldea를 수정하지 않았습니다 | 저장 공간을 확인하세요. 다음 변경 때 다시 시도합니다. |
| 계정을 확인할 수 없어 반영하지 않았습니다 | 친구 코드가 아직 수집되지 않았습니다. 게임에 다시 로그인하세요. |
| 반영에 실패해 Chaldea 데이터를 원래대로 되돌렸습니다 | 파일은 그대로입니다. 다음 변경 때 다시 시도합니다. |
| 복원 실패: 백업 위치 … | 되돌리지 못했습니다. 표시된 백업 폴더 안의 `userdata.json`과 `userdata.json.bak`을 Chaldea의 `files/user/` 폴더로 직접 복사하세요. |
| 이전에 중단된 반영을 확인하지 못했습니다(코드) | 중단된 쓰기를 검사할 수 없어 아무것도 쓰지 않습니다. 코드를 알려 주시고, 스위치를 껐다 켜면 다시 시도합니다. 백업은 그대로 있습니다. |
| 반영에 실패했습니다(코드) | 그 밖의 오류입니다. 코드를 알려 주세요. |

실패 메시지는 다음 성공이나 스위치를 껐다 켤 때까지 남습니다.
