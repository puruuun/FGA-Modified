# 게임 영역

**더 보기 → 추가기능 → 게임 영역**에서 게임 화면의 범위를 정합니다. **기본값**, **사용자 지정**, 직접 저장한 설정 중 하나를 고를 수 있습니다. Surface Duo 전용 항목은 제거되었으며, 이전에 그 항목을 사용했다면 기본값으로 읽습니다. 기존 사용자 지정 좌표는 유지됩니다.

## 분할 화면에서 맞추기

1. Android 분할 화면에 FGO와 FGA 설정을 나란히 엽니다. FGO의 메뉴나 전투 화면처럼 실제 게임 이미지의 가장자리가 보이는 화면을 사용하세요.
2. FGA 접근성 서비스를 켜고 **게임 영역 → 사용자 지정**을 선택합니다.
3. 좌측·상단·우측·하단 좌표 아래의 **영역 미리보기**를 켭니다. 접근성 서비스가 꺼져 있으면 스위치가 비활성화되고 안내가 표시됩니다. 디버그 모드는 필요하지 않습니다.
4. 좌표를 조정하면서 **초록 선을 실제 게임 이미지의 가장자리**에 맞춥니다. 분할 창 전체나 위쪽 제목 표시줄, 게임 밖의 파란 무늬까지 포함하지 않도록 하세요. 버튼을 누르고 있는 동안에도 테두리가 갱신됩니다. 숫자를 누르면 직접 입력할 수 있습니다.
5. 조정이 끝나면 설정 화면에서 나갑니다. 오프셋을 바꾼 뒤 화면을 나갈 때 캡처 배율을 한 번 적용합니다. 게임 영역 목록에서 항목을 선택하거나 **초기화**를 눌러도 즉시 적용합니다. 서비스가 꺼져 있으면 다음에 켤 때 현재 설정을 사용합니다. 실행 중인 화면 캡처는 기존 권한을 그대로 사용하므로 다시 캡처 허용을 요청하지 않습니다.
6. 게임을 실행할 화면 배치를 유지합니다. **분할 비율을 바꿨다면 저장된 설정을 다시 선택하거나 사용자 지정 좌표를 다시 조정**하세요. 배치 자체가 달라졌다면 좌표도 새 배치에 맞춰야 합니다. 실행 시 자동 재조정이나 범위 경고는 없습니다.

## 최소 영역과 초기화

사용자 영역은 화면 픽셀 기준 **너비 1280 이상, 높이 720 이상**이어야 합니다. 각 좌표의 상한은 화면 크기와 반대쪽 여백으로 계산합니다. 최소 크기에 도달하면 해당 **+** 버튼이 비활성화되고, 직접 입력한 숫자도 허용 범위로 제한됩니다. 화면의 너비나 높이가 이보다 작으면 사용자 지정 좌표는 모두 0만 허용합니다.

**초기화**는 사용자 지정의 네 좌표를 모두 0으로 돌리고 캡처 배율을 적용합니다. 저장된 설정은 삭제하지 않습니다. 실행 중에는 게임 영역 설정을 바꿀 수 없습니다.

## 설정 저장·선택·삭제

1. 사용자 지정에서 좌표를 맞춘 뒤 **설정 추가**를 누릅니다.
2. 이름을 입력하고 확인합니다. 기본 이름은 **분할화면 N**입니다.
3. 저장한 이름이 게임 영역 목록에 추가됩니다. 선택하면 저장된 네 좌표와 캡처 배율이 적용됩니다.
4. 저장된 설정 화면에서는 좌표를 읽기 전용으로 확인하고 **영역 미리보기**를 켤 수 있습니다. 수정하려면 사용자 지정에서 조정한 뒤 새 설정으로 추가하세요.
5. **삭제**를 누르면 선택한 설정이 삭제되고 기본값으로 돌아갑니다. 같은 이름으로 저장한 다른 설정은 유지됩니다.

## 테두리와 숫자의 뜻

- **빨간 선**: 네 좌표로 설정한 사용자 영역입니다. 화면을 반대 가로 방향으로 돌리면 기존 스크립트와 똑같이 좌우 기준이 바뀝니다.
- **초록 선**: 사용자 영역 안에서 FGA가 실제로 인식하고 터치하는 게임 영역입니다. 게임 화면 비율에 맞게 위아래 또는 좌우 여백을 제외하므로 빨간 선과 다를 수 있습니다.
- **영역 / 게임 / 비율**: 사용자 영역과 실제 인식 영역의 너비×높이(화면 픽셀), 실제 인식 영역의 가로/세로 비율입니다.

예를 들어 3040×1904 태블릿에서 좌측 1049·상단 107·우측 0·하단 0은 분할 창 대부분을 포함하지만, 가운데 맞춤 때문에 초록 선이 실제 게임 이미지보다 아래에 놓일 수 있습니다. 같은 배치의 측정값인 좌측 1049·상단 432·우측 0·하단 356은 사용자 영역 1991×1116을 만듭니다. 기기와 배치마다 값이 다르므로 숫자를 그대로 복사하기보다 초록 선을 확인하세요.

## 자동으로 꺼지는 경우

스위치를 끄거나, 설정 화면에서 나가거나, 앱이 정지 상태로 들어가거나, 접근성 서비스가 끊기면 테두리가 사라집니다. **스크립트 시작 시에는 화면 판별 캡처 전에 제거**하며 실행 중에는 켤 수 없습니다. 설정 화면을 다시 열어도 미리보기는 꺼진 상태입니다.

미리보기는 화면 표시 기능이며 게임을 조작하거나 좌표를 자동으로 맞추지 않습니다. 캡처 배율과 인식 영역은 선택한 게임 영역을 기준으로 함께 계산하며 추가 권한은 필요하지 않습니다.
