# 外部アプリのプロキシモード

Android では同時に 1 つの VPN しか起動できないため、ローカル VPN 型のアプリ（AdGuard など）と FGA の標準 VPN 収集モードを同時に有効にできません。**外部アプリのプロキシ**モードを選択すると、FGA は VPN を開かずに端末内部のアドレス（`127.0.0.1`）に常駐ローカルプロキシを開き、外部のプロキシ・ファイアウォールアプリから FGO アプリの通信だけをこのプロキシへ送って連携します。

接続モードの初期値は **FGA VPN** であり、他の VPN・プロキシアプリを併用しない場合は変更する必要はありません。

> すべての通信は端末内部でのみ処理され、外部サーバーへ送信されることはありません。

## 事前準備

1. **その他の設定 → 追加機能 → ログ収集**で**ログ収集を有効にする**をオンにし、ご案内に同意します。
2. 従来の VPN 方式と同様に、FGA 証明書を作成して端末の**ユーザー CA 証明書**としてインストールします。（JP サーバーの root 自動注入を使う場合でも、証明書やモジュールの設定は同じです。）
3. **接続モード**で**外部アプリのプロキシ**を選択します。
4. カード上部の**ホスト**（`127.0.0.1`）と**ポート**（例: `8899`）を確認します。各項目の**コピー**ボタンでホストとポートを個別にコピーでき、`1024〜65535` の範囲で別のポートを入力して**適用**（またはキーボードの完了）を押すとポートを変更できます。
5. バックグラウンドで FGA が終了されないよう、**バッテリー最適化から FGA を除外**します。カードの**バッテリー最適化から除外**ボタン（すでに除外済みなら「除外済み」と表示）から設定画面を開きます。
6. FGA のユーザー補助サービスをオンにしておくと、FGO が画面前面に来たときにプロキシが落ちていれば、FGA がプロキシを待機状態で再開します（最大 30 秒に 1 回確認）。収集自体は自動ではオンになりません。

## 共通の要件（外部アプリの種類を問わず）

どの外部アプリを使う場合でも、以下の 3 つの条件をすべて満たす必要があります。

1. **FGO のみ `127.0.0.1:ポート`（SOCKS5 または HTTP、認証なし）へ送ること**（KR と JP を両方使う場合は JP も含む）。
2. **そのアプリの対象から FGA を除外すること**。FGA はゲームサーバーへ直接接続するため、外部アプリが FGA の HTTPS 通信まで横取り・プロキシするとゲームサーバーへ接続できなくなります。
3. **そのアプリが FGO の HTTPS を復号しない設定にすること**。外部アプリが FGO の通信を先に復号すると、ゲーム側で接続エラーが起きたりログが空になったりすることがあります。

> 他の VPN・プロキシアプリも上記の共通要件を満たせば**原理上は動作可能**ですが、実際の動作は**ご自身での確認が必要**です。

## AdGuard を使用する場合の設定手順

代表的な利用例として、**AdGuard** を使う場合の設定手順は次の通りです。

1. **AdGuard → 設定 → フィルタリング → ネットワーク → プロキシ → プロキシサーバー**でサーバーを追加する際、ホスト欄とポート欄を分けて入力します（`127.0.0.1:8899` のようにホスト欄へポートを一緒に入れないでください）。
   - **種類**: `SOCKS5` または `HTTP`
   - **ホスト**: `127.0.0.1`
   - **ポート**: FGA に表示されているポート番号（初期値 `8899`）
   - **プロキシ認証**: **オフのまま**にします。
2. **「プロキシ経由で動作するアプリ」**で **FGO だけ**を選択します（KR と JP の両方を使う場合は JP も）。
3. **AdGuard のアプリ管理**で **FGA を AdGuard の対象から外します**。
4. **AdGuard のアプリ管理**で **FGO の HTTPS フィルタリングをオフにします**。
5. AdGuard で**プロキシをオン**にします。

### AdGuard プロキシ自動切り替え

端末に AdGuard（`com.adguard.android`）がインストールされている場合、**AdGuard を使用する場合**欄の下に**AdGuard プロキシ自動切り替え**設定が表示されます。これをオンにすると、FGA がログ収集のオン/オフを切り替える際に AdGuard の送信プロキシも自動でオン/オフします。

- **設定方法**:
  1. **AdGuard 設定の「オートメーション」画面**で**オートメーション**をオンにし、表示されたオートメーションパスワードをコピーまたは控えます。
  2. FGA の**AdGuard オートメーションパスワード**欄にパスワードを入力し、**AdGuard プロキシ自動切り替え**スイッチをオンにします。（パスワードが空の場合、自動切り替えは動作しません。）
- **動作の仕組み**:
  - **収集をオン**: FGA プロキシが開いた後、FGA が AdGuard に既定プロキシ（`127.0.0.1:ポート`、SOCKS5）を指定してプロキシをオンにします。
  - **収集をオフ**: 収集をオフにする直前に、FGA が AdGuard のプロキシをオフにします。
  - **待機状態でサービス開始**: 収集がオフの状態で FGA プロキシサービスが初めて起動したとき（アプリ起動、端末再起動など）、サービスインスタンスごとに 1 回 AdGuard プロキシをオフにします。
  - **モード切り替えまたは機能オフ**: 自動切り替えが有効（スイッチオン＋パスワード入力済み）な場合、「先に外部プロキシをオフにしてください」の確認ダイアログをスキップし、AdGuard プロキシをオフにしてから終了します。
  - **自動切り替えスイッチをオフにしたとき**: スイッチをオフにした時点では AdGuard へコマンドを送らず、現在の状態を維持します。
- **パスワードが間違っている場合の確認方法**:
  - AdGuard のオートメーションブロードキャストは、パスワードが間違っていても FGA 側にエラーを返さず**サイレントに失敗**します。
  - 収集をオンにした後、カードの**最後の FGO 接続**が更新されず FGO の接続確認ができない場合は、AdGuard のオートメーション画面のパスワードと FGA に入力したパスワードが一致しているか確認してください。

## プロキシ待機と収集のオン/オフ

- **プロキシ待機中**: 外部プロキシアプリが FGO の接続を通し続けられるよう、**収集をオフ**にしている状態でも FGA のローカルプロキシサービスは常駐状態で開いたままになります。この状態ではゲーム応答を記録・復号せずそのまま中継します。（AdGuard 自動切り替えを使う場合は、収集中のみ AdGuard のプロキシがオンになります。）
- **収集をオン / 収集をオフ**: 常駐通知のボタン、**その他の設定 → 追加機能 → ログ収集**、メイン画面のボタン、ホーム画面ウィジェットから切り替えられます。FGA VPN の権限確認ダイアログは出ず、収集をオフにしてもプロキシは開いたまま残るため FGO の接続は切れません。
- **ポート変更**: 収集中だった場合はまず収集をオフにしてから新しいポートを開き古いポートを閉じますが、切り替えの瞬間に FGO の既存接続が一時的に切れることがあります。自動切り替えを使っていない場合は、外部アプリ側のポート番号も合わせて変更してください。

## 状態確認とトラブルシューティング

- **最後の FGO 接続**: FGO がプロキシ経由でゲームサーバーへ接続した最後の時刻を分単位で表示します。まだ記録がない場合は、外部アプリ側でプロキシがオンになっているか、FGO がプロキシ対象アプリに含まれているか（自動切り替え使用時はオートメーションパスワードが正しいか）を確認してください。
- **ポート使用中エラー**: 選択したポートを他のアプリが使用している場合、そのポートでプロキシを開けません。別のポートに変更し、外部アプリにも同じポートを設定した上で、必要に応じて競合アプリを終了し、収集ボタンまたはアプリ再起動でやり直してください。
- **TLS / 上流接続失敗の警告**:
  - **ゲームが FGA の証明書を拒否した場合**: **外部アプリで FGO の HTTPS 復号（HTTPS フィルタリング）をオフにし**、FGA の証明書が端末のユーザー CA 証明書としてインストールされているかも確認してください。
  - **FGA がゲームサーバーに接続できなかった場合**: **外部アプリから FGA を対象外にしているか**と、端末のネットワーク状態を確認してください。
- **IPv6 のないネットワーク（一部 Wi-Fi・エミュレータなど）**: 外部アプリがゲームへ IPv6 アドレスを返して IPv6 接続要求が来ても、端末のネットワークが IPv6 に対応していなければ FGA が即座に接続失敗応答を返し、ゲームが IPv4 で接続し直すよう促します（別途設定は不要です）。

## 既知の制限事項

- **収集中に FGA を強制終了した場合**: 収集をオンにして AdGuard 自動切り替えがプロキシをオンにした状態で、Android 設定の**強制停止**などで FGA が即座に終了されると、FGA が終了コマンドを送れないため AdGuard のプロキシがオンのまま残り、FGO が通信できなくなります。この場合は FGA を開き直すか、AdGuard 側で直接プロキシをオフにしてください。
- **既存の AdGuard 既定プロキシの上書き**: AdGuard 自動切り替えをオンにして収集を始めると、FGA が `127.0.0.1:ポート` を AdGuard の既定プロキシサーバーに設定するため、ユーザーが AdGuard に別途設定していた既定プロキシサーバーがあった場合は収集オン時点で上書きされます。
- **タスク一覧からのスワイプ終了と強制停止**: 最近のアプリ一覧から FGA をスワイプで消してもプロキシは維持されます。Android 設定の**強制停止**を押した場合のみプロキシが停止します。
- **バッテリー最適化**: FGA がバッテリー最適化の対象だとバックグラウンドで終了され、FGO の接続が切れることがあります。カードの**バッテリー最適化から除外**ボタンで除外してください。
- **アプリアップデートと再起動**: FGA をアップデートしている数秒間は FGO がオフラインになります。アップデート完了後や端末の再起動後にはプロキシが自動で再開されます。
- **ネットワーク切り替え時の応答欠落**: Wi-Fi とモバイルデータの切り替え中に処理中だった応答は、ログから漏れる場合があります。

## モードを戻す・機能をオフにする場合

外部アプリが FGO の通信を FGA プロキシ（`127.0.0.1`）へ送っている状態のままで FGA の接続モードを **FGA VPN** に戻したり、**ログ収集を有効にする**をオフにしたりすると、プロキシが終了して FGO の通信が遮断されることがあります。

- **手動設定（または自動切り替えオフ）**: 必ず**先に AdGuard などのプロキシアプリ側でプロキシ設定をオフにしてから**、FGA 側の確認ダイアログを確定して切り替え・オフにしてください。
- **AdGuard 自動切り替え使用中**: FGA が AdGuard のプロキシをオフにしてから切り替え・終了するため、確認ダイアログなしでそのまま切り替え・終了します。
