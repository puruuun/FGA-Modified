# サポート画像の検索・保存

**1.2.1 開発ベータ**から、サーヴァントや概念礼装を番号または名前で検索し、FGA の設定言語に合わせた名前で保存できるようになりました。正式版 `1.1.0` には従来のサーヴァント番号取り込みが含まれています。

## 使い方

1. **その他の設定 → 追加機能 → サポート画像の検索・保存** を開きます。
2. **サーヴァント / 概念礼装** を選び、**図鑑番号または名前**（公式名称の一部でも可）を入力して検索します。例：サーヴァント `90`、`ネロ`、`スカサハ`／概念礼装 `34`、`カレイド`、`컬라이더`。
3. 番号・名前・クラス・レアリティ・肖像画を確認し、保存したい項目を選択します。検索結果が1件だけのときは自動選択されますが、複数ある場合は最初の項目を自動で選びません。
4. **生成・保存** を押します。検索と専用画像の照会は **JP → KR → NA** の順に行われ、結果が見つかった最初のサーバーで確定します。サーバーを手動で選ぶ項目はなく、CN・TW は画像照会に使用しません。
5. **バトルの設定 → サポート** で、**選択するサーヴァント** または **選択する概念礼装** から該当フォルダーを選択します。

保存先は指定した FGA フォルダー内の `support/servant/No.<番号> <名前>/` または `support/ce/No.<番号> <名前>/` です。サポートイメージメーカーを実行したりゲーム画面を操作したりする必要はありません。インターネット接続が必要です。

## 選択するサーヴァント・概念礼装の選択画面から画像を取得する

**1.8.0 開発ベータ**では、**バトルの設定 → サポート** の **選択するサーヴァント** または **選択する概念礼装** 選択画面の左下にある **画像を取得** から、同じ検索・保存画面を直接開くことができます。サーヴァント選択画面からは **サーヴァント**、概念礼装選択画面からは **概念礼装** があらかじめ選ばれた状態で開きます。宝具名・フレンド名選択画面にはこのボタンはありません。

1枚以上保存すると選択リストを再読み込みし、保存したフォルダーにすぐチェックが入ります。開いていた選択画面ですでにチェックしていた項目も維持されます。検索画面内で種類を切り替えて保存した場合は、現在開いている選択画面と同じ種類だけがチェックされます。**OK** を押して初めて設定に反映され、**キャンセル** を押すと今回の選択変更は破棄されますが、取得した画像はフォルダーに残ります。検索画面だけを閉じたり、保存に失敗したり、保存フォルダーが未設定の場合は選択は変わりません。

すでに番号フォルダーがある場合は、選択画面から開くとそのフォルダーへ画像を保存し、名前と既存の設定を維持します。**その他の設定 → 追加機能** から開く検索・保存機能も従来通り使用できます。

## 名前言語と検索

名前は **FGA で選択しているアプリ言語** を使用します。アプリ言語がシステム準拠の場合は Android の有効な言語に従います。韓国語は KR、日本語は JP、英語は NA、中国語簡体字・繁体字は CN・TW のデータを使用し、該当言語の名前がない場合や非対応言語の場合は JP の日本語名で代替します。

たとえば韓国語環境では `No.90` を `No.90 네로 클라우디우스(브라이드)` として保存し、韓国版データがない `No.444` は `No.444 Ｕ－オルガマリー` として保存します。翻訳の有無は照会時点の Atlas データに準拠します。

図鑑番号は **日本版（JP）を優先** します。JP に検索結果がない場合は KR、続いて NA の図鑑を参照します。同じ内部 ID が JP にも存在する場合は JP の図鑑番号を維持し、地域限定項目はその地域の番号を使用します。地域間で名前を結び付ける際は図鑑番号ではなく内部 ID を照合するため、番号が異なる別地域の名前が誤って付くことはありません。公式名および部分一致で検索でき、日本語名での検索も併用できます。空白・一般的な句読点・英字の大文字小文字・全角半角の違いは正規化されます。コミュニティの愛称や機械翻訳から韓国語名を自動推定することはありません。

**KR 未実装サーヴァントの韓国語名検索 — 1.7.1 ベータ追加。** 日本版には実装されているものの KR 版にはまだ実装されていないサーヴァントには公式の韓国語名がありません。こうしたサーヴァントでも、アプリ内蔵の韓国語名辞書（ナムウィキ準拠、再臨別名称を含む）で検索できます。例：`히폴` → ヒポリュテー（`히폴리테`）、`카구야` → `No.448`。この辞書は対象サーヴァントが KR 図鑑へ登録されるまでのみ使用され、KR に公式名が追加されると辞書項目は無視されて公式名のみで検索します。表示名・図鑑番号・保存フォルダー名はそのまま公式の日本語名に従います。辞書にまだ載っていないサーヴァントは日本語名または図鑑番号で検索してください。現在辞書には `No.438〜487` が収録されており、一部のサーヴァントはコミュニティの俗称（例：`버미육` → 松永久秀 `마츠나가 히사히데`、`큐티 코마` → ダイナマイト利休 `다이너마이트 리큐`）でも見つけられます。辞書は今後のバージョンで順次拡充します。番号検索と概念礼装検索では辞書を使用しません。

**再臨・霊衣・真名解放によって変わる公式名でも同じサーヴァントとして検索** できます。たとえば「妖精騎士ランスロット（`요정기사 랜슬롯`）」と「メリュジーヌ（`멜뤼진`）」のどちらでも `No.312` が見つかり、「メリュジーヌ」の検索では同名の別クラスも個別の候補として表示されます。フォルダーには検索語ではなく図鑑の代表名が使われるため、検索語を変えてもフォルダーが重複することはありません。

名前検索時は Atlas の公開ゲームデータ `mstSvt`・`mstSvtLimitAdd`・`mstSvtChange` から基本名、再臨・霊衣によるサーヴァント名上書き、真名変更名を集めて内部 ID と結び付けます。宝具名・スキル名や説明文は検索対象に含みません。初回のサーヴァント名検索には追加の名前一覧のダウンロードが必要で、集めた名前一覧も下記のキャッシュ更新ルールに従います。番号検索と概念礼装検索ではこの追加ダウンロードを行いません。

再生成して名前が変わった場合は既存の番号フォルダーを更新し、すべてのバトル設定における選択状態もそのまま維持します。JP にない地域限定項目は `KR.No.<番号> <名前>` または `NA.No.<番号> <名前>` フォルダーに保存し、同じ番号の JP 画像や既存の選択設定と混ざらないようにします。他の内蔵画像やユーザーが作成したファイルは削除しません。古い名前を使っている設定ファイルでも、番号から現在のフォルダーを見つけられます。

## 画像と検証範囲

サーヴァントは `extraAssets.faces`・`facesChange` から再臨・霊衣・対応する特殊バリエーションを収集します。JP 専用画像一覧がある場合はその一覧を使用し、項目がないか一覧が空のときだけ KR、続いて NA を確認し、異なるサーバーの画像を混ぜません。従来の `128×128` 専用肖像画 → `158×158` → `(3,47,125,44)` 変換を使用します。

概念礼装は通常のカードイラストではなく **`extraAssets.equipFace` の `150×68` 専用画像** を使用します。照合サイズへ調整し、通常・グランドサポートで使用する帯画像を生成します。表示名の言語とは別に、専用画像は **JP → KR → NA** の順に照会します。データがないか画像規格が異なる場合、全体イラストを勝手に切り抜いて保存することはありません。

対応サーバーの実際のゲーム表示と異なる概念礼装の誤検出については、画面サンプルでの個別検証が必要です。未確認の端末や画面比率すべてでの認識は保証されません。個別の失敗は保存／失敗数に表示され、再生成でやり直せます。

検索に使う KR・JP のサーヴァント・概念礼装一覧と追加名前一覧はアプリキャッシュに保存し、Atlas のデータバージョン（最大1時間に1回確認）に合わせて更新するため、新しいサーヴァントや概念礼装が Atlas に追加され次第検索できるようになります。バージョンを読み取れない場合や NA など他地域の一覧は従来の24時間ルールに従い、KR 未実装サーヴァント用の韓国語名辞書はアプリ内蔵の固定一覧をそのまま使用します。有効なキャッシュがあれば一時的な通信エラー時にも検索に再利用します。画像の生成・ダウンロードはユーザーが実行したときにのみ行われます。

## 選択するサーヴァントからのサポートクラス自動選択

バトル設定の **選択するサーヴァント** を **ちょうど1騎だけ** に変更すると、そのサーヴァントのクラスタブがサポートクラスとして自動選択されます（内蔵画像と `No.<番号>` フォルダーの両方が対象）。シールダー・ルーラー・アヴェンジャー・ムーンキャンサー・アルターエゴ・フォーリナー・プリテンダー・ビースト系は **Extra** タブになります。サーヴァントが0騎または2騎以上のとき、ユーザー自作フォルダー、クラス不明、概念礼装だけを変更したときには変更せず、手動で選んだクラスは再びサーヴァント選択を変えるまで維持されます。
