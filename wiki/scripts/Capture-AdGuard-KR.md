# AdGuard 프록시 모드

Android는 한 번에 하나의 VPN만 실행할 수 있어 AdGuard(로컬 VPN 기반)와 FGA의 기본 VPN 수집 모드를 동시에 켤 수 없습니다. **AdGuard 모드**를 선택하면 FGA가 VPN을 열지 않고 기기 내부 주소(`127.0.0.1`)에 상주 로컬 프록시를 열어 두고, AdGuard가 FGO 앱의 트래픽만 이 프록시로 보내도록 연결합니다.

> 모든 통신은 기기 내부에서만 처리되며 외부 서버로 전송되지 않습니다.

## 사전 준비

1. **더보기 → 로그 수집**에서 **로그 수집 사용**을 켜고 안내 동의에 동의합니다.
2. 기존 VPN 방식과 마찬가지로 FGA 인증서를 발급해 기기의 **사용자 인증서**로 설치합니다. (JP 서버 루트 자동 주입을 사용하는 경우에도 인증서/모듈 설정은 동일합니다.)

## AdGuard 설정 방법

1. FGA의 **더보기 → 로그 수집**에서 **연결 방식**을 **AdGuard**로 선택합니다.
2. 화면에 표시된 **프록시 주소**(`127.0.0.1:8899` 등)와 포트 번호를 확인합니다. 필요한 경우 **복사** 버튼으로 복사하거나, `1024~65535` 범위의 다른 포트를 입력한 뒤 **적용**(또는 키보드 완료)을 눌러 바꿀 수 있습니다.
3. **AdGuard → 설정 → 네트워크 → 프록시 → 프록시 서버**에서 서버를 추가합니다.
   - **유형**: `SOCKS5` 또는 `HTTP`
   - **호스트**: `127.0.0.1`
   - **포트**: FGA에 표시된 포트 번호(기본 `8899`)
   - **프록시 인증**: **끈 상태**로 둡니다.
4. **프록시 사용 앱** 설정에서 다른 앱은 제외하고 **FGO 앱만** 이 프록시를 사용하도록 지정합니다.

## 프록시 대기와 수집 켜기·끄기

- **프록시 대기 중**: AdGuard가 FGO 연결을 계속 통과시킬 수 있도록, **수집 끄기** 상태에서도 FGA의 로컬 프록시 서비스는 상주 상태로 열려 있습니다. 이 상태에서는 게임 응답을 기록·해독하지 않고 그대로 전달만 합니다.
- **수집 켜기 / 수집 끄기**: 상시 알림의 버튼, **더보기 → 로그 수집**, 메인 화면 버튼, 홈 화면 위젯에서 전환할 수 있습니다. FGA VPN 권한 창은 뜨지 않으며, 수집을 꺼도 프록시는 열린 채로 남아 FGO 연결이 끊기지 않습니다.
- **포트 변경**: 새 포트를 먼저 연 뒤 기존 포트를 닫지만, 전환 순간 FGO의 기존 연결이 잠시 끊길 수 있습니다. 포트가 바뀌면 AdGuard 쪽 포트 번호도 맞춰 주세요.

## 상태 확인과 문제 해결

- **마지막 FGO 연결**: FGO가 프록시를 통해 게임 서버에 연결한 마지막 시각을 분 단위로 표시합니다. 아직 기록이 없다면 AdGuard에서 프록시 서버가 켜져 있는지, **프록시 사용 앱**에 FGO가 포함되어 있는지 확인하세요.
- **포트 사용 중 오류**: 선택한 포트를 다른 앱이 쓰고 있으면 해당 포트로 프록시를 열 수 없습니다. 포트를 바꾼 뒤 **적용**하거나, 해당 앱을 종료한 뒤 수집 버튼 또는 앱 재진입으로 다시 시도하세요.
- **TLS / 업스트림 실패 경고**: TLS 실패가 올라가면 FGA 인증서가 사용자 인증서로 설치되었는지 확인하고, 업스트림 연결 실패가 보이면 기기 네트워크나 AdGuard 설정을 확인하세요.

## 모드 되돌리기 또는 기능 끄기

AdGuard에서 FGO 트래픽을 FGA 프록시(`127.0.0.1`)로 보내고 있는 상태에서 FGA의 연결 방식을 **FGA VPN**으로 바꾸거나 **로그 수집 사용**을 끄면, 프록시가 종료되면서 FGO의 통신이 차단될 수 있습니다.

- 반드시 **AdGuard의 프록시 설정(또는 FGO 프록시 적용)을 먼저 끈 뒤**, FGA에서 안내 창을 확인하고 전환하거나 끄세요.
