# 敵配置ごとのターゲット指定

スキルコマンドの敵ターゲット指定はもともと `t1`・`t2`・`t3`（通常の3体配置）だけでした。敵が6体いる配置やレイド配置では敵の位置が異なるため、`t1`〜`t3` では別の場所をタップしてしまいます。この機能は2つの配置向けの固定ターゲットコードを追加します。`t1`〜`t3` の位置と動作は変わりません。

## コード一覧

| 配置 | コード | タップする場所 |
|---|---|---|
| 通常3体 | `t1` `t2` `t3` | 左・中央・右の敵 |
| 6体（上段） | `t4` `t5` `t6` | 上段の左・中央・右の敵 HP バー |
| 6体（下段） | `t7` `t8` `t9` | 下段の左・中央・右の敵 HP バー |
| レイド（ボス） | `tR` | 画面上部にある全幅 HP バーのボス |
| レイド（下1段目） | `tA` `tB` `tC` | ボス下の1段目に並ぶ左・中央・右の敵 |
| レイド（下2段目） | `tD` `tE` `tF` | ボス下の2段目に並ぶ左・中央・右の敵 |

レイド配置には2つの形式があります。

- ボスの下で左右に HP バーだけがある形式（例: Grand Marie）
- ボスの下に敵が3枠ずつ2段並んでいる形式

`tA`〜`tC` はどちらの形式でも敵を押せる重なり部分に座標を合わせています。2段目（`tD`〜`tF`）は6枠形式でのみ使用します。

- 以前のバージョンで使われていた `t10`・`t11`・`t12` は `tA`・`tB`・`tC` として読み込まれ、スキルメーカーで保存し直すと `tA`・`tB`・`tC` に書き換わります。`t14` のように `t1` の後ろに別の数字が続く組み合わせは従来の意味のままです（`t1` の次に宝具4番）。
- 存在しないコード（`t0`、`tX` など）はスキルコマンド解釈エラーで停止します。
- 21:9 などのワイド画面でも同じコードを使用でき、画面比率に合わせて位置が自動的に調整されます。

## スキルメーカーでの使い方

1. スキルメーカーのメイン画面左上にあるオレンジ色の **ターゲット設定** ボタンを押します。現在選択中のターゲットはボタン上には表示されません。
2. スキル対象選択画面のように専用の **敵ターゲット選択** 画面が開き、中央にバトル画面と同じ配置でターゲットボタンが表示されます。
   - **3体**: `t1` `t2` `t3` の1列
   - **6体**: `t4` `t5` `t6` の下に `t7` `t8` `t9`
   - **レイド**: 幅広の `tR` の下に `tA` `tB` `tC`、さらにその下に `tD` `tE` `tF`
3. 画面下の **3体 / 6体 / レイド** から配置を切り替えます。画面は現在のターゲットが属する配置で開きます。
4. ターゲットを押すとそのターゲットがコマンドに追加されてメイン画面へ戻ります。すでに選択されているターゲットをもう一度押しても何も追加されません。選ばずにシステムの戻る操作を行うと、変更せずメイン画面に戻ります。

## 注意点

- レイド2段目の `tD`（左）・`tE`（中央）の位置は**推定値**です。右端の `tF` だけを実機キャプチャから計測し、残りは等間隔で算出しています。ずれている場合はお知らせください。
- **ターゲットの自動選択** が認識できるのは通常の3体配置の位置だけです。6体配置・レイド配置では自動選択できないため、必要な場合は上記コードで直接指定してください。
- 画面上の配置までは確認しません。別配置のコードを指定するとその座標をそのままタップするため、クエストの配置に合ったコードを使用してください。
- Chaldea 取り込みでは従来通り `t1`〜`t3` のみを生成します。
