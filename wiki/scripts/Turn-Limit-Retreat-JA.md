# 撤退して再開

パーティーが全滅するか、バトルが指定したターンに到達するとクエストから撤退し、クエストを最初からやり直します。バトル設定ごとにオン・オフを切り替えられ、1つのスイッチで両方の動作をまとめて扱います。

| 設定 | パーティー全滅 | Nターン到達 |
|---|---|---|
| オフ（初期値） | 停止（`"すべてのサーヴァントが撃破され、動作停止しました。"`） | 何もしない |
| オン、N = 0 | 撤退して再開 | - |
| オン、N ≥ 1 | 撤退して再開 | 撤退して再開（KR・JP サーバーのみ） |

たとえば N を `6` に設定して4ターン目に全滅した場合は、全滅撤退として処理してクエストをやり直します。6ターン目が始まった瞬間にはスキルやカードを使わず撤退します。

## 対象サーバー

- 全滅時の撤退はすべてのサーバーで使用できます。
- Nターン到達時の撤退は韓国（KR）サーバーと日本（JP）サーバーでのみ使用できます。N の値はどのサーバーでも設定画面で指定できますが、実際に適用されるのは KR・JP サーバーだけです。他のサーバーでは保存された N が1以上であっても無視してバトルを続行します（N = 0 と同じ動作）。全滅撤退はサーバーを問わずスイッチに従います。

## 設定方法

**バトルの設定 → <使用する設定>** の設定行にある **撤退して再開** をタップして開きます。設定はバトル設定ごとに個別に保存されます。

| 項目 | 説明 |
|---|---|
| オン／オフ | このバトル設定で **撤退して再開** を使うかどうかを設定します。 |
| Nターンで撤退 | 撤退するターン数 N です（0〜99、初期値 0）。0 の場合はパーティーが全滅したときだけ撤退します。 |
| N回連続で撤退したら停止 | オンにすると、撤退が N 回連続で発生したときにスクリプトを停止します。全滅撤退とターン制限撤退を合わせて数えます。チェックボックス横のステッパーで N を 1〜99 から指定します（初期値 3）。チェックボックスと **撤退して再開** スイッチの両方がオンのときだけ変更できます。すでにチェックボックスをオンにしていた設定は N = 3 のまま動作します。 |

設定行の表示値は、オフなら `Off`、N = 0 なら `全滅時に撤退`、N ≥ 1 なら `Nターンで撤退` になります。これら4つの項目はバトル設定のエクスポートおよびインポート時に一緒に保存されます。（以前の **その他の設定 → バトル → 撤退有効化** スイッチがオンだった場合、アップデート後の初回起動時に1回だけ、撤退して再開がオフだった設定が **オン、N = 0** に移行されます。）

## パーティー全滅時の動作

全滅画面の撤退ボタン、確認、閉じるを順番に押す従来の動作はそのままです。変わったのは周回のカウント方法です。

- 全滅撤退もターン制限撤退と同じく**周回数として数えません**。実行回数、周回上限、ターン数や時間統計には加算せず、周回状態を初期化してクエストをやり直します。
- 撤退回数と連続撤退回数には加算されます。**N回連続で撤退したら停止** がオンの場合は判定します。
- 全滅は正常クリアではないため連続撤退回数を 0 に戻しません。正常にクリアした周回でのみ 0 にリセットされます。

## Nターン到達時の動作

1. 毎ターンの開始時、スキル・カード・コマンド開始条件を確認する前に現在のターンが N に達しているか確認します。ターンはウェーブをまたいでゲーム画面の `TURN` 表示と同じ基準で数え続けます（画面の読み取りは行いません）。
2. コマンド開始条件（**Command card count mode**）で**待機したターン**は数えません。N を `4` にして1ターン待機した場合、ゲームの `TURN` が `5` になった瞬間に撤退します。
3. 撤退は次の手順で行います。
   1. バトルメニューボタンを押してメニューを開きます。0.5 秒待機したあと最大 3 秒間、撤退ボタン（韓国語 `"후퇴하기"`、日本語 `"撤退する"`）を待ちます。表示されなければもう一度押し、それでも出なければ停止します。
   2. 撤退ボタンを押します。0.5 秒待機したあと最大 3 秒間、確認ダイアログ（`확인` / `決定` ボタン）が開いたか確認します。開かなければ決定ボタンを押さず、メニューの `X` を押して閉じてから停止します。メニューだけが開いた状態で同じ位置を押すと、ゲーム内の「スキル使用確認」設定が切り替わってしまうためです。
   3. 決定ボタンを押します。1 秒待機したあと最大 15 秒間、「クエストから撤退しました」（韓国語 `"퀘스트에서 철수했습니다"`）画面の閉じるボタンを待ちます。
   4. 閉じるを押してクエスト一覧が出るまで 6 秒待機し、通常の周回フローへ戻ります。15 秒以内に閉じるボタンが出ない場合は、まず通信エラー（再試行）画面が出ていないか確認します。出ていればそのまま通常フローへ戻って既存のエラー処理に任せ、この場合も撤退として数えます。通信エラーでなく確認ダイアログがまだ残っている場合は決定ボタンをもう一度押し、1 秒後に再び最大 15 秒待ちます。それでも閉じるボタンが出なければ下の表の通り停止します。まだバトル中のため、周回状態は初期化しません。
4. その後は通常通り一番上のクエストを選び直し、AP が足りなければ設定した回復アイテムで回復してからサポートを選んで再開します。

## 周回と統計

- 撤退したバトルは、全滅でもターン制限でも**周回として数えません**。周回数、周回制限、ターン数や時間統計には加算されません。
- 撤退でも AP は消費します。次の周回では既存の AP 回復ロジックがそのまま働き、AP が尽きた場合は通常通り停止します。
- **今回で動作終了** と周回制限は、撤退後にクエスト一覧へ戻ったときに通常通り判定します。
- 終了画面には **`N 回撤退しました(全滅 a 回、ターン制限 b 回)`** の1行が表示されます（0回の場合は非表示）。
- 正常にクリアした周回があると、連続撤退回数は 0 に戻ります。

## 停止条件

| 状況 | 結果 |
|---|---|
| オフの状態でパーティー全滅 | `"すべてのサーヴァントが撃破され、動作停止しました。"` を表示して停止 |
| メニューまたは撤退ボタンが2回試しても表示されない | `"ターン制限での撤退に失敗しました。他の操作をする前に停止しました。"` を表示して停止 |
| 確認ダイアログが開かない | メニューを閉じて `"ターン制限での撤退に失敗しました。他の操作をする前に停止しました。"` を表示して停止 |
| 決定を押したが15秒以内に閉じるボタンが出ず、通信エラー画面も確認ダイアログもない | 撤退回数と周回状態を変更せず `"ターン制限での撤退に失敗しました。他の操作をする前に停止しました。"` を表示して停止 |
| 決定を押したが閉じるボタンが出ず、確認ダイアログが残っている | 決定をもう一度押して再び15秒待機。それでも出なければ上行と同様に停止 |
| 決定を押したが閉じるボタンが出ず、通信エラー画面が表示されている | 撤退として数え、通常フローに戻って通信エラー処理へ任せる |
| 撤退後にクエスト一覧へ戻れないまま1周回内で3回目の撤退を試みた | `"ターン制限での撤退に失敗しました。他の操作をする前に停止しました。"` を表示して停止 |
| **N回連続で撤退したら停止** がオンで、全滅・ターン制限を合わせて N 回連続で撤退 | `"N回連続して撤退したため停止しました。"` を表示して停止（N は設定した回数） |

## 注意事項

- [ウィークリーミッションクリア](Weekly-Mission-Route-JA.md) のルート周回ではターン制限撤退は使用しません。パーティーが全滅した場合は選択したバトル設定のスイッチに従って撤退または停止し、撤退した場合はそのルートクエストを終了します。
- ターン制限撤退の撤退ボタンは韓国語・日本語クライアントの画像で探索します。ゲームのアップデートでバトルメニューの配置や文言が変わると認識できなくなる場合があります。
- バトル途中の撤退であるため AP を消費し、ドロップも獲得できません。初めて使うときは N を大きめに設定して動作を確認してください。
