# FGA(mod) 퇴각 후 재시작

파티가 전멸하거나 전투가 정한 턴에 도달하면 퀘스트에서 퇴각한 뒤, 퀘스트를 처음부터 다시 시작합니다. 전투 설정마다 켜고 끄며, 스위치 하나로 두 동작을 함께 다룹니다.

| 설정 | 파티 전멸 | N턴 도달 |
|---|---|---|
| 꺼짐 (기본값) | 정지 ("모든 서번트가 패배하였으며 자동 철수는 비활성화 상태입니다") | 아무것도 하지 않음 |
| 켜짐, N = 0 | 퇴각 후 재시작 | - |
| 켜짐, N ≥ 1 | 퇴각 후 재시작 | 퇴각 후 재시작 (한국·일본 서버만) |

예를 들어 N을 6으로 정하고 4턴에 파티가 전멸하면, 전멸 퇴각으로 처리하고 퀘스트를 다시 시작합니다. 6턴이 시작되는 순간에는 스킬과 카드를 쓰지 않고 퇴각합니다.

## 서버

- 전멸 퇴각은 모든 서버에서 사용할 수 있습니다.
- N턴 도달 퇴각은 한국 서버와 일본 서버에서만 사용할 수 있습니다. N은 어느 서버에서든 설정 창에서 정할 수 있지만, 한국·일본 서버에서만 적용됩니다. 다른 서버에서는 저장된 N이 1 이상이어도 무시하고 전투를 계속 진행합니다(N = 0과 같게 동작). 전멸 퇴각은 서버와 관계없이 스위치를 따릅니다.

## 설정 방법

**Battle Configs → 사용할 설정**의 설정 줄에 있는 **퇴각 후 재시작** 칸을 눌러 엽니다. 설정은 전투 설정마다 따로 저장됩니다.

| 항목 | 설명 |
|---|---|
| 켜기/끄기 | 이 전투 설정에서 퇴각 후 재시작을 사용할지 정합니다. |
| N턴 도달 시 퇴각 | 퇴각할 턴 N입니다. 0~99이며 기본값은 0입니다. 0이면 파티가 전멸했을 때만 퇴각합니다. |
| 3회 연속 퇴각 시 정지 | 켜면 퇴각이 3번 연속 발생했을 때 스크립트를 정지합니다. 전멸 퇴각과 턴 제한 퇴각을 함께 셉니다. 횟수 3은 고정입니다. |

설정 줄의 값은 꺼짐이면 "꺼짐", N = 0이면 "전멸 시 퇴각", N ≥ 1이면 "N턴 도달 시 퇴각"으로 표시됩니다. 세 항목은 전투 설정을 내보내고 가져올 때 함께 저장됩니다.

### 이전 "퇴각 활성화" 스위치

이전 버전의 **More → Battle → 퇴각 활성화**는 없어졌습니다. 업데이트 후 처음 실행할 때 한 번만 이전 설정을 옮깁니다.

- 이전 스위치가 켜져 있었다면, 퇴각 후 재시작이 꺼져 있던 모든 전투 설정이 **켜짐, N = 0**으로 바뀝니다. 이미 켜져 있던 설정은 그대로 둡니다.
- 이전 스위치가 꺼져 있었다면 아무것도 바꾸지 않습니다.
- 옮긴 뒤에는 다시 실행하지 않으므로, 이후에 직접 끈 설정은 되살아나지 않습니다.

## 파티 전멸 시 동작

전멸 화면의 퇴각 버튼, 확인, 닫기를 순서대로 누르는 기존 동작은 그대로입니다. 달라진 점은 처리 방식입니다.

- 전멸 퇴각은 턴 제한 퇴각과 똑같이 **주회로 세지 않습니다.** 주회 수, 주회 제한, 턴 수와 시간 통계에 더하지 않고, 주회 상태를 초기화한 뒤 퀘스트를 다시 시작합니다.
- 퇴각 횟수와 연속 퇴각 횟수에 더합니다. "3회 연속 퇴각 시 정지"가 켜져 있으면 확인합니다.
- 전멸은 정상 클리어가 아니므로 연속 퇴각 횟수를 0으로 되돌리지 않습니다. 정상적으로 클리어한 주회만 되돌립니다.

## N턴 도달 시 동작

1. 매 턴이 시작될 때, 스킬·카드·커맨드 시작 조건을 검사하기 전에 현재 턴이 N에 도달했는지 확인합니다. 턴은 게임 화면의 TURN 표시와 같은 기준으로 웨이브를 넘어 계속 셉니다. 화면을 읽지는 않습니다.
2. 커맨드 시작 조건(커맨드 카드 개수 선택 모드)으로 **대기한 턴**은 세지 않습니다. N을 4로 정하고 한 턴을 대기했다면, 게임의 TURN이 5가 되는 순간 퇴각합니다.
3. 퇴각은 아래 순서로 진행합니다.
   1. 배틀 메뉴 버튼을 눌러 메뉴를 엽니다. 0.5초 기다린 뒤 최대 3초 동안 퇴각 버튼(한국어 "후퇴하기", 일본어 "撤退する")을 기다립니다. 나타나지 않으면 한 번 더 누르고, 그래도 없으면 정지합니다.
   2. 퇴각 버튼을 누릅니다. 0.5초 기다린 뒤 최대 3초 동안 확인 창(확인/決定 버튼)이 열렸는지 확인합니다. 열리지 않으면 확인 버튼을 누르지 않고 메뉴의 X를 눌러 닫은 뒤 정지합니다. 메뉴만 열린 상태에서 같은 자리를 누르면 게임의 "스킬 사용 확인" 설정이 바뀌기 때문입니다.
   3. 확인 버튼을 누릅니다. 0.5초 기다린 뒤 최대 15초 동안 "퀘스트에서 철수했습니다" 창의 닫기 버튼을 기다립니다.
   4. 닫기를 누르고 퀘스트 목록이 뜰 때까지 5초 기다린 뒤 평소의 주회 흐름으로 돌아갑니다. 15초 안에 닫기 버튼이 나타나지 않으면 먼저 통신 오류(재시도) 창이 떠 있는지 확인합니다. 떠 있으면 그대로 평소 흐름으로 돌아가 기존 처리가 맡고, 이 경우도 퇴각으로 셉니다. 아니고 확인 창이 아직 남아 있으면 확인 버튼을 한 번 더 누르고 0.5초 뒤 다시 최대 15초 기다립니다. 그래도 닫기 버튼이 없으면 아래 표처럼 정지합니다. 아직 전투 중이므로 주회 상태는 초기화하지 않습니다.
4. 이후 평소처럼 맨 위 퀘스트를 다시 선택하고, AP가 부족하면 설정한 회복 아이템으로 회복한 뒤 서포트를 고르고 시작합니다.

## 주회와 통계

- 퇴각한 전투는 전멸이든 턴 제한이든 **주회로 세지 않습니다.** 주회 수, 주회 제한, 턴 수와 시간 통계에 더하지 않습니다.
- 퇴각은 AP를 소모합니다. 다음 주회는 기존 AP 회복 로직을 그대로 따르며, AP가 없으면 평소처럼 정지합니다.
- "이번 주회 후 정지"와 주회 제한은 퇴각 뒤 퀘스트 목록으로 돌아왔을 때 평소와 같이 확인합니다.
- 종료 화면에 **퇴각 N회 (전멸 a회, 턴 제한 b회)** 한 줄이 표시됩니다. 0회이면 표시하지 않습니다.
- 정상적으로 클리어한 주회가 있으면 연속 퇴각 횟수는 0으로 돌아갑니다.

## 정지 조건

| 상황 | 결과 |
|---|---|
| 꺼짐 상태에서 파티 전멸 | "모든 서번트가 패배하였으며 자동 철수는 비활성화 상태입니다" 후 정지 |
| 메뉴나 퇴각 버튼이 두 번 시도해도 나타나지 않음 | "턴 제한 퇴각에 실패했습니다" 후 정지 |
| 확인 창이 열리지 않음 | 메뉴를 닫고 "턴 제한 퇴각에 실패했습니다" 후 정지 |
| 확인을 눌렀는데 닫기 버튼이 15초 안에 나타나지 않고, 통신 오류 창도 확인 창도 없음 | 퇴각 횟수와 주회 상태를 건드리지 않고 "턴 제한 퇴각에 실패했습니다" 후 정지 |
| 확인을 눌렀는데 닫기 버튼이 나타나지 않고 확인 창이 그대로 남아 있음 | 확인을 한 번 더 누르고 다시 15초 기다림. 그래도 없으면 위 행과 같이 정지 |
| 확인을 눌렀는데 닫기 버튼이 나타나지 않고 통신 오류 창이 떠 있음 | 퇴각으로 세고 평소 흐름으로 돌아가 통신 오류 처리에 맡김 |
| 퇴각 후 퀘스트 목록으로 돌아가지 못한 채 한 주회에서 세 번째 퇴각을 시도 | "턴 제한 퇴각에 실패했습니다" 후 정지 |
| "3회 연속 퇴각 시 정지"가 켜져 있고 전멸·턴 제한 퇴각을 합쳐 3번 연속 발생 | "퇴각이 3회 연속 발생해 정지했습니다" 후 정지 |

## 주의

- [주간 미션 클리어](Weekly-Mission-Route-KR.md) 경로에서는 N턴 도달 퇴각을 사용하지 않습니다. 파티가 전멸하면 선택한 전투 설정의 스위치를 따라 퇴각하거나 정지하고, 퇴각했다면 그 경로 퀘스트는 종료합니다.
- N턴 도달 퇴각의 퇴각 버튼은 한국어·일본어 클라이언트의 이미지로 찾습니다. 게임 업데이트로 배틀 메뉴 배치나 문구가 바뀌면 인식되지 않을 수 있습니다.
- 전투 중 퇴각이므로 AP가 소모되고 드롭을 얻지 못합니다. 처음 사용할 때는 N을 크게 잡고 동작을 확인하세요.
