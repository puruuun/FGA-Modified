# 해당 턴의 공격 순서 직접 지정

**정규 버전 0.4.0**에서 일반 카드와 보구를 포함한 세 장의 선택 순서를 해당 턴에 고정할 수 있습니다. [FGA(mod) APK](https://github.com/puruuun/FGA-Modified/releases/tag/v0.4.0)는 기존 수정판과 같은 패키지·서명으로 업데이트 설치합니다. 앱 이름은 FGA(mod), 아이콘은 파란색 Arts입니다.

## 설정 방법

1. 사용할 전투 설정의 **커맨드 편집 → 공격**을 엽니다.
2. **보구 전 공격 카드** 옆 **일반 카드 직접 지정** 버튼을 누릅니다.
3. **이 턴의 공격 순서 직접 지정**을 켭니다.
4. 첫 번째·두 번째·세 번째 공격을 각각 버스터, 아츠, 퀵 또는 서번트 1~3의 보구 중에서 선택합니다.
5. 색이 부족할 때 다른 카드로 채우려면 **카드 부족 시 우선순위로 대체**를 체크합니다. 기본값은 꺼짐이며 직접 지정을 끄면 비활성화됩니다.
6. **저장**을 누르고 표시된 순서를 확인한 뒤 **다음 턴 / 다음 웨이브**로 커맨드에 추가합니다.

직접 지정 중에는 기존 보구 선택과 보구 전 카드 수 대신 지정한 세 장을 사용합니다. 버튼을 다시 열어 토글을 끄면 같은 화면의 기존 설정으로 돌아갑니다. **닫기**로 취소하면 변경을 적용하지 않습니다. 다음 공격 설정을 새로 열 때는 기본 방식으로 시작하므로 원하는 턴에서만 켭니다.

## 문자열 문법

`&` 뒤에 정확히 세 글자를 지정합니다. 대체를 켠 턴은 `&` 바로 뒤에 `?` 한 글자를 추가합니다(`&?b4a`). `?`는 공격 자리가 아니며 나머지 규칙은 같습니다. 기존 `&b4a`는 대체 없이 그대로 실행합니다. `b/a/q`는 각각 **버스터/아츠/퀵**, `4/5/6`은 **현재 전열 1/2/3번 서번트의 보구**입니다. 일반 카드의 소유 서번트를 별도로 제한하지 않으므로 한 서번트의 카드로 만드는 스킬을 사용할 때는 그 스킬을 먼저 설정하세요.

```text
&ba4,&bba,&b5a,#,
```

| 명령 | 선택 순서 |
|---|---|
| `&ba4` | 버스터 → 아츠 → 전열 1번 보구 |
| `&bba` | 버스터 → 다른 버스터 → 아츠 |
| `&b5a` | 버스터 → 전열 2번 보구 → 아츠 |
| `&a4b` | 아츠 → 전열 1번 보구 → 버스터 |
| `&4ba` | 전열 1번 보구 → 버스터 → 아츠 |

기존 `,`는 턴, `,#,`는 웨이브 구분자입니다. 기존 스킬은 `&` 앞에 붙입니다. 예를 들어 `ab&b5a`는 스킬 a·b를 사용한 후 고정 공격을 수행합니다. 대문자 B/A/Q 입력은 소문자로 정규화합니다. WB·RB 등 상성 지정은 이 문법에서 지원하지 않습니다.

고정 공격은 해당 턴의 마지막 명령이어야 합니다. 같은 턴에서 기존 보구 명령이나 `n1/n2`와 함께 사용하면 오류로 중단합니다. 같은 보구를 두 번 지정하거나 세 장보다 짧거나 긴 명령도 거부합니다. 기존 무동작 `0`은 앞에 있어도 무시합니다.

## 선택 규칙과 제한

- 현재 카드 화면을 인식해 필요한 세 장을 모두 결정한 후 클릭합니다. 같은 색 안에서는 **약점 → 일반 → 내성** 순서로 고르고 상성이 같으면 왼쪽부터 선택합니다. 이미 선택한 일반 카드는 제외합니다.
- 스턴 등 사용 불가 일반 카드는 제외합니다. 대체를 끈 상태에서 지정 색이 부족하거나, 대체를 켜도 사용 가능한 일반 카드가 부족하거나, 정상 카드의 종류를 판독하지 못하면 **첫 카드도 누르지 않고 중단**합니다. 지정한 보구의 전열 위치가 비어 있어도 중단합니다.
- 기본 직접 지정에는 카드·서번트 우선순위를 적용하지 않습니다. 대체를 켜면 부족한 일반 카드 자리만 현재 웨이브와 선택된 첫 번째·두 번째 설정의 카드·서번트 우선순위를 따릅니다. 두 방식 모두 브레이브 체인 선택, 카드 재정렬과 추가 보구 자동 사용을 적용하지 않습니다. 다음 턴의 일반 공격은 기존 방식으로 동작합니다.
- 기존 스킬 자동 사용과 공통 셔플 설정은 유지합니다. 스킬과 셔플 이후의 실제 손패에서 지정한 종류를 찾습니다. 스킬이 만든 손패를 유지하려면 공통 셔플 조건도 확인하세요.
- **보구 게이지·보구 봉인·사용 가능 상태를 새로 판독하는 기능은 아닙니다.** 기존 보구 실행과 같이, 사용할 보구가 준비되도록 스킬·충전 설정을 구성해야 합니다.
- 첫 번째·두 번째 시작 조건의 커맨드에 모두 사용할 수 있고, 기존 `.fga` 복사·내보내기·가져오기에 명령 문자열이 포함됩니다. 기존 0.3.0 APK는 `&` 명령을 해석할 수 없습니다.

## 카드 부족 시 우선순위로 대체 — 1.6.7-beta.1

체크하면 세 자리 전체에서 존재하는 지정 색을 먼저 확보합니다. 같은 색은 약점 → 일반 → 내성 순서로, 상성이 같으면 화면 왼쪽부터 확보합니다. 여러 자리가 같은 색을 요구하면 앞선 자리가 가장 좋은 카드를 먼저 확보합니다. 이후 빈 일반 카드 자리만 남은 손패의 기존 카드·서번트 우선순위로 채웁니다. 보구 자리와 확보한 카드의 자리는 바꾸지 않습니다.

예를 들어 `&?b4a`(버스터 → 전열 1번 보구 → 아츠), 아츠 한 장·퀵 네 장, 버스터 > 아츠 > 퀵 우선순위이면 **퀵 → 전열 1번 보구 → 아츠**입니다. 마지막 아츠를 먼저 확보하므로 앞선 대체 자리가 그 아츠를 가져가지 않습니다. 같은 손패에서 `&b4a`는 클릭 없이 중단합니다.

이 선택은 해당 턴에만 저장됩니다. 편집·복사·`.fga` 내보내기와 가져오기, 첫 번째·두 번째 설정 모두에서 유지합니다. 체크를 해제하고 저장하면 `?`가 제거되며 새 공격은 꺼짐으로 시작합니다. **닫기**는 변경을 적용하지 않습니다. 이전 버전은 `&?` 문법을 해석하지 못하므로 이 명령을 사용할 앱도 업데이트하세요.

판독하지 못한 정상 카드, 불완전하거나 중복된 손패, 부족한 사용 가능 카드, 비어 있는 지정 보구 전열은 대체하지 않습니다. “고정 공격 …에 필요한 카드를 확인하지 못했습니다. 카드는 선택하지 않았습니다.”가 나오면 손패와 전열을 확인하고 지정 색·대체 설정을 조정하세요. 잘못된 명령은 커맨드 문법을 고쳐야 합니다. 보구 사용 가능 상태를 새로 판독하지 않습니다.

대체가 실제 발생한 공격은 진단 로그의 `FGA.DirectCards`에 요청 명령과 최종 세 카드 순서를 한 번 기록합니다.
