# 해당 턴의 공격 순서 직접 지정

**0.4.0-beta.1**에서 일반 카드와 보구를 포함한 세 장의 선택 순서를 해당 턴에 고정할 수 있습니다. [베타 APK](https://github.com/puruuun/FGA-card-count/releases/tag/v0.4.0-beta.1)는 기존 수정판과 같은 앱·패키지·서명으로 업데이트 설치합니다.

## 설정 방법

1. 사용할 전투 설정의 **커맨드 편집 → 공격**을 엽니다.
2. **보구 전 공격 카드** 옆 **일반 카드 직접 지정** 버튼을 누릅니다.
3. **이 턴의 공격 순서 직접 지정**을 켭니다.
4. 첫 번째·두 번째·세 번째 공격을 각각 버스터, 아츠, 퀵 또는 서번트 1~3의 보구 중에서 선택합니다.
5. **저장**을 누르고 표시된 순서를 확인한 뒤 **다음 턴 / 다음 웨이브**로 커맨드에 추가합니다.

직접 지정 중에는 기존 보구 선택과 보구 전 카드 수 대신 지정한 세 장을 사용합니다. 버튼을 다시 열어 토글을 끄면 같은 화면의 기존 설정으로 돌아갑니다. **닫기**로 취소하면 변경을 적용하지 않습니다. 다음 공격 설정을 새로 열 때는 기본 방식으로 시작하므로 원하는 턴에서만 켭니다.

## 문자열 문법

`&` 뒤에 정확히 세 글자를 지정합니다. `b/a/q`는 각각 **상성 무관한 버스터/아츠/퀵**, `4/5/6`은 **현재 전열 1/2/3번 서번트의 보구**입니다. 일반 카드의 소유 서번트를 별도로 제한하지 않으므로 한 서번트의 카드로 만드는 스킬을 사용할 때는 그 스킬을 먼저 설정하세요.

```text
&ba4,&bba,&b5a,#,
```

| 명령 | 선택 순서 |
|---|---|
| `&ba4` | 버스터 → 아츠 → 전열 1번 보구 |
| `&bba` | 버스터 → 다른 버스터 → 아츠 |
| `&b5a` | 버스터 → 전열 2번 보구 → 아츠 |
| `&a4b` | 아츠 → 전열 1번 보구 → 버스터 |
| `&4ba` | 전열 1번 보구 → 버스터 → 아츠 |

기존 `,`는 턴, `,#,`는 웨이브 구분자입니다. 기존 스킬은 `&` 앞에 붙입니다. 예를 들어 `ab&b5a`는 스킬 a·b를 사용한 후 고정 공격을 수행합니다. 대문자 B/A/Q 입력은 소문자로 정규화합니다. WB·RB 등 상성 지정은 이 문법에서 지원하지 않습니다.

고정 공격은 해당 턴의 마지막 명령이어야 합니다. 같은 턴에서 기존 보구 명령이나 `n1/n2`와 함께 사용하면 오류로 중단합니다. 같은 보구를 두 번 지정하거나 세 장보다 짧거나 긴 명령도 거부합니다. 기존 무동작 `0`은 앞에 있어도 무시합니다.

## 선택 규칙과 제한

- 현재 카드 화면을 인식해 필요한 세 장을 모두 결정한 후 클릭합니다. 같은 종류가 여러 장이면 **왼쪽부터**, 이미 선택한 일반 카드는 제외합니다.
- 스턴 등 사용 불가 일반 카드는 제외합니다. 필요한 일반 카드가 부족하거나 정상 카드의 종류를 판독하지 못하면 **첫 카드도 누르지 않고 중단**합니다. 지정한 보구의 전열 위치가 비어 있어도 중단합니다.
- 이 턴에는 카드·서번트 우선순위, 브레이브 체인 선택, 카드 재정렬과 추가 보구 자동 사용을 적용하지 않습니다. 다음 턴의 일반 공격은 기존 방식으로 동작합니다.
- 기존 스킬 자동 사용과 공통 셔플 설정은 유지합니다. 스킬과 셔플 이후의 실제 손패에서 지정한 종류를 찾습니다. 스킬이 만든 손패를 유지하려면 공통 셔플 조건도 확인하세요.
- **보구 게이지·보구 봉인·사용 가능 상태를 새로 판독하는 기능은 아닙니다.** 기존 보구 실행과 같이, 사용할 보구가 준비되도록 스킬·충전 설정을 구성해야 합니다.
- 첫 번째·두 번째 시작 조건의 커맨드에 모두 사용할 수 있고, 기존 `.fga` 복사·내보내기·가져오기에 명령 문자열이 포함됩니다. 기존 0.3.0 APK는 `&` 명령을 해석할 수 없습니다.

## 확인 범위

실행 로직 101개·설정 저장 15개·앱 편집기 등 8개, 총 **124개 테스트**가 통과했습니다. 명령 해석·턴/웨이브·스킬 결합, 정확한 클릭 순서, 반복 일반 카드의 중복 방지, 상성 무시, 자동 정책 배제, 카드 부족·스턴·인식 실패·빈 전열의 클릭 전 중단, 다음 턴 초기화, 두 번째 설정 적용, 편집기의 읽기·변경·저장과 기존 문법 호환을 포함합니다.

실제 Android 설정 화면의 시각 검수와 FGO에서의 터치 동작은 아직 검증하지 않았습니다. 이 릴리스는 베타로 표시합니다.

```sh
FGA_VERSION_CODE=3066 FGA_VERSION_NAME=0.4.0-beta.1 ./gradlew \
  :scripts:test :prefs:testCiUnitTest :app:testCiUnitTest :app:compileDebugKotlin :app:assembleCi
```
