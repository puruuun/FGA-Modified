# オリジナルFGAのデータを取り込む

**その他の設定 → 追加機能 → オリジナルFGAのデータを取り込む**から、次のいずれかを選択します。

- **スクリプトのみ**
- **サポート画像のみ**
- **スクリプトとサポート画像の両方**

## 準備と取り込み

1. スクリプトを移行するには、オリジナルFGAの **バトルの設定 → すべてエクスポートする** で `.fga` ファイルをフォルダーに保存します。
2. 修正版の取り込み画面で **エクスポートしたスクリプトのフォルダーを選択** からそのフォルダーを指定します。サブフォルダー内の `.fga` ファイルも読み込みます。
3. 画像を移行するには、**元のサポート画像フォルダーを選択** でオリジナルFGAの保存先またはその中の `support` フォルダーを指定します。`servant`・`ce`・`friend` 内の画像およびサーヴァント別のサブフォルダーが、現在の修正版保存先にコピーされます。
4. **取り込む** を押すと進行状況とスクリプト・画像ごとの取り込み／スキップ／失敗件数が表示されます。エラーがあるファイルはファイル名と理由が表示され、他のファイルの処理は続行されます。

アプリをアップデートすると、内蔵サポート画像は保存先フォルダーへ自動的に再抽出されます（保存先フォルダーを変更した直後にも1回抽出されます）。

画像を取り込む前に、**その他の設定 → ストレージ** で修正版の保存先フォルダーを設定してください。両方を取り込む場合はスクリプトと画像のフォルダーをそれぞれ選択します。スクリプトのみ取り込む場合は、画像フォルダーや保存先の指定は不要です。

## 既存データと競合

- 既存のスクリプトは保持され、名前を含めて保存内容がすべて一致する設定については不足分のみが新規追加されます。たとえばオリジナルから同じ内容のスクリプトが `a.fga`、`a (1).fga`、`a (2).fga` としてエクスポートされていた場合、未登録なら3件すべて取り込まれ、すでに1件ある場合は2件が追加され1件はスキップされます。同じフォルダーを再度取り込んでもコピーは増えません。名前が同じでも内容が異なる場合は、それぞれ別スクリプトとして取り込まれます。
- 同名の既存画像は、デフォルトでは既存ファイルを保持してスキップされます。元の画像で置き換える場合は **同名の既存画像を上書きする** にチェックを入れてください。
- 元のフォルダーとコピー先に同じ保存先を指定した場合、同一の画像ファイルは上書きされません。元の画像フォルダー内に別のコピー先を指定する設定は拒否されます。
- サポート画像のファイル名とスクリプト内の参照名はそのまま保持されます。スキップや失敗した画像がある場合は、読み込んだスクリプトのサポート設定を確認してください。

## 互換範囲

ビルド番号による制限はありません。旧バージョンのフラットな JSON 形式 `.fga` ファイルと現行形式の両方を読み込み、対応する追加設定値も保持されます。この修正版で読み取れないコマンドが含まれるスクリプトは失敗として案内されます。今後オリジナル版のファイル形式やコマンド構文が変更された場合は、互換対応の追加が必要になることがあります。

オリジナルアプリの非公開データには直接アクセスしません。オリジナルからエクスポートされたスクリプトと、ユーザーがアクセスを許可した画像フォルダーのみを使用します。アプリ共通設定・AP回復設定・Androidの権限は移行されません。

## 修正版のスクリプトをオリジナルFGAへ戻す場合

修正版からエクスポートした `.fga` ファイルは、オリジナルFGAでもそのまま読み込むことができます。ファイル形式が同じで、オリジナル版は未知の項目を保持したまま使用しないため、アプリが停止したり設定が破損したりすることはありません。スキルコマンド、基本的なカードの優先順位・サーヴァント優先、ブレイブチェイン、リピート設定、パーティー、素材、サポートの基本設定はオリジナル版でもそのまま動作します。

ただし、修正版専用の設定はオリジナル版では**適用されません**。

| 修正版の設定 | オリジナルFGAでの動作 |
|---|---|
| スキルコマンドの `&`（[攻撃順の直接指定](Direct-Cards-JA.md)）・`aH{…}`（[ハクノシャッフル](Hakuno-Shuffle-JA.md)）・`t4`〜`t9`・`tR`・`tA`〜`tF`（[敵配置ごとのターゲット指定](Enemy-Layout-Targets-JA.md)） | **戦闘開始時にコマンド解釈エラーで停止します。** オリジナル版で使う場合は該当部分を削除するか通常のコマンド（`t1`〜`t3` など）に書き換えてください。 |
| サポートの[再臨の区別](Ascension-Select-JA.md)・[アペンドスキル判定](Support-Append-Skills-JA.md)・+62/+16 スコア判定・[宝具レベル判定](Support-NP-Level-JA.md)・クエスト後のフレンド申請 | 無視されます。**これらの条件なしでサポートが選ばれるため**、オリジナル版でサポート設定を再確認してください。 |
| 2番目・3番目の実行設定、[サーヴァント条件モード](Card-Count-Start-JA.md) | 無視され、1番目（基本）の設定のみで動作します。 |
| [カードの優先順位の拡張](Card-Priority-JA.md)（サーヴァント方式・ターン基準・4項目目以降・青子のカード変化を検出） | 無視され、基本的なカードの優先順位とサーヴァントの優先順位設定のみが適用されます。 |
| [撤退して再開](Turn-Limit-Retreat-JA.md)・[絆ポイント集計・MAX停止](Bond-Tracking-JA.md)・[バトル設定フォルダ](Battle-Config-Folders-JA.md) | 無視されます（フォルダーなしで取り込まれ、撤退はオリジナル版のグローバル設定に従います）。 |
| コマンドシャッフル「1ターン目のコマンド開始条件を満たしていない場合」 | オリジナル版にない値のため **使用しない** に戻ります。 |

オリジナルFGAへ移行した後は、サポート設定とスキルコマンドを一度確認してからご使用ください。
