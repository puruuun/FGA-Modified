# オリジナルFGAのデータ取り込み

[한국어](Original-FGA-Import-KR.md) | [English](Original-FGA-Import.md) | [日本語](Original-FGA-Import-JA.md)

**その他のオプション → 追加機能 → オリジナルFGAのデータを取り込む**から、**スクリプトのみ**・**サポート画像のみ**・**両方**を選択します。

1. オリジナルFGAの**保存先の最上位フォルダーを1つ**選び、スクリプトのみ・画像のみ・両方を指定します。
2. スクリプトを移す場合、先に原版ですべてエクスポートし、`.fga`ファイルをその保存先またはサブフォルダーに保存してください。原版アプリの非公開領域にしかないスクリプトは直接読み取れません。
3. **取り込む**を押すと、選択したフォルダー内の`.fga`と`support/servant`・`support/ce`・`support/friend`の画像を自動で探します。種類ごとに別のフォルダーを選ぶ必要はありません。
4. 種類ごとの取り込み・スキップ・失敗件数と、失敗したファイル名および理由を表示します。一部のファイルが失敗しても他のファイルは処理します。

画像のコピー先は現在のFGA(mod)保存先です。事前に**その他のオプション → ストレージ**で設定してください。スクリプトのみの場合はコピー先フォルダーの指定は不要です。

既存スクリプトは保持し、新しい項目として追加します。名前を含めて保存内容が同一ならスキップし、同名でも内容が異なる場合は別項目として追加します。同名の画像は初期設定ではスキップします。置き換える場合は**同名の既存画像を上書きする**を選択してください。同一内容や同じファイルは再書き込みしません。元の画像フォルダー内へのコピーは拒否します。

画像名とスクリプト内の参照名を維持します。画像の欠落・スキップ・失敗があった場合は、取り込んだスクリプトのサポート設定を確認してください。

ビルド番号による制限はありません。旧版の平面JSON形式と現在の`.fga`形式に対応します。この改変版で解析できないコマンドがあるスクリプトは失敗として案内します。今後、原版のファイル形式やコマンド文法が変更された場合は対応追加が必要になることがあります。

原版の非公開データには直接アクセスしません。エクスポートしたファイルと、ユーザーがアクセスを許可した画像フォルダーを使用します。共通設定・AP回復設定・Android権限は移行しません。

3つの選択方法、旧形式、重複回避、名前の保持、一部失敗、画像の競合を自動テストで確認します。Androidのフォルダー選択画面や端末固有のストレージ機能は、別途実機で確認する必要があります。
