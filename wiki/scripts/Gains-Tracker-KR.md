# 로그 수집

**KR·JP 서버의 게임이 서버와 주고받는 응답을 이 기기 안에서 읽기 전용으로 모아, 계정 요약(AP, 성정석, 과일, 프리즘, QP 등)과 실행별 전투 획득량을 보여 줍니다.**

Android 10 이상에서 KR 서버(`com.netmarble.fgok`)와 루트 기기의 공식 JP 서버(`com.aniplex.fategrandorder`)를 지원합니다. Android 9 이하에서는 메뉴가 보이지 않습니다. 메인 화면의 계정 카드, **저장소 → 로그 아이콘 데이터 다운로드**, **추가 기능 → Chaldea 파일 내보내기**와 **프렌드 관리**는 **로그 수집 사용**을 켠 Android 10 이상에서만 나타나며, 스위치를 켜고 끄면 화면을 나가지 않아도 바로 나타나거나 사라집니다. 저장된 데이터는 삭제되지 않습니다. **로그 수집** 설정 항목(스위치를 켜는 곳)과 **메인 → 로그**는 스위치와 관계없이 그대로 보입니다. 전투 스크립트를 로그 수집 중에 시작하면 재료 개수와 인연 정지는 응답으로 판단합니다. 자세한 적용 조건은 아래를 참고하세요.

## JP 서버 (루트) — 1.9.0 개발 중

Android 10 이상에서 공식 FGO JP 앱이 설치되어 있으면 **로그 수집 → JP 서버 (루트)**가 표시됩니다. 루트 권한이 필요하며, 권한이 없거나 거부하면 켤 수 없습니다. 스위치를 켜 두면 **로그 수집 시작** 한 번으로 설치된 KR·JP 게임을 함께 수집합니다. JP만 사용하는 경우에도 시작할 수 있으며 KR 게임이나 KR 인증서는 필요하지 않습니다. JP 스위치가 켜져 있고 공식 JP 앱과 JP 인증서가 준비되어 있어야 합니다.

- KR 인증서의 **인증서 만들기 / 설치 방법** 버튼 아래에 JP 설정이 표시됩니다. 스위치를 켜면 JP 전용 인증서를 만들고 시스템 CA 저장소에 자동 설치합니다. KR 인증서는 바뀌지 않고 Download에 JP 인증서를 저장하지 않습니다. **JP 인증서: 설치됨**은 JP 인증서의 현재 설치 상태입니다.
- JP 응답으로 추가된 계정은 메인 카드·대시보드·프렌드 관리 계정 선택기에 **JP**로 표시하며, KR 계정은 **KR**로 표시합니다. 계정은 `userId`별로 따로 보관합니다. JP의 Chaldea 내보내기는 기존 응답 구조를 그대로 사용하며, Chaldea의 기본 서버 판별은 JP입니다.
- 처음 설치했을 때 게임이 켜져 있었다면 JP 게임을 종료한 뒤 다시 실행하세요. FGA는 게임을 종료하지 않습니다.
- 재부팅하면 설치가 해제되며 다음 로그 수집 시작 시 자동으로 다시 설치합니다. 설치에 실패해도 KR 수집은 계속됩니다.
- 로그 수집을 중지해도 CA는 남습니다. **JP 서버 (루트)**를 끄면 가능한 마운트를 해제하고, **완전히 지우려면 기기를 재부팅하세요**를 표시합니다.

## 안전과 개인정보

- VPN으로 **게임 앱의 통신만** 이 기기 안의 프록시로 보냅니다. 다른 앱은 지나가지 않습니다.
- 프록시는 요청과 응답을 **고치지 않고** 그대로 전달하며, 게임 서버(`yfgo-game.netmarble.com`, JP 설정을 켠 경우 `game.fate-go.jp`)의 응답만 읽습니다. 다른 주소는 그대로 통과시킵니다.
- 계정·로그인 토큰 경로는 읽지도 저장하지도 않습니다. 요청 본문, 토큰, 헤더는 기록하지 않습니다.
- 모은 계정 요약은 기기 안(앱 전용 저장소)에만 저장하고 **어디로도 전송하지 않습니다**.
- 인증서 개인 키는 저장하지 않습니다. 인증서를 만들 때 서명용 키로 한 번만 서명하고 버립니다.

## 설정 순서

1. **더 많은 옵션 → 추가 기능 → 로그 수집**를 엽니다.
2. **로그 수집 사용**을 켜고 **로그 수집 사용 전 안내**를 읽습니다. **동의하고 사용**을 눌러야 설정이 켜집니다. **취소**하면 꺼진 상태로 남습니다.
3. **인증서 만들기**를 누릅니다. 인증서가 `Download/fga-capture-ca.cer`로 저장됩니다.
4. **설치 방법 → 보안 설정 열기**로 설정 앱을 엽니다. **보안 → 암호화 및 사용자 인증 정보 → 인증서 설치 → CA 인증서**를 고르고 `fga-capture-ca.cer`를 선택합니다. 기기에 따라 메뉴 이름이 조금 다를 수 있습니다. 메뉴를 찾기 어려우면 설정 앱 검색창에서 **CA 인증서**를 검색하세요.
5. FGA로 돌아오면 인증서 상태가 **CA 인증서로 설치되어 있습니다**로 바뀝니다.
6. **VPN → 시작**을 누릅니다. 처음에는 Android의 VPN 연결 요청이 나오며 허용합니다.
7. 게임을 시작합니다(이미 켜져 있었다면 한 번 종료하고 다시 시작합니다). 로그인 응답을 받으면 계정 요약 카드가 채워집니다. 스냅샷이 없는 동안에는 **로그 수집을 켠 상태에서 게임을 시작해 주세요**가 표시됩니다.

게임이 인증서를 거부하면 VPN 줄에 거부 횟수와 안내가 표시됩니다. CA 인증서로 설치했는지 확인하세요.

## 처음 사용할 때 안내

**로그 수집 사용 전 안내**는 작동 방식(기기 안의 VPN·프록시와 직접 설치한 CA 인증서), 필요한 권한, 다른 VPN과의 동시 사용 제한을 설명합니다. 작은 화면에서는 안내 내용을 위아래로 스크롤할 수 있습니다.

- 게임 업데이트로 동작하지 않을 수 있습니다. 로그인이 안 되면 로그 수집을 끄면 됩니다.
- 일부 화면(이벤트 안내 등)이 처음에 늦게 뜰 수 있습니다.
- 로그 수집이 꺼져 있던 동안의 변화는, 켠 상태로 다시 로그인하기 전까지 반영되지 않습니다.
- 게임 운영사 약관상 제3자 프로그램 사용은 제재 대상이 될 수 있습니다.
- **이 기능의 사용과 그 결과에 대한 책임은 사용자 본인에게 있습니다.**

동의는 저장됩니다. 이후 안내 문구의 동의 버전이 바뀌면 다시 동의를 요청할 수 있습니다. 설정의 **안내 다시 보기**로 언제든 다시 읽을 수 있습니다. 다시 보는 것만으로 사용 설정이 켜지지는 않습니다.

## 메인 화면에서 쓰기

로그 수집 사용 설정이 켜져 있고, Android 10 이상이며 KR 게임 또는 JP 설정을 켠 공식 JP 게임이 설치되어 있으면 서비스 버튼 왼쪽에 **로그 수집 시작** 버튼이 나타납니다. 두 버튼이 한 줄에 들어가지 않으면 서비스 버튼 위로 올라갑니다.

- **파란색 · 로그 수집 시작**: 수집이 꺼져 있습니다. 동의가 없다면 안내부터 표시합니다. 인증서가 없으면 짧은 안내와 함께 로그 수집 설정을 엽니다. Android VPN 허용이 필요하면 연결 요청을 표시하고, 허용한 뒤 시작합니다.
- **노란색 · 로그 수집 중지**: 실제 VPN이 실행 중입니다. 누르면 로그 수집 VPN만 멈추고 FGA 서비스는 계속 실행됩니다.
- 다른 VPN이 대신하거나 알림에서 중지하거나 시스템이 VPN을 종료하면 버튼은 바로 파란색으로 돌아옵니다.

로그 수집 사용 설정이 켜져 있고(Android 10 이상) 로그인 스냅샷이 있으면 메인 화면 위쪽에 **프로필 카드**가 나타납니다. 계정마다 마스터 이름과 작은 **KR / JP** 서버 표시, AP 현재/최대와 AP가 가득 차는 시각을 표시하며, 이미 가득 차면 **가득 참**으로 표시합니다. 카드는 빌드·접근성 상태 줄 아래에 일정한 폭으로 가로 나열되며, 여러 계정이면 현재(최근 플레이) 계정이 맨 앞에 옵니다. 화면에 다 들어가지 않으면 좌우로 스크롤합니다. 화면을 보는 동안 AP는 1분마다 갱신됩니다. 카드를 누르면 해당 계정의 대시보드가 열립니다.

빌드 배지 오른쪽에는 **접근성 서비스: 활성화됨 / 비활성화됨** 상태 칩이 표시됩니다. 좁으면 배지 아래 오른쪽으로 줄바꿈됩니다. 누르면 접근성 설정을 열거나 켜진 접근성 서비스를 끕니다. FGA 서비스가 실행 중이면 접근성 서비스를 끄는 동작은 사용할 수 없습니다.

전투 실행 창을 열 때 로그 수집이 실행 중이면 **인연포인트 획득량 추적** 옵션은 숨기고, **인연 MAX 확인 시 정지**와 정지가 켜져 있을 때의 무시할 칸 설정은 유지합니다. 숨겨진 추적 설정의 저장값은 바뀌지 않습니다.

## 여러 계정 쓰기

계정을 직접 선택할 필요가 없습니다. 로그인 응답의 `userId`로 계정을 자동으로 추가하고, 이후 응답도 그 안의 계정 ID에 맞춰 저장합니다. 다른 계정으로 로그인하면 메인의 가로 카드 목록에서 **마지막으로 플레이한 계정**이 맨 앞으로 옵니다. 서로 다른 계정 ID가 섞인 응답은 반영하지 않습니다.

**더 많은 옵션 → 추가 기능 → 로그 수집**에는 계정별 카드가 최근 플레이 순으로 표시됩니다. 각 카드에서 계정 요약과 마지막 갱신 시각을 확인할 수 있고, 현재 계정에는 **최근 플레이**가 표시됩니다.

- **이름 변경**: 처음에는 게임의 마스터 이름을 사용합니다. 원하는 이름을 입력할 수 있으며, 비워 두고 확인하면 마스터 이름으로 돌아갑니다. 메인 카드에도 이 이름이 표시됩니다.
- **삭제**: 확인 창에 표시된 계정의 수집 데이터와 해당 Chaldea 파일만 지웁니다. 최근 플레이 계정을 지우면 남은 계정 중 가장 최근 계정이 표시됩니다. 이후 그 계정으로 다시 로그인하면 새로 추가됩니다.
- 계정 상태와 이름은 앱 내부 `capture/accounts/<userId>/`에 각각 보관됩니다. 이전 단일 계정 데이터는 처음 실행할 때 자동으로 이전됩니다. 로그인 스냅샷이 없는 새 계정은 다음 로그인 후 요약이 채워집니다.

전투 로그에는 실행 계정의 이름이 표시됩니다. 실행은 시작할 때의 계정에 속하며, 아직 계정이 없으면 처음 확인된 응답의 계정에 속합니다. 도중에 다른 계정의 응답이 들어와도 그 실행의 획득량에는 섞이지 않습니다. 기록에 저장된 이름은 나중에 이름을 바꾸거나 계정을 지워도 유지됩니다.

**듀얼 앱·복제 앱 등 여러 게임 인스턴스의 동시 실행은 지원하지 않습니다.** 공식 KR 게임(`com.netmarble.fgok`)과 JP 설정을 켠 공식 JP 게임(`com.aniplex.fategrandorder`)의 응답을 수집합니다. BetterFGO는 지원 대상에서 제외됩니다.

## FGA 서비스와 함께 쓰기

로그 수집을 켜고 KR 또는 JP 경로가 준비된 상태에서 메인의 **서비스 시작**을 누르면, FGA 서비스가 시작된 뒤 로그 수집 VPN도 시작합니다. VPN 권한이 없으면 그 자리에서 Android 연결 요청을 표시하며, 허용하면 VPN을 시작합니다. 인증서가 없으면 짧은 안내를 표시하고 FGA 서비스는 그대로 실행합니다.

**서비스가 멈추면 로그 수집 중지**(기본 꺼짐, 기존에 저장한 설정은 유지)를 켜 두면 메인의 서비스 중지, FGA 서비스 알림의 중지, 시스템에 의한 서비스 종료 시 로그 수집도 멈춥니다. 직접 시작한 VPN도 포함합니다. 설정을 끄면 서비스가 멈춰도 로그 수집은 유지됩니다.

스크립트를 시작할 때 로그 수집이 꺼져 있다면, KR 서버 또는 JP 경로가 준비된 공식 JP 서버이고 로그 수집 사용 설정·VPN 권한·인증서가 준비된 경우 다시 시작합니다. 권한이나 인증서가 없으면 안내만 표시하고 스크립트는 그대로 실행합니다. **스크립트 종료만으로는 VPN을 멈추지 않습니다.** 실행별 획득량 수집은 기존처럼 스크립트 시작부터 끝까지입니다.

## 전투의 재료 집계와 인연 정지

전투 스크립트 시작 시 **KR 서버이고 로그 수집 VPN이 실행 중이면**, 해당 실행은 재료 개수와 인연 정지에 로그 수집 응답을 사용합니다. 스크립트 시작 때 VPN을 자동으로 시작하는 중이면 최대 3초 기다린 뒤 결정합니다. 결정은 실행 중 바뀌지 않으므로, 중간에 VPN을 켜도 기존 화면 판독 실행은 그대로이고 중간에 꺼도 응답 방식은 유지됩니다. JP와 수집 없이 시작한 실행은 기존 동작을 유지합니다.

- **재료**: 드롭 화면에서 선택한 재료의 이미지 매칭을 생략하고, 해당 전투 응답의 아이템별 드롭 개수를 합산합니다. 재료 개수 제한은 기존처럼 드롭 화면에서 확인하며, 실행 종료 시 제한 개수 자동 차감에도 같은 합계를 사용합니다. 종료 화면과 전투 로그의 재료 집계에도 반영합니다.
- **인연**: OCR과 그 판독 대기를 생략하고, 결과 화면을 인연 추적을 끈 때와 같은 횟수로 넘깁니다. 종료 화면의 캐릭터별 인연 합계 대신 로그의 **획득량 (로그 수집)**에서 서번트별 포인트를 확인합니다.
- **인연 MAX 정지**: 인연 기능과 MAX 정지가 켜져 있으면 첫 결과 화면에서 판단합니다. 덱 순서에서 서포트·팔로워를 제외한 1~5번 중, 무시하지 않은 칸이 인연 상한(`10 + 인연 상한 확장 횟수`)에 도달했거나 이번 전투에서 레벨이 올라 10 이상이 되면 기존 MAX 메시지로 정지합니다. 완료한 퀘스트는 주회 횟수에 포함합니다.
- **응답 누락**: 첫 결과 화면에서 해당 전투 응답을 최대 3초 기다립니다. 응답이 오지 않거나 필요한 데이터가 빠져 있으면 재료 제한·인연 MAX 정지 설정과 관계없이 **정지하지 않고 계속 진행**하며, 그 전투의 재료 개수는 더하지 않습니다. 화면 판독으로 되돌아가지는 않습니다. 인연 MAX는 유지되므로 다음에 응답을 받은 전투에서 정지합니다.

CE 드롭 확인, 스크린샷, 나머지 화면 감지와 터치·대기는 기존 설정을 따릅니다. 인연 설정과 기존 화면 판독 방식은 [인연포인트 누적·MAX 정지](Bond-Tracking-KR.md)를 참고하세요.

## 추가 기능과 Chaldea 파일 내보내기

**더 많은 옵션 → 추가 기능**에는 **서포트 이미지 검색·저장**, **원본 FGA 데이터 가져오기**, **Chaldea 파일 내보내기**가 있습니다. 메인 화면의 도구 메뉴는 없어졌고, 세 항목을 추가 기능 탭에서 바로 엽니다.

**Chaldea 파일 내보내기**는 로그 수집 사용이 켜진 Android 10 이상이고 수집된 계정 데이터가 있을 때만 나타납니다. 계정이 하나면 바로 내보내고, 여러 개면 계정을 골라 해당 계정만 내보냅니다. 로그 수집 설정의 계정 카드에서도 해당 계정을 내보낼 수 있습니다. 로그 화면의 **Chaldea 파일 만들기** 버튼은 추가 기능 탭으로 이동했습니다. 내보내기 전에 계정 카드의 마지막 갱신 시각을 확인하세요.

1. 로그인 스냅샷이 없으면 **로그 수집을 켠 상태에서 게임을 시작해 주세요**가 표시됩니다. 게임을 다시 시작해 계정 카드가 채워진 뒤 재시도합니다.
2. 해당 계정 상태를 `Download/FGA/chaldea-account-<userId>-<yyyyMMdd-HHmm>.json`으로 저장합니다. 계정 정보가 담긴 파일이므로 **계정별로 최신 한 개만 남깁니다**. 다른 계정의 최신 파일은 유지하며, 기존 `chaldea-kr-<userId>-<yyyyMMdd-HHmm>.json`도 계정별로 함께 정리하며, FGA가 예전에 만든 계정 ID 없는 `chaldea-kr-<yyyyMMdd-HHmm>.json` 파일은 내보낼 때 정리합니다.
3. 저장이 끝나면 **저장했습니다. Chaldea에서 이 파일을 선택하세요** 안내 창에 파일 이름과 가져오는 순서를 표시합니다. **확인**은 창을 닫고, **Chaldea로 이동**은 Chaldea를 연 뒤 창을 닫습니다. 자동으로 앱을 열지는 않습니다. Play/GitHub판과 F-Droid판을 지원합니다.
4. Chaldea가 설치되지 않았으면 **Chaldea로 이동** 버튼 대신 설치 안내가 표시됩니다. 파일은 저장되어 있으므로 Chaldea를 설치한 뒤 **가져오기 → HTTPS 스니핑 → 파일에서**에서 안내된 파일을 고르세요. 저장이나 이전 파일 정리에 실패하면 기존 오류 안내를 확인하고 다시 시도합니다.

**파일에는 로그 수집이 실행 중일 때 받은 내용만 반영됩니다.** 로그 수집 없이 플레이했다면 로그 수집을 켜고 게임을 다시 시작해 스냅샷을 갱신한 뒤 파일을 만드세요. FGA는 계정 데이터를 외부로 전송하지 않으며, Chaldea에서 파일을 직접 선택해 가져옵니다.

친구들의 서포트 서번트를 모아 보는 화면은 [프렌드 관리](Friend-Manager-KR.md)를 참고하세요.

## 전투 로그에서 획득량 보기

VPN이 실행 중인 동안 스크립트의 전투 결과를 모읍니다. 직접 켠 VPN과 스크립트가 자동으로 켠 VPN 모두 지원합니다. 스크립트가 끝나면 **메인 → 로그**의 해당 기록에 **추적됨** 표시가 붙고, 상세 요약 아래에 **획득량 (로그 수집)**가 추가됩니다.

- **아이템**: 서버가 알려 준 드롭을 합산해 획득량이 큰 순서로 표시합니다. 개념예장 등도 포함합니다. 계정 스냅샷이 있으면 아이템의 종료 시 보유량도 표시합니다.
- **QP**: 퀘스트 클리어 QP, QP 드롭, 첫 클리어 QP를 합칩니다.
- **마스터 EXP·인연**: 전투 전후 차이를 표시합니다. 인연은 서번트별로 합산합니다.
- **사용한 과일**: 황금색·백은색·청동색·적동색 과일별로 `시작 보유량 − 종료 보유량 + 획득량`을 계산합니다. 시작 또는 종료 스냅샷이 없으면 **알 수 없음**입니다.
- **전투별 내역 펼치기**: 기본은 접혀 있습니다. 펼치면 각 전투의 시각, 퀘스트 ID, 드롭, QP, EXP와 인연을 확인합니다.

스크립트 도중 VPN을 켜거나, 다른 VPN으로 바꾸거나, 권한 철회 등으로 로그 수집이 중지되면 이미 모은 내역은 남습니다. 완료한 주회보다 기록한 전투가 적으면 **전투를 기록하지 못했습니다**라는 누락 안내가 표시됩니다. 이 경우 획득량은 일부일 수 있으며, 중지 후 변화는 반영하지 못합니다. 보유량과 과일 사용량도 마지막으로 추적한 시점을 기준으로 합니다. 계정 스냅샷이 없어도 드롭과 응답에서 확인되는 QP·EXP·인연은 기록합니다. 응답에 없는 값은 **알 수 없음**으로 표시하거나 생략합니다.

로그 수집을 한 번도 실행하지 않은 기록과 예전 기록은 기존 요약만 보여 줍니다. 일시정지 상태 확인 화면과 0회 주회는 전투 로그를 저장하지 않습니다. 스크립트 밖에서 직접 플레이한 전투는 아래의 **스크립트 밖 변화**에 포함됩니다. 전투 로그와 스크립트 밖 기록의 보관 한도는 **로그 → 필터 아이콘 → 로그 보관 개수 (종류별)**에서 50·100·200·500건 중 고르며 기본은 각각 200건입니다.

아이템·서번트·개념예장 이름은 **Atlas Academy의 공개 KR 목록**에서 가져옵니다. 처음 필요할 때 내려받아 앱 내부 `capture/names/`에 ID와 이름, 아이템 아이콘 주소를 보관하고, 모르는 ID가 나타나면 목록별 하루 최대 한 번 갱신합니다. 다운로드가 실패하면 `Item #6510`, `Servant #100100`, `CE #9400010` 같은 ID 표시를 쓰며 기록은 정상적으로 저장합니다.

획득량과 사용량은 **획득 (+)**·**사용 (−)** 두 묶음의 작은 타일로 표시합니다. 아이템은 아이콘·짧은 이름·개수를, QP·마나프리즘·레어프리즘·성정석·과일·성정편은 아이콘과 개수만 표시합니다. 성정석에는 작은 무료·유료 구분도 붙습니다. 모든 타일은 같은 높이이며, 아이콘 왼쪽·텍스트 오른쪽 구조입니다. 종료 시 보유량이나 무료·유료 구분은 아이콘 아래가 아닌 텍스트의 둘째 줄에 표시합니다. 타일을 누르거나 길게 눌러도 팝업은 열리지 않으며, 화면 읽기 도구에는 이름과 개수를 제공합니다. 아이콘 주소 목록은 이름 목록과 별도로 최초 다운로드와 실패 재시도 제한을 관리합니다. 화면에 표시할 아이콘 중 파일이 없는 것만 공개 `static.atlasacademy.io` HTTPS 서버에서 내려받아 앱 내부 `capture/icons/<아이템 ID>.png`에 영구 보관합니다. 이후에는 이 파일을 사용하며 Coil의 디스크 캐시에 의존하지 않습니다. APK에는 포함하지 않습니다. 오프라인이거나 다운로드가 실패하면 이름으로 표시하고, 최소 한 시간 뒤 다시 시도합니다. 공개 목록과 이미지만 내려받고 계정·게임 데이터는 업로드하지 않습니다.

## 계정 대시보드

메인 화면의 계정 카드를 누르면 **그 카드의 계정** 대시보드가 열립니다. 오른쪽 위 **설정 아이콘**은 로그 수집 설정을 엽니다. 설정 왼쪽의 **내보내기 아이콘**은 지금 보고 있는 계정의 Chaldea 파일을 만들고 위의 저장 안내 창을 보여 줍니다(Android 10 이상). 친구 목록을 받은 계정이면 설정 왼쪽(내보내기 아이콘 오른쪽)에 **프렌드 아이콘**이 나타나며, 누르면 그 계정이 선택된 프렌드 관리가 열립니다. **더 많은 옵션 → 추가 기능 → 로그 수집**에서도 설정에 들어갈 수 있습니다.

대시보드는 기기에 저장된 수집 상태를 읽기만 하며 새 응답을 받으면 갱신합니다. 없는 항목은 숨기고 임의로 0을 채우지 않습니다. 폭 840dp 미만은 아래 순서대로 한 열입니다. 840dp 이상은 **왼쪽: 프로필 → 재화와 AP → 보관 현황 → 마술예장 → 최근 활동**, **오른쪽: 서번트 도감 → 아이템 보유 현황**의 독립된 두 열이며 한 페이지로 함께 스크롤합니다. 짧은 카드 아래에는 바로 다음 카드가 붙고, 데이터가 없는 카드는 그 열에서 빠집니다. 최대 폭은 1280dp이며 카드 안의 긴 목록은 일정 높이 안에서 따로 스크롤합니다.

1. **프로필**: 사용자 지정 이름과 게임 이름, 마스터 레벨·경험치, 복사 가능한 친구 코드, 코스트·친구 상한, 생성일·프렌드 포인트, KR / JP, 스냅샷·마지막 갱신 시각을 표시합니다. 생일과 메시지는 표시하지 않습니다.
2. **재화와 AP**: 현재·최대 AP와 완전 회복 시각, 이월 AP, 무료·유료 성정석, 성정편, QP·마나프리즘·레어프리즘, 네 종류 과일·청동색 묘목, 앞으로의 영주 회복 시각을 표시합니다.
3. **보관 현황**: 서번트와 기타(종화·포우 등), 개념예장을 일반 보관 상한과 비교하고 커맨드 코드·두 번째 보관소 수를 표시합니다. Atlas 분류 목록이 없으면 총수만 표시합니다. 보관소 확장 보정값은 상한에 더하지 않습니다.
4. **서번트 도감**: 보유 상태인 서번트의 이름·클래스·레어도·코스트·얼굴, 인연·보구·최고 스킬·최고 레벨을 표시합니다. 정렬 버튼은 **인연 / 코스트 / Lv** 순서이며 기본은 인연입니다. 모두 높은 순서로 정렬하고 인연은 포인트도 비교합니다. 동률은 인연→포인트→코스트→최고 Lv 중 아직 비교하지 않은 항목, 마지막으로 ID 순으로 정합니다. 코스트는 ★5=16, ★4=12, ★3=7, ★2=4, ★1=3, ★0=4이며 마슈는 0입니다. 클래스 필터는 같은 표시 이름을 하나로 묶으며 모든 비스트 종류는 **비스트** 하나로 고릅니다. 모르는 클래스는 원래 이름을 표시합니다. 이름 검색과 보유·인연 요약 줄은 없습니다. 서번트 행은 이름과 클래스·★·Lv·인연·보구, 다음 줄에 스킬·어펜드를 표시하며 해금하지 않은 어펜드는 –로 나타냅니다. 처음 5기이며 **전체 보기 (N)**를 누르면 약 10행 높이의 내부 스크롤 목록에서 선택된 서번트 전체를 볼 수 있고, **접기**로 돌아갑니다.
5. **아이템 보유 현황**: 양수가 있는 아이템을 강화 재료(퓨어 프리즘·짐승의 발자국 포함), 휘석·마석·비석, 피스·모뉴먼트, 성배·전승 결정, 이벤트, 기타로 나눕니다. 이벤트·기타는 처음에 접혀 있고 위에 나온 재화는 중복하지 않습니다. 재화·AP에는 호부와 스톰 포드가 항상(없으면 0) 표시되고, 가진 티포트는 모두 합쳐 **티포트** 타일 하나로 보여 주며 이 항목들은 목록에서 빠집니다.
6. **마술예장**: 레벨순으로 이름·아이콘·레벨과 장착 상태를 표시합니다.
7. **최근 활동**: 해당 계정의 최근 전투 기록과 스크립트 밖 변화의 시각·이름 또는 기간·간단한 증감을 보여 주며 **로그** 버튼으로 전체 기록을 엽니다.

Atlas KR의 공개 아이템·서번트·개념예장·마술예장 목록을 파일별로 캐시하고, 실패 재시도는 각 파일의 하루 제한으로 따로 관리합니다. 이름을 모르는 서번트는 `#ID`로 표시합니다. 얼굴과 마술예장 아이콘은 표시할 때 없는 파일만 공개 HTTPS 자산 서버에서 내려받아 영구 보관합니다. **로그 수집 데이터 삭제** 후에도 이 공개 목록과 이미지는 남습니다. 계정 데이터는 전송하지 않습니다.

**더 많은 옵션 → 저장소 → 로그 아이콘 데이터 다운로드**(로그 수집 사용이 켜진 Android 10 이상에서만 표시)로 대시보드와 로그 아이콘을 미리 준비할 수도 있습니다. 서포트 이미지 추출과는 별개의 항목입니다. 일반 서번트·마슈 얼굴, 스킬·보구 강화 재료, 재화·과일, 마술예장을 받으며 이벤트 아이템은 제외합니다. 첫 다운로드는 약 15 MB로 Wi-Fi를 권장합니다. 화면을 나가도 계속되며 진행 중 다시 눌러도 작업이 중복되지 않습니다. 앱 종료 후에는 다음에 누를 때 없는 파일만 받습니다. 항목 아래에는 진행 상태나 결과만 표시합니다. [진행 표시와 재시도 안내](Default-Support-Images-KR.md)

## 스크립트 밖 변화

로그 수집이 실행 중이고 스크립트를 실행하지 않는 동안의 계정 변화를 **메인 → 로그**에 한 기간당 **한 줄**로 모읍니다. 스킬 강화, 퀘스트 없이 과일 사용, 선물함 수령, 상점 교환, 소환, 수동 퀘스트 등이 대상입니다. 스크립트 실행 중의 응답은 기존 실행별 전투 로그에서 처리하며 이 기록에 중복으로 넣지 않습니다.

첫 자원 변화부터 목록 맨 위에 **진행 중** 기록을 표시합니다. 변화가 추가될 때마다 합계·출처·종료 시각이 바로 갱신됩니다. 다음 경우 같은 기록을 확정하며 중복으로 추가하지 않습니다.

- 다음 스크립트 시작
- 버튼·알림·권한 철회·시스템 종료 등으로 로그 수집 중지
- FGA 서비스 종료(서비스가 멈춰도 로그 수집을 유지하는 설정일 때도 확정)
- 다른 계정의 응답 수신: 이전 계정의 기간을 확정하고 계정을 섞지 않음

변화가 없는 기간은 기록하지 않습니다. **로그인(`login/top`)의 차이는 기록하지 않습니다.** 로그 수집을 끄거나 다른 기기에서 플레이한 변화가 섞일 수 있으므로, 로그인에서는 계산 기준만 새 스냅샷으로 바꿉니다. 이후 받은 응답부터 변화를 계산합니다.

목록 카드는 두 줄입니다. 첫 줄은 제목과 바로 옆의 작은 계정 이름, 오른쪽의 시각(전투는 종료 일시, 스크립트 밖 변화는 시작–종료 범위)을 표시합니다. 둘째 줄은 전투의 주회 수·평균 턴·추적됨·종료 이유 또는 스크립트 밖 변화의 아이템·카드 증감 종류 수·성정석 변화를 표시합니다. 전투 카드는 회색, 스크립트 밖 카드는 별도 색과 아이콘을 사용하며 선택했을 때만 같은 테두리가 붙습니다. 누르면 다음을 확인할 수 있습니다.

- **전체 변화**: 기간 내 아이템·서번트·개념예장·종화·포우·커맨드 코드의 순변화를 합산해 획득(+)과 사용(−) 목록으로 나누고, 각각 양이 큰 순서로 표시합니다. QP, 마나프리즘, 레어프리즘, 무료·유료 성정석은 부호가 붙은 수로 표시합니다.
- **사용한 과일**: 황금색·백은색·청동색·적동색 과일이 각 응답에서 줄어든 수를 합칩니다. 나중에 과일을 받더라도 앞서 사용한 수는 지워지지 않습니다.
- **출처별 변화**: 선물함, 상점, 소환, 룰렛, 강화, AP 회복, 수동 퀘스트, 미션별로 묶습니다. 기본은 접혀 있으며 누르면 같은 형식의 자원 변화를 볼 수 있습니다. 분류되지 않은 응답은 **기타**와 쿼리를 제외한 경로를 표시합니다.

서번트·개념예장·종화·포우는 일반 보관함과 두 번째 보관소의 카드 수를 합쳐 종류별로 비교합니다. 강화에 종화 12장을 쓰면 −12, 상점에서 같은 개념예장 3장을 팔면 −3으로 기록합니다. 보관함 사이 이동이나 레벨·재림·잠금만 바뀐 경우에는 개수 변화가 생기지 않습니다. 커맨드 코드도 종류별 카드 수를 비교합니다.

전체·출처별 상세는 같은 아이콘 타일을 사용합니다. 변하지 않은 재화와 사용하지 않은 과일 등 **0인 항목은 숨깁니다**. 과일은 순변화에 묻히지 않도록 받은 양과 실제 사용한 양을 나누어 표시합니다.

카드 이름과 얼굴은 Atlas KR의 공개 `basic_svt`(모든 카드 종류, 약 2 MB)·`basic_command_code` 목록을 사용합니다. 종화는 같은 이름 뒤에 클래스 이름을 괄호로 붙이며, 모든 비스트 계열은 **비스트**, ALL 클래스는 **전체**로 표시합니다. 이름이 없으면 `#ID`로 표시합니다. 목록은 앱 내부 `capture/names/`에 보관하며 파일이 없거나 받은 지 7일 이상이면 파일별 하루 최대 한 번 갱신을 시도합니다. 카드 얼굴은 표시할 때 없는 파일만 받아 서번트·개념예장·종화·포우는 `capture/icons/servants/`, 커맨드 코드는 `capture/icons/commandCodes/`에 보관합니다. **로그 수집 데이터 삭제** 후에도 공개 목록과 아이콘은 남습니다.

출처는 API 경로로 추정합니다. KR 응답에서 확인된 경로는 `present/receive`(선물함)와 `battle/result`(수동 퀘스트)입니다. 나머지 접두사(`shop/`에서 `shop/Verify` 제외, `gacha/`, `boxGacha/`, `card/`, `svt` 계열, `item/recover`, `eventMission/`, `mission/`)는 추정 분류이며 게임 업데이트나 실제 응답에 따라 달라질 수 있습니다. 강화의 `svt` 계열에는 `svt/`뿐 아니라 `svtCombine/`, `svtSkill/`처럼 접두사를 공유하는 경로도 포함합니다. `shop/Verify`와 모르는 경로는 기타로 남습니다.

열린 기간은 앱 내부 `capture/accounts/<userId>/outside-period.json`에 저장되며 프로세스가 종료되어도 다음 초기화 때 이어집니다. 확정된 기록은 별도의 `outside-log.json`에 설정한 보관 개수만큼 최신 기록을 보관합니다. 진행 중 기록 다음에 전투 로그와 함께 종료 시각 순으로 표시합니다. 폭 840dp 이상에서는 목록과 상세가 나란히 표시됩니다.

상단 **삭제** 옆의 **필터 아이콘**에서 **오늘 / 7일 / 30일 / 전체** 또는 **기간 지정**의 시작일·종료일과 **획득 자원**을 함께 고른 뒤 **적용**합니다. 기간 지정은 양 끝 날짜를 포함합니다. 기간은 기기의 현지 날짜를 기준으로 오늘을 포함하며, 기록의 종료 시각으로 판단합니다. **획득 자원** 위의 검색 칸에 이름 일부를 입력하면(대소문자 구분 없음) 목록이 좁혀지고, 비우면 모두 표시합니다. **모든 자원**과 현재 선택한 자원은 검색 중에도 항상 보입니다. 필터 창은 화면 너비의 약 90%(최대 900dp)로 열리고, 자원 칩은 가로로 이어 붙어 좁은 화면에서도 날짜와 보관 개수 항목에 닿을 수 있습니다. 자원 선택 목록은 보관된 수집 기록에 등장하는 아이템·재화·서번트·개념예장·종화·포우·커맨드 코드의 이름과 아이콘으로 구성합니다. 같은 ID인 아이템과 카드는 각각 구분해서 고릅니다. 선택한 자원을 획득한 전투와 스크립트 밖 기록만 남으며, 스크립트 밖 기록은 다른 출처에서 더 많이 사용해 최종 합계가 음수여도 획득한 출처가 있으면 표시합니다. 필터가 켜져 있으면 아이콘의 작은 표시와 목록 위 한 줄 요약이 나타나며 **해제**로 초기화합니다. 화면을 회전해도 필터와 설정 중인 조건이 유지됩니다. 조건에 맞는 기록이 없으면 필터에 맞는 기록이 없다는 안내가 나옵니다.

같은 필터 창에서 **로그 보관 개수 (종류별)**를 50·100·200·500건 중 선택할 수 있습니다. 전투와 스크립트 밖 기록에 각각 적용하며 기본은 200건입니다. 현재 기록 수보다 작은 값으로 줄이면 확인 후 오래된 기록부터 영구 삭제합니다. 확인을 취소하면 설정과 기록은 바뀌지 않습니다.

상단 휴지통 아이콘이 붙은 **삭제**를 누르면 각 기록에 체크가 나타납니다. **선택 삭제**는 체크한 전투·스크립트 밖 기록을, **전체 삭제**는 필터로 가려진 기록까지 모두 지웁니다. 모두 확인 창을 거치며 **취소**로 선택 모드를 종료할 수 있습니다. 진행 중 기록도 삭제할 수 있습니다. 삭제하면 그 열린 기간을 버리고, 이후 새 변화부터 새 기간을 시작합니다. 이미 확정된 기록을 포함해 삭제는 되돌릴 수 없습니다.

계정을 삭제하면 그 계정의 열린 기간을 버리고, **로그 수집 데이터 삭제**는 모든 열린 기간을 버립니다. 이미 확정된 전투 로그와 스크립트 밖 기록은 유지되므로 **메인 → 로그**에서 따로 삭제합니다.

## 제한

- Android는 한 번에 **VPN 하나**만 허용합니다. 다른 VPN 앱을 켜면 로그 수집은 중지되고 중지 사유가 표시됩니다.
- 로그 수집이 켜져 있는 동안 상단 알림에 **중지** 버튼이 표시됩니다.
- 로그 수집이 실행 중일 때 받은 응답만 반영합니다. 게임을 시작하지 않은 사이의 변화는 다음 로그인에서 새 스냅샷으로 갱신됩니다.

## 데이터와 인증서 지우기

- **로그 수집 데이터 삭제**를 누르고 확인하면 **모든 계정**의 수집 데이터와 열린 기간, FGA가 `Download/FGA/`에 만든 Chaldea 파일을 지웁니다. 계정 카드의 **삭제**는 그 계정만 지웁니다. 이미 저장된 전투 로그와 스크립트 밖 기록은 **메인 → 로그**에서 별도로 삭제합니다. 공개 자산인 이름 목록과 아이콘 파일은 유지합니다.
- **인증서 만들기**를 다시 누르면 새 인증서가 만들어지고 이전 인증서는 쓸 수 없게 됩니다. 이 경우 확인 창이 먼저 나옵니다. 이전 인증서를 삭제하고 새 인증서를 설치하세요.
- 인증서를 완전히 지우려면 **설정 → 보안 → 암호화 및 사용자 인증 정보 → 사용자 인증서**(또는 신뢰할 수 있는 인증 정보의 사용자 탭)에서 `FGA-Modified log collection`(기존 인증서는 `FGA-Modified gains tracker`) 인증서를 삭제합니다. 필요하면 `Download/fga-capture-ca.cer` 파일도 지웁니다.
