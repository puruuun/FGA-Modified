# 클래스 스코어 +62·그랜드 스코어 +16 판독 — 0.6.0

## 설정

전투 설정의 **서포트 선택 → 서번트 선호**에서 다음 두 토글을 사용합니다. 보구 레벨 설정 아래, 어펜드 설정 위에 있습니다.

- **클래스 스코어 +62 판독**: 클래스 스코어가 +62인지 확인합니다.
- **그랜드 스코어 +16 판독**: 그랜드 스코어가 +16인지 확인합니다.

둘 다 켜면 **스코어 조건 적용**에서 **두 조건 모두 만족** 또는 **둘 중 하나 이상 만족**을 고릅니다. 처음에는 모두 만족입니다. 한 토글만 켜면 켠 항목만 검사합니다. 둘 다 끄면 스코어 검사를 생략합니다.

| 실제 표시 | 클래스만 | 그랜드만 | 둘 다 / 모두 만족 | 둘 다 / 하나 이상 |
|---|---|---|---|---|
| +62/+16 | 통과 | 통과 | 통과 | 통과 |
| +0/+16 | 탈락 | 통과 | 탈락 | 통과 |
| +62/+0 | 통과 | 탈락 | 탈락 | 통과 |
| +16/+62 | 탈락 | 탈락 | 탈락 | 탈락 |
| 일반 +62 (그랜드 없음) | 통과 | 탈락 | 탈락 | 통과 |
| 둘 다 미달 또는 판독 불가 | 탈락 | 탈락 | 탈락 | 탈락 |

위 표는 조건 로직이며 모든 행의 실물 이미지가 제공된 것은 아닙니다. 클래스 값을 설정한 다른 숫자로 비교하거나 스코어를 계산하는 기능은 아닙니다.

기존 **스코어 +62 판독** 설정은 같은 저장 키를 사용해 클래스 판독으로 유지됩니다. 새 그랜드 토글은 기본적으로 꺼져 있습니다. 토글과 조합 방식은 설정 복사·내보내기·가져오기에 포함됩니다. 한 토글을 끄더라도 조합 방식과 다른 조건은 유지됩니다.

## 동작 순서

일반 스킬·스코어·보구 레벨·예장 등 일반 조건을 먼저 검사하고, 모두 통과한 후보에서만 어펜드 스킬 검사와 표시 전환을 합니다. 스코어 검사 자체는 화면 전환이 필요 없습니다.

스코어의 **하나 이상 만족**은 클래스·그랜드 두 스코어 안에서만 적용합니다. 보구 레벨이나 어펜드 조건을 우회하지 않습니다. 서번트·예장 이미지 없이 스코어만 사용하는 선호 선택도 가능합니다.

이 필터는 **선호 선택** 모드에 적용됩니다. 조건을 반드시 지키려면 기존 실패 시 대체 동작을 **수동 선택**으로 설정하세요. **첫 번째 서포트 선택**을 고르면 선호 조건을 우회할 수 있습니다.

## 판독 방법

일반 `+62` 표시는 기존 한국·일본 이미지 매칭과 유사도 0.90을 유지합니다. 압축된 `+62/+16` 표시는 동일 후보의 숫자 영역을 기존 Tesseract로 읽고 `/` 앞뒤 값을 구분합니다. 새 OCR 엔진이나 서비스는 추가하지 않았습니다.

확대율·밝기 처리가 다른 네 결과로 확인하며, 각 항목에서 신뢰도가 높은 결과 두 개 이상이 같은 값을 가리켜야 그 항목을 확정합니다. 한 항목의 결과가 충돌하면 그 항목을 미확정으로 처리합니다. 다른 항목이 확정됐고 해당 조건만 켜져 있다면 통과할 수 있습니다. 그랜드가 없는 일반 표시에 그랜드 +16을 임의로 부여하지 않습니다. OCR에서 작은 `+`가 빠져도 `/`와 두 숫자를 완전히 읽으면 위치에 따라 구분합니다.

## 제공 자료 검사

- 기존 한국·일본 전체 서포트 화면 5장의 숫자 영역 26개를 두 정규화 순서로 확인했습니다. 실제 클래스 값 +62·+0·+23·+43을 포함합니다. 클래스만·그랜드만·AND·OR의 **104개 조건 검사**가 통과했습니다.
- 새로 제공한 스코어 칸 `+62/+16` 한 개를 기존 720p 스코어 칸 크기에 맞춘 두 배율과 두 축소 순서로 처리했습니다. 클래스 62와 그랜드 16을 모두 읽었고 **16개 조건 검사**가 통과했습니다. 이는 서로 다른 실물 자료 16개가 아닙니다.
- 보구 레벨의 기존 16장·44개 표시도 두 정규화 순서에서 88/88로 다시 통과했습니다.
- 코드 테스트는 클래스만·그랜드만·AND·OR, 판독 불가, 항목별 불일치, 그랜드 숫자를 클래스로 잘못 적용하지 않기, 스코어 실패 시 어펜드 생략, 설정 보존을 포함합니다.

새 자료는 전체 화면이 아닌 스코어 칸 확대 이미지이므로 새 표시를 포함한 전체 행의 위치 탐지와 실제 Android/FGO 선택은 아직 확인하지 않았습니다. 그랜드가 +16이 아닌 실물 이미지도 제공되지 않았으므로 그 사례의 판독 정확도는 실물 자료로 추가 확인이 필요합니다. 해당 조건 로직은 자동 테스트로 확인했습니다.

## 재현

OpenCV 4.11.0, Pillow, Tesseract 5.5.1을 사용하는 tesserocr 환경이 필요합니다.

```sh
python -m pip install -r tools/np-level-vision-requirements.txt
python tools/verify_support_grand_score_images.py \
  --input-dir /path/to/original/screenshots \
  --compound-image /path/to/스코어.png \
  --report class-grand-score-tests.json
```
