# 서포트 스코어 +62 판독

수정판 **0.3.0**에서 스킬 아이콘 옆 **스코어 / スコア** 숫자가 **+62인지** 확인할 수 있습니다. 스코어를 계산하거나 다른 목표 숫자를 지정하는 기능은 아닙니다.

## 설정과 동작

전투 설정의 **서포트 선택 → 서번트 선호**에서 **스코어 +62 판독** 토글을 켭니다. 0.5.0에서는 보구 레벨 설정 아래, 어펜드 설정 위에 있습니다. 기본값은 꺼짐이며 설정은 복사·내보내기·가져오기에 포함됩니다.

- 켜면 해당 후보의 숫자가 +62일 때만 스코어 조건을 통과합니다.
- +0·+23·+43 등 다른 숫자이거나 숫자를 확인하지 못하면 다른 서번트를 찾습니다.
- 일반 스킬 표시와 어펜드 표시에서 모두 검사할 수 있습니다. 스코어 확인 자체에는 표시 전환이 필요 없습니다.
- 어펜드 판독과 함께 켜면 **두 조건을 모두** 만족해야 합니다. 스코어가 부족하면 어펜드 화면으로 전환하지 않고 다음 후보로 넘어갑니다.
- 서번트나 예장을 별도로 지정하지 않아도 스코어 +62 조건만으로 선호 선택을 사용할 수 있습니다. 다른 선호 조건을 설정하면 함께 적용합니다.
- 끄면 기존 서포트 선택 방식을 유지하며, 어펜드 설정은 그대로 보존합니다.

이 조건은 **선호 선택** 모드의 필터입니다. 기존 실패 시 대체 동작에서 **첫 번째 서포트 선택**을 고르면 선호 조건을 우회할 수 있으므로, 조건을 반드시 지키려면 **수동 선택**을 사용하세요.

## 판독 방법과 검증

후보 행 안의 스코어 숫자 영역만 기존 이미지 매칭으로 비교합니다. 숫자 +62 전체를 사용해 +0이나 다른 숫자를 걸러내며, 유사도 기준은 **0.90**입니다. 한국·일본 화면의 숫자 크기가 달라 각각에 맞는 기준 이미지를 사용합니다. `En`의 기본 템플릿은 제공된 일본 화면에서 추출했고, 한국 서버는 `Kr`의 별도 템플릿을 사용합니다. 검증한 서버는 한국·일본입니다.

| 제공 화면 | 실제 스코어 | +62 판정 |
|---|---|---|
| 한국 일반·어펜드 첫 번째 후보 | +0 | 불통과 |
| 한국 일반·어펜드 두 번째 후보 | +62 | 통과 |
| 기존 일본 일반·어펜드 후보 3명 | +62 | 모두 통과 |
| 새 일본 화면 상단 후보 | +23 | 불통과 |
| 새 일본 화면 가운데 후보 | +0 | 불통과 |
| 새 일본 화면 아래 후보 | +43 | 불통과 |

제공된 5개 전체 화면을 두 가지 방식으로 정규화해 **스코어 판정 26개**를 확인했습니다. 기존 일반/어펜드 **레벨 판정 80개·표시 상태 판정 8개**도 다시 통과했습니다. 코드·설정 테스트 **105개**는 스코어 실패 후 다음 후보 선택, 어펜드와의 동시 조건, 검사 해제, 스코어만 사용하는 설정, 저장·내보내기·가져오기를 포함합니다.

플레이어 이름이 포함된 전체 원본 화면은 공개 저장소에 넣지 않고 스코어 칸만 검증용으로 보관합니다. 정지 화면 판독과 코드 테스트를 완료했으며, 실제 Android/FGO에서의 터치·스크롤 동작은 아직 검증하지 않았습니다.

```sh
  --kr-normal '/path/to/Kr skill.png' \
  --kr-append '/path/to/kr_appendskill.png' \
  --jp-normal '/path/to/jp skill.png' \
  --jp-append '/path/to/jp_appendskil.png' \
  --jp-other '/path/to/Screenshot_20261013-143344.png' \

```

Python 환경은 [어펜드 스킬 안내](Support-Append-Skills-KR.md#이미지-테스트-재현)의 방법으로 준비합니다. 스크립트는 제공된 5개 화면의 예상 숫자와 후보 위치를 사용하며, 앱 소스의 좌표·유사도와 실제 기준 이미지를 읽어 비교합니다.
