# FGA(mod) 詳細ガイド

初めて使う場合は[インストール案内](Installation-JA.md)と[ログ収集の初期設定](Log-Collection-Setup-JA.md)を先にご覧ください。

**KR（韓国）・JP（日本）サーバーに限定してテストしています。他のサーバーでの動作は確認していません。**

各機能の詳細な設定はそれぞれの専用ページをご確認ください。このページは全体の概要です。

## ゲームエリア

**その他の設定 → 追加機能 → ゲームエリア（実験的機能）**で、赤い設定領域と緑の実際の認識領域をプレビューしながらカスタム座標を調整できます。分割画面では緑の枠をゲーム画面の端に合わせます。[詳細](Game-Area-Preview-JA.md)

## ハクノシャッフル

NP を消費するスキル 1 をカード条件を満たすまで繰り返し、最小・最大回数と未達成時の停止を設定できます。ゲーム内のスキル使用確認は OFF にしてください。[詳細](Hakuno-Shuffle-JA.md)

## 概念礼装の自動強化

JP・KR サーバーでゲームのおすすめ選択フィルターを使って自動セットを有効にし、強化を繰り返します。[詳細](CE-Auto-Enhance-JA.md)

## バトル開始条件

<a id="card-start"></a>

### 通常カード枚数によるコマンド開始

**コマンドカード枚数選択モード**をオンにし、前衛 1〜3 番から対象サーヴァントと必要な通常カード枚数（1〜5 枚）を指定します。手札に設定値**以上**の使用可能なカードが出ると、予約したコマンドを最初から実行します。スタンなどで使えないカードは数えません。

条件を満たさない場合はスキル・宝具を使わず通常攻撃でターンを進め、次のターンに再判定します。最大待機ターン（0 は無制限）も設定できます。トグルをオフにすると従来の動作に戻り、設定値は保持されます。[詳細](Card-Count-Start-JA.md)

<a id="turn-limit-retreat"></a>

### 撤退して再開

パーティーが全滅したとき（全サーバー）に撤退してクエストをやり直し、N を 1 以上に設定するとバトルが N ターン目に達したときも撤退します（KR・JP）。撤退は周回数に数えず、3 回連続で撤退したときに停止することもできます。以前の「撤退を有効化」スイッチに代わる機能です。[詳細](Turn-Limit-Retreat-JA.md)

<a id="dual-conditions"></a>

### 2 つのサーヴァント条件

2 つ目の対象サーヴァントと必要枚数を追加できます。両方の条件を同じ手札で判定します。

| 1 つ目の条件 | 2 つ目の条件 | 実行 |
|---|---|---|
| 満たす | 未満 | 1 つ目の設定 |
| 未満 | 満たす | 2 つ目の設定 |
| 満たす | 満たす | 1 つ目の設定を優先 |
| 未満 | 未満 | 通常攻撃後に次ターン再判定 |

一度選んだ設定はそのバトルが終わるまで維持され、次の周回で改めて判定します。2 つ目の対象を**使用しない**にすると単一条件になります。同じサーヴァントを両条件に指定すると開始しません。

2 つ目の条件を使用中の場合は 3 つ目の条件も追加できます（判定順は `1 → 2 → 3`、最初に満たした設定で開始）。3 つ目の条件も独自のコマンド・カード優先順位を持ち、詳しい設定は[サーヴァント条件モード](Card-Count-Start-JA.md)をご覧ください。

<a id="separate-settings"></a>

### 条件別のコマンド・カード設定

有効な開始条件ごとにそれぞれ異なる**コマンド、カードの優先順位、サーヴァントの優先順位を設定する、Brave Chains、優先順位を逆転する**を保存します。基本設定と 1 つ目の設定は同じ値であり、コピー・エクスポート・インポートにもすべての条件設定が含まれます。

<a id="command-timing"></a>

### 待機した分だけコマンド位置をずらす

実際に条件を満たした時点をコマンドの 1 ウェーブ 1 ターンとして扱います。たとえば実際の 2 ウェーブ 3 ターン目で開始した場合、コマンド 1 ウェーブ 2 ターン目は実際の 2 ウェーブ 4 ターン目に実行されます。開始後は開始条件を再度確認しません。

<a id="shared-automatic-use"></a>

### リピート設定・コマンドシャッフルは共通

**スキル・宝具自動使用（リピート設定）**、**コマンドシャッフル**、パーティー・サーバー・サポート・ターゲットの自動選択は条件別に分けず 1 か所で管理します。

<a id="first-turn-shuffle"></a>

### 1 ターン目の条件不足時にシャッフル

**コマンドシャッフル → タイミング → 1 ターン目のコマンド開始条件を満たしていない場合**を選ぶと、1 ウェーブ 1 ターン目に条件不足のときマスタースキル 3 で 1 回シャッフルしてから再判定します。満たせば同じターンでコマンドを開始し、満たさなければ通常攻撃で次ターンへ進みます。シャッフルはバトルの 1 ターン目に 1 回だけ行い、待機ターン数には含めません。

カード枚数選択モードでのみ使用でき、マスタースキル 3 がカードシャッフルの魔術礼装が必要です。カード認識が不確かな場合は同じ手札を最大 3 回確認した上で攻撃せず停止します。

## サポート選択

<a id="auto-friend-request"></a>

### クエスト後のフレンド申請

設定欄にはタイトルのみ表示されます。

バトル設定の**サポート → 優先 → フレンド選択 → クエスト後にフレンド申請を送る**をオンにすると、フレンド以外のサポートを使った後に拒否せずフレンド申請を送ります。バトル設定ごとに保存され、初期値はオフです。**優先**モードで動作し、フォールバックの一番上を選択・手動選択で選んだサポートにも適用されます。**フレンドのみ**をオンにするとこの項目はオフかつ無効になります。

相手のフレンド枠がいっぱいで申請画面のまま残った場合は、1 秒後に新しい画面を確認して拒否します。

### 選択するサーヴァント・概念礼装の画像取得

**バトルの設定 → 使用する設定 → サポート**の**選択するサーヴァント・選択する概念礼装**選択ダイアログ左下にある**画像を取得**から検索・保存ダイアログを直接開けます。保存したフォルダーは既存のチェックを保ったまま追加でチェックされます。**OK** を押すと設定に反映され、**キャンセル**しても取得済みの画像は残ります。[詳細](Servant-Number-Portraits-JA.md)

<a id="support-append"></a>

### サポートのアペンドスキル

**サポート → 優先 → 選択するサーヴァント → アペンドスキル判定**をオンにし、アペンド 1〜5 枠を `10 / x` で指定します。`10` に設定した枠がすべて Lv.10 のサポートのみ選び、未解放枠は 10 とみなしません。[詳細](Support-Append-Skills-JA.md)

<a id="support-score"></a>

### サポートのスコア判定（クラス +62 / グランド +16）

**サポート → 優先 → 選択するサーヴァント**でクラススコア +62 とグランドスコア +16 を個別にオンにできます。オンにした条件をすべて満たす必要があります。[詳細](Support-Score-62-JA.md)

<a id="support-np"></a>

### サポートの宝具レベル

**サポート → 優先 → 選択するサーヴァント → 宝具レベル判読**をオンにし、**宝具レベルの下限**（1〜5）を設定します。設定レベル以上のサポートのみ選びます。[詳細](Support-NP-Level-JA.md)

判定順は「サーヴァント → 通常条件・スコア・宝具レベル → アペンド → 選択」です。手前の条件に失敗した場合はアペンド確認のための画面切り替えを行いません。

### 再臨の区別

サポートイメージメーカーで作成した「サーヴァント名＋宝具名」画像を使って、再臨段階の異なるサーヴァントを区別して選びます。[詳細](Ascension-Select-JA.md)

## バトル中

<a id="direct-cards"></a>

### 攻撃順の直接指定（通常カード直接指定）

**コマンド → Attack → 宝具前に選択するコマンドカード枚数の横の通常カード直接指定**で、通常カードと宝具 3 枚の順番を指定します。直接指定したターンには Brave Chains 選択・優先順位の逆転・追加宝具の自動使用は適用されません。

必要なカードがない場合はタップ前に停止します。各枠で**未選択**を選ぶか**カード不足・未選択時は優先順位で代替**にチェックを入れると、空いている通常カード枠をカード優先順位で補います（未選択がある場合は自動でチェックされます）。[詳細](Direct-Cards-JA.md)

<a id="quest-items"></a>

### ティーポット・ストームポッドの自動 ON/OFF

**その他の設定 → バトル → ティーポット・ストームポッドの自動設定を使用**をオンにすると、起動ダイアログの**ストームポッドを使用 / ティーポットを使用**チェックに合わせてクエスト開始前に ON/OFF を切り替えます。選択はサーバーごとに記憶します。[詳細](Quest-Items-JA.md)

<a id="bond-tracking"></a>

### 絆ポイント集計・MAX 停止

**バトル起動ダイアログ → 絆ポイント**で設定します。結果画面のキャラクター 1〜5 ごとの獲得量を集計して終了画面に表示し、無視指定していないキャラクターが MAX になるとそのクエストの結果画面で停止します。**MAXで停止しないキャラクター**にチェックを入れられます。[詳細](Bond-Tracking-JA.md)

<a id="command-spell-tap"></a>

### 令呪ボタン固定位置タップ

バトル中に令呪を使う際、「令呪/영주」の文字を探さず、マスター肖像画左側の令呪ボタン（ひし形）の 16:9・ワイド画面ごとの固定座標を直接タップします。以降の処理は従来と同じで、確認ダイアログが出ない場合は令呪不足とみなしてバトルを停止します。[詳細](Command-Spell-Tap-JA.md)

### マスタースキルメニューの待機時間

マスタースキル（またはオーダーチェンジ）を使うとき、マスタースキルのボタンを押してからメニューが開くまで待つ時間を **微調整 → 待機 → マスタースキルメニューの待機時間** で変更できます。範囲は 300〜3000ms（100ms 単位）、初期値は 1500ms で、初期値では従来と同じ動作です。短くしすぎると、動作の遅い端末でマスタースキルが使われないことがあります。この待機時間にも **待機時間倍率** の設定が適用されます。固定 1.5 秒だったころと同じく倍率に従い、例えば 300ms を 50% にすると 150ms 待ちます。

## その他の機能

アプリ言語の選択は**その他の設定 → その他 → アプリ言語**へ移動しました。**その他の設定 → その他 → ダークモード**で**システム設定に従う**（初期値）、**ライト**、**ダーク**から選べ、選んだ瞬間にアプリ画面へ反映されます。スクリプト実行中のオーバーレイは常に暗い色になり、AP ウィジェットはウィジェット設定のテーマに従います。

メイン画面の**ログ**からバトル終了記録とスクリプト外の変化の確認・削除ができます（保存上限 50 / 100 / 200 件の選択や、日付・プロフィール・出典・獲得資源フィルターに対応）。[詳細](Battle-Log-JA.md)

<a id="chaldea-import"></a>

### Chaldea リンクからコマンド入力

コマンド行の**リンクから入力**に Chaldea の共有リンクを貼り付けて**変換して入力**を押すと、戦闘行動がコマンドに変換されます。変換に成功した場合のみ既存のコマンドを置き換えます。**エネミーターゲット情報を無視**にチェックを入れると敵ターゲット命令を省きます。[詳細](Chaldea-Import-JA.md)

<a id="original-fga-import"></a>

### オリジナルFGAのデータを取り込む

**その他の設定 → 追加機能**から、オリジナル版 FGA のスクリプト・サポート画像・または両方を取り込めます。[詳細](Original-FGA-Import-JA.md)

### ログ収集 · フレンド管理 · 追加ツール

[ログ収集の初期設定](Log-Collection-Setup-JA.md) · [ログ収集](Gains-Tracker-JA.md) · [フレンド管理](Friend-Manager-JA.md) · [FP召喚自動売却](FP-Auto-Sell-JA.md) · [スキル・アペンドスキル自動強化](Auto-Skill-Level-JA.md) · [ウィークリーミッション周回](Weekly-Mission-Route-JA.md) · [サーヴァント図鑑番号での画像作成](Servant-Number-Portraits-JA.md)

### アップデートを確認

**その他の設定 → その他 → アップデートを確認**をオンにすると、アプリ起動時に最新の正式リリースとインストール済みバージョンを比較します。新しいバージョンがある場合は**リリースを開く**で GitHub ページを開きます。プレリリースは対象外であり、APK の自動インストールは行いません。

### バトル設定の 2 列レイアウト

画面幅が 600dp 以上（タブレット、横画面、BlueStacks）では、バトル設定編集画面が自動で 2 列表示になります。左側にパーティー名・メモ、コマンド、概要カードを、右側にサポート、コマンド開始条件、コマンドシャッフルを配置します。600dp 未満の画面では従来通りの 1 列表示です。切り替え設定はなく、画面配置だけが変わるため自動化動作や保存済み設定はそのまま維持されます。

ウィンドウ幅が 1280dp を超える場合は、メイン・バトル設定一覧・カードの優先順位・その他の設定・ウィークリークエスト追跡設定・ライセンス・微調整・追加機能の微調整・優先サポート・リピートモード画面の内容幅を 1280dp に制限して中央揃えにします。別途設定なしで常に適用され、1280dp 以下では従来通りです。

### ワイド画面（21:9、2560×1080）

BlueStacks `1680×720`・`2560×1080` のような横長画面でも動作するよう、画面端のボタン位置を調整しました。21:9 より広い画面はオリジナル FGA と同様に 21:9 として計算します。小さな数字（`+62/+16` など）は解像度が低い・ぼやけている場合に読み取れないことがあり、読み取れなかったサポートは条件未達としてスキップします。

### バトル後の「閉じる」ダイアログ対応

強化クエストの「開放されました！」案内の後など、バトル終了後に下部中央の**閉じる**ボタンが出た場合は閉じてクエスト一覧へ戻り続行します。ストームポッドが尽きた場合は消耗品不足の案内を確認して終了します。

<a id="mission-popup-clear"></a>

### 連続出撃前にミッション通知を消す

**その他の設定 → バトル → 連続出撃前にミッション通知を消す**をオンにすると、連続出撃確認画面で連続出撃を押す前に画面上部中央を設定時間（1〜60 秒、初期値 10 秒）だけ高速連打し、溜まったミッション通知を消します。[詳細](Mission-Popup-Clear-JA.md)

### 画面オフ後の画面キャプチャ再取得

画面をオフにすると Android により画面キャプチャが終了します。その後再生ボタンを押すと画面キャプチャの許可ダイアログが再び表示され、許可すればすぐ開始します（サービスを再起動する必要はありません）。許可しなければ開始しません。スクリプト実行中に画面をオフにすると一時停止し、再開してもキャプチャが切れているため停止します。その場合は再度再生ボタンを押してください。root キャプチャ使用時は該当しません。

### ウィークリーミッションルート設定

**その他の設定 → バトル → ウィークリーミッション自動化機能を使用**をオフにすると、起動ダイアログのボタンを非表示にします（初期値はオン）。ミッションは元の順番で表示され、手動ミッションにはチェックボックスがなく、チェックを外したミッションは灰色で残ります。空のルートでは実行しません。宝物庫は最後に「メイン → カルデアゲート → 曜日クエスト一覧」の順で移動し、左側のボタンと一覧内容で判別します。[詳細](Weekly-Mission-Route-JA.md)

### その他の設定とアカウントダッシュボード

**その他**タブの上部には**アップデートを確認**、ベータ限定の**サポート判定の診断を保存**、**ウィークリークエスト追跡設定**があります。**バトル**タブの末尾には**ウィークリーミッション自動化機能を使用**、**絆ポイント追跡機能を使用**、**ティーポット・ストームポッドの自動設定を使用**があります。**追加機能**タブでは **サポート画像の検索・保存 → オリジナルFGAのデータを取り込む → Chaldeaファイルをエクスポート → ログ収集 → フレンド管理 → ゲームエリア（実験的機能）** の順に表示されます。

**その他の設定 → その他 → バッテリー使用最適化が無効**（自動でサービス開始のすぐ下）をタップすると端末のバッテリー最適化一覧が開きます。FGA を選んで**制限なし（最適化しない）**に設定してください。

メイン画面のアカウントカードをタップするとそのアカウントの読み取り専用ダッシュボードが開き、**プロフィール・所持資源とAP・所持枠・サーヴァント一覧（絆・コスト・Lv で並び替え可能）・所持アイテム・プレゼントボックス・サポート編成・グランド編成・魔術礼装・コマンドコード図鑑・クラススコア・召喚履歴・最近の活動**を確認でき、データのない項目は非表示になります。広い画面ではサマリーと一覧を独立した 2 列で表示します。設定左側のエクスポートアイコンから現在のアカウントの Chaldea ファイルを作成でき、保存後はファイル名と取り込み手順を案内して **OK** で閉じるか、Chaldea がインストールされていれば**Chaldeaを開く**から開けます。[詳細](Gains-Tracker-JA.md)

## インストールとアップデート

- **[最新の正式版 APK](https://github.com/puruuun/FGA-Modified/releases/latest)**: Android 7 以降の ARM 端末（`arm64-v8a` / `armeabi-v7a`）に対応しています。
- **Obtainium**: ソース URL `https://github.com/puruuun/FGA-Modified`（GitHub）を追加するか、[obtainium.json](../../obtainium.json) をインポートしてください。「プレリリースを含む」はオフにします。
- GitHub Releases および Obtainium 以外から入手した APK はインストールしないでください。

アプリ名は **FGA(mod)**、パッケージ名は `io.github.fate_grand_automata.cardcount` です。オリジナル版 FGA とは別アプリとしてインストールでき、以前の修正版の上には上書きアップデートできます。インストール手順やベータ版については[インストール案内](Installation-JA.md)、ログ収集の初期設定は[ログ収集の初期設定](Log-Collection-Setup-JA.md)、オリジナル版の設定インポートは[オリジナルFGAのデータを取り込む](Original-FGA-Import-JA.md)をご覧ください。

アプリ内の**その他の設定 → その他 → ライセンス**で MIT ライセンスの全文を確認できます。

## ホーム画面ウィジェット

FGA サービスを開始・停止する 1×1 ウィジェットと、収集したアカウントの AP を表示するアカウント情報ウィジェットをホーム画面に配置できます。[詳細](Widgets-JA.md)
