# 재림 구분 (서번트 이름 + 보구)

서포트 목록에서 재림마다 보구가 다른 서번트를 골라야 할 때 씁니다. 예: メリュジーヌ는 재림에 따라 「今は知らず、無垢なる湖光」(Arts)와 「誰も知らぬ、無垢なる鼓動」(Buster)로 나뉩니다. 보구 이름만으로는 다른 서번트의 같은 보구와 구분되지 않으므로, 이미지에는 **서번트 이름 줄과 보구 줄을 함께** 담습니다.

FGA는 화면의 그림을 직접 찾습니다. 글자를 읽지 않으므로 이름의 언어와 보구 레벨(Lv.)은 상관없습니다.

## 준비: 재림 구분 이미지 만들기

1. 서포트 선택 화면을 엽니다. 목록의 서번트 행이 보여야 합니다.
2. 화면 왼쪽 아래의 재생 버튼을 누르고 **Support Image Maker**를 실행합니다.
3. 메이커가 끝나면 이름 지정 화면이 열립니다. 아래쪽 **서번트 이름 + 보구 (재림 구분)** 칸에 행마다 그림이 나옵니다.
4. 저장할 칸의 체크박스를 켜고 이름을 씁니다. 예: `メリュジーヌ 今は知らず`
5. 완료를 누릅니다.

그림은 서번트 이름 줄의 위쪽부터 보구 줄의 아래쪽까지, 카드 아이콘부터 `Lv.` 바로 앞까지입니다. 보구 레벨이 달라도 같은 그림이 되도록 `Lv.N`과 강화 표시는 넣지 않습니다. 서번트 이름 줄에 붙은 친구 코멘트나 다른 줄은 같은 그림에 들어가지 않습니다.

- **예전 버전에서 만든 보구 이름만 있는 그림은 다시 만드세요.** 보구 이름만으로는 1재림과 2재림을 구분할 수 없어서, 예전 그림은 재림 구분에 쓰면 안 됩니다. 이 버전은 예전 그림도 맞게 찾지만, 같은 보구를 가진 다른 재림과 구분되지 않습니다.
- 행에 `Lv.` 표시가 보이지 않으면 그 행의 보구 그림은 만들어지지 않습니다. 서번트와 예장 그림은 평소처럼 만들어집니다.
- 같은 이름을 두 칸에 쓰면 뒤 칸이 앞 칸을 덮어씁니다. 칸마다 다른 이름을 쓰세요.

## 선택: 설정에서 고르기

배틀 설정 → 서포트 → 선호 항목을 열어 **서번트 선호** 바로 아래의 **재림 구분 (서번트 이름 + 보구)** 에서 이름을 고릅니다. 여러 개를 고르면 그중 하나라도 맞는 서포트를 찾습니다. 고르지 않으면 이 조건은 적용되지 않습니다.

## 함께 쓰는 법

그림에 서번트 이름이 들어 있어도 **서번트 선호와 함께** 고르는 것을 권합니다. 서번트 선호로 먼저 서번트를 좁히면 재림 구분 검사가 더 정확하고 빠르게 끝납니다.

- 서번트 선호: メリュジーヌ
- 재림 구분: メリュジーヌ 今は知らず

순서는 서번트 → 재림 구분 → 점수 → 예장 → 친구 → 보구 레벨입니다. 서번트가 맞지 않으면 재림 구분 검사는 하지 않습니다.

## 한계

- **서번트 이름, 보구 이름, 카드가 모두 같으면 재림을 구분할 수 없습니다.** 이 경우 다른 조건(점수, 보구 레벨)과 함께 쓰세요.
- 그림은 자기 서버 화면에서 만든 것만 씁니다. 다른 서버의 그림은 맞지 않습니다.
- 이미지를 만든 뒤 게임 글꼴이나 화면 크기가 바뀌면 다시 만드세요.

## 문제가 생기면

- 로그(`FGA.SupportNp`)에 행마다 `NP name best score`와 `matched`가 남습니다. 맞아야 할 서포트가 `matched: false`이고 점수가 0.85 근처라면 이미지를 다시 만드세요.
- 이름 지정 화면에 칸이 없으면 그 버전의 메이커가 쓰이지 않은 것입니다. 메이커를 다시 실행하세요.
