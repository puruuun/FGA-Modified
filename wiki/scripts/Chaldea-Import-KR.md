# Chaldea 공유 링크로 커맨드 입력

스크립트 수정 화면의 커맨드 오른쪽에서 **문법으로 입력(터미널 아이콘)** 왼쪽의 **링크로 입력(링크 아이콘)**을 누릅니다.

1. Chaldea에서 스킬·공격 행동이 기록된 전투의 공유 링크를 복사합니다.
2. 새 창의 **Chaldea 공유 링크** 칸에 주소 전체를 붙여넣습니다.
3. 적 선택 정보를 빼고 가져오려면 주소 바로 아래의 **에너미 타겟팅 정보 무시**를 체크합니다. 기본값은 체크하지 않은 상태입니다.
4. 기존 커맨드 대체 안내를 확인하고 **변환하여 입력**을 누릅니다.
5. 변환과 FGA 문법 검증이 성공하면 해당 커맨드가 바로 입력됩니다.

첫 번째·두 번째 커맨드 각각에서 사용할 수 있습니다. 누른 쪽의 커맨드만 대체하며, 편성·서포트·개념예장·카드 우선순위 등 다른 스크립트 설정은 가져오지 않습니다. 주소 오류, 변환 실패 또는 취소 시 기존 커맨드는 유지됩니다.

**에너미 타겟팅 정보 무시**를 켜면 `t1`·`t2`·`t3`와 특수한 적 슬롯 등 모든 적 선택 정보가 커맨드에서 빠집니다. 적 하나를 대상으로 하는 스킬도 스킬 알파벳은 그대로 들어갑니다. 아군 대상 번호·스킬 선택지·오더 체인지·보구·공격 순서는 유지됩니다. 이 선택은 해당 링크를 가져올 때만 적용하며 게임에서는 적 선택을 변경하는 커맨드를 실행하지 않습니다.

특수 배치의 적 대상 번호로 가져오기가 실패하면 링크를 확인하거나 이 옵션을 체크한 후 다시 시도할 수 있습니다. 손상된 링크나 다른 필수 행동 정보의 오류까지 무시하는 옵션은 아닙니다. 이전에 오류를 보고한 퀘스트 94146807 링크는 체크했을 때 `defab1cgix31hgj54`로 변환됩니다.

## 변환 방식

대상 선택, 보구 종류, 교체 효과 판정을 위해 [Atlas Academy](https://api.atlasacademy.io/docs)의 JP 스킬·보구·마스터 예장 데이터를 조회합니다. 처음 사용하는 데이터는 인터넷 연결이 필요합니다. 조회한 데이터는 앱 캐시에 저장하며, 오래된 데이터는 갱신합니다. 기존 데이터가 있으면 통신 실패 시 재사용할 수 있습니다. 원본 변환기와 동일하게 FGA의 서버 선택과 관계없이 JP 데이터를 사용합니다.

## 지원 범위

- `data=`에 전투 정보가 들어 있는 Chaldea 공유 링크를 사용합니다. 행동 기록이 없는 편성만의 링크는 변환할 수 없습니다.

- 선택형 스킬은 현재 FGA가 실행할 수 있는 2개·3개 선택지를 지원합니다. 그 밖의 선택지나 알 수 없는 행동은 오류로 안내하고 기존 커맨드를 유지합니다.
