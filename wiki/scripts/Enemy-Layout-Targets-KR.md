# 적 배치별 타겟 지정

스킬 명령의 적 타겟은 원래 `t1`·`t2`·`t3`(일반 3마리 배치)뿐이었습니다. 적이 6마리인 배치와 레이드 배치에서는 적이 다른 위치에 있어서 `t1`~`t3`이 엉뚱한 곳을 누릅니다. 이 기능은 두 배치를 위한 고정 타겟 코드를 추가합니다. `t1`~`t3`의 위치와 동작은 바뀌지 않습니다.

## 코드

| 배치 | 코드 | 누르는 곳 |
|---|---|---|
| 일반 3마리 | `t1` `t2` `t3` | 왼쪽, 가운데, 오른쪽 적 |
| 6마리 (윗줄) | `t4` `t5` `t6` | 윗줄의 왼쪽, 가운데, 오른쪽 적 HP 바 |
| 6마리 (아랫줄) | `t7` `t8` `t9` | 아랫줄의 왼쪽, 가운데, 오른쪽 적 HP 바 |
| 레이드 (보스) | `tR` | 화면 위쪽 전체 폭 HP 바의 보스 |
| 레이드 (아래 적) | `t10` `t11` `t12` | 보스 아래의 왼쪽, 가운데, 오른쪽 적 HP 바 |

- `t10`·`t11`·`t12`는 `t` 뒤에 `1`이 오고 그 뒤에 `0`, `1`, `2`가 오면 두 자리 코드로 읽습니다. 예를 들어 `t12a`는 `t12` 다음에 `a` 스킬입니다. `t1` 다음에 NP 4번을 쓰고 싶은 `t14`처럼 `1` 뒤가 `0`·`1`·`2`가 아니면 예전과 같이 `t1`입니다.
- 없는 코드(`t0`, `tX` 등)는 스킬 명령 해석 오류로 멈춥니다.
- 21:9 같은 와이드 화면에서도 같은 코드를 쓰면 됩니다. 화면 비율에 맞춰 위치가 자동으로 옮겨집니다.

## 스킬 메이커에서 쓰기

1. 스킬 메이커 메인 화면 왼쪽 위의 주황색 **타겟 설정** 버튼을 누릅니다. 현재 타겟은 버튼에 표시되지 않습니다.
2. 스킬 대상 선택 화면처럼 별도의 **적 타겟 선택** 화면이 열리고, 가운데에 전투 화면과 같은 모양으로 타겟 버튼이 나옵니다. 현재 타겟은 파란색으로 강조됩니다.
   - 3마리: `t1` `t2` `t3` 한 줄
   - 6마리: `t4` `t5` `t6` 아래에 `t7` `t8` `t9`
   - 레이드: 넓은 `tR` 아래에 `t10` `t11` `t12`
3. 화면 아래의 **3마리 / 6마리 / 레이드** 선택으로 배치를 바꿉니다. 화면은 현재 타겟이 속한 배치로 열립니다.
4. 타겟을 누르면 그 타겟이 명령에 추가되고 메인 화면으로 돌아갑니다. 이미 선택된 타겟을 다시 누르면 아무것도 추가되지 않습니다. 고르지 않고 시스템 뒤로 가기를 누르면 변경 없이 메인 화면으로 돌아갑니다.

## 알아둘 점

- `t11`(레이드 가운데 아래)의 위치는 **임시 추정값**입니다. 해당 배치의 캡처가 아직 없어서 양옆 위치로 계산했습니다. 어긋나면 알려 주세요.
- **자동 타겟 선택**은 일반 3마리 배치의 위치만 압니다. 6마리·레이드 배치에서는 자동으로 고르지 못하므로, 필요하면 위 코드로 직접 지정하세요.
- 화면에서 배치를 확인하지 않습니다. 다른 배치의 코드를 쓰면 그 위치를 그대로 누를 뿐이니, 퀘스트의 배치에 맞는 코드를 쓰세요.
- Chaldea 가져오기는 이전처럼 `t1`~`t3`만 만듭니다.
