# 再臨の区別（サーヴァント名＋宝具名）

サポート一覧で再臨段階によって宝具が異なるサーヴァントを区別して選びたい場合に使用します。例：`メリュジーヌ` は再臨によって「今は知らず、無垢なる湖光」（Arts）と「誰も知らぬ、無垢なる鼓動」（Buster）に分かれます。宝具名だけでは同じ宝具名を持つ別サーヴァントと区別できないため、画像には**サーヴァント名の行と宝具名の行を一緒に**収めます。

FGA は画面の画像を直接照合します。文字を OCR で読むわけではないため、保存名の言語や宝具レベル（`Lv.`）は関係ありません。

## 準備：再臨区別の画像を作成する

1. ゲーム内でサポート選択画面を開きます（一覧にサーヴァント行が表示されている状態）。
2. 画面左下の再生ボタンを押し、**サポートイメージメーカー** を実行します。
3. メーカーが完了すると名前指定画面が開きます。下部の **サーヴァント名＋宝具名（再臨の区別）** 欄に行ごとの画像が表示されます。
4. 保存したい項目のチェックボックスをオンにして名前を入力します。例：`メリュジーヌ 今は知らず`。保存時、ゲームサーバーに応じて `JP) ` または `KR) ` が自動で先頭に付きます（すでに付いている場合は重複して付きません）。アプリ言語とは無関係であり、サーヴァント・概念礼装・フレンド画像には付きません。
5. **完了** を押します。

切り出される画像は、サーヴァント名行の上端から宝具名行の下端まで、名前の文字の始まりから `Lv.` の直前までです。ラベルとカード種別アイコンは除外され、宝具レベルが違っても同じ画像として一致するよう `Lv.N` と強化マークも入れません。サーヴァント名の行に付くフレンドコメントや別の行は同じ画像に含まれません。以前のバージョンで作成したアイコン付きの画像も引き続き認識します。

- **旧バージョンで作った宝具名だけの画像は作り直してください。** 宝具名だけでは第1再臨と第2再臨などを区別できないため、古い画像を再臨の区別に使うべきではありません。このバージョンは古い画像も認識しますが、同じ宝具を持つ別の再臨とは区別できません。
- 行に `Lv.` 表示が見えない場合、その行の宝具画像は作成されません。サーヴァント画像と概念礼装画像は通常通り作成されます。
- 同じ名前で再臨画像を保存し直すと既存の画像は保持され、同じ項目に新しい画像が追加されます。2つの枠に同じ名前を入力しても1つの項目にまとめられ、その中のいずれかの画像に一致すれば通過します。

## 選択：設定で選ぶ

**バトルの設定 → サポート → 優先** を開き、**選択するサーヴァント** のすぐ下にある **再臨の区別（サーヴァント名＋宝具名）** から名前を選びます。`JP) メリュジーヌ 今は知らず` のように保存された名前がそのまま表示されます。接頭辞は表示用であり、サーバーフィルターではありません。複数選ぶと、そのうちいずれか1つに一致するサポートを探します。何も選ばなければこの条件は適用されません。

## 選択するサーヴァントとの併用

画像にサーヴァント名が含まれていても、**選択するサーヴァントとあわせて指定することを推奨します**。先に選択するサーヴァントで対象を絞り込むことで、再臨の区別判定がより正確かつ高速になります。

- **選択するサーヴァント**: `メリュジーヌ`
- **再臨の区別（サーヴァント名＋宝具名）**: `JP) メリュジーヌ 今は知らず`

確認の順番は サーヴァント → 再臨の区別 → スコア → 概念礼装 → フレンド → 宝具レベル です。サーヴァントが一致しなければ再臨の区別判定は行いません。

## 制限事項

- **サーヴァント名・宝具名・カード種別がすべて同じ場合は再臨を区別できません。** その場合はスコアや宝具レベルなど他の条件を併用してください。
- 使用するサーバーの画面から作成した画像だけを使用してください。別サーバーの画像は一致しません。
- 画像を作成したあとにゲーム内のフォントや画面サイズが変更された場合は作り直してください。

## 問題が発生した場合

- ログ（`FGA.SupportNp`）に行ごとの `NP name best score` と `matched` が出力されます。一致するはずのサポートで `matched: false` となりスコアが `0.85` 付近になっている場合は画像を作り直してください。
- 名前指定画面に項目が出ない場合は、対応バージョンのメーカーが使われていません。メーカーをもう一度実行してください。

## 1.6.2 — サーヴァントを変更すると再臨の区別を初期化

**選択するサーヴァント** を別の組み合わせに変更すると、**再臨の区別（サーヴァント名＋宝具名）** は「なし」に初期化されます。宝具名画像は選択したサーヴァントに紐づくためです。同じサーヴァントのまま確定すれば、既存の再臨選択は維持されます。Chaldea からサポートを取り込む際も同じルールを適用します。
