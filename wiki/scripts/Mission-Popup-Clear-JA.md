# 連続出撃前にミッション通知を消す

クエスト終了後に画面上部中央へ表示されるミッション達成通知が溜まりすぎると、次のバトル開始後も消えずに残り、右上のウェーブ・ターン表示を隠してしまうことがあります。この機能をオンにすると、連続出撃の確認画面で **連続出撃** を押す前に、通知が表示される位置を設定時間だけ連打してあらかじめ消去します。

## 設定方法

**その他の設定 → バトル** で設定します。アプリ全体の設定であるため、すべてのバトル設定に共通して適用されます。

| 項目 | 説明 |
|---|---|
| 連続出撃前にミッション通知を消す | 機能のオン・オフを切り替えます。初期値はオフです。 |
| 連打時間 | 通知の位置を連打する時間（1〜60秒）を設定します。初期値は 10秒で、上のスイッチがオンのときだけ変更できます。 |

## 動作の仕組み

- **連続出撃の確認画面でのみ動作します。** 他の画面やバトル中には連打しません。
- 連打する位置は画面上部中央（ミッション通知の位置）の1か所だけです。
- 通知が出ているかどうかを個別に確認しないため、**通知がない周回でも毎回設定した時間だけ周回時間が増えます。**
- 1回あたり10タップずつまとめて送り、経過時間を確認します。**微調整** でクリック後の待機秒数などを長く設定している場合は、設定時間より最大で約 1〜2 秒長くかかることがあります。
- 連打が終わると、更新された画面で連続出撃ボタンをもう一度探します。
  - 連続出撃ボタンが見つかれば通常通り連続出撃を押します（ブーストアイテム設定を含む）。
  - 連打後に連続出撃ボタンが見えない場合は、どのボタンも押さずメインループへ戻ります。同じ連続出撃画面でボタンを再検出しても、すでに1回連打済みであれば再び N 秒連打せずそのまま連続出撃を押します。
- 連打の途中でも停止要求が入ると即座に停止します。

## 注意事項

- スイッチがオフのときは、連打・追加待機・追加の画面確認は一切行われず、従来と同じ動作になります。
- サーバー（KR・JP）や画面比率（16:9・21:9 など）に関わらず画面上部中央をタップします。
