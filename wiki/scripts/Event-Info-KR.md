# 진행 중인 이벤트

메인 화면에서 로그 수집 프로필 아래, 메뉴 카드 위에 **진행 중인 이벤트 (KR)** 카드가 표시됩니다. 별도 설정 없이 사용할 수 있으며 로그 수집을 켜지 않아도 동작합니다. 앱의 게임 서버 설정과 관계없이 한국 서버 정보가 표시됩니다.

## 카드 내용

- 진행 중인 기간 한정 이벤트마다 배너, 이름, 남은 일수 또는 시간, 종료 시각을 보여 줍니다. 배너가 제공되지 않는 이벤트는 이름부터 표시됩니다.
- 24시간 이상 남으면 일수로, 그보다 적게 남으면 시간으로 표시합니다. 1시간 미만은 1시간으로 표시합니다.
- 종료 시각은 기기의 현지 시간대를 따릅니다.
- 보너스 예장 정보가 있으면 예장 종류 수와 드롭 UP, 포인트 UP, 인연 UP, 출현율 UP, 기타 태그가 표시됩니다.
- 이벤트를 누르면 **이벤트 보너스 예장** 화면에서 예장 이름과 보너스 종류를 확인할 수 있습니다. 예장 이름을 아직 받지 못했으면 `#번호`로 표시됩니다.
- 캠페인은 종료가 빠른 순으로 요약됩니다. 캠페인 줄을 누르면 전체 목록과 각각의 종료 시각을 펼치거나 접을 수 있습니다.

180일을 넘는 상시 항목은 제외됩니다. 진행 중인 항목이 없거나 이벤트 정보를 한 번도 받지 못한 경우 카드는 표시되지 않습니다.

## 정보 출처와 갱신

데이터는 [Atlas Academy](https://atlasacademy.io)의 KR 공개 데이터에서 가져옵니다.

- 메인 화면을 열 때 이벤트 일정을 확인하며 다운로드 시도는 하루에 한 번으로 제한됩니다.
- 진행 중인 기간 한정 이벤트의 보너스 예장 정보가 없을 때만 예장 데이터를 내려받습니다. 이 시도도 하루에 한 번으로 제한됩니다. 앱에는 이벤트별 보너스 예장 목록만 저장됩니다.
- 배너 주소는 이벤트별로 한 번 확인해 저장합니다. 배너가 없다는 결과도 저장합니다. 요청 실패 시 다음 날 다시 시도할 수 있습니다.
- 인터넷 연결이 없거나 갱신에 실패하면 마지막으로 저장한 정보를 사용합니다. 메인 화면에 오류 메시지는 표시되지 않습니다.

Atlas Academy의 갱신 시점에 따라 실제 게임과 정보 차이가 있을 수 있습니다.
