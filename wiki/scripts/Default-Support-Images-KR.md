# 기본 서포트 이미지 추출

**더 많은 옵션 → 저장소 → 기본 서포트 이미지 추출**을 누르면 앱에 포함된 기본 서번트·개념예장 서포트 이미지를 선택한 FGA 폴더로 추출합니다. 먼저 같은 탭의 **폴더**에서 저장 위치를 지정하세요. 추출 결과는 항목 아래에 표시됩니다.

로그와 계정 대시보드에 쓰는 아이콘은 **추출과 별개로**, 바로 아래 **로그 아이콘 데이터 다운로드**를 눌러 받습니다. 추출만으로는 아이콘을 받지 않으며, 이 항목에는 설명 줄 없이 진행 상태나 결과만 표시됩니다(대기 중에는 비어 있음). 첫 다운로드는 **약 15 MB**이므로 Wi-Fi를 권장합니다.

- Atlas Academy의 공개 KR 목록을 준비한 뒤 일반 서번트·마슈의 얼굴, 스킬·보구 강화 재료, 로그와 대시보드에 쓰는 재화·과일, 마술예장 아이콘을 받습니다. 이벤트 아이템은 미리 받지 않습니다.
- 이미 있는 아이콘은 다시 받지 않으며, 없는 파일을 최대 4개씩 받습니다. 아이콘은 앱 내부 `capture/icons/`에 저장하고 얼굴은 `servants/`, 마술예장은 `mystics/` 하위 폴더에 보관합니다. APK나 선택한 FGA 폴더에 추가하지 않습니다.
- 화면을 나가도 계속 진행합니다. 진행 중 다시 누르면 아무 일도 일어나지 않고 같은 작업의 현재 진행 상태를 계속 보여 줍니다. 앱 프로세스가 종료되면 멈추며, 다음에 다시 누르면 저장된 파일을 재사용하고 없는 파일만 받습니다.
- 서포트 선택 화면(선호 서포트)에서 하는 이미지 추출은 아이콘을 받지 않습니다.
- **로그 수집 데이터 삭제** 후에도 공개 목록과 아이콘은 남습니다. 공개 목록·이미지만 내려받으며 계정 정보는 전송하지 않습니다.

## 진행 표시와 실패

**로그 아이콘 데이터 다운로드** 아래에 **아이콘 목록 받는 중…**, **아이콘 받는 중 n/m**이 표시됩니다. 완료되면 **아이콘 m개 준비됨** 또는 **아이콘 m개 준비됨, k개 실패**로 바뀝니다. 준비된 수에는 이전에 저장한 파일도 포함되며, 진행 수에는 실패한 시도도 포함됩니다.

**아이콘 목록을 받지 못했습니다**가 나오면 연결을 확인하고 나중에 다시 누르세요. 기존 목록 다운로드·재시도 제한을 그대로 사용하므로 반복해서 눌러도 제한을 건너뛰지 않습니다. 개별 아이콘 실패는 나머지 다운로드를 멈추지 않으며, 기존 아이콘 재시도 간격(최소 한 시간)을 유지합니다. 화면에 표시할 때도 없는 아이콘은 기존 방식으로 받습니다.

서포트 이미지 추출과 아이콘 다운로드는 서로 독립적이며 각자의 결과를 자기 항목 아래에 표시합니다. 이미지가 없으면 로그와 대시보드는 이름으로 표시합니다.

대시보드의 구성과 공개 데이터 보관 방식은 [로그 수집 (KR)](Gains-Tracker-KR.md)을 참고하세요.
