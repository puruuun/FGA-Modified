# 戦闘ログ

メイン画面の**ログ**から、バトル終了時の記録を新しい順に確認できます。幅 840dp 以上の広い画面では、左側に一覧、右側に選択した記録の詳細が表示されます。最初は最新の記録が選択されており、選択中の記録を削除すると次に新しい記録へ移動します。狭い画面では、カードをタップするとスクリプト終了時と同じ詳細サマリーが開きます。記録中の**スクリプト外の変化**がある場合は、**進行中**として一番上に表示され、変化のたびに更新されます。

カードは 2 行で表示されます。1 行目には設定名・小さく薄いアカウント名・右側に終了日時が表示され、2 行目には周回数・平均ターン数・**追跡済み**・停止理由が表示されます。スクリプト外カードの 2 行目には、その期間内に初めて現れた順で **プレゼントボックス · ミッション** のように出所が表示されます。進行中の期間は **進行中 ·** で始まり、出所が長い場合は 1 行の末尾で省略記号になります。バトルカードは灰色で、スクリプト外カードは別の色を維持します。どちらの種類も選択中のみ同じ枠線が付きます。

ログ収集で記録されたバトルカードはタイトルの左側に鍵アイコンが表示され、画面認識のみで記録されたバトルカードはアイコンなし、スクリプト外の変化および進行中カードは双方向矢印アイコンで表示されます。

バトルスクリプトが終了したとき、完了した周回数が 1 回以上であれば 1 件として自動保存されます。ウィークリーミッションルート終了時に表示されるバトル終了サマリーも保存されます。**一時停止中の状態確認画面**と **0 周回**は記録されません。

記録には、当時のバトル設定名、終了時刻・停止理由、周回数・上限、AP回復アイテムの使用回数・上限、最小・平均・最大ターン数、合計・平均戦闘時間、概念礼装ドロップ数、全滅・ターン制限撤退の回数が含まれます。停止理由は保存時点のアプリ言語で記録されます。

**素材**は素材カウントをオンにして集計された項目がある場合のみ、**絆ポイント**は絆追跡機能を有効にしている場合のみ詳細画面に表示されます。

[ログ収集](Gains-Tracker-JA.md)が実行中だった場合、カードに**追跡済み**が付きます。詳細画面の**獲得量（ログ収集）**では、サーバー応答に基づくアイテム・QP・マスターEXP・サーヴァント別の絆、果実やその他使用アイテム（ストームポッド、ティーポットなど）の消費量、折りたたみ式のバトルごとの内訳を確認できます。獲得・使用タイルは画面幅に合わせて折り返され、アイテムはアイコン・短縮名・個数、資源はアイコン・個数で表示されます。タイルをタップまたは長押ししてもポップアップは開かず、スクリーンリーダーには名前と個数が読み上げられます。画像読み込みに失敗した場合は名前で代替表示されます。KR データにまだないアイテムは、KR データが更新されるまで日本語名で表示されます。アイコンは表示時に未保存のファイルのみ Atlas の公開 HTTPS サーバーから一度だけダウンロードし、アプリ内部に恒久保存します。以降は保存済みファイルを使用し、アカウントデータは送信しません。収集できなかったバトルがある場合は欠損の案内が表示されます。収集記録のないログでは従来のサマリーのみが表示されます。

**スクリプト外の変化**の詳細では、合計と展開した出所別の内訳に、QP・聖晶石・フレンドポイントなどの資源の増減が符号付き・桁区切りで表示されます。フレンドポイントのみが変化した場合でも、新しい期間が始まるか進行中の記録に追記されます。フレンドポイント召喚の消費量と、応答に含まれる新規サーヴァント・概念礼装は**召喚**の内訳で確認できます。サポート使用報酬など別の経路で受け取ったフレンドポイントは、該当応答の出所に集計されます。

バトル以外の FGA スクリプト（フレンドポイント召喚、箱イベ、プレゼントボックス、強化、スキル・アペンドスキル自動強化など）によって起きた変化も**スクリプト外の変化**に記録されます。スクリプト実行中に新しく記録された変化は出所が**スクリプト**として表示され、スクリプト終了後の変化は再びプレゼントボックス・召喚など元の出所で表示されます。同じ期間内でも両者の内訳は区別され、過去の既存記録の出所はそのまま維持されます。バトルスクリプト（通常周回・ウィークリールート）を開始すると進行中だった期間は確定して閉じられ、戦闘中の変化はバトル記録にのみ反映されます。

上部の**削除**の横にある**フィルターアイコン**をタップすると、日付・プロフィール・出所・獲得リソース・ログの保存件数を設定する画面が開きます。日付は**今日 / 7日 / 30日 / すべて**、または**期間を指定**から開始日と終了日を選びます。期間は端末のローカル日付と記録の終了時刻を基準とし、両端の日付を含みます。プロフィールは**すべて**、または保存されているログに登場するプロフィール名（名前がない場合は **#アカウントID**）から選択します。選択したプロフィールのバトル・スクリプト外記録のみが表示され、アカウント ID がない記録（ログ収集オフで実行した記録やプロフィール情報のない古い記録）は**すべて**で表示されるほか、該当記録が 1 件以上ある場合に一覧末尾へ現れる**プロフィールなし**を選ぶとその記録のみ表示できます。選択したプロフィール（または**プロフィールなし**）の記録がない場合は**すべて**を表示します。画面回転や画面復元後の読み込み中でも選択したプロフィールを記憶し、該当プロフィールの記録が現れるとフィルターを再適用します。プロフィールは日付・リソース条件と併用され、リソース選択一覧も選択中の日付とプロフィールに従います。獲得リソースは**複数**選べます。チップを押すと選択のオン・オフが切り替わり、**すべてのリソース**は選択をすべて解除します。選んだリソースの**いずれか**を獲得した両種類の記録を表示し、検索で絞り込んでも選択済みのリソースは表示されたままです。日付・プロフィール・出所を変えて一覧から消えたリソースは条件から外れます。フレンドポイントも QP と同様にリソース一覧に表示され、スクリプト外記録は該当リソースの獲得履歴がある場合にフィルターへ現れます。**適用**を押すと条件が反映されます。フィルターが有効なときはアイコンに小さなバッジと一覧上部に 1 行のサマリーが表示されます。サマリーを押すとフィルターが開きます。リソースは「 · 」でつなぎ、3 件を超えると最初の 2 件と残りの件数に省略します。ダイアログ下部の**リセット**は日付・プロフィール・出所・リソース・検索語をすべて初期値に戻します。反映されるのは**適用**を押したときで、すべて初期値のときは押せません。ログ保持数はリセットしません。適用中のフィルターや選択中の条件は画面を回転しても維持され、一致する記録がない場合は該当記録なしの案内が表示されます。

**出所**は**すべての出所 / スクリプト / プレゼントボックス / ショップ / 召喚 / ボックスガチャ / 強化 / AP回復 / 手動クエスト / ミッション / その他**から 1 つ選びます。**スクリプト**にはすべてのバトル記録と、バトル以外の FGA スクリプト実行中に新しく記録された変化が含まれます。スクリプト外記録はその期間内の出所のうち 1 つでも一致すれば表示され、詳細では一致した出所を先頭に表示し、残りの内訳も保持します。日付・プロフィール・獲得リソースの条件と併用でき、リソース選択一覧も選択した出所に従います。出所条件は一覧上部のフィルターサマリーに表示され、適用前の選択も適用済みの条件も回転・画面復元後に維持されます。**すべての出所**は出所で絞り込まず、ほかのフィルターとまとめて戻すには**リセット**を押して**適用**します。

**ログの保存件数（種類ごと）**は **50 / 100 / 200** から選び、初期値および上限は **200** です。以前に保存された **500** や非対応の値は **200** として扱われ、既存のログ整理が実行されると種類ごとに最新 200 件を超える古い記録は削除されます。バトル記録とスクリプト外記録のそれぞれに同じ上限が適用され、設定が保存されます。現在の記録件数より少ない上限へ減らすときは、確認ダイアログを経て古い記録から順に削除されます。確認をキャンセルすると保存件数設定と記録はそのまま維持されます。その後、上限を超えた場合は古い記録から自動的に削除されます。手動で削除するには上部の**削除**を押して選択モードに入り、チェックを入れて**選択削除**を押します。**すべて削除**はフィルターで隠れている記録も含めてすべて削除します。どちらの操作も確認ダイアログが表示され、**キャンセル**で選択を破棄します。進行中の記録も削除でき、以降の新しい変化から新しい期間が始まります。削除した記録は復元できません。Chaldea エクスポートは**その他の設定 → 追加機能**から利用できます。

アカウントごとの最近の活動は、メイン画面のアカウントカードをタップして**アカウントダッシュボード → 最近の活動**からも確認できます。資源タイルはすべて同じ高さで、終了時の所持数・無償/有償の区別がアイコン右側の 2 行目に表示されます。

**その他の設定 → ストレージ → ログアイコンデータをダウンロード**から、素材・資源・果実アイコンを事前にダウンロードできます（サポート画像の抽出とは別機能です）。初回ダウンロードは約 15 MB で、イベントアイテムは除外されます。すでに取得したファイルはログとダッシュボードで共有されます。[アイコンの準備と進捗表示](Default-Support-Images-JA.md)
