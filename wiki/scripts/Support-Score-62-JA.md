# クラススコア +62・グランドスコア +16

## 設定と通過条件

**バトルの設定 → サポート → 選択するサーヴァント** の下にある **Require Class score +62**（クラススコア +62 判定）と **Require Grand score +16**（グランドスコア +16 判定）の各トグルを個別にオンにします。両トグルは、選択するサーヴァントが1体以上あるときだけ表示され、グランドのトグルはさらに**グランドサーヴァント**がオンのときだけ表示されます（ゲームが +16 をグランドサーヴァントにだけ表示するためです）。条件を満たさなくなって隠れたトグルは、保存されている値もオフになります。再び表示されたときはオフの状態で、以前の値は復元されません。両方のトグルをオンにすると、両方の条件を満たす必要があります。トグルはコピー・エクスポート・インポートに含まれます。

| 実際の表示 | クラスのみ | グランドのみ | 両方オン |
|---|---|---|---|
| +62/+16 | 通過 | 通過 | 通過 |
| +0/+16 | 除外 | 通過 | 除外 |
| +62/+0 | 通過 | 除外 | 除外 |
| +16/+62 | 除外 | 除外 | 除外 |
| 通常 +62 | 通過 | 除外 | 除外 |
| 通常 +0・+23・+43 | 除外 | 除外 | 除外 |
| 表示形式・値未確定 | クラス `62` の確定が必要 | 特殊表示とグランド `16` の確定が必要 | 両条件の確定が必要 |

**グランド条件をオンにすると、クラス／グランド特殊表示の `+16` が必須になります。** クラスのみをオンにした場合は、通常の `+62` と特殊表示の `+62/+16` の両方を許可します。特殊表示では `/` の前をクラス、後ろをグランドとして判定します。

通常スキル・宝具・概念礼装など他の条件もすべて通過する必要があり、アペンドスキル判定は常に最後に実行されます。このフィルターは **優先** 選択モードに適用されます。フォールバックを **一番上を選択** にすると優先条件を回避してしまうため、条件を厳密に守りたい場合はフォールバックを **手動** に設定してください。

JP サーバーのスコア表示では、OCR が `+` 記号を `4` と誤読しても別の判定や `+16` テンプレートがグランド `16` を確認できた場合や、複数回の OCR 判定のうち一部がグランドスコア部分だけを読み取った場合でも、`+62/+16` を正常に認識します。画面が暗く数字の OCR 結果が空になっても、`+16` テンプレートが最後の桁まで確認できれば正常に認識されます。判定結果が不明瞭または矛盾する場合は従来通り未確定としてそのサポートをスキップし、KR サーバーのスコア読み取り動作は変更されていません。
