# ティーポット・ストームポッド自動使用

## 使い方

1. **その他の設定 → バトル → ティーポット・ストームポッドの自動設定を使用** をオンにします。新規設定の初期値はオンです。
2. 韓国・日本または北米(NA)サーバーを選択し、再生ボタンを押します。
3. 実行画面の右側、**AP回復アイテムと周回設定の間 → アイテム自動使用** にある横並びの **ストームポッドを使用**、**ティーポットを使用** をそれぞれ設定します。チェックボックスまたは項目名をタップして選択できます。名前が1行に収まらないほど狭い場合は2行に分かれます。
4. チェックでON、解除でOFFです。**OK** を押すと選択した実行設定で開始します。

この2つの選択はサーバーごとに記憶され、個別のバトル設定のスキルコマンドやカード優先順位には保存されません。実行画面の2つの選択は最初はオフになっています。上記の自動設定機能がオンの場合のみ、表示されているアイテムを実行画面で選んだON/OFFに合わせます。スクリプト設定ファイルを別の端末へ移行した場合は、実行画面でこの項目を選び直してください。

| 実行画面の選択 | クエスト開始直前の状態 |
|---|---|
| 両方オフ | ストームポッド OFF、ティーポット OFF |
| ストームポッドのみチェック | ストームポッド ON、ティーポット OFF |
| ティーポットのみチェック | ストームポッド OFF、ティーポット ON |
| 両方チェック | ストームポッド ON、ティーポット ON |

自動設定機能がオフの場合、ゲーム内の状態検査と変更はすべて省略されます。実行画面の選択は保持され、アイテムブロック全体が非表示になります。機能をオンにすると実行画面の選択を適用します。以前に直接保存した使用・無視の選択は維持され、未選択の設定は初期値オンです。その他のサーバー(BetterFGO、中国、台湾)では現在この制御を省略します。

## 動作

**サポート選択 → 4秒 → パーティー選択 → 1秒 → アイテム設定 → 1秒 → クエスト開始** の順に進みます。パーティー選択自体の1.2秒・1秒待機は維持されます。開始を押した後は従来どおり 2秒待機 → ブーストアイテム選択 → ストーリースキップ準備 → 5秒待機 を経ます。この待機順はすべてのサーバーに適用され、通常の待機時間倍率に従います。

**パーティー確認画面から直接再生する開始方法は非対応です。** サポート選択から続く開始順序を使用してください。すでにアイテム設定ダイアログを手動で開いている場合は、閉じてから再生してください。

見た目が同じメインボタンを1回押して、直接切り替え型か設定ダイアログ型かを判別します。直接切り替え型であれば変わった状態を確認し、指定した最終状態に合わせます。最初から希望の状態だった直接切り替え型は2回目のクリックで元に戻します。アイテムはクエスト開始時に消費されるため、この確認タップで消費されることはありません。

設定ダイアログ型の場合は **左：ストームポッド／右：ティーポット** をそれぞれ確認し、状態が異なる項目のみ変更します。新しい画面で両方の状態を確認した後 **閉じる** を押し、メインのアイテムボタンが指定した状態に戻ったことまで確認します。変更や閉じる動作を確認できない場合はクエスト開始前に中断します。数量 `0` や `0/9` の表示はON/OFFとは別であり、状態読み取りには使用しません。

アイテムボタンがないパーティー画面ではそのまま開始します。1種類のみ提供されるクエストでは見えているアイテムだけを制御し、提供されていないアイテムを勝手にタップしません。ゲームの**連続出撃**でパーティー確認画面が省略された場合はすでに合わせた設定をそのまま使い、サポート選択後の開始時に再検査します。

## 北米(NA)サーバー

北米サーバーにも対応しています。韓国・日本は設定ウィンドウのタイトル画像と閉じるボタン・両方のボタンを合わせて確認しますが、北米はタイトル画像を使わず、**閉じるボタンとストームポッド・ティーポットのON/OFFボタン2つがすべて見つかったとき**に設定ウィンドウと判断します。閉じるボタンは見えるのに2つのボタンのどちらかがない、または不確かな場合は、アイテムを押さずクエスト開始前に停止します。

北米サーバーは直接プレイしていないため、端末では検証していません。閉じるボタンは北米のスクリーンショットで、画面配置は公式告知で確認しただけで、北米の実機テストは行っていません。

パーティータイトル画像が一致しなくても出発できるよう、タイトル確認と最大3秒の再試行、確認後の2秒待機、スキップログを削除しました。すべてのサーバーで上記の4秒・1秒・1秒の順に進みます。KR・JP・NA以外のサーバーや自動設定を無効にしている場合はアイテム操作を省略しますが、1秒待機は維持されます。

## 固定待機での出発

アイテムアイコンやON/OFFボタンがない、または不確実な場合はアイテムを押さずに開始へ進みます。設定ダイアログタイトル・閉じる・両ボタンの確認は維持します。実際にアイテムボタンを押した後に切り替え・復元・閉じる結果を確認できなかった場合は、従来の文言で中断します。
