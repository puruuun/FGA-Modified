# ハクノシャッフル

**ゲーム内のスキル使用確認は OFF** にしてください。ハクノシャッフルがコマンドに含まれているとサーヴァントカード確認は自動でオンになるため、別途設定する必要はありません。NP を消費してコマンドカードを配り直すスキル1を、指定した条件を満たすまで繰り返します。

スキルメーカーで前衛1〜3番の **スキル1 → Hakuno Shuffle**（ハクノシャッフル）を選択してください。**Min shuffle presses**（最小シャッフル回数、初期値 0）、**Max shuffle presses**（最大シャッフル回数、1〜30、初期値 10）、前衛位置ごとのカード色（All / B / A / Q）と必要枚数（1〜5枚）、**Stop the battle if the condition is not met**（条件未達成時にバトル停止）を設定します。条件行は `Slot [1] · [All] · [3] or more cards` のように枚数の後ろに **or more cards**（枚以上）と表示されます。条件行は追加・削除できます。**スタン状態でないコマンドカードを数えます。いずれかの条件を満たすと停止します。** **All**（全体）は従来通りすべての色を数え、色を選ぶとその色のカードだけを数えます。色を判別できなかったカードは色別条件に含めません。

直接入力の書式は `<スキル>H{[最小-]最大:位置[色]枚数[|位置[色]枚数…][!]}` です。スキルには各サーヴァントのスキル1である `a`・`d`・`g` だけを使い、すぐ後ろに大文字の `H` と `{` を付けます。小文字の `h` は前衛3番のスキル2であるため、`ah` はスキル2回扱いとなり、`ah{…}` や `a{…}` は入力エラーになります。色は `b`（Buster）・`a`（Arts）・`q`（Quick）で、大文字・小文字を区別せず保存時は小文字になります。**色指定なし = All（全色）** です。従来の `13`、`22|31!` 条件もそのまま動作します。

`1.7.0-beta.3` で保存された以前の `a{…}` 形式のコマンドは、シャッフル編集画面で再設定して保存し直す必要があります。

- `aH{10-30:1b2|1q2}`: 最小10回、最大30回。前衛1番の Buster が2枚以上 **または** Quick が2枚以上になるとシャッフルを止めます。
- `aH{8:13|2a2}`: 前衛1番のカードが全色合計3枚以上 **または** 2番の Arts が2枚以上です。
- `aH{8:13|22}`: 最大8回、前衛1番が3枚以上 **または** 2番が2枚以上で終了します。最初の手札で満たしていれば0回になります。
- `aH{2-8:13|22!}`: 最低2回使ってから判定し、最大8回でも未達成、または NP 不足・読み取り失敗でバトルを停止します。
- `dH{30:23}`: 前衛2番のスキル1を最大30回、前衛2番のコマンドカードが3枚以上になるまで使用します。

NP 不足ダイアログが出た場合は閉じてバトル画面へ戻ります。カード読み取りは同じ手札をさらに2回読み直しても失敗した場合に終了します。`!` がない場合は条件未達成でも残りのコマンドを続行します。バトル画面へ戻れなかった場合は常に停止します。

スキル1を押すとすぐに NP 不足ダイアログを確認します。ダイアログが見つかった場合のみ閉じる前に 0.5 秒待機し、見つからなければ通常のスキルモーション短縮タップをそのまま送ります。NP 不足ダイアログを閉じてバトル画面を確認したあと、および手札画面からバトル画面へ戻ったあとも、それぞれ 0.5 秒待機します。

このトークンを使ったターンでは魔術礼装のシャッフルを追加で使用しません。その後の通常攻撃は既存のカードの優先順位・Brave Chains・宝具設定に従います。実行結果や回数、条件別の枚数（`counts=1b:2,1q:1`）は `HakunoShuffle` ログで確認してください。

## アプリ言語

ハクノシャッフルの設定と終了案内は韓国語に対応しています。新規インストール時に保存されたアプリ言語がない場合はシステム言語（韓国語・日本語・中国語簡体字/繁体字・ベトナム語）から選んで保存し、非対応の場合は英語を使用します。初回案内と設定の言語表示は同じ値を使い、手動で選んだ言語は保持されます。**その他の設定 → その他 → アプリ言語** から変更できます。
