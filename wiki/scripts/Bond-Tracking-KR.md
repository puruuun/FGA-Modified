# 인연포인트 누적·MAX 정지 — 0.8.0

재생 버튼의 실행 창에서 **인연포인트** 항목을 설정합니다. 한국·일본 서버를 지원하며 설정은 서버별로 기억합니다. 두 기능의 기본값은 꺼짐입니다.

- **인연포인트 획득량 추적**: 일반 결과 화면의 기본값과 보너스를 더하여, 이번 실행 동안 원래 파티 위치별 획득량을 누적합니다. 예: `+4,748(+2,660)` → `7,408`.
- **인연 MAX 확인 시 정지**: 감시하는 위치에서 MAX를 확인하면 다음 퀘스트 전에 멈춥니다. 획득량 추적과 독립적으로 사용할 수 있습니다.
- **MAX 정지 예외**: 체크한 자리는 MAX여도 계속 진행합니다. 번호는 전투 전 편성의 1~6번입니다. 예외 설정은 획득량 집계를 끄지 않습니다.

서포트는 편성 화면의 `SUPPORT` 표시로 제외합니다. 서포트가 3번이면 결과창의 1~5번째는 파티 1·2·4·5·6번에 대응합니다. 전투 중 사망·후열 등장·오더 체인지로 결과창 대응을 바꾸지 않습니다. 실행 도중 파티를 바꾸면 합계는 계속 같은 위치별로 합산되므로, 캐릭터별 합계를 분리하려면 실행을 종료하고 다시 시작하세요.

## 일반 결과와 레벨업 창

일반 결과는 MAX 이미지와 증가량을 따로 읽습니다. 증가량은 높은 신뢰도의 판독 두 개 이상이 일치해야 하고, 서로 다른 신뢰도 높은 값이 있으면 미확정으로 남깁니다. 연속 프레임에서도 값이 일치해야 기록하며, 같은 퀘스트의 화면을 다시 보아도 중복 합산하지 않습니다.

레벨업 창에서는 가려진 배경의 증가량·MAX를 읽지 않습니다. 화살표 오른쪽의 **도달 레벨**만 확인합니다. 10 이상이고 결과 카드의 LEVEL UP 표시로 위치를 확정할 수 있으면 해당 위치의 MAX 정지 조건에 적용합니다. 9 이하는 정지 조건에 적용하지 않습니다.

위치나 도달 레벨이 미확정인 레벨업 창은 건너뜁니다. 사용자 지정 정책에 따라 **다음 퀘스트의 일반 결과에서 MAX를 다시 확인**합니다. 이 경우 추가 퀘스트 한 회가 진행될 수 있습니다. 여러 후보 위치를 임의로 선택하지 않습니다.

## 종료 화면의 합계

**이번 스크립트 인연포인트 판독 합계**에 위치별 포인트, 집계 횟수와 누락 횟수가 표시됩니다. MAX가 이미 표시된 일반 결과는 증가량 0으로 기록할 수 있지만, 레벨업으로 가려진 증가량이나 판독 실패는 실제 0으로 기록하지 않습니다. 누락이 있으면 전체 실제 획득량보다 합계가 작을 수 있습니다.

보석을 이용한 현재 인연레벨 추적과 NEXT 숫자 판독은 하지 않습니다. 결과 화면을 읽기 전에 여러 번 연속 클릭하지 않도록, 기능을 켠 경우 결과 화면을 하나씩 넘깁니다. 두 기능을 모두 끄면 기존 결과 처리로 동작합니다.

편성 위치를 먼저 확인해야 하므로 **퀘스트 목록 또는 서포트 선택부터 실행**하세요. 파티를 확인하지 못하면 임의의 자리로 집계하지 않고 안내 후 중단합니다. 연속 주회가 편성 화면을 생략하면 처음 확인한 대응을 유지합니다.

## 검증 범위

실제 제공한 한국·일본 전체 화면을 720p 게임 영역 기준으로 정규화하여, 출하 템플릿·좌표·OCR 설정으로 검사합니다. 일반 결과 3장(15칸: 증가량 6개, MAX 9개), 레벨업 5장(도달 7·10·11·12·16), 편성 3장(서포트 1번·3번), 빈 화면 2개를 사용합니다. 명령:

```bash
python tools/verify_bond_images.py --output bond-image-results.json
```

도구에는 OpenCV·Pillow·tesserocr가 필요합니다. 데스크톱 이미지 시험과 자동 테스트는 실제 Android/FGO의 터치·화면 전환 검증을 대신하지 않습니다. 적은 인원 편성, 여러 캐릭터가 동시에 레벨업하는 장면은 추가 실기 확인이 필요합니다.

티포트·스톰포드는 기존의 **화면 아이템 아이콘 기준** 동작을 유지합니다. [아이템 안내](Quest-Items-KR.md).
