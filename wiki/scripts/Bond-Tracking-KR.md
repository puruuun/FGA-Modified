# 인연포인트 누적·MAX 정지 — 0.9.2

**스크립트 수정 → 커맨드 시작 조건과 카드 셔플 사이의 인연포인트**에서 설정합니다. 한국·일본 서버를 지원하며 스크립트별로 저장하고, 복사·내보내기·가져오기에 포함합니다. 추적과 MAX 정지의 기본값은 꺼짐입니다. 0.8.0의 실행 창 설정은 새 번호 체계로 자동 이전하지 않으므로 사용할 스크립트에서 다시 켜세요.

- **인연포인트 획득량 추적**: 퀘스트 종료 후 결과창의 왼쪽부터 **캐릭터 1·2·3·4·5**로 기본값과 보너스를 합산합니다. `+4,748(+2,660)`은 `7,408`입니다.
- **인연 MAX 확인 시 정지**: 체크하지 않은 캐릭터의 MAX를 확인하면 해당 퀘스트 인연 결과 화면에서 정지하고 다음 퀘스트를 시작하지 않습니다.
- **MAX 정지를 무시할 캐릭터**: 가로로 배치된 캐릭터 이름 아래 체크박스를 선택합니다. **2번을 체크하면 2번의 MAX를 무시하고 계속 진행**합니다. 새 설정의 기본값은 모두 체크 해제입니다. 이 선택은 획득량 집계를 끄지 않습니다.

0.9.0의 기존 정지 동작은 유지합니다. 이전에 정지 대상으로 선택했던 캐릭터는 새 예외 화면에서 체크 해제로 표시됩니다. 인연 기능 아래의 서버 안내·긴 설명은 UI에서 제거했습니다.

**시작 전 편성 화면을 읽거나 서포트 위치와 연결하지 않습니다.** 번호는 원래 파티의 1~6번이 아니라 결과창의 다섯 칸입니다. 퀘스트 시작 화면·전투 중·결과창에서 실행하더라도 사전 편성 확인을 요구하지 않습니다. 편성 및 결과창 순서의 일관성은 사용자가 조율합니다. 실행 중 캐릭터를 바꾸면 같은 결과 칸에 계속 합산되므로 별도로 집계하려면 실행을 종료한 뒤 다시 시작하세요.

## 일반 결과와 레벨업 창

일반 결과창을 감지하면 **1.5초 기다린 뒤 새 화면에서** MAX 이미지와 증가량을 읽습니다. 게임의 숫자 증가 애니메이션을 기다리는 시간이므로 앱 대기 배율로 줄어들지 않습니다. 증가량은 신뢰도가 높은 판독 두 개 이상과 연속 화면의 값이 일치해야 기록합니다. 같은 퀘스트의 화면을 다시 보아도 중복 합산하지 않습니다. 다른 칸의 판독 실패로 칸 번호를 당겨 바꾸지 않습니다.

레벨업 창에서는 가려진 배경의 증가량·MAX를 읽지 않습니다. 화살표 오른쪽의 **도달 레벨**이 10 이상이고 결과 카드의 LEVEL UP 표시로 결과 칸을 확정할 수 있으면 그 캐릭터의 MAX 정지 조건에 적용합니다. 9 이하는 정지 조건에 적용하지 않습니다.

위치나 도달 레벨이 미확정인 레벨업 창은 건너뛰고, 사용자 지정 정책에 따라 **다음 퀘스트의 일반 결과에서 MAX를 재확인**합니다. 이 경우 추가 퀘스트 한 회가 진행될 수 있습니다. 보석으로 현재 인연레벨을 추적하거나 NEXT 숫자를 읽지 않습니다.

## 종료 화면의 합계

이번 실행 동안 캐릭터 1~5별 포인트 합계, 집계 횟수와 누락 횟수를 표시합니다. 새로 실행하면 합계를 초기화합니다. 이미 MAX인 일반 결과는 증가량 0으로 기록하지만, 가려졌거나 읽지 못한 획득량은 누락으로 표시합니다. 누락이 있으면 표시 합계가 실제 전체 획득량보다 작을 수 있습니다.

기능을 켜면 결과 화면을 한 번씩 넘겨 판독 시간을 확보합니다. 두 기능을 끄면 기존 결과 처리로 동작합니다. MAX 정지만 켜면 증가량 OCR과 합계 표시는 생략합니다.

## 검증 범위

제공된 한국·일본 전체 화면을 720p 게임 영역 기준으로 정규화하여 출하 템플릿·좌표·OCR 설정으로 검사합니다. 일반 결과 3장(15칸: 증가량 6개, MAX 9개), 레벨업 5장(도달 7·10·11·12·16), 편성 화면 3장(인연 결과로 오인하지 않는지 확인), 빈 화면 2개를 사용합니다.

```bash
python tools/verify_bond_images.py --output bond-image-results.json
```

OpenCV·Pillow·tesserocr가 필요합니다. 자동 테스트는 사전 편성 확인 없는 실행, 다섯 칸 독립 누적, 중복 방지, 각 칸 MAX 정지·예외, 스크립트별 저장·복사·내보내기를 검사합니다. 데스크톱 시험은 실제 Android/FGO 터치·전환 검증을 대신하지 않습니다. 적은 인원 편성이나 여러 캐릭터의 동시 레벨업은 추가 실기 확인이 필요합니다.

티포트·스톰포드는 기존의 **화면 아이템 아이콘 기준** 동작을 유지합니다. 자동 설정 기능은 기본 꺼짐이며 **더 많은 옵션 → 추가기능 → 티포트·스톰포드 자동 설정 사용**에서 켤 수 있습니다. [아이템 안내](Quest-Items-KR.md).
