# 인연포인트 누적·MAX 정지

**정규판 1.6.0부터 실행 창에서 설정합니다.** 더 많은 옵션 → 추가기능 → **인연 추적 기능 사용**은 기본 켜짐입니다. 끄면 실행 창의 인연 블록을 숨기고 추적·MAX 정지를 생략합니다. 전투 설정별 저장 값은 유지하며, 다시 켜면 기존 선택을 사용합니다.

**재생 버튼 → 전투 실행 창 → 아이템 자동 사용 아래의 인연포인트**에서 설정합니다. 왼쪽에서 전투 설정을 고른 뒤 추적·MAX 정지·무시할 캐릭터 칸을 선택하고 **확인**을 누르면 그 전투 설정에 저장됩니다. 취소하면 인연 설정 변경은 저장하지 않습니다. 설정을 편집하는 화면의 인연 항목은 제거했습니다. 한국·일본 서버를 지원하며 기존 저장 키와 값, 복사·내보내기·가져오기는 유지됩니다. 추적과 MAX 정지의 기본값은 꺼짐입니다.

- **인연포인트 획득량 추적**: 퀘스트 종료 후 결과창의 왼쪽부터 **캐릭터 1·2·3·4·5**로 기본값과 보너스를 합산합니다. `+4,748(+2,660)`은 `7,408`입니다.
- **인연 MAX 확인 시 정지**: 체크하지 않은 캐릭터의 MAX를 확인하면 해당 퀘스트 인연 결과 화면에서 정지하고 다음 퀘스트를 시작하지 않습니다.
- **MAX 정지를 무시할 캐릭터**: 가로로 배치된 캐릭터 이름 아래 체크박스를 선택합니다. **2번을 체크하면 2번의 MAX를 무시하고 계속 진행**합니다. 새 설정의 기본값은 모두 체크 해제입니다. 이 선택은 획득량 집계를 끄지 않습니다.

0.9.0의 기존 정지 동작은 유지합니다. 이전에 정지 대상으로 선택했던 캐릭터는 새 예외 화면에서 체크 해제로 표시됩니다. 인연 기능 아래의 서버 안내·긴 설명은 UI에서 제거했습니다.

**시작 전 편성 화면을 읽거나 서포트 위치와 연결하지 않습니다.** 번호는 원래 파티의 1~6번이 아니라 결과창의 다섯 칸입니다. 퀘스트 시작 화면·전투 중·결과창에서 실행하더라도 사전 편성 확인을 요구하지 않습니다. 편성 및 결과창 순서의 일관성은 사용자가 조율합니다. 실행 중 캐릭터를 바꾸면 같은 결과 칸에 계속 합산되므로 별도로 집계하려면 실행을 종료한 뒤 다시 시작하세요.

## 일반 결과와 레벨업 창

일반 결과창을 감지하면 **1.2초 기다린 뒤 새 화면에서** MAX 이미지와 증가량을 읽습니다. 게임의 숫자 증가 애니메이션을 기다리는 시간이므로 앱 대기 배율로 줄어들지 않습니다. 증가량은 신뢰도가 높은 판독 두 개 이상과 연속 화면의 값이 일치해야 기록합니다. 같은 퀘스트의 화면을 다시 보아도 중복 합산하지 않습니다. 다른 칸의 판독 실패로 칸 번호를 당겨 바꾸지 않습니다.

레벨업 창에서는 가려진 배경의 증가량·MAX를 읽지 않습니다. 화살표 오른쪽의 **도달 레벨 10~16**을 확인하면 결과 칸을 찾지 못해도 정지합니다. OCR을 먼저 사용하고 실패하면 밝은 숫자의 폭으로 한 자리·두 자리를 구분합니다. 350ms 뒤에도 10 이상으로 확인되어야 정지하며, 9 이하는 계속 진행합니다.

도달 레벨과 숫자 폭이 모두 미확정이면 해당 창을 한 번 넘깁니다. 다음 팝업을 건너뛰지 않으며, 일반 결과의 MAX 확인과 인연 스크린샷 설정은 유지합니다. 칸을 찾지 못한 정지는 **도달 인연 레벨 10 이상을 확인하여 정지했습니다.**로 표시합니다. 확인 후 편성을 조정하세요. 가려진 획득량은 누락으로 남기며, 보석으로 현재 인연레벨을 추적하거나 NEXT 숫자를 읽지 않습니다.

## 종료 화면의 합계

이번 실행 동안 캐릭터 1~5별 포인트 합계, 집계 횟수와 누락 횟수를 표시합니다. 새로 실행하면 합계를 초기화합니다. 이미 MAX인 일반 결과는 증가량 0으로 기록하지만, 가려졌거나 읽지 못한 획득량은 누락으로 표시합니다. 누락이 있으면 표시 합계가 실제 전체 획득량보다 작을 수 있습니다.

기능을 켜면 결과 화면을 한 번씩 넘겨 판독 시간을 확보합니다. 두 기능을 끄면 기존 결과 처리로 동작합니다. MAX 정지만 켜면 증가량 OCR과 합계 표시는 생략합니다.
