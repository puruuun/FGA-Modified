# 개념예장 자동 강화

JP·KR의 개념예장 강화 화면에서 강화할 예장을 고르고, 게임의 **추천 선택** 필터를 먼저 설정한 뒤 FGA를 시작하세요. 별도 설정 창 없이 시작합니다.

FGA는 자동 세트를 ON으로 바꾸고 **실행 → 강화 → 확인/결정**을 반복합니다. 추천 선택은 게임의 필터를 그대로 쓰며, 잠금·즐겨찾기 예장 보호도 게임 설정을 따릅니다. 경험치 과잉 환급 창은 닫고 계속합니다.

- **최대 레벨**: 회색 추천 선택 버튼을 확인하면 종료합니다.
- **필터에 맞는 예장 없음**: 필터와 재료 보유 상태를 확인하세요.
- **강화 재료 또는 QP 부족**: 보유량을 확인하세요. 강화 후 3초 안에 확인 창이 안 떠도 이 사유로 종료합니다.
- **중단/예상하지 못한 오류**: 화면을 확인한 뒤 다시 시작하세요.

강화 대상이 없는 화면과 다른 서버는 지원하지 않습니다. 기존 CE 폭탄 모드는 제거되었습니다.
