# 개념예장 자동 강화

시작 창의 제목 아래에 **시작전 필터설정 확인하세요** 안내를 표시합니다. 시작 전에 게임 내 필터 설정이 원하는 강화 재료를 선택하도록 되어 있는지 확인하세요.

JP·KR의 개념예장 강화 화면에서 강화할 예장을 고르고, 게임의 **추천 선택** 필터를 먼저 설정한 뒤 FGA를 시작하세요. **개념예장 강화** 시작 창에서 확인을 누르면 시작하며, 취소하면 실행하지 않습니다.

JP·KR에서는 시작 창 아래의 **서번트 레벨업으로 전환** / **개념예장 강화로 전환**으로 실행할 모드를 바꿀 수 있습니다. 화면을 다시 판별하지 않고 창 내용만 바뀌며, 확인을 누르면 현재 표시된 모드를 실행합니다. 자동 판별이 다른 모드를 골랐다면 실제 게임 화면에 맞춰 전환하세요.

FGA는 자동 세트를 ON으로 바꾸고 **실행 → 강화 → 확인/결정**을 반복합니다. 추천 선택은 게임의 필터를 그대로 쓰며, 잠금·즐겨찾기 예장 보호도 게임 설정을 따릅니다. 경험치 과잉 환급 창은 닫고 계속합니다.

- **최대 레벨**: 회색 추천 선택 버튼을 확인하면 종료합니다.
- **필터에 맞는 예장 없음**: 필터와 재료 보유 상태를 확인하세요.
- **강화 재료 또는 QP 부족**: 보유량을 확인하세요. 강화 후 3초 안에 확인 창이 안 떠도 이 사유로 종료합니다.
- **중단/예상하지 못한 오류**: 화면을 확인한 뒤 다시 시작하세요.

강화 대상이 없는 화면과 다른 서버는 지원하지 않습니다. 기존 CE 폭탄 모드는 제거되었습니다.
