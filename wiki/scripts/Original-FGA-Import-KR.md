# 원본 FGA 데이터 가져오기

[한국어](Original-FGA-Import-KR.md) | [English](Original-FGA-Import.md) | [日本語](Original-FGA-Import-JA.md)

**더 많은 옵션 → 추가기능 → 원본 FGA 데이터 가져오기**에서 다음 중 하나를 선택합니다.

- 스크립트만 가져오기
- 서포트 이미지만 가져오기
- 스크립트와 서포트 이미지 모두 가져오기

## 준비와 가져오기

1. 스크립트를 옮기려면 원본 FGA의 **오토 스킬 → 모두 내보내기**로 `.fga` 파일들을 폴더에 저장합니다.
2. 수정판의 가져오기 창에서 **내보낸 스크립트 폴더 선택**으로 해당 폴더를 지정합니다. 하위 폴더의 `.fga` 파일도 읽습니다.
3. 이미지를 옮기려면 **원본 서포트 이미지 폴더 선택**에서 원본 FGA 저장소 또는 그 안의 `support` 폴더를 지정합니다. `servant`·`ce`·`friend` 안의 이미지와 서번트별 하위 폴더를 현재 수정판 저장소로 복사합니다.
4. **가져오기**를 누르면 진행 상황과 스크립트·이미지별 가져옴/건너뜀/실패 건수를 표시합니다. 문제가 있는 파일은 이름과 이유를 표시하고 다른 파일은 계속 처리합니다.

이미지를 가져오기 전에 **더 많은 옵션 → 저장소 → 폴더**에서 수정판 저장소를 설정해야 합니다. 두 종류를 모두 가져오는 경우 스크립트와 이미지 폴더를 각각 선택합니다. 스크립트만 가져올 때에는 이미지 폴더나 수정판 저장소를 지정할 필요가 없습니다.

## 기존 데이터와 충돌

- 기존 스크립트를 유지하고 새 항목으로 추가합니다. 이름을 포함해 모든 저장 내용이 같은 스크립트는 건너뜁니다. 이름이 같아도 내용이 다르면 새 스크립트로 추가합니다.
- 이름이 같은 이미지는 기본적으로 기존 파일을 유지하고 건너뜁니다. 원본 이미지로 교체하려면 **같은 이름의 기존 이미지 덮어쓰기**를 체크하세요.
- 같은 저장소를 원본과 대상으로 선택했을 때 같은 이미지 파일을 다시 쓰지 않습니다. 원본 이미지 폴더 안에 별도의 복사 대상을 만드는 설정은 거부합니다.
- 서포트 이미지 이름과 스크립트 안의 참조 이름을 그대로 유지합니다. 누락되거나 건너뛴 이미지가 있다면 불러온 스크립트의 서포트 설정을 확인하세요.

## 호환 범위

빌드 번호로 제한하지 않습니다. 구버전의 평면 JSON `.fga` 파일과 현재 형식을 읽고, 지원하는 추가 설정 값도 보존합니다. 이 수정판이 읽을 수 없는 커맨드가 있는 스크립트는 실패로 안내합니다. 앞으로 원본의 파일 형식이나 커맨드 문법이 바뀌면 호환 처리 추가가 필요할 수 있습니다.

원본 앱의 비공개 데이터에 직접 접근하지 않습니다. 원본에서 내보낸 스크립트와 사용자가 접근을 허용한 이미지 폴더를 사용합니다. 앱 공통 설정·AP 회복 설정·Android 권한은 이전하지 않습니다.

세 가지 선택, 구형 JSON, 중복 방지, 이름 보존, 개별 실패와 이미지 충돌을 자동 테스트로 확인합니다. 실제 Android 문서 선택기와 기기별 저장소 제공자의 동작은 별도 기기 검증이 필요합니다.
