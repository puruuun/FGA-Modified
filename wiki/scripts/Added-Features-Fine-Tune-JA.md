# 追加機能の微調整

**その他の設定 → その他 → 追加機能の微調整** で、追加機能ごとの固定待機時間やテンプレート類似度基準を少しずつ調整できます。初期値のままでは従来の動作と完全に同じです。変更した値は **次のスクリプト実行から** 適用され、実行中のスクリプトには影響しません。

## セクション

| セクション | 対象 |
|---|---|
| ウィークリーミッション自動化 | ルート移動、バナー・ボタン判別、一覧スクロールバー |
| FP自動売却とバナー復帰 | 売却画面待機、スクロールバー・ロック判別、召喚待機 |
| スキル / アペンドレベル | 選択・強化・キャンセル・スキップ待機、ラベル・ダイアログ・パネル輪郭判別 |
| 概念礼装の自動強化 | 強化画面待機、おすすめ選択表示判別 |
| ストームポッド / ティーポットとクエスト開始 | アイテム操作後の待機、再確認間隔、アイテム状態・アイコン判別 |
| 絆追跡と停止 | 絆画面待機、絆画像判別 |
| 追加サポート判定 | 宝具名・レベル、スコア、スキル表示 |

ハクノシャッフルとカードの優先順位は対象外です。

## 項目

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 待機倍率 | 50〜300%（10%単位） | 100% | セクションの固定待機に掛けます。もともと全体の待機時間倍率が適用されていた待機には両方の倍率が合わせて適用されます。 |
| 類似度オフセット | -0.05〜+0.05 | 0.00 | テンプレート判定基準に加算し、0.40〜0.99の範囲に制限します。負の値はより弱い一致も許容します。 |
| アイテム操作後の待機 | 50〜1000ms | 100ms | ストームポッド・ティーポットをタップした後の待機です。セクション倍率のみが適用されます。 |
| アイテム再確認間隔 | 100〜2000ms | 300ms | アイテム状態を読み直す間隔です。再試行回数は10回のまま維持されます。 |

## 変わらないもの

安全確認間隔と制限時間、OCRの輝度基準、色ルール、インク比率、スコア差、座標は変更しません。

## リセット

各セクションの **初期設定へ戻す** ボタンはそのセクションだけを、**すべて初期設定へ戻す** ボタンはすべてのセクションを初期値へ戻します。

## 使い方のヒント

- 認識にたびたび失敗する場合は、類似度オフセットを -0.01〜-0.02 ずつ下げてみてください。誤認識が出る場合は再び上げてください。
- 画面切り替えが遅い端末では、まず待機倍率を上げてみてください。
