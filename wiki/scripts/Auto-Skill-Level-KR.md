# 스킬·어펜드 스킬 자동 강화

**서번트를 선택한 스킬 강화 / 어펜드 스킬 강화 화면에서, 칸마다 정한 목표 레벨까지 강화를 반복합니다. 강화는 QP와 재료를 쓰는 되돌릴 수 없는 동작입니다. 처음에는 한 칸, 목표 = 현재 레벨 + 1로 확인하세요.**

KR·JP 서버에서만 동작합니다.

## 시작하는 방법

1. 게임에서 **강화 → 스킬 강화**(또는 **어펜드 스킬 강화**)를 열고 서번트를 **먼저 선택**합니다.
2. FGA 재생 버튼을 누릅니다. 화면 가운데 왼쪽, 재료 목록 위의 안내 문구(`스킬 강화에 필요한 아이템` / `어펜드 스킬 강화/해방 시 필요 아이템`, JP는 `スキル強化に必要なアイテム` / `アペンドスキルの強化/解放に必要なアイテム`)를 보고 스킬 강화인지 어펜드 스킬 강화인지 자동으로 고릅니다. 오른쪽 위 제목 배너는 더 이상 쓰지 않습니다.
3. 설정 창에서 칸마다 **목표 레벨**을 정하고 확인을 누릅니다.

서번트를 선택하지 않은 화면(왼쪽 위에 `서번트 재선택` / `サーヴァント再選択` 버튼이 없는 화면)에서는 설정 창 없이 "서번트를 먼저 선택하세요" 안내만 띄우고 끝냅니다.

## 설정

| 항목 | 기본값 | 동작 |
|---|---|---|
| 스킬 강화 1~3번 칸 | **끔(0)** | 목표 레벨 1~10. 현재 레벨이 목표 이상이면 건드리지 않습니다. |
| 어펜드 스킬 강화 1~5번 칸 | **끔(0)** | 같습니다. 잠긴 칸은 목표를 정해도 건너뜁니다. |

모든 칸이 꺼져 있으면 확인 버튼이 눌리지 않습니다. 설정 창은 열 때마다 **모든 칸이 끔(0)** 으로 시작하며, 정한 값은 저장하지 않습니다. 실행할 때마다 목표를 직접 정해야 합니다.

## 동작과 보호 규칙

### 베타 전용: 레벨 판독만 확인

강화 재료를 쓰지 않고 패널·확인창 판독을 비교하려면, 서번트를 선택한 스킬/어펜드 강화 화면에서 FGA 재생 버튼을 누르고 **레벨 판독만 확인 (강화하지 않음)** 을 체크하세요. 목표 레벨은 무시하고 왼쪽부터 첫 칸을 포함해 모든 칸을 한 번씩 확인합니다. 매번 기본값은 체크 해제이며 저장하지 않습니다. Stable에는 이 옵션이 없습니다.

잠긴 칸은 해방하지 않습니다. 자물쇠가 보이는 칸은 선택도 하지 않고, 선택 뒤 패널을 읽고 해방 버튼이나 패널의 잠금 증거가 보이면 더 누르지 않습니다. 나머지 칸은 강화 버튼을 눌러 확인창을 읽은 뒤 **항상 취소**합니다. 패널에서 10을 읽어도 확인창 비교를 시도합니다. 예상 밖의 창도 취소하며, 취소 실패 시 전체 실행을 중지합니다. 강화 결정은 코드에서 차단됩니다. 확인창이 뜨지 않으면 최대 레벨 버튼 유무에 따라 `max` 또는 `no-response`를 남깁니다. 재료 부족은 따로 구별하지 않습니다.

- **어펜드 패널 판독**: 각 칸 자체 샘플(점수 0.70, 마진 0.10, 두 색상 후보 일치 및 타 칸 확정값과 충돌 없음)로 먼저 읽고, 기권 시 보조 노란색·금색 숫자 판독으로 보완합니다. 두 판독 모두 기준을 만족하지 못하면 기권합니다.
- **확인창 한쪽 추론**: 확인창의 현재·다음 중 한쪽만 확실히 읽히면 **다음 = 현재 + 1**로 다른 쪽을 추론해 `dialog=9(inferred)` / `dialog=8(next-inferred)` 형태로 기록합니다. 양쪽을 읽었는데 연속하지 않으면 덮어쓰지 않으며, 현재 0이 읽히거나 추론되면 해방 방지를 위해 취소합니다.

종료창과 `SkillLevel` 로그에 칸마다 다음과 같은 한 줄을 남깁니다. `slot`은 1부터이며 어펜드의 `score`/`margin`도 함께 표시합니다.

```text
slot=1 panel=3 dialog=unread verdict=panel-only reason=cancelled score=0.9 margin=0.2
```

| verdict | 뜻 |
|---|---|
| `match` / `mismatch` | 두 판독값이 일치 / 불일치 |
| `panel-only` / `dialog-only` | 패널만 / 확인창만 읽음 |
| `both-unread` | 둘 다 읽지 못함 |
| `no-dialog` | 강화 버튼을 누른 뒤 확인창 없음 (`reason=max` 또는 `no-response`) |
| `locked` | 잠김 |

`panel=abstain:원인`은 패널 판독 기권, `dialog=unread`는 열린 창의 유효한 레벨을 읽지 못함, `dialog=-`는 창을 열지 못했거나 열지 않음을 뜻합니다. `reason=unexpected-dialog`는 강화 확인창이 아니어서 취소한 경우이고, `cancel-failed`는 취소 실패로 멈춘 경우입니다.

**`mismatch`나 `both-unread`이면** 앱 버전, KR/JP 서버, 스킬/어펜드, 칸 번호·실제 레벨·해상도, 선택된 칸이 보이는 강화 화면과 가능하면 확인창의 원본 스크린샷, 해당 실행의 전체 `SkillLevel` 로그와 종료 요약을 보내 주세요. 재현을 위해 강화 결정을 누르지 마세요.

### 일반 강화

칸마다 다음을 반복합니다.

1. 자물쇠가 보이면 건너뜁니다. 나머지는 칸 아이콘을 눌러 선택하고 화면이 안정될 때까지 기다립니다. 같은 칸을 두 번째부터 다시 할 때는, 그 칸이 아직 선택된 것으로 보이지 않을 때만 아이콘을 다시 누릅니다.
2. 선택한 칸의 패널 레벨을 읽고 해방 버튼과 패널의 잠금 증거를 확인합니다. 잠긴 칸이면 건너뜁니다.
3. 확실하게 읽은 패널 값이 10이면 "최대 레벨", 목표 이상이면 "목표 도달", 직전 강화 전 레벨보다 정확히 1 높지 않으면 "레벨이 오르지 않아 정지"로 끝냅니다. 이때 강화 버튼은 누르지 않습니다. 애매한 패널 값은 사용하지 않습니다.
4. 해방 버튼이 아닌지 누르기 직전에 다시 확인하고 오른쪽 아래 버튼 **자리**를 누릅니다. **0.4초 기다린 뒤** 최대 2초 동안 강화 확인창이 뜨는지 봅니다. 안 뜨면 최대 레벨 버튼이 보일 때 "최대 레벨", 그 외에는 "강화 불가"입니다. 단, 직전 결정으로 목표에 도달했다면 "목표 도달"을 유지합니다. 재료·QP·코인 부족은 따로 구별하지 않습니다. 강화 제목을 확인한 창에서 `Lv.현재 › Lv.다음`을 읽고 패널과 비교합니다. 두 값이 다르면 취소합니다. 확인창의 현재 1~9와 다음 = 현재 + 1이 확인되면 그 값을 씁니다. 한쪽만 확정된 경우에는 다른 쪽을 ±1로 추론하며, 양쪽을 읽지 못해도 패널이 확실하면 패널 현재값과 현재 + 1을 씁니다. 패널이 애매하면 확인창만으로 판단합니다. 선택한 값이 **목표보다 작고**, 첫 강화가 아니면 **직전 강화 전보다 정확히 1 높을 때만** 결정을 누릅니다.
5. **결정 또는 취소 후 처리**:
   - 목표 도달로 **취소를 누르면 0.4초 기다린 뒤** 다음 칸으로 넘어갑니다. 결정 뒤에는 추가 대기를 넣지 않습니다.
   - 결정 뒤 오른쪽 위 제목 자리를 0.5초 간격으로 눌러 연출과 결과 화면을 넘기고, 스킬 강화 화면이 다시 보일 때까지 최대 20초 기다립니다(초과 시 정지).
   - 기다리는 동안 통신 오류 창의 `다시 시도`(JP `やり直す`)가 보이면 최대 3번 누르고 20초를 다시 셉니다. 4번째에도 보이면 누르지 않고 정지합니다.
   - 스킬 모드에서는 이 기다리는 동안 안내 문구는 보이는데 `서번트 재선택` 버튼이 보이지 않는 상태가 0.5초 간격으로 두 번 연속 확인되면, 세 스킬이 모두 10이 되어 게임이 서번트 선택을 해제한 것으로 보고 아래 이유로 정지합니다. 어펜드 모드는 그대로입니다.

기간 한정 합류 서번트는 강화 확인창 앞에 안내창이 한 번 더 뜹니다. 이 안내창의 오른쪽 버튼(`실행` / `実行する`)이 보이면 그 버튼을 눌러 통과하고(버튼이 보일 때마다, 기존 FGA의 서번트 강화와 같습니다), 이어서 뜨는 강화 확인창에서 위와 같은 레벨 확인을 그대로 적용합니다. 실행 버튼이 보이지 않는 다른 창이 뜨면 결정 없이 취소합니다. 일본(JP)·한국(KR) 서버에서 확인했으며, 인식은 기간 한정 서번트 강화(서번트 레벨업)와 같은 `실행` 버튼 이미지를 씁니다.

보호 규칙입니다.

- **해방(`해방` / `解放する`) 버튼은 어떤 경우에도 누르지 않습니다.** 어펜드 칸은 자물쇠 그림, 패널의 잠금 증거, 버튼 글자로 확인합니다. 버튼 글자는 누르기 직전에도 다시 검사합니다. 확인창에서 0이 읽히면 패널 값이 있어도 취소합니다.
- **목표 레벨을 넘지 않습니다.** 결정은 현재 레벨이 목표보다 작을 때만 누릅니다.
- 패널과 확인창을 모두 읽지 못하거나, 두 확정값이 다르거나, 선택한 현재값이 직전보다 정확히 1 높지 않으면 결정하지 않고 그 칸을 멈춥니다. 열린 확인창은 취소합니다.
- 모르는 확인창(강화 제목이 아닌 창)이 뜨면 취소합니다.
- 성정석·사과·상점은 쓰지 않습니다. 재료나 QP를 구해 주지 않습니다.

## 종료 메시지

종료할 때 칸마다 `시작 Lv → 끝 Lv (목표) 이유`를 보여 줍니다.

| 이유 | 뜻 |
|---|---|
| 목표 도달 | 목표 레벨까지 올렸거나 이미 목표 이상이었습니다. |
| 최대 레벨 | 10레벨이라 더 올릴 수 없습니다. |
| 강화 불가 | 확인창이 뜨지 않았습니다. 재료·QP·코인 부족 등은 따로 구별하지 않으므로 화면을 확인하세요. |
| 잠김, 건너뜀 | 잠긴 어펜드 칸입니다. 해방하지 않았습니다. |
| 레벨 확인 실패, 강화하지 않음 | 패널과 확인창에서 사용할 레벨을 얻지 못했거나 확인창에서 0을 읽었습니다. |
| 패널과 확인창 레벨 불일치, 취소함 | 두 판독값이 달라 취소했습니다. 자동 재시도하지 말고 실제 레벨을 확인한 뒤 아래 진단 자료를 보내 주세요. |
| 레벨이 오르지 않아 정지 | 결정을 눌렀는데 레벨이 오르지 않았습니다. 게임 화면을 확인하세요. |
| 예상 밖의 확인창, 취소함 | 강화 확인창이 아니어서 취소했습니다. |
| 게임이 강화 화면으로 돌아오지 않았습니다 | 연출 뒤 20초 안에 화면이 돌아오지 않았습니다. 강화가 이미 일어났을 수 있으니 확인하세요. |
| 통신 오류가 계속되어 정지 | 결정 뒤 통신 오류 창의 `다시 시도`가 4번 보여 정지했습니다. 강화가 이미 일어났을 수 있으니 화면을 확인하세요. |
| 모든 스킬이 10레벨에 도달하여 선택이 해제되었습니다 | 마지막 강화로 세 스킬이 모두 10이 되어 게임이 서번트 선택을 해제했습니다. 강화는 완료됐습니다. |
| 끔 | 목표를 0으로 둔 칸입니다. |

전체 메시지는 `완료했습니다.`, `서번트가 선택되지 않았습니다…`, `스킬 강화 / 어펜드 스킬 강화 화면이 아니어서 정지했습니다.`, `모든 칸이 꺼져 있어 할 일이 없습니다.`, `사용자가 정지했습니다.` 중 하나로 시작합니다.

## 진단 로그

태그는 `SkillLevel`입니다. 베타에서도 INFO 로그를 기록합니다. 칸 선택, 패널 판독, 강화 탭, 확인창 유무, 현재·다음 레벨, 결정·취소, 스킵 복귀를 단계별로 남깁니다. 정지 안내와 칸별 요약에도 **칸 선택 / 강화 버튼 / 확인창 / 레벨 OCR / 결정·취소 / 스킵·복귀** 단계를 표시합니다.

화면 판별이 실패해 `WrongScreen` / `NoServantSelected`로 멈추거나, 자동 판별이 KR·JP에서 실행될 때는 안내 문구 점수를 한 줄로 남깁니다. 보고할 때 이 줄을 함께 보내 주세요(`<0.30`은 점수가 0.30 미만이라는 뜻입니다).

```text
scores label-append=1.000 label-skill=0.680 reselect=1.000 detected=Append
```

```text
adb -s 127.0.0.1:5555 logcat -s SkillLevel
slot=1 step=ocr current=3 next=4
slot=1 step=ocr panel=3 dialog=3 source=both score=0.9 margin=0.2
slot=1 step=confirm action=confirm
slot=1 step=skip return=true
stop slot=1 step=ocr reason=Reached
summary slot=1 step=ocr target=4 start=3 end=4 reason=Reached
```

오류나 수동 정지 때도 진행 중인 칸의 요약을 보존합니다. `slot`은 1부터이며, 시작 전 검사의 `slot=0`은 아직 칸을 실행하지 않았다는 뜻입니다. 오류가 나면 위 명령으로 로그를 수집하고 게임에서 실제 강화 결과를 확인하세요.

매 회차 `panel=<레벨|abstain:원인|locked> dialog=<레벨|unread> source=<dialog|panel|both>`를 기록하며 어펜드는 패널 `score`와 `margin`도 남깁니다. `abstain`은 패널 판독을 사용하지 않았다는 뜻입니다. 확인창을 열기 전 정지한 회차의 `dialog=unread source=panel`은 확인창을 읽지 않았다는 뜻입니다. 두 값 모두 읽지 못한 회차에도 `source=panel`을 기록하지만 강화는 하지 않습니다.

**불일치가 나오면** 앱 버전, KR/JP 서버, 스킬/어펜드 모드, 칸 번호, 목표·실제 레벨, 화면 해상도, 선택된 칸이 보이는 강화 화면과 가능하면 확인창의 원본 스크린샷, 해당 실행의 `SkillLevel` 로그 전체와 종료 요약을 보내 주세요. 확인창을 재현하려고 강화 결정을 누를 필요는 없습니다.

## 알려진 한계

- 확인창의 반투명 배경 등으로 현재·다음 레벨을 읽지 못할 때는 선택된 칸의 확실한 패널 레벨(1–9)로 보완합니다. 두 값이 모두 확정되면 반드시 같아야 하며, 다르면 강화하지 않고 취소합니다. 숫자 9는 OCR이 읽지 못하면 화면 모양을 보조로 확인하며, 애매하면 인정하지 않습니다.
