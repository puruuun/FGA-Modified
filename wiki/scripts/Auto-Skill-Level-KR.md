# 스킬·어펜드 스킬 자동 강화

**서번트를 선택한 스킬 강화 / 어펜드 스킬 강화 화면에서, 칸마다 정한 목표 레벨까지 강화를 반복합니다. 강화는 QP와 재료를 쓰는 되돌릴 수 없는 동작입니다. 처음에는 한 칸, 목표 = 현재 레벨 + 1로 확인하세요.**

KR·JP 서버에서만 동작합니다.

## 시작하는 방법

1. 게임에서 **강화 → 스킬 강화**(또는 **어펜드 스킬 강화**)를 열고 서번트를 **먼저 선택**합니다.
2. FGA 재생 버튼을 누릅니다. 화면 가운데 왼쪽, 재료 목록 위의 안내 문구(`스킬 강화에 필요한 아이템` / `어펜드 스킬 강화/해방 시 필요 아이템`, JP는 `スキル強化に必要なアイテム` / `アペンドスキルの強化/解放に必要なアイテム`)를 보고 스킬 강화인지 어펜드 스킬 강화인지 자동으로 고릅니다. 오른쪽 위 제목 배너는 더 이상 쓰지 않습니다.
3. 설정 창에서 칸마다 **목표 레벨**을 정하고 확인을 누릅니다.

서번트를 선택하지 않은 화면(왼쪽 위에 `서번트 재선택` / `サーヴァント再選択` 버튼이 없는 화면)에서는 설정 창 없이 "서번트를 먼저 선택하세요" 안내만 띄우고 끝냅니다.

## 설정

| 항목 | 기본값 | 동작 |
|---|---|---|
| 스킬 강화 1~3번 칸 | **끔(0)** | 목표 레벨 1~10. 현재 레벨이 목표 이상이면 건드리지 않습니다. |
| 어펜드 스킬 강화 1~5번 칸 | **끔(0)** | 같습니다. 잠긴 칸은 목표를 정해도 건너뜁니다. |

모든 칸이 꺼져 있으면 확인 버튼이 눌리지 않습니다. 설정 창은 열 때마다 **모든 칸이 끔(0)** 으로 시작하며, 정한 값은 저장하지 않습니다. 실행할 때마다 목표를 직접 정해야 합니다.

## 동작과 보호 규칙

### 베타 전용: 레벨 판독만 확인 (1.6.8-beta.2)

강화 재료를 쓰지 않고 패널·확인창 판독을 비교하려면, 서번트를 선택한 스킬/어펜드 강화 화면에서 FGA 재생 버튼을 누르고 **레벨 판독만 확인 (강화하지 않음)** 을 체크하세요. 목표 레벨은 무시하고 왼쪽부터 모든 칸을 한 번씩 확인합니다. 매번 기본값은 체크 해제이며 저장하지 않습니다. Stable에는 이 옵션이 없습니다.

잠긴 칸은 해방하지 않습니다. 자물쇠가 보이는 칸은 선택도 하지 않고, 선택 뒤 해방 안내/버튼이 보이면 더 누르지 않습니다. 강화 가능한 칸은 확인창을 열어 읽은 뒤 **항상 취소**합니다. 예상 밖의 창도 취소하며, 취소 실패 시 전체 실행을 중지합니다. 강화 결정은 코드에서 차단됩니다. 최대 레벨·재료 부족·무응답이면 패널 판독과 이유만 남깁니다.

종료창과 `SkillLevel` 로그에 칸마다 다음과 같은 한 줄을 남깁니다. `slot`은 1부터이며 어펜드의 `score`/`margin`도 함께 표시합니다.

```text
slot=1 panel=3 dialog=unread verdict=panel-only reason=cancelled score=0.9 margin=0.2
```

| verdict | 뜻 |
|---|---|
| `match` / `mismatch` | 두 판독값이 일치 / 불일치 |
| `panel-only` / `dialog-only` | 패널만 / 확인창만 읽음 |
| `both-unread` | 둘 다 읽지 못함 |
| `no-dialog` | 확인창 없음 (`reason=max`, `shortage`, `band-other`, `no-response`) |
| `locked` | 잠김 |

`panel=abstain:원인`은 패널 판독 기권, `dialog=unread`는 열린 창의 유효한 레벨을 읽지 못함, `dialog=-`는 창을 열지 못했거나 열지 않음을 뜻합니다. `reason=unexpected-dialog`는 강화 확인창이 아니어서 취소한 경우이고, `cancel-failed`는 취소 실패로 멈춘 경우입니다.

**`mismatch`나 `both-unread`이면** 앱 버전, KR/JP 서버, 스킬/어펜드, 칸 번호·실제 레벨·해상도, 선택된 칸이 보이는 강화 화면과 가능하면 확인창의 원본 스크린샷, 해당 실행의 전체 `SkillLevel` 로그와 종료 요약을 보내 주세요. 재현을 위해 강화 결정을 누르지 마세요. 실제 게임에서의 체크 모드 실행 확인은 소유자가 진행합니다.

1.6.8-beta.3부터 노란색·금색 어펜드 아이콘의 패널 숫자 판독을 보완했습니다. 두 색상 판독이 충돌하거나 점수·마진이 부족하면 계속 기권합니다.

### 일반 강화

칸마다 다음을 반복합니다.

1. 칸 아이콘을 눌러 선택합니다.
2. 위쪽 안내 줄을 읽습니다. "강화" 안내면 계속하고, "해방" 안내나 빨간 글씨(재료·QP·코인 부족)면 그 칸을 건너뜁니다.
3. 선택한 칸의 패널 레벨을 읽습니다. 확실하게 읽은 값이 10이면 "최대 레벨", 목표 이상이면 "목표 도달", 직전 강화 전 레벨보다 정확히 1 높지 않으면 "레벨이 오르지 않아 정지"로 끝냅니다. 이때 강화 버튼은 누르지 않습니다. 애매한 패널 값은 사용하지 않습니다.
4. 오른쪽 아래 버튼 **자리**를 누르고 **0.4초 기다린 뒤**, 최대 2초 동안 강화 확인창이 뜨는지 봅니다. 안 뜨면 그 칸은 "강화 불가"(최대 레벨, 재료·QP 부족 등)입니다. 강화 제목을 확인한 창에서 `Lv.현재 › Lv.다음`을 읽고 패널과 비교합니다. 두 값이 다르면 취소합니다. 확인창의 현재 1~9와 다음 = 현재 + 1을 모두 읽으면 그 값을 쓰고, 확인창이 읽히지 않아도 패널이 확실하면 패널 현재값과 현재 + 1을 씁니다. 패널이 애매하면 기존처럼 확인창만으로 판단합니다. 선택한 값이 **목표보다 작고**, 첫 강화가 아니면 **직전 강화 전보다 정확히 1 높을 때만** 결정을 누릅니다.
5. 결정 뒤 추가 대기는 넣지 않습니다. 목표 도달로 **취소를 누르면 0.4초 기다린 뒤** 다음 칸으로 넘어갑니다. 결정 뒤에는, 오른쪽 위 제목 자리를 0.5초 간격으로 눌러 연출과 결과 화면을 넘기고, 스킬 강화 화면이 다시 보일 때까지 최대 20초 기다립니다. 넘으면 정지합니다.

보호 규칙입니다.

- **해방(`해방` / `解放する`) 버튼은 어떤 경우에도 누르지 않습니다.** 어펜드 칸은 자물쇠 그림, 안내 줄, 버튼 글자를 모두 확인하고 하나라도 걸리면 패널을 읽기 전에 건너뜁니다. 확인창에서 0이 읽히면 패널 값이 있어도 취소합니다.
- **목표 레벨을 넘지 않습니다.** 결정은 현재 레벨이 목표보다 작을 때만 누릅니다.
- 패널과 확인창을 모두 읽지 못하거나, 두 확정값이 다르거나, 선택한 현재값이 직전보다 정확히 1 높지 않으면 결정하지 않고 그 칸을 멈춥니다. 열린 확인창은 취소합니다.
- 모르는 확인창(강화 제목이 아닌 창)이 뜨면 취소합니다.
- 성정석·사과·상점은 쓰지 않습니다. 재료나 QP를 구해 주지 않습니다.

## 종료 메시지

종료할 때 칸마다 `시작 Lv → 끝 Lv (목표) 이유`를 보여 줍니다.

| 이유 | 뜻 |
|---|---|
| 목표 도달 | 목표 레벨까지 올렸거나 이미 목표 이상이었습니다. |
| 최대 레벨 | 10레벨이라 더 올릴 수 없습니다. |
| 재료·QP·코인 부족 | 안내 줄이 빨간 글씨였습니다. 재료나 QP를 채운 뒤 다시 시작하세요. |
| 강화 불가 | 확인창이 뜨지 않았고 이유를 알 수 없습니다. 화면을 확인하세요. |
| 잠김, 건너뜀 | 잠긴 어펜드 칸입니다. 해방하지 않았습니다. |
| 레벨 확인 실패, 강화하지 않음 | 패널과 확인창에서 사용할 레벨을 얻지 못했거나 확인창에서 0을 읽었습니다. |
| 패널과 확인창 레벨 불일치, 취소함 | 두 판독값이 달라 취소했습니다. 자동 재시도하지 말고 실제 레벨을 확인한 뒤 아래 진단 자료를 보내 주세요. |
| 레벨이 오르지 않아 정지 | 결정을 눌렀는데 레벨이 오르지 않았습니다. 게임 화면을 확인하세요. |
| 예상 밖의 확인창, 취소함 | 강화 확인창이 아니어서 취소했습니다. |
| 게임이 강화 화면으로 돌아오지 않았습니다 | 연출 뒤 20초 안에 화면이 돌아오지 않았습니다. 강화가 이미 일어났을 수 있으니 확인하세요. |
| 끔 | 목표를 0으로 둔 칸입니다. |

전체 메시지는 `완료했습니다.`, `서번트가 선택되지 않았습니다…`, `스킬 강화 / 어펜드 스킬 강화 화면이 아니어서 정지했습니다.`, `모든 칸이 꺼져 있어 할 일이 없습니다.`, `사용자가 정지했습니다.` 중 하나로 시작합니다.

## 진단 로그

태그는 `SkillLevel`입니다. 베타에서도 INFO 로그를 기록합니다. 칸 선택, 안내 줄 상태, 강화 탭, 확인창 유무, 현재·다음 레벨, 결정·취소, 스킵 복귀를 단계별로 남깁니다. 정지 안내와 칸별 요약에도 **칸 선택 / 강화 버튼 / 확인창 / 레벨 OCR / 결정·취소 / 스킵·복귀** 단계를 표시합니다.

화면 판별이 실패해 `WrongScreen` / `NoServantSelected`로 멈추거나, 자동 판별이 KR·JP에서 실행될 때는 안내 문구 점수를 한 줄로 남깁니다. 보고할 때 이 줄을 함께 보내 주세요(`<0.30`은 점수가 0.30 미만이라는 뜻입니다).

```text
scores label-append=1.000 label-skill=0.680 reselect=1.000 detected=Append
```

```text
adb -s 127.0.0.1:5555 logcat -s SkillLevel
slot=1 step=ocr current=3 next=4
slot=1 step=ocr panel=3 dialog=3 source=both score=0.9 margin=0.2
slot=1 step=confirm action=confirm
slot=1 step=skip return=true
stop slot=1 step=ocr reason=Reached
summary slot=1 step=ocr target=4 start=3 end=4 reason=Reached
```

오류나 수동 정지 때도 진행 중인 칸의 요약을 보존합니다. `slot`은 1부터이며, 시작 전 검사의 `slot=0`은 아직 칸을 실행하지 않았다는 뜻입니다. 오류가 나면 위 명령으로 로그를 수집하고 게임에서 실제 강화 결과를 확인하세요.

매 회차 `panel=<레벨|abstain:원인|locked> dialog=<레벨|unread> source=<dialog|panel|both>`를 기록하며 어펜드는 패널 `score`와 `margin`도 남깁니다. `abstain`은 패널 판독을 사용하지 않았다는 뜻입니다. 확인창을 열기 전 정지한 회차의 `dialog=unread source=panel`은 확인창을 읽지 않았다는 뜻입니다. 두 값 모두 읽지 못한 회차에도 `source=panel`을 기록하지만 강화는 하지 않습니다.

**불일치가 나오면** 앱 버전, KR/JP 서버, 스킬/어펜드 모드, 칸 번호, 목표·실제 레벨, 화면 해상도, 선택된 칸이 보이는 강화 화면과 가능하면 확인창의 원본 스크린샷, 해당 실행의 `SkillLevel` 로그 전체와 종료 요약을 보내 주세요. 확인창을 재현하려고 강화 결정을 누를 필요는 없습니다.

## 알려진 한계

- 확인창 16장(KR·JP)의 현재 1–9, 다음 2–10을 기기 QA로 확인했습니다. 두 자리 10도 포함합니다. 숫자 9는 OCR이 읽지 못하면 화면 모양을 보조로 확인하며, 애매하면 인정하지 않습니다. 1.6.8-beta.1부터 확인창 판독 실패 시 확실한 패널 값(1~9)으로 보완합니다. 확인창의 0과 강화 제목 검사는 그대로 유지합니다.
- 소유자는 beta.2 JP에서 한 칸, 목표 = 현재 + 1로 강화가 된 것을 확인했지만 중간 오류도 있었습니다. 원인은 아직 확정하지 못했습니다. beta.3은 소유자가 JP·KR 스킬 화면에서 실행해 정상 동작을 확인했습니다. 어펜드 강화는 아직 실제 게임에서 실행하지 않았습니다. 1.6.1-beta.2는 2560×1080 KR 어펜드 캡처에서 다섯 칸·네 자물쇠·확인창·결과의 위치를 별도로 확인했습니다. 잠긴 칸은 건너뛰며 해금하지 않습니다. 이번 버전의 기기 QA와 와이드 실제 게임 실행 확인은 대기 중입니다.

### 1.6.2-beta.4

태블릿의 일본 어펜드 스킬 확인창에서 다음 레벨 10의 윗부분이 잘리던 숫자 영역을 넓혔습니다. 9→10을 확인할 수 있으며, 현재 레벨과 다음 레벨이 확정되지 않으면 기존처럼 중지합니다.

### 1.6.2-beta.9 — 태블릿 어펜드 2→3

한국판 태블릿 확인창의 현재 숫자 영역을 숫자 열로 좁혔습니다. Lv. 기호와 뒤쪽 슬롯 그림 때문에 2를 4로 읽던 표를 줄입니다. 현재·다음 레벨의 확정 판독과 **다음 = 현재 + 1** 조건은 그대로이며, 애매하면 확인하지 않고 취소합니다.

### 1.6.2 — KR·JP 어펜드 숫자 판독

한국판 7→8 등에서 배경이 숫자에 합쳐지던 이진화 조건을 어펜드 전용으로 보완했습니다. 현재 숫자 영역은 폭을 늘리지 않고 왼쪽으로 조금 옮겨 윤곽 여백을 확보합니다. KR·JP 와이드의 1→2부터 9→10까지와 BlueStacks 7→8 저장 화면을 확인했습니다. 와이드 자료는 업로드에서 축소된 화면입니다. 일반 스킬은 기존 판독 조건을 유지합니다. 서로 일치하는 복수 판독과 **다음 = 현재 + 1** 조건은 계속 필요하며, 불확실하면 취소합니다.

### 1.6.8-beta.1 — 패널·확인창 교차 검증

반투명한 KR 확인창을 읽지 못할 때 선택된 칸의 패널 레벨로 보완합니다. 두 값이 모두 확정되면 반드시 같아야 하며, 다르면 강화하지 않고 취소합니다. 패널의 판독 기준은 완화하지 않았습니다. 특히 16:9 어펜드 4번 칸은 여전히 판독을 포기할 수 있고, 실제 16:10 캡처 검증은 아직 없습니다. 실제 게임에서의 KR 스킬·어펜드 보완 동작과 JP 회귀 확인은 소유자 확인이 필요합니다.
