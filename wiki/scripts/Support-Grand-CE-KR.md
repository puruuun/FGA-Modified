# 그랜드 서포트 개념예장 조건

전투 설정의 **서포트 → 선호 개념예장**에서 원하는 예장과 **최대 해방**, **일반·보상 슬롯 모두 일치**, **인연 예장 효과**를 설정합니다.

그랜드 서포트는 일반 슬롯과 보상 슬롯의 예장을 확인합니다. 두 슬롯 모두 일치를 켜면 각 슬롯에 선호 예장 중 하나가 있어야 합니다. 최대 해방을 켜면 일치한 예장의 최대 해방 별도 확인합니다. 인연 예장 효과는 **NP 충전**, **기본 효과**, **무시** 중 선택하며, 무시는 효과 아이콘 조건을 적용하지 않습니다.

`1.7.0-beta.1`부터 작은 인연 효과 아이콘의 판정 기준은 0.60이며, 아이콘 확인 영역을 아래로 6px(720p 기준) 늘렸습니다. 기기에서 실제 NP 아이콘은 0.739, 반대 아이콘은 0.20–0.22였고 호스트에서 CE 열 배경은 최고 0.45 이하였습니다. 이 차이를 바탕으로 JP 와이드 화면의 축소 변동 여유를 확보해 NP 충전 효과가 누락되던 문제를 보완합니다. 다른 예장·최대 해방 조건은 기존 기준을 사용합니다.

베타에서는 그랜드 행을 검사할 때 `FGA.SupportCe` 로그에 일반·보상 슬롯의 예장 점수와 영역, 최대 해방 결과, 인연 효과 설정과 NP/기본 효과 점수, 최종 선택 여부가 한 줄로 표시됩니다. 선택되지 않으면 이 로그와 서포트 설정을 함께 확인하세요.
