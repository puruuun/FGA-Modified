# 그랜드 서포트 개념예장 조건

전투 설정의 **서포트 → 선호 개념예장**에서 원하는 예장과 **최대 해방**, **일반·보상 슬롯 모두 일치**, **인연 예장 효과**를 설정합니다.

1.8.0 개발 베타에서는 **선호 서번트·선호 개념예장** 선택창 왼쪽 아래 **이미지 받기**로 [서포트 이미지 검색·저장](Servant-Number-Portraits-KR.md)을 바로 열 수 있습니다. 저장한 폴더는 기존 체크를 유지한 채 추가 체크되며 **확인**을 눌러야 설정에 반영됩니다. **취소**해도 다운로드한 이미지는 남습니다.

그랜드 서포트는 일반 슬롯과 보상 슬롯의 예장을 확인합니다. 두 슬롯 모두 일치를 켜면 각 슬롯에 선호 예장 중 하나가 있어야 합니다. 최대 해방을 켜면 일치한 예장의 최대 해방 별도 확인합니다. 인연 예장 효과는 **NP 충전**, **기본 효과**, **무시** 중 선택하며, 무시는 효과 아이콘 조건을 적용하지 않습니다.

**인연 예장 효과**와 **일반·보상 슬롯 모두 일치**는 선호 서번트의 **그랜드 서번트**를 켰을 때만 화면에 표시되고 적용됩니다. 그랜드 서번트가 꺼져 있으면 두 옵션은 숨겨지며, 이전에 설정해 둔 값이 남아 있어도 무시(효과 조건 없음, 한쪽 슬롯만 일치해도 통과)로 처리합니다. 따라서 그랜드가 아닌 서포트가 남은 NP 설정 때문에 선택되지 않는 일이 없습니다.

인연 효과 아이콘은 원본 FGA와 같은 이미지와 같은 판정 기준(공통 최소 유사도)을 사용합니다.

베타에서는 그랜드 행을 검사할 때 `FGA.SupportCe` 로그에 일반·보상 슬롯의 예장 점수와 영역, 최대 해방 결과, 인연 효과 설정과 NP/기본 효과 점수, 최종 선택 여부가 한 줄로 표시됩니다. 선택되지 않으면 이 로그와 서포트 설정을 함께 확인하세요.
