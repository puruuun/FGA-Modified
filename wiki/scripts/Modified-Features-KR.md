# FGA(mod) 상세 안내

[한국어](Modified-Features-KR.md) | [English](Modified-Features.md)

[README로 돌아가기](../../README.md)

**KR(한국)·JP(일본) 서버에서만 테스트했습니다. 다른 서버의 동작은 확인하지 않았습니다.**

기능별 자세한 설정은 각 기능 페이지에서 확인하세요. 이 페이지는 전체 개요입니다.

## 하쿠노 셔플

NP를 소모하는 1스킬을 카드 조건까지 반복하며 최소·최대 횟수와 미달 시 중단을 설정합니다. 게임의 스킬 사용 확인은 OFF로 두세요. [자세히](Hakuno-Shuffle-KR.md)

## 개념예장 자동 강화

JP·KR에서 게임의 추천 선택 필터를 사용해 자동 세트를 켜고 강화를 반복합니다. [자세히](CE-Auto-Enhance-KR.md)

## 전투 시작 조건

<a id="card-start"></a>

### 일반 카드 개수로 커맨드 시작

**커맨드 카드 개수 선택 모드**를 켜고, 전열 1~3번 중 대상 서번트와 필요한 일반 카드 수(1~5장)를 정합니다. 손패에 설정값 **이상**이 나오면 예약한 커맨드를 처음부터 시작합니다. 스턴 등으로 쓸 수 없는 카드는 세지 않습니다.

조건이 부족하면 스킬·보구를 쓰지 않고 일반 공격으로 턴을 넘긴 뒤 다시 검사합니다. 최대 대기 턴(0은 무제한)도 정할 수 있습니다. 토글을 끄면 기존 방식으로 동작하며 설정은 보존됩니다. [자세히](Card-Count-Start-KR.md)

<a id="dual-conditions"></a>

### 두 서번트 조건

두 번째 대상 서번트와 필요 카드 수를 추가할 수 있습니다. 두 조건은 같은 손패로 확인합니다.

| 첫 번째 조건 | 두 번째 조건 | 실행 |
|---|---|---|
| 충족 | 미달 | 첫 번째 설정 |
| 미달 | 충족 | 두 번째 설정 |
| 충족 | 충족 | 첫 번째 설정 우선 |
| 미달 | 미달 | 일반 공격 후 다음 턴 재검사 |

한 번 고른 설정은 그 전투가 끝날 때까지 유지하고, 다음 주회에서 다시 검사합니다. 두 번째 대상을 **사용 안 함**으로 두면 단일 조건입니다. 같은 서번트를 두 조건에 지정하면 시작하지 않습니다.

<a id="separate-settings"></a>

### 조건별 커맨드·카드 설정

첫 번째·두 번째 설정에 각각 다른 **커맨드, 카드·서번트 우선순위, 브레이브 체인, 카드 재정렬**을 저장합니다. 기본 설정과 첫 번째 설정은 같은 값이며, 복사·내보내기·가져오기에도 두 설정이 함께 들어갑니다.

<a id="command-timing"></a>

### 기다린 만큼 커맨드 위치 이동

실제로 조건을 채운 시점을 커맨드의 1웨이브 1턴으로 봅니다. 예를 들어 실제 2웨이브 3턴에 시작하면 커맨드 1웨이브 2턴은 실제 2웨이브 4턴에 실행합니다. 시작한 뒤에는 카드 조건을 다시 검사하지 않습니다.

<a id="shared-automatic-use"></a>

### 스팸 모드·카드 셔플은 공통

**스킬·보구 자동 사용(스팸 모드)**, **카드 셔플**, 파티·서버·서포트·자동 적 지정은 조건별로 나누지 않고 한 곳에서 관리합니다.

<a id="first-turn-shuffle"></a>

### 첫 턴 조건 부족 시 셔플

**카드 셔플 → 사용 조건 → 첫 턴 커맨드 시작 조건 불만족**을 선택하면, 첫 웨이브 첫 턴에 조건이 부족할 때 마스터 3번 스킬로 셔플을 한 번 하고 다시 검사합니다. 충족하면 같은 턴에 커맨드를 시작하고, 아니면 일반 공격 후 다음 턴으로 넘어갑니다. 셔플은 전투 첫 턴에 한 번만 하며 대기 턴 수에 포함하지 않습니다.

카드 개수 선택 모드에서만 쓰며, 마스터 3번 스킬이 카드 셔플인 마술예장이 필요합니다. 카드 인식이 불명확하면 같은 손패를 최대 세 번 확인한 뒤 공격 없이 멈춥니다.

## 서포트 선택

<a id="auto-friend-request"></a>

### 퀘스트 후 친구 신청

설정에는 제목만 표시합니다.

전투 설정의 **서포트 선택 → 선호 → 친구 → 퀘스트 후 친구 신청**을 켜면, 친구가 아닌 서포트를 쓴 뒤 거절 대신 친구 신청을 보냅니다. 전투 설정별로 저장하며 기본은 꺼짐입니다. **선호(Preferred)** 모드에서만 동작하고, 실패 시 첫 번째·수동 선택으로 고른 서포트에도 적용됩니다. **친구 한정**을 켜면 이 옵션은 꺼지고 비활성화됩니다.

상대 친구 목록이 가득 차 신청 화면이 그대로면, 1초 뒤 새 화면을 확인하고 거절합니다.

<a id="support-append"></a>

### 서포트 어펜드 스킬

**서포트 선택 → 서번트 선호 → 어펜드 스킬 판독**을 켜고 어펜드 1~5번 칸을 `10 / x`로 정합니다. `10`인 칸이 모두 레벨 10인 서포트만 고르며, 잠긴 칸은 10으로 치지 않습니다. [자세히](Support-Append-Skills-KR.md)

<a id="support-score"></a>

### 서포트 스코어 (클래스 +62 / 그랜드 +16)

**서포트 선택 → 서번트 선호**에서 클래스 +62, 그랜드 +16을 각각 켭니다. 켠 조건은 모두 만족해야 통과합니다. [자세히](Support-Score-62-KR.md)

<a id="support-np"></a>

### 서포트 보구 레벨

**서포트 선택 → 서번트 선호 → 보구 레벨 판독**을 켜고 최소 보구 레벨(1~5)을 정합니다. 설정 레벨 이상인 서포트만 고릅니다. [자세히](Support-NP-Level-KR.md)

검사 순서는 서번트 → 일반 조건·스코어·보구 레벨 → 어펜드 → 선택입니다. 앞 조건이 실패하면 어펜드 확인을 위한 화면 전환을 하지 않습니다.

### 재림 구분

서포트 이미지 메이커로 만든 서번트 이름 + 보구 그림으로, 재림이 다른 서번트를 구분해 고릅니다. [자세히](Ascension-Select-KR.md)

## 전투 중

<a id="direct-cards"></a>

### 공격 순서 직접 지정

**커맨드 편집 → 공격 → 보구 전 공격 카드 옆 일반 카드 직접 지정**에서 일반 카드·보구 세 장의 순서를 정합니다. 직접 지정한 턴에는 브레이브 체인 선택·카드 재정렬·추가 보구 자동 사용을 적용하지 않습니다.

필요한 카드가 없으면 클릭 전에 멈춥니다. **카드 부족 시 우선순위로 대체**를 체크하면 부족한 일반 카드 자리만 우선순위로 채웁니다. [자세히](Direct-Cards-KR.md)

<a id="quest-items"></a>

### 티포트·스톰포드 자동 ON/OFF

**더 많은 옵션 → 추가기능 → 티포트·스톰포드 자동 설정 사용**을 켜면, 실행 창의 **스톰포드 사용 / 티포트 사용** 체크에 맞춰 퀘스트 시작 전에 ON/OFF를 맞춥니다. 선택은 서버별로 기억합니다. [자세히](Quest-Items-KR.md)

<a id="bond-tracking"></a>

### 인연포인트 누적·MAX 정지

**스크립트 수정 → 인연포인트**에서 설정합니다. 결과창의 캐릭터 1~5별 획득량을 합산해 종료 화면에 보여 주고, MAX가 된 캐릭터가 있으면 그 퀘스트 결과창에서 멈춥니다. **MAX 정지를 무시할 캐릭터**를 체크할 수 있습니다. [자세히](Bond-Tracking-KR.md)

## 그 밖의 기능

<a id="chaldea-import"></a>

### Chaldea 링크로 커맨드 입력

커맨드 화면의 **링크로 입력**에 Chaldea 공유 주소를 붙여넣고 **변환하여 입력**을 누르면 전투 행동이 커맨드로 바뀝니다. 변환에 성공했을 때만 기존 커맨드를 대체합니다. **에너미 타겟팅 정보 무시**를 체크하면 적 선택 명령을 뺍니다. [자세히](Chaldea-Import-KR.md)

<a id="original-fga-import"></a>

### 원본 FGA 데이터 가져오기

**더 많은 옵션 → 추가기능**에서 원본 FGA의 스크립트, 서포트 이미지, 또는 둘 다 가져옵니다. [자세히](Original-FGA-Import-KR.md)

### FP 소환 자동 판매 · 스킬 자동 강화 · 주간 미션 · 서번트 번호 이미지

[FP 소환 자동 판매](FP-Auto-Sell-KR.md) · [스킬·어펜드 스킬 자동 강화](Auto-Skill-Level-KR.md) · [주간 미션 클리어](Weekly-Mission-Route-KR.md) · [서번트 번호 이미지 생성](Servant-Number-Portraits-KR.md)

### 업데이트 확인

**더 많은 옵션 → 추가기능 → 업데이트 확인**을 켜면 앱을 열 때 최신 정규 릴리스와 설치 버전을 비교합니다. 새 버전이 있으면 **릴리스 열기**로 GitHub 페이지를 엽니다. 사전 릴리스는 제외하며 APK를 자동 설치하지 않습니다.

### 와이드 화면(21:9, 2560×1080)

블루스택 1680×720·2560×1080 같은 가로로 긴 화면에서도 동작하도록 화면 가장자리 버튼 위치를 맞췄습니다. 21:9보다 넓은 화면은 원본 FGA처럼 21:9로 계산합니다. 작은 숫자(`+62/+16` 등)는 해상도가 낮거나 흐리면 읽지 못할 수 있으며, 읽지 못한 서포트는 조건 미달로 보고 건너뜁니다.

### 전투 뒤 닫기 안내

강화 퀘스트의 "개방되었습니다!" 안내처럼 전투 뒤 하단 중앙 **닫기** 버튼이 나오면 닫고 퀘스트 목록으로 돌아가 계속합니다. 스톰포드가 소진되면 소모품 부족 창을 확인하고 종료합니다.

<a id="installation"></a>

## 설치와 업데이트

- **[최신 정규판 APK](https://github.com/puruuun/FGA-Modified/releases/latest)**: Android 7 이상 ARM 기기(arm64-v8a / armeabi-v7a)를 지원합니다.
- **Obtainium**: 소스 URL `https://github.com/puruuun/FGA-Modified`(GitHub)를 추가하거나 [obtainium.json](../../obtainium.json)을 가져옵니다. 사전 릴리스 포함은 끕니다.
- GitHub Releases와 Obtainium 외의 곳에서 받은 APK는 설치하지 마세요.

앱 이름은 FGA(mod), 패키지는 `io.github.fate_grand_automata.cardcount`입니다. 원본 FGA와 별도로 설치되며, 이전 수정판 위에는 업데이트 설치할 수 있습니다. 원본 앱의 설정은 `.fga` 파일로 내보낸 뒤 [수정판에서 가져오세요](Original-FGA-Import-KR.md).

앱의 **더 많은 옵션 → 고급 → 라이선스**에서 MIT 라이선스 전문을 볼 수 있습니다.

### 주간 미션 경로 설정

**더 많은 옵션 → 추가기능 → 주간 미션 경로 활성화**를 끄면 시작 창의 버튼을 숨깁니다(기본 켜짐). 미션은 원래 순서로 표시하며 수동 미션에는 체크박스가 없고, 체크를 끈 미션은 회색으로 남습니다. 빈 경로에서는 실행하지 않습니다. 보물창고는 마지막에 메인 → 게이트 → 요일 목록 순서로 방문하며 좌측 버튼과 목록 내용으로 확인합니다.
