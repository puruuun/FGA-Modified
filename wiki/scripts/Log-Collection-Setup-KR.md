# 로그 수집 시작 설정

로그 수집을 처음 켜고 KR 또는 JP 서버의 첫 데이터를 받기까지의 설정 순서입니다. 기능의 상세 동작, 계정 대시보드, Chaldea 내보내기, 데이터 삭제는 [로그 수집](Gains-Tracker-KR.md)을 참고하세요.

!!! note "지원 조건과 보안"
    - **Android 10 이상**에서 공식 KR 앱(`com.netmarble.fgok`)과 루트 기기의 공식 JP 앱(`com.aniplex.fategrandorder`)을 지원합니다. BetterFGO·듀얼 앱·복제 앱은 지원하지 않습니다.
    - 모든 통신은 기기 내부의 읽기 전용 프록시에서만 처리되며, 계정 정보나 로그인 토큰은 저장하거나 외부로 전송하지 않습니다.
    - 인증서 파일을 저장할 수 있도록 먼저 **더 많은 옵션 → 저장소**에서 FGA 폴더를 지정해 두는 것을 권장합니다([설치 안내](Installation-KR.md)).

## 1. 로그 수집 켜기 및 안내 동의

1. **더 많은 옵션 → 추가기능 → 로그 수집**을 엽니다.
2. **로그 수집 사용** 스위치를 켭니다.
3. **로그 수집 사용 전 안내**를 읽고 **동의하고 사용**을 누릅니다(**취소**하면 꺼진 상태로 남습니다).

## 2. 서버별 인증서 준비

수집할 서버에 따라 인증서를 준비합니다. 두 서버를 모두 준비하면 한 번의 수집 시작으로 함께 기록합니다.

### KR 서버 (루트 불필요)

1. **KR 서버 → 인증서 만들기**를 누릅니다.
   - 선택한 FGA 폴더의 `capture/fga-capture-ca.crt`에 저장됩니다(폴더를 쓸 수 없으면 시스템 저장 창이 열립니다).
2. **설치 방법 → 보안 설정 열기**를 눌러 기기 설정으로 이동합니다(메뉴를 찾기 어려우면 설정 검색창에서 **CA 인증서**를 검색하세요).
3. **보안 → 암호화 및 사용자 인증 정보 → 인증서 설치 → CA 인증서**에서 `fga-capture-ca.crt`를 선택해 설치합니다.
4. FGA로 돌아와 상태가 **KR 인증서: CA 인증서로 설치됨**으로 바뀌었는지 확인합니다.

!!! warning "CA 인증서로 설치하세요"
    Wi-Fi 인증서 등으로 잘못 설치하면 게임이 인증서를 거부하여 수집되지 않습니다.

### JP 서버 (루트 기기 전용)

Android 10 이상에서 공식 JP 앱이 설치되어 있으면 **JP 서버 (루트)** 구역이 표시됩니다.

1. **루트 권한으로 JP 인증서를 자동 설치합니다** 스위치를 켜고 루트 권한 팝업을 허용합니다.
2. 상태가 **JP 인증서: 설치됨**으로 바뀌는지 확인합니다.
3. 이미 JP 게임이 켜져 있었다면 게임을 완전히 종료한 뒤 다시 실행하세요.

!!! note "재부팅 후 JP 인증서"
    기기를 재부팅하면 시스템 CA 마운트가 해제되지만, 다음에 로그 수집을 시작할 때 FGA가 자동으로 다시 설치합니다.

## 3. 연결 방식 선택

**수집 연결 → 연결 방식**에서 사용 환경에 맞는 방식 하나를 선택합니다.

| 연결 방식 | 추천 환경 | 준비할 사항 |
|---|---|---|
| **FGA VPN** (기본) | 다른 VPN·광고 차단 앱을 쓰지 않을 때 | 별도 앱·루트 불필요. 처음 시작할 때 Android VPN 연결 요청만 허용합니다. 다른 VPN과 동시에 켤 수 없습니다. |
| **외부 앱 프록시** | AdGuard 등 로컬 VPN 앱을 함께 쓸 때 | 배터리 최적화 제외, 외부 앱에 `127.0.0.1:포트`(기본 `8899`) 등록, 외부 앱에서 FGA 제외 및 FGO HTTPS 필터링 해제가 필요합니다. 자세한 절차: [외부 앱 프록시 모드](Capture-AdGuard-KR.md) |
| **루트** | 루트 기기에서 WireGuard 등 개인 VPN과 함께 쓸 때 | 루트 권한 허용과 커널 지원(`nat REDIRECT`, `iptables owner`)이 필요합니다. 자세한 절차: [루트 수집 모드](Capture-Root-KR.md) |

## 4. 수집 시작 및 첫 확인

네 가지 방법 중 하나로 수집을 시작할 수 있습니다.

- **로그 수집 화면**: **수집 연결**에서 **시작**(FGA VPN) 또는 **수집 켜기**(외부 앱 프록시·루트)
- **메인 화면**: 오른쪽 아래 파란색 **로그 수집 시작** 버튼(실행 중이면 노란색 **로그 수집 중지**로 바뀜)
- **FGA 서비스와 함께 시작**: 준비가 끝난 상태에서 메인 화면의 **서비스 시작**을 누르면 서비스와 함께 시작됩니다.
- **홈 화면 위젯**: 위젯의 로그 수집 버튼([홈 화면 위젯](Widgets-KR.md))

수집을 켠 상태에서 **FGO를 새로 실행**합니다(이미 실행 중이었다면 한 번 종료 후 다시 시작; 루트 모드는 타이틀 화면 재접속 등 새 연결부터 기록). 로그인 응답을 받으면 메인 화면 상단에 마스터 이름과 AP가 표시된 **프로필 카드**가 나타납니다.

## 자주 막히는 점

- **게임이 인증서를 거부했다는 경고가 뜰 때**: KR은 **CA 인증서**로 설치했는지(Wi-Fi 인증서 아님), 외부 앱 프록시는 외부 앱에서 **FGO의 HTTPS 복호화(필터링)를 껐는지** 확인하세요.
- **와이파이에서는 되는데 모바일 데이터(LTE/5G)에서 게임이 접속되지 않을 때**: 수집 중에는 FGO 통신이 FGA를 거치므로, 휴대폰 설정에서 **FGA의 모바일 데이터 사용**이 허용되어 있는지 확인하세요.
- **스크립트·로그 활용**: 수집된 내용은 메인 화면 **프로필 카드(계정 대시보드)**, **[전투 로그](Battle-Log-KR.md)**, **[프렌드 관리](Friend-Manager-KR.md)**, **[Chaldea 자동 반영](Chaldea-Sync-KR.md)**에서 활용할 수 있습니다.
