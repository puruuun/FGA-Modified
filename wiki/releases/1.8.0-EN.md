# 1.8.0 — Log Collection, Account Dashboard, Chaldea Auto Sync & Home Screen Widgets

This is stable release **1.8.0 / 3101**. It updates over 1.7.5 without uninstalling. Includes all changes from `1.8.0-beta.1~48`.

## New Features

- **Log collection** (Android 10+, KR and official JP)
  - Reads the game server's responses on the device and records each script run's gains (items, QP, Master EXP, bond per Servant, fruit and other items used) as the server reports them.
  - Also records changes made outside scripts (present box, shop, summons, enhancement, missions, etc.) by source.
  - KR battle scripts take bond numbers from the responses while log collection runs. Material counts and the bond MAX stop keep using screen reading.
  - Choose one of three connection modes: **FGA VPN** (default), an **external proxy app** such as AdGuard (with AdGuard proxy auto-switch), or **root** (works alongside another VPN).
  - KR uses the FGA certificate installed as a CA certificate. For JP, FGA installs its certificate automatically with root.
  - Off by default; turning it on the first time asks you to agree to the notice. Collected data never leaves the device. [Guide](../scripts/Gains-Tracker-EN.md) · [External proxy app](../scripts/Capture-AdGuard-EN.md) · [Root](../scripts/Capture-Root-EN.md)
- **Account dashboard and main-screen account cards**
  - The top of the main screen shows each account's AP and when it will be full; tapping a card opens a read-only dashboard.
  - Shows the profile, currencies and AP, storage, the Servant collection, items, Mystic Codes, recent activity, class scores, summon history, and your support and Grand formations. [Guide](../scripts/Modified-Features-EN.md)
- **Friend manager**: Collects the Servants and CEs in your friends' normal, event and Grand formations from the friend list received by log collection, with filters for name, Servant, CE, level and days since last login. [Guide](../scripts/Friend-Manager-EN.md)
- **Chaldea auto sync**: Writes the account data from log collection straight into Chaldea's `userdata.json` through Shizuku or root. Off by default. [Guide](../scripts/Chaldea-Sync-EN.md)
- **Chaldea file export**: Saves the account data as a file Chaldea can import. [Guide](../scripts/Gains-Tracker-EN.md)
- **Home screen widgets**: A 1x1 widget that starts and stops the FGA service, and an account info widget that shows the AP of collected accounts. Log collection can also be turned on and off from the widgets. [Guide](../scripts/Widgets-EN.md)
- **Aoko card change detection**: When turned on in a battle config, command cards with the swap icon are treated as Arts. Off by default. [Guide](../scripts/Card-Priority-EN.md)
- **Third target in Servant condition mode**: While the second condition is in use, you can add a third target with its own command and card priority. [Guide](../scripts/Card-Count-Start-EN.md)
- **Clear mission popups before Repeat**: Taps the popup area for a set time before pressing Repeat, so piled-up mission popups do not cover the wave and turn display. Off by default. [Guide](../scripts/Mission-Popup-Clear-EN.md)
- **Dark mode setting**: Choose Follow system, Light or Dark under More options → Advanced.
- **Download images from the Preferred Servant / CE picker**: **Download images** in the picker opens support image search and save directly and checks the saved folders. [Guide](../scripts/Servant-Number-Portraits-EN.md)
- **Support class from the preferred Servant**: Picking exactly one preferred Servant selects that Servant's class tab as the support class. [Guide](../scripts/Servant-Number-Portraits-EN.md)
- **Extract default support images** and **Download log icon data** are now separate items in the Storage tab. [Guide](../scripts/Default-Support-Images-EN.md)
- Added an **installation guide** and **English and Japanese manuals**.

## Changed Features

- **Command spells**: Taps the fixed command spell button position for 16:9 and wide screens instead of searching for the `영주/令呪` label. [Guide](../scripts/Command-Spell-Tap-EN.md)
- **JP support scores**: Reads `+62/+16` on dimmed rows, when OCR reads `+` as `4`, and when only part is read. [Guide](../scripts/Support-Score-62-EN.md)
- **Original FGA v3071 sync**: The bond CE icon of Grand supports is judged at a 0.60 threshold. [Guide](../scripts/Support-Grand-CE-EN.md)
- **Skill / Append Skill auto-upgrade**: Presses `Retry` on a connection error dialog after Decide, and stops if it appears four times. [Guide](../scripts/Auto-Skill-Level-EN.md)
- **Screen capture consent again**: After the screen was turned off, pressing play asks for screen capture consent again, without restarting the service.
- **Drop screen material counting** works without log collection, as before.
- **Battle config folders**: Each folder is shown as one box, in two columns on wide screens; the launcher list uses the same boxes. [Guide](../scripts/Battle-Config-Folders-EN.md)
- **Battle log**: Added filters for date, profile, source and resources gained, a retention setting (50/100/200), and a key icon on runs recorded with log collection. [Guide](../scripts/Battle-Log-EN.md)
- **Support image search**: Lists refresh with the Atlas data version, so new Servants and CEs can be searched right away. The Korean names for Servants not yet on KR and the nickname dictionary were extended. [Guide](../scripts/Servant-Number-Portraits-EN.md)
- **Import original FGA data**: When the same script appears several times, only the missing copies are imported. [Guide](../scripts/Original-FGA-Import-EN.md)
- **More options rearranged**: Battle switches moved to the **Battle** tab, update check and weekly quest tracking to the **Advanced** tab, and a battery optimization shortcut was added.
- The launcher shows the Storm Pod and Teapot checkboxes side by side.

## Known Limitations

- Log collection needs Android 10 or later, and JP needs a rooted device. A game update may break it; turning log collection off restores the previous behaviour.
- In external proxy app mode, FGO cannot connect while FGA is closed. Start FGA again or turn off the proxy setting in the proxy app (with AdGuard proxy auto-switch, this applies only while collecting).
- Root mode needs a kernel with the per-app network rule (iptables owner). Devices without it get a notice when collection starts.
- Running several game instances at once (dual apps, clone apps) and BetterFGO are not supported by log collection.
- **Split-screen touch:** While FGA runs in split screen, touches in the other app may be interrupted ([#119](https://github.com/puruuun/FGA-Modified/issues/119), [#120](https://github.com/puruuun/FGA-Modified/issues/120)).
