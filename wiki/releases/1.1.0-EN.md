# FGA(mod) 1.1.0

This is a stable release incorporating beta development results and reading improvements since the previous stable release 1.0.1.

## Changes

- **Generate support images by Servant number**: Under **More options → Additional features**, entering a collection number looks up public ascension/costume portraits and saves them as FGA recognition images. Folders display `No.<number> <Servant name>`, and previous numbered folders and preferred Servant selections are preserved.
- **Support score reading improvements**: Improved recognition of small Grand score digits on JP. When both Class +62 and Grand +16 are required, both values must be displayed to pass. When only Class +62 is required, both standalone `+62` and compound `+62/+16` displays are accepted.
- **Bond point reading improvements**: Separated base gains from bonuses in parentheses and re-read narrow digits to reduce missed reads. Distinguishes `MAX` and `NEXT` numbers from gained points.
- **KR Teapot / Storm Pod dialog fix**: Added real BlueStacks dialog title samples. Quest start proceeds only after confirming both item states and closing the dialog.
- **Direct start from party confirmation**: On both KR and JP servers, pressing FGA Play goes through party selection and item settings before starting the quest. Close any manually opened item settings dialog before pressing Play.
- **Simplified stop guidance**: Removed the game-screen and additional-options hints that appeared after Teapot/Storm Pod errors.

## Installation & Updates

- Version: **1.1.0 / 3082**
- APK: **FGA-mod-1.1.0-arm.apk**
- App name: **FGA(mod)**
- App ID: `io.github.fate_grand_automata.cardcount`
- Supports Android 7+, ARM 32/64-bit

Installs as an update over the existing stable release with the same package ID and signing key. Can be updated via the Obtainium stable configuration. `FGA(beta)` is a separate app, and its storage folder and settings are not transferred automatically.
