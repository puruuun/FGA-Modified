# 1.7.0 — 하쿠노 셔플, 개념예장 자동 강화, 카드 우선순위 확장, 게임 영역 자동 맞춤

정규판 **1.7.0 / 3095**입니다. 기존 수정판 패키지와 서명을 유지하며, 1.6.7 위에 업데이트 설치할 수 있습니다. 1.6.8 베타(스킬 레벨 판독)와 1.7.0-beta.1~13의 변경을 모두 포함합니다.

## 새 기능

- **하쿠노 셔플**
  - 서번트 1스킬(NP 소모)을 카드 조건이 맞을 때까지 반복합니다.
  - 최소·최대 횟수, 색별 장수 조건(OR), 조건 미달 시 중단을 설정합니다.
  - 커맨드는 `aH{…}` 형식입니다. [설명](../scripts/Hakuno-Shuffle-KR.md)
- **개념예장 자동 강화** (JP·KR)
  - 게임의 추천 선택 필터로 자동 세트를 켜고 강화를 반복합니다.
  - 시작 창에서 서번트 모드로 바꿀 수 있습니다. [설명](../scripts/CE-Auto-Enhance-KR.md)
- **카드 우선순위 확장**
  - 항목을 최대 10개까지 둘 수 있고, 구분 기준을 웨이브 또는 턴으로 고릅니다.
  - 서번트 순서대로 카드를 고르는 **서번트 방식**을 추가했습니다. [설명](../scripts/Card-Priority-KR.md)
- **게임 영역 설정** (더 보기 → 추가기능 → 게임 영역)
  - 사용자 지정 좌표를 바꾸면서 실제 인식 영역을 화면 위에 미리 볼 수 있습니다.
  - 좌표를 프리셋으로 저장할 수 있습니다.
  - **스크린샷으로 자동 맞춤**: 메인 화면에서 누르면 분할 화면의 게임 영역을 자동으로 찾아 프리셋으로 저장합니다(JP·KR). [설명](../scripts/Game-Area-Preview-KR.md)
- **추가 기능 미세 조정** (고급 탭)
  - 수정판 기능의 대기 시간 배율과 이미지 유사도 보정을 구역별로 조정합니다.
  - 기본값이면 이전과 똑같이 동작합니다. [설명](../scripts/Added-Features-Fine-Tune-KR.md)
- **퀘스트 후 친구 신청**
  - 선호 서포트 모드에서, 친구가 아닌 서포트를 쓴 뒤 거절 대신 친구 신청을 보냅니다. [설명](../scripts/Modified-Features-KR.md#auto-friend-request)
- **그랜드 서포트 개념예장 조건**
  - 일반·보상 슬롯 예장, 최대 해방, 인연 예장 효과(NP 충전·기본 효과·무시)를 확인합니다. [설명](../scripts/Support-Grand-CE-KR.md)

## 바뀐 기능

- **주간 미션 클리어**
  - 경로를 계산하기 전에 돌 미션을 직접 고를 수 있습니다.
  - 보물창고 초급을 경로 후보에 넣었습니다.
  - 지도 위치 찾기를 지도 그림 비교에서 **지도 가장자리 기준 이동 측정**으로 바꿨습니다. JP·KR 메인 스토리 지점을 블루스택 21:9와 태블릿에서 모두 통과했습니다.
  - 목록 위·아래 끝에서 스크롤을 멈춥니다. [설명](../scripts/Weekly-Mission-Route-KR.md)
- **FP 소환 자동 판매**
  - 판매 후에는 배너 제목 비교 대신, 사용자가 정한 **배너 위치(뒤에서 1~7번째)**로 돌아갑니다.
  - 도착한 배너에 FP 표시와 소환 버튼이 없으면 소환하지 않고 멈춥니다.
  - 판매 목록 끝에서 스크롤을 멈춥니다. [설명](../scripts/FP-Auto-Sell-KR.md)
- **카드 조건으로 커맨드 시작**
  - 조건을 색별 줄로 추가하고, 줄끼리 AND/OR를 고를 수 있습니다. [설명](../scripts/Card-Count-Start-KR.md)
- **스킬·어펜드 스킬 자동 강화**
  - 보유 스킬 패널의 레벨을 직접 읽고, 확인창 레벨과 교차 확인합니다. 둘이 다르면 강화하지 않고 취소합니다.
  - 어펜드 칸은 칸별 숫자 샘플로 읽고, 9→10 확인창처럼 한쪽만 읽히는 경우는 다른 쪽에서 보완합니다. [설명](../scripts/Auto-Skill-Level-KR.md)
- **인연포인트 MAX 정지**: 결과 화면에 칸 표시가 없어도 인연 레벨이 10 이상으로 오르면 멈춥니다.
- **공격 순서 직접 지정**: 같은 색 카드가 여럿이면 상성상 약점 카드를 먼저 고릅니다.
- **서포트**: U-올가마리 영의(코스튬) 서포트 이미지를 추가했습니다.
- **와이드 화면**: 주간 목록과 FP 판매 목록의 끝 판정이 16:9~21:9 사이 모든 비율(예: 2340×1080)에서 맞도록 고쳤습니다.
- **자동 감지**: FP 소환은 배너 화면의 FP 표시가 있을 때만 고릅니다. 소환 결과 화면에서 재생해도 FP가 시작되지 않습니다.
- 처음 실행할 때 기기 언어에 맞는 앱 언어를 고릅니다. 선호 서포트 두 설정은 설명 없이 제목만 표시합니다.
