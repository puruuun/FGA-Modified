# 1.7.1 — 오토 스킬 폴더, 턴 제한 퇴각, 적 배치별 타겟, 서명 키 교체

정규판 **1.7.1 / 3096**입니다. 1.7.0 위에 지우지 않고 업데이트 설치할 수 있습니다. 1.7.1-beta.1~15의 변경을 모두 포함합니다.

## 서명 키 교체 (꼭 읽어 주세요)

- 이번 버전부터 APK를 **개인 서명 키**로 서명합니다. 지금까지는 저장소에 공개된 디버그 키를 썼습니다.
- APK 서명 v3의 키 교체 방식을 써서, 1.7.0 위에 **앱을 지우지 않고 그대로 업데이트**됩니다. 설정도 유지됩니다.
- 새 인증서 SHA-256: `563754b164de0d4209191f728ebb26644d53b0fbc0a47d5c8eb6a327b5dbe8f8`
- **Android 9 이상**에서는 업데이트한 뒤로 이 키로 서명한 APK만 설치됩니다. 공개 키로 누군가 만든 APK는 덮어쓸 수 없습니다.
- **Android 7~8**은 새 키를 읽지 못해 이 보호를 받지 못합니다. 설치와 업데이트는 그대로 됩니다.
- APK는 GitHub Releases와 Obtainium에서만 받으세요.

## 새 기능

- **오토 스킬 폴더**
  - 배틀 설정을 폴더로 묶어 목록과 런처에서 접고 펼 수 있습니다.
  - 선택 모드의 「폴더로 이동」으로 옮기고, 내보내기·불러오기에 폴더가 함께 저장됩니다. [설명](../scripts/Battle-Config-Folders-KR.md)
- **턴 제한 퇴각**
  - "퇴각 후 재시작" 하나로 전멸 퇴각과 N턴 도달 퇴각을 함께 설정합니다. 전역 "퇴각 활성화"는 없앴습니다.
  - N회 연속 퇴각하면 멈추게 할 수 있습니다(1~99회).
  - 종료 화면에 "퇴각 N회 (전멸 a회, 턴 제한 b회)"가 나옵니다. [설명](../scripts/Turn-Limit-Retreat-KR.md)
- **적 배치별 타겟**
  - 6타겟 배치(`t4`~`t9`)와 레이드 배치(`tR`, 아래 1줄 `tA`~`tC`, 아래 2줄 `tD`~`tF`)를 지정할 수 있습니다. `t1`~`t3`은 그대로입니다.
  - 스킬 메이커 왼쪽 위의 주황색 **타겟 설정** 버튼으로 3타겟/6타겟/레이드 화면을 열어 고릅니다. [설명](../scripts/Enemy-Layout-Targets-KR.md)
- **카드 우선순위 웨이브·턴별 방식**
  - 방식(상성/서번트)과 서번트 우선순위 사용을 웨이브·턴 항목마다 정합니다. 요약도 항목별 방식에 맞춰 보여 줍니다. [설명](../scripts/Card-Priority-KR.md)
- **KR 미실장 서번트 한국어 검색**
  - 서포트 이미지 검색에서 한국 서버에 아직 없는 서번트를 한국어 이름으로 찾습니다. [설명](../scripts/Servant-Number-Portraits-KR.md)

## 바뀐 기능

- **서번트 카드 확인 자동 판단**
  - "서번트 카드 아이콘 확인 생략" 옵션을 없앴습니다. 전투 설정을 보고 필요할 때만 확인을 켭니다(서번트 방식, 서번트 우선순위, 브레이브 체인, 보구 맞춤 셔플, 하쿠노 셔플, 카드 조건 시작).
  - 전투 설정 화면에 판단 결과가 한 줄로 나옵니다.
  - "서포트를 자신의 서번트처럼 취급합니다"를 **"서포트 아이콘 확인 생략"**으로 이름을 바꿨습니다(더 보기 → 배틀).
- **공격 순서 직접 지정**: 자리를 **미선택**(`p`)으로 두면 카드 우선순위대로 채웁니다. [설명](../scripts/Direct-Cards-KR.md)
- **스킬 자동 강화**: 10/10/10이 되어 서번트 선택이 풀리면 멈춥니다. [설명](../scripts/Auto-Skill-Level-KR.md)
- **주간 미션 (JP)**: 千手千眼 퀘스트 이름을 글자로 못 읽을 때 이름 그림으로 확인합니다.
- **번역**: 그랜드 서포트의 "일반 예장·보상 증가(인연/FP/QP/EXP) 예장 모두 일치" 옵션을 한국어로 표시합니다.
- 원본 FGA의 Play 스토어·후원·위키 관련 파일과 쓰지 않는 링크를 정리했습니다.

## 알려진 한계

- **Chaldea 가져오기**는 아직 `t1`~`t3`만 만듭니다. 6타겟·레이드 퀘스트는 "적 타겟 정보 무시"를 켜고 가져오세요([#162](https://github.com/puruuun/FGA-Modified/issues/162)).
- 레이드 아래 2줄의 왼쪽·가운데(`tD`·`tE`) 위치는 추정값입니다. 어긋나면 알려 주세요.
- **분할 화면 터치:** 화면을 나눠 쓸 때 FGA가 실행 중이면 다른 앱의 터치가 끊길 수 있습니다([#119](https://github.com/puruuun/FGA-Modified/issues/119), [#120](https://github.com/puruuun/FGA-Modified/issues/120)).
