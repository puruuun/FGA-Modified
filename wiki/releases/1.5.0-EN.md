# FGA(mod) 1.5.0

- Added **Auto Skill Level / Auto Append Skill Level**. Pressing the FGA Play button on the skill enhancement or append skill enhancement screen with a Servant selected repeats enhancements up to the target level set for each slot. Works on KR and JP servers only.
- Every slot starts at **Off (0)** whenever the settings dialog opens, and target values are not saved. It never enhances past the target, and **never unlocks** locked append slots (skips them).
- Reads both the current level and the next level in the confirmation dialog and confirms only when `next = current + 1`. Cancels and stops if unreadable.
- Stop reasons are recorded with readable names, and step-by-step guidance appears on screen and in logs.

**Enhancement is an irreversible action that spends QP and materials. Test first with one slot and target = current level + 1.**

[Auto Skill / Append Skill Level guide](../scripts/Auto-Skill-Level-EN.md)

The stable APK file is `FGA-mod-1.5.0-arm.apk`. Because it is signed with the debug key published in the repository, install only from trusted owner distributions. The owner verified normal operation in live gameplay for skill enhancement (JP and KR) and append skill enhancement.
