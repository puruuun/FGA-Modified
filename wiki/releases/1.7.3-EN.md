# 1.7.3 — Battle Log & Chaldea Wave/Turn Splitting

This is stable release **1.7.3 / 3098**. It updates in-place over 1.7.2 without uninstalling. Includes all changes verified in `1.7.3-beta.1` and `1.7.4-beta.1~3`. The version number `1.7.4` was used only in betas.

## New Features

- **Battle log** ([#186](https://github.com/puruuun/FGA-Modified/issues/186), [#191](https://github.com/puruuun/FGA-Modified/issues/191)) [Guide](../scripts/Battle-Log-EN.md)
  - Saves the exit screen summary when a battle ends.
    - Base details: config name, date, stop reason, run count, turns, time, CEs, retreats
    - Material counts and bond tracking are saved only when those features are enabled.
  - View newest-first under **Main → Log**.
    - When screen width is 600dp or more, displays the list on the left and details on the right.
    - On narrower screens, tapping a record opens its details.
  - Keeps up to the latest 200 entries. Records can be deleted individually or all at once.
  - Paused status views and runs finishing with 0 completions are not recorded.

## Fixed Issues

- **Importing a Chaldea link entered every attack as a wave transition** ([#180](https://github.com/puruuun/FGA-Modified/issues/180), [#185](https://github.com/puruuun/FGA-Modified/issues/185)) [Guide](../scripts/Chaldea-Import-EN.md)
  - Chaldea links do not record wave changes. As a result, subsequent turns in the same wave were also entered as wave transitions (`,#,`), and on single-wave quests such as Grand Training, FGA used only face cards from turn 2 onward.
  - Now looks up the quest's wave count and handles it as follows:
    - 1 wave: directly inserts turns (`,`) between all attacks.
    - Number of attacks ≤ wave count: directly inserts wave transitions between all attacks.
    - Number of attacks > wave count or lookup fails: opens a dialog to choose wave/turn after each attack.

## Changed Behavior

- **Separate display for misses caused by bond level-up popups** ([#172](https://github.com/puruuun/FGA-Modified/issues/172)) [Guide](../scripts/Bond-Tracking-EN.md)
  - Quests whose gains could not be read due to a level-up popup are excluded from each character's "Missing" count.
  - Instead, they are shown separately on the exit screen as `"Missing due to bond level-up popups: n quests"`.
  - Removed the description text below bond totals. Unconfirmed level-up lines show only the count.
- **Wide-screen layout** ([#177](https://github.com/puruuun/FGA-Modified/issues/177), [#179](https://github.com/puruuun/FGA-Modified/issues/179)) [Guide](../scripts/Modified-Features-EN.md)
  - The Battle Config (**Edit config**) screen splits into two columns when screen width is 600dp or more.
  - When the window is wider than 1280dp, 10 main and settings screens center their content at a 1280dp width.
  - Narrower screens such as phones remain as before.
- **App Language setting location** ([#183](https://github.com/puruuun/FGA-Modified/issues/183))
  - Moved **App Language** from Main to the top of **More options → Advanced**.
  - **Log** takes that spot on Main.
