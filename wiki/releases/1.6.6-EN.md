# 1.6.6 — KR Rank Up Result Screen Recognition

This is stable release **1.6.6 / 3093**. Retains the existing modified build package ID and signing.

- **Fixed stopping on KR Noble Phantasm / Skill Rank Up result screens**
  - Cause: KR had no dedicated image, so it was searching with the differently shaped English image (similarity 0.28).
  - Updated KR to use the same small double-arrow image as JP (0.91).
  - Now, once the result screen is recognized, it taps the center of the screen to advance to the next screen like original FGA. No settings change is needed.
- Verification
  - The Noble Phantasm Rank Up screen provided by the owner was a 16:9 image scaled down in chat.
  - Not yet verified on KR Skill Rank Up screens or wide screens.
  - Distributed directly as a stable release without a beta at the owner's request.
