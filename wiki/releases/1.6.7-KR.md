# 1.6.7 — 카드 부족 시 우선순위 대체, 알림창·편성창 정지 수정

정규판 **1.6.7 / 3094**입니다. 기존 수정판 패키지와 서명을 유지합니다.

- **공격 순서 직접 지정: 카드 부족 시 우선순위로 대체** (1.6.7-beta.1)
  - 직접 지정 화면에 **"카드 부족 시 우선순위로 대체"** 체크박스를 추가했습니다. 켜면 해당 공격 앞에 `?`가 붙습니다(예: `&?b4a`).
  - 지정한 색 카드를 먼저 모든 칸에서 확보하고, 부족한 칸만 현재 카드·서번트 우선순위로 채웁니다. 예를 들어 `B → 보구1 → A`에 A 1장, Q 4장이면 `Q → 보구1 → A`로 공격합니다.
  - 끄면 이전과 같이 카드를 누르지 않고 멈춥니다. [설명](../scripts/Direct-Cards-KR.md).
- **강화 퀘스트 개방 알림창에서 멈추던 문제 수정** (1.6.7-beta.2)
  - 강화 퀘스트를 깬 뒤 "…이(가) 개방되었습니다!" 창의 닫기를 스톰포드 소진 창으로 오인해, 목록으로 돌아가면서 정지했습니다.
  - 이제 전투 뒤 하단 가운데 닫기는 누르기만 하고 계속 진행합니다.
  - 스톰포드가 떨어지면 다음 퀘스트를 누를 때 나오는 부족 창에서 정지합니다. 마지막 판은 한 번만 집계합니다.
- **서포트 선택 뒤 편성창에서 멈추던 문제 수정** (1.6.7-beta.2)
  - 일부 기기에서 편성창 제목 인식에 실패하면 퀘스트 개시를 누르지 않고 멈췄습니다.
  - 제목 인식을 없애고 원본 FGA처럼 고정 대기로 진행합니다: 서포트 → 4초 → 파티 선택 → 1초 → 스톰포드·티포트 → 1초 → 퀘스트 개시.
  - 편성창에서 바로 스크립트를 시작하는 기능은 없어졌습니다. 퀘스트 목록이나 서포트 화면에서 시작하세요. [설명](../scripts/Quest-Items-KR.md).
- 검증
  - 소유자가 태블릿에서 스톰포드 소진 정지·회차 집계, 새 출발 순서, 카드 부족 시 대체를 확인했습니다.
  - 강화 퀘스트 개방 알림창은 제보 화면 기준이며 실기기에서 다시 띄워 보지는 못했습니다.
