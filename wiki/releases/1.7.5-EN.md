# 1.7.5 — Handling ★4/★5 Warning Dialog in CE Auto-Enhance

This is stable release **1.7.5 / 3100**. It updates in-place over 1.7.4 without uninstalling. Adds only the single fix below on top of 1.7.4.

## Fixed Issues

- **CE enhancement stopping on ★4/★5 warning dialogs** ([#286](https://github.com/puruuun/FGA-Modified/issues/286)) [Guide](../scripts/CE-Auto-Enhance-EN.md)
  - When the game's recommended-selection filter includes ★4/★5 CEs or already-enhanced CEs, tapping **Execute** brings up an extra confirmation dialog ("Confirm recommended selection targets" / `추천 재료 선택 대상 확인`).
  - Previously, FGA could not find the OK (`決定`) button on this dialog and could not proceed to enhancement.
  - Now, when this dialog appears after tapping **Execute**, FGA taps OK and proceeds to **Enhance** as before. When the dialog does not appear, behavior is unchanged.
  - Follows the filter settings selected in the game as-is.
