# 1.7.2 — 서포트 카드 구분 수정

정규판 **1.7.2 / 3097**입니다. 1.7.1 위에 지우지 않고 업데이트 설치할 수 있습니다. 1.7.2-beta.1~3의 변경을 모두 포함합니다.

## 고친 문제

- **웨이브·턴별 카드 우선순위가 가끔 다른 서번트 카드를 고르던 문제** ([#167](https://github.com/puruuun/FGA-Modified/issues/167))
  - 서번트 방식이나 서번트 우선순위를 쓸 때, 서포트 카드를 본인 서번트 카드로 잘못 나누는 경우가 있었습니다. 그러면 웨이브별 순서를 정해 두어도 엉뚱한 서번트의 카드를 먼저 골랐습니다.
  - 원인은 카드의 `SUPPORT` 표시를 찾는 그림이 지금 게임 화면과 맞지 않았던 것입니다. 버프 아이콘이 표시 앞부분을 가리는 것도 영향을 줬습니다.

## 바뀐 동작

- **서포트 카드 구분 방식** [설명](../scripts/Card-Priority-KR.md)
  - 카드의 `SUPPORT` 표시 중 버프 아이콘에 덜 가려지는 끝부분(`ORT`)을 봅니다.
  - 서포트도 시작할 때 상세 창을 열어 얼굴을 저장합니다. 같은 서포트로 다음 주회를 돌 때는 다시 열지 않습니다.
  - 표시를 놓친 카드는 필드에 있는 서번트 얼굴과 비교해서 가장 비슷한 쪽으로 정합니다.
  - 서포트가 본인 서번트와 같은 얼굴이면(같은 서번트, 같은 그림) 서포트 얼굴은 비교에 쓰지 않고 표시로만 구분합니다.
- **"서포트 아이콘 확인 생략" 옵션 삭제** (더 보기 → 배틀)
  - 위 방식이 자동으로 처리하므로 옵션을 없앴습니다. 예전에 켜 둔 값은 무시됩니다.

## 알려진 한계

- 새 표시 그림은 JP 화면에서 잘랐습니다. KR·EN 등 다른 서버도 같은 영문 `SUPPORT` 표시라 그대로 쓰지만, 다른 서버 화면에서 직접 재지는 못했습니다. 서포트 카드를 잘못 고르면 알려 주세요.

## 검증

- 단위 테스트 전체와 Main CI 통과.
- 블루스택 기기 검사 11개 묶음 전체 통과(실패 0).
- 실게임 확인
  - 같은 서번트를 본인과 서포트로 쓴 파티, 다른 서포트를 쓴 파티로 각각 한 주회씩 돌렸습니다.
  - 서포트 표시 점수는 0.93~0.98, 본인 카드는 0.40~0.50이었습니다.
  - 3턴마다 서번트별 카드가 5장씩 맞게 나뉘었습니다.
- 자세한 내용은 [검증 리포트](https://github.com/puruuun/FGA-Modified/blob/main/docs/releases/1.7.2-validation.md)를 보세요.
