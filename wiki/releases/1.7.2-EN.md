# 1.7.2 — Support Card Distinction Fix

This is stable release **1.7.2 / 3097**. It updates in-place over 1.7.1 without uninstalling. Includes all changes from `1.7.2-beta.1~3`.

## Fixed Issues

- **Per-wave/turn Card Priority occasionally picking another Servant's cards** ([#167](https://github.com/puruuun/FGA-Modified/issues/167))
  - When using Servant style or Servant priority, support cards were sometimes misclassified as your own Servant's cards. As a result, even when per-wave order was set, cards of the wrong Servant were picked first.
  - The cause was that the template used to match the `SUPPORT` label on cards did not match the current game screen. Buff icons covering the front of the label also contributed.

## Changed Behavior

- **Support card distinction method** [Guide](../scripts/Card-Priority-EN.md)
  - Inspects the trailing part (`ORT`) of the card's `SUPPORT` label, which is less obscured by buff icons.
  - Also opens the support's detail dialog at battle start to save its face image; subsequent repeats using the same support do not reopen it.
  - Cards whose label is missed are compared against the faces of Servants on the field and assigned to the closest match.
  - If the support shares the same face as an own Servant (same Servant, same portrait), the support face is excluded from face matching and only the `SUPPORT` label is used.
- **Removed "Skip support icon check" option** (More options → Battle)
  - Removed the option because the method above handles it automatically. Previously enabled values are ignored.

## Known Limitations

- The new label image was verified on JP and KR screens. Other servers such as EN use the same English `SUPPORT` label and share it as-is, though it has not been measured directly on them. Please report if support cards are mispicked.

## Verification

- Passed all unit tests and Main CI.
- Passed all 11 BlueStacks device QA suites (0 failures).
- Live game verification
  - Ran one quest each with a party using the same Servant for both own and support, and a party using a different support.
  - Support label scores were `0.93~0.98`, while own cards scored `0.40~0.50`.
  - Across every 3 turns, 5 cards per turn were accurately split by Servant.
- See the [validation report](https://github.com/puruuun/FGA-Modified/blob/main/docs/releases/1.7.2-validation.md) for details.
