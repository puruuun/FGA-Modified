# FGA(mod) 1.6.0

Added **Weekly mission clear** to the stable release. Calculates the lowest-AP route for this week's JP/KR missions and runs it using the selected battle configuration. See [the guide](../scripts/Weekly-Mission-Route-EN.md). The navigation probe and weekly route diagnostic PNGs are beta-only.

- **Enable Teapot/Storm Pod control** under Additional features defaults to ON. Existing saved values are kept, and actual usage is checked in the launcher dialog.
- Added **Enable bond tracking** (defaults to ON) under Additional features. Turning it off skips bond tracking and MAX stops.
- Disabled features hide their blocks in the launcher dialog while keeping saved selections.
- Moved **Save support score diagnostics** from Advanced to Additional features. Off by default.
