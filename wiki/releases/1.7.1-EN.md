# 1.7.1 — Battle Config Folders, Turn-Limit Retreat, Enemy Layout Targets & Signing Key Rotation

This is stable release **1.7.1 / 3096**. It can be installed over 1.7.0 without uninstalling. Includes all changes from `1.7.1-beta.1~15`.

## Signing Key Rotation

- Starting from this version, APKs are signed with a **private signing key**. Previously, the public debug key in the repository was used.
- Uses APK Signature Scheme v3 key rotation so it **updates cleanly over 1.7.0 without uninstalling**. Settings are also preserved.
- New certificate SHA-256: `563754b164de0d4209191f728ebb26644d53b0fbc0a47d5c8eb6a327b5dbe8f8`
- On **Android 9 and later**, after updating, only APKs signed with this key can be installed. An APK built by someone else using the public key cannot overwrite it.
- **Android 7–8** cannot read the new key and do not receive this protection. Installation and updates still work as before.
- Download APKs only from GitHub Releases and Obtainium.

## New Features

- **Battle config folders**
  - Group battle configurations into folders that can be collapsed and expanded in the list and launcher.
  - Move configs with **Move to folder** in selection mode; folders are saved together during export and import. [Guide](../scripts/Battle-Config-Folders-EN.md)
- **Turn-limit retreat**
  - Configures both wipe retreat and turn-N retreat with a single **Retreat and Restart** setting. Removed the global "Enable withdraw" option.
  - Can stop after N retreats in a row (`1–99`).
  - Displays `Retreated N times (wipe a, turn limit b)` on the exit screen. [Guide](../scripts/Turn-Limit-Retreat-EN.md)
- **Enemy layout targets**
  - Supports targeting 6-enemy layouts (`t4`–`t9`) and raid layouts (`tR`, bottom row 1 `tA`–`tC`, bottom row 2 `tD`–`tF`). `t1`–`t3` remain unchanged.
  - Tap the orange **Set target** button at the top-left of Skill Maker to open the 3 enemies / 6 enemies / Raid dialog. [Guide](../scripts/Enemy-Layout-Targets-EN.md)
- **Per-entry Card Priority style by Wave/Turn**
  - Sets style (Affinity/Servant) and **Use Servant Priority** individually per wave/turn entry. Summaries also reflect each entry's style. [Guide](../scripts/Card-Priority-EN.md)
- **Korean search for Servants not yet on KR**
  - Search Servants not yet released on the Korean server by Korean name in support image search. [Guide](../scripts/Servant-Number-Portraits-EN.md)

## Changed Features

- **Automatic Servant face-card check**
  - Removed the "Skip servant card icon check" option. Automatically enables the check based on the battle configuration only when needed (Servant style, Servant priority, Brave Chains, NP-matching shuffle, Hakuno Shuffle, Card-count start).
  - Displays the decision in one line on the Battle Config screen.
  - Renamed "Treat Support same as own Servant" to **"Skip support icon check"** (More options → Battle).
- **Direct cards**: Setting a slot to **Unselected** (`p`) fills it by Card Priority. [Guide](../scripts/Direct-Cards-EN.md)
- **Auto Skill Level**: Stops when all skills reach 10/10/10 and the game deselects the Servant. [Guide](../scripts/Auto-Skill-Level-EN.md)
- **Weekly mission (JP)**: Uses a name image to verify the `千手千眼` quest when its text cannot be read by OCR.
- **Translation**: Displays the Grand Support option **"Match both free slot & bonus-up (Bond/FP/QP/EXP) slot"** in Korean.
- Cleaned up original FGA files and unused links related to the Play Store, donations, and wiki.

## Known Limitations

- **Chaldea import** still generates only `t1`–`t3`. For 6-enemy or raid quests, enable **Ignore enemy targeting information** before importing ([#162](https://github.com/puruuun/FGA-Modified/issues/162)).
- The left and center positions on the raid bottom row 2 (`tD` and `tE`) are estimated values. Please report if they are misaligned.
- **Split-screen touch**: When using split screen while FGA is running, touches in the other app may be interrupted ([#119](https://github.com/puruuun/FGA-Modified/issues/119), [#120](https://github.com/puruuun/FGA-Modified/issues/120)).
