# 1.7.0 — Hakuno Shuffle, CE Auto-Enhance, Card Priority Extensions & Game Area Auto-Fit

This is stable release **1.7.0 / 3095**. It retains the existing modified build package ID and signing and updates over 1.6.7. Includes all changes from the 1.6.8 beta (skill level reading) and `1.7.0-beta.1~13`.

## New Features

- **Hakuno Shuffle**
  - Repeats a Servant's 1st skill (NP cost) until the card condition is met.
  - Configures minimum/maximum presses, card-count conditions by color (OR), and stopping if the condition is not met.
  - Uses the `aH{…}` command format. [Guide](../scripts/Hakuno-Shuffle-EN.md)
- **CE enhancement** (JP/KR)
  - Turns on auto-select using the game's recommended-selection filter and repeats enhancement.
  - Can switch to servant level-up mode from the start dialog. [Guide](../scripts/CE-Auto-Enhance-EN.md)
- **Card Priority extensions**
  - Supports up to 10 entries, with **Split by** selectable between **Wave** and **Turn**.
  - Added **Servant** style, which picks cards in Servant order. [Guide](../scripts/Card-Priority-EN.md)
- **Game Area** (More options → Additional features → Game area)
  - Previews the actual recognition area on screen while adjusting custom offsets.
  - Allows saving offsets as presets.
  - **Calibrate from screenshot**: tapping on the main screen automatically detects the split-screen game area and saves it as a preset (JP/KR). [Guide](../scripts/Game-Area-Preview-EN.md)
- **Added features fine tune** (Advanced tab)
  - Adjusts delay multipliers and image similarity offsets per feature area for modified-build features.
  - With default values, behaves identically to before. [Guide](../scripts/Added-Features-Fine-Tune-EN.md)
- **Send friend request after quest**
  - In **Preferred** support mode, sends a friend request instead of declining after using a non-friend support. [Guide](../scripts/Modified-Features-EN.md#auto-friend-request)
- **Grand support CE conditions**
  - Checks free and bonus-up slot CEs, max-limit broken status, and Bond CE effects (**NP charge**, **Default effects**, **Ignore**). [Guide](../scripts/Support-Grand-CE-EN.md)

## Changed Features

- **Weekly mission clear**
  - Lets you choose which missions to run before computing the route.
  - Added Treasure Vault Beginner to route candidates.
  - Replaced map-image comparison for map positioning with **map-edge-based movement measurement**. Passed all JP and KR main-story spots on both BlueStacks 21:9 and tablet.
  - Stops scrolling at the top and bottom ends of the list. [Guide](../scripts/Weekly-Mission-Route-EN.md)
- **FP summon auto-sell**
  - After selling, returns to the user-set **banner position (1st–7th from the end)** instead of comparing banner titles.
  - Stops without summoning if the reached banner lacks the FP indicator and summon button.
  - Stops scrolling at the end of the sell list. [Guide](../scripts/FP-Auto-Sell-EN.md)
- **Card-count command start**
  - Allows adding condition rows by color and choosing `AND`/`OR` between rows. [Guide](../scripts/Card-Count-Start-EN.md)
- **Auto Skill / Append Skill Level**
  - Directly reads skill levels from the Servant's skill panel and cross-checks them against the confirmation dialog. Cancels without enhancing if they differ.
  - Append slots use per-slot digit samples; when only one side is readable (such as the 9→10 confirmation dialog), the other side supplements it. [Guide](../scripts/Auto-Skill-Level-EN.md)
- **Bond MAX stop**: Stops when Bond level increases to 10 or higher even if no slot indicator is present on the result screen.
- **Direct cards**: When multiple cards of the same color exist, picks effective (weak) affinity cards first.
- **Support**: Added U-Olga Marie costume support images.
- **Wide screen**: Fixed end-of-list detection for the weekly list and FP sell list across all ratios between 16:9 and 21:9 (e.g., `2340×1080`).
- **Auto-detection**: FP summon is selected only when the FP indicator is present on the banner screen. Pressing Play on the summon result screen no longer starts FP summon.
- On first launch, chooses the app language matching the device language. Two Preferred support settings display titles only without descriptions.

## Known Limitations

- **Split-screen touch**: When using split screen while FGA is running, touches in the other app may be interrupted. This is an Android platform limitation ([#119](https://github.com/puruuun/FGA-Modified/issues/119), [#120](https://github.com/puruuun/FGA-Modified/issues/120)).
