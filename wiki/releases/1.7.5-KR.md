# 1.7.5 — 개념예장 자동 강화의 ★4·★5 경고 창 처리

정규판 **1.7.5 / 3100**입니다. 1.7.4 위에 앱을 지우지 않고 업데이트 설치할 수 있습니다. 1.7.4에 아래 수정 하나만 더했습니다.

## 고친 문제

- **개념예장 자동 강화가 ★4·★5 경고 창에서 멈추던 문제** ([#286](https://github.com/puruuun/FGA-Modified/issues/286)) [설명](../scripts/CE-Auto-Enhance-KR.md)
  - 게임의 추천 선택 필터에 ★4·★5나 강화 완료 예장이 포함되어 있으면, 실행을 누른 뒤 "추천 재료 선택 대상 확인" 창이 한 번 더 뜹니다.
  - 예전에는 이 창의 확인(決定) 버튼을 찾지 못해 강화로 넘어가지 못했습니다.
  - 이제 실행을 누른 뒤 이 창이 있으면 확인을 누르고, 예전처럼 강화하기로 진행합니다. 창이 없으면 동작이 바뀌지 않습니다.
  - 필터 설정은 게임에서 고른 그대로 따릅니다.

## 검증

- 단위 테스트 전체와 Main CI를 통과했습니다.
- 블루스택에서 기기 검사 11개 묶음 전체를 통과했습니다. JP·KR 경고 창 화면도 포함됩니다.
- 1.7.5-beta.1로 실게임에서 확인했습니다.
- 자세한 내용은 [검증 리포트](https://github.com/puruuun/FGA-Modified/blob/main/docs/releases/1.7.5-validation.md)에 있습니다.
