# FGA(mod) 1.6.1

- **Wide screen (wider than 18:9) support.** Features added by this modified build now also work on wide-aspect phones.
  - Scope: FP auto-sell, Auto Skill/Append Skill Level, Weekly mission clear, Teapots/Storm Pods, Bond tracking, Support reading
  - Follows the same rule as original FGA: 18:9 and narrower uses 16:9, between 18:9 and 21:9 scales to the screen width, and wider than 21:9 is treated as 21:9.
- The owner verified all JP features and KR FP auto-sell on BlueStacks 21:9 (`1680×720`) and `2560×1080`.

[Wide screen guide](../scripts/Modified-Features-EN.md)

The stable APK file is `FGA-mod-1.6.1-arm.apk`. Because it is signed with the debug key published in the repository, install only from trusted owner distributions.
