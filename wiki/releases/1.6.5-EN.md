# 1.6.5 — Built-in CE Cleanup, Korean Bond 20% Labels & All Built-in CEs Linked in Chaldea Import

This is stable release **1.6.5 / 3092**. Retains the existing modified build package ID and signing.

- **Removed 5 built-in default CEs (28 → 23)**: Removed 5 infrequently used default CEs (`Aerial Drive`, `Golden Sumo: Boulder Plains` [`Golden Sumo ~Iwabasyo~`], `GudaGuda Poster Girl`, `Holy Night Supper`, `Painting Summer`) from the built-in default list.

- **All 23 built-in CEs linked in Chaldea support import**: Updated the built-in CE mapping table (`builtin-ids.json`), which previously mapped only 11 CEs, using KR, JP, and NA Atlas Academy data so all 23 CEs connect immediately to built-in images.
