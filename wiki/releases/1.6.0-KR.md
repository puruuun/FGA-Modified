# FGA(mod) 1.6.0

주간 미션 클리어를 정규판에 추가했습니다. JP·KR의 이번 주 미션에 맞는 최소 AP 경로를 계산하고 선택한 전투 설정으로 진행합니다. [사용 설명](../scripts/Weekly-Mission-Route-KR.md)을 확인하세요. 탐색 시험과 주간 루트 진단 PNG는 베타 전용입니다.

- 추가기능의 티포트·스톰포드 자동 설정은 기본 켜짐입니다. 기존 저장 값은 유지하며 실제 사용은 실행 창에서 체크합니다.
- 추가기능에 인연 추적 기능 사용(기본 켜짐)을 추가했습니다. 끄면 추적·MAX 정지를 생략합니다.
- 꺼진 기능의 실행 창 블록은 숨기며 저장된 선택은 유지합니다.
- 서포트 판독 진단 저장을 고급에서 추가기능으로 옮겼습니다. 기본 꺼짐입니다.
