# FGA(mod) 1.4.0

정규판 1.2.1 이후 추가된 FP 자동 판매와 서포트 재림 구분을 포함합니다.

## FP 소환 자동 판매

**판매 화면에 보이는 서번트·경험치 카드·포우 카드 중 잠금이 아닌 칸을 모두 선택해 판매합니다. 시작 전에 판매 화면의 필터 설정을 꼭 확인하세요.**

앱에서도 이 경고를 큰 빨간 굵은 글씨로 표시합니다. 종류·별 수·NEW!로 대상을 제한하지 않으므로 게임 판매 화면의 필터와 잠금을 먼저 설정하세요.

- FP 실행 화면에서 **자동 판매 켜기**를 켜면 서번트칸 가득 참 → 판매 → 원래 FP 배너 복귀 → 재소환을 반복합니다. 기본값은 꺼짐입니다.
- 잠금·선택 불가·임시 가입·그랜드 서번트·PARTY, 이미 선택된 칸과 빈 슬롯은 누르지 않습니다. 실제 판매에서는 잠금 판별이 불분명한 칸도 선택하지 않습니다.
- **시험 모드는 베타 전용**입니다. 정규판은 시험 모드 스위치·설명을 숨기고, 저장된 시험 모드 값과 관계없이 실제 판매합니다. KR·JP 및 잠금 템플릿의 실제 판매 허용 조건을 만족하지 않으면 판매 없이 정지합니다.
- 목록 끝에서는 결정 → 최종 확인 → 변환 → 닫기까지 진행합니다. 판매 뒤 다시 가득 차면 판매를 반복하고 더 선택할 칸이 0이면 정지합니다.
- 배너는 처음 기억한 제목으로 복귀하며 왼쪽으로 최대 10번 찾습니다. 1.4.0의 재소환 확인 방식은 [1.4.1](1.4.1-KR.md)에서 처음 소환과 같은 원본 FGA 경로로 되돌렸습니다.

[사용법과 보호 규칙](../scripts/FP-Auto-Sell-KR.md)

## 서포트 재림 구분 (1.3.0 기능 포함)

서포트 이미지 메이커에서 **서번트 이름 + 보구 (재림 구분)** 그림을 만들고, 배틀 설정 → 서포트 → 선호 항목에서 고를 수 있습니다. 재림마다 보구가 다른 서번트를 구분할 때 사용합니다. 저장 시 JP·KR 서버 접두어가 붙으며 같은 이름에 여러 그림을 추가할 수 있습니다.

예전 보구 이름만 담긴 그림은 다시 만들어 주세요. 이름·보구·카드가 모두 같은 재림은 구분할 수 없습니다. [재림 구분 사용법](../scripts/Ascension-Select-KR.md)

## 검증 범위와 설치

- 소유자는 beta.10에서 JP·KR FP 자동 판매 시험 모드 전체 흐름을 확인했습니다.
- KR 첫 실제 판매는 92칸 판매와 배너 복귀까지 확인됐습니다. 이후 FP 사용 확인창에서 정지한 문제를 beta.11에서 수정했습니다. **이 확인창 수정 자체는 아직 게임에서 확인하지 않았습니다.**
- 재림 구분 기능은 고정 화면을 이용한 기기 QA까지 확인했으며 실제 게임 확인은 남아 있습니다.
- 정규판 파일 이름은 `FGA-mod-1.4.0-arm.apk`입니다. 저장소에 공개된 debug 키로 서명하므로 신뢰할 수 있는 소유자 배포본에서만 설치하세요.
