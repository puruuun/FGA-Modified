# FGA(mod) 1.4.0

正式版 1.2.1 以降に追加された FP 自動売却とサポート再臨の区別を含みます。

## フレンドポイント召喚・自動売却

**売却画面に表示されているロックされていないサーヴァント・経験値カード・フォウくんカードをすべて選択して売却します。開始前に必ず売却画面のフィルター設定を確認してください。**

アプリ内でもこの警告を大きな赤い太字で表示します。種類・レアリティ・`NEW!` で対象を制限しないため、ゲーム内の売却画面でフィルターとロックを先に設定してください。

- FP 実行画面で **自動売却を有効にする** をオンにすると、サーヴァント枠がいっぱい → 売却 → 元の FP バナーへ復帰 → 再召喚 を繰り返します。初期値はオフです。
- ロック済み・選択不可・仮加入・グランドサーヴァント・`PARTY`、すでに選択済みの枠や空き枠はタップしません。実際の売却では、ロック判定が不明確な枠も選択しません。
- **ドライラン（試験モード）はベータ専用です。** 正式版ではテストモードのスイッチと説明を非表示にし、保存されたテストモード値にかかわらず実際の売却を行います。KR・JP およびロックテンプレートの実売却許可条件を満たさない場合は売却せずに停止します。
- リストの末尾では 決定 → 最終確認 → 変換 → 閉じる まで進みます。売却後も枠がいっぱいの場合は売却を繰り返し、選択できる枠が 0 になると停止します。
- バナーへの復帰は最初に記憶したタイトルを使って左へ最大 10 回探します。1.4.0 の再召喚確認方式は、[1.4.1](1.4.1-JA.md) にて初回召喚と同じオリジナル FGA 経路に戻しました。

[使い方と保護ルール](../scripts/FP-Auto-Sell-JA.md)

## サポートの再臨の区別（1.3.0 の機能を含む）

**サポートイメージメーカー** で **サーヴァント名＋宝具名（再臨の区別）** 画像を作成し、**バトルの設定 → サポート → 優先** 項目から選択できます。再臨ごとに宝具が異なるサーヴァントを区別するときに使用します。保存時には JP・KR サーバーの接頭辞が付き、同じ名前に複数の画像を追加できます。

以前の宝具名だけを含む画像は作り直してください。名前・宝具・カードがすべて同じ再臨は区別できません。[再臨の区別の使い方](../scripts/Ascension-Select-JA.md)

## 検証範囲とインストール

- オーナーは `beta.10` で JP・KR の FP 自動売却テストモードの一連の流れを確認しました。
- KR での初回実売却は 92 枠の売却とバナー復帰まで確認されました。その後 FP 使用確認ダイアログで停止した問題を `beta.11` で修正しました。**この確認ダイアログの修正自体は、まだ実ゲームで確認されていません。**
- 再臨の区別機能は静止画面を用いた実機 QA まで確認済みであり、実ゲームでの確認が残っています。
- 正式版ファイル名は `FGA-mod-1.4.0-arm.apk` です。リポジトリに公開されているデバッグキーで署名しているため、信頼できるオーナーの配布元からのみインストールしてください。
