# FGA(mod) 1.4.1

- Unified re-summoning after FP auto-sell to use the **same original FGA path as the initial summon**: regular summons tap Summon → 0.3s → Confirm, and daily free summons tap initial Free Summon → 0.3s → Continue. Removed the separate confirmation dialog image check and its dedicated error.
- Removed the top description in the **Search and save support images** dialog and the notice below Class score +16. **+16 reading and the JP-only condition remain unchanged.**
- Preserves returning to the original FP banner, the sell-filter warning, and lock/exclusion protections. **Dry-run mode is beta-only** and on by default. The stable build stops without selling if blocked by live-sale validation checks.

**Every visible unlocked servant, EXP card and Fou card on the sell screen will be selected and sold. Check the sell-screen filter before starting.**

[FP Auto-Sell guide](../scripts/FP-Auto-Sell-EN.md)

The stable APK file is `FGA-mod-1.4.1-arm.apk`. Because it is signed with the debug key published in the repository, install only from trusted owner distributions. The new re-summon path in this version was verified by automated tests; live game execution was not included in verification.
