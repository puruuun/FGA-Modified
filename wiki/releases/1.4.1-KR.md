# FGA(mod) 1.4.1

- FP 자동 판매 뒤 재소환을 **처음 소환과 같은 원본 FGA 경로**로 통일했습니다. 일반 소환은 소환 → 0.3초 → 확인, 매일 무료 소환은 처음 무료 소환 → 0.3초 → 계속을 누릅니다. 별도 확인창 이미지 검사와 전용 오류는 제거했습니다.
- 서포트 이미지 검색·저장 창 상단 설명과 클래스 스코어 +16 아래 안내 두 문구를 제거했습니다. **+16 판독 및 JP 전용 조건은 그대로**입니다.
- 원래 FP 배너 복귀, 판매 필터 경고와 잠금·제외 보호는 유지합니다. **시험 모드는 베타 전용**이며 기본 켜짐입니다. 정규판은 실제 판매 허용 검사에 막히면 판매 없이 정지합니다.

**판매 화면에 보이는 서번트·경험치 카드·포우 카드 중 잠금이 아닌 칸을 모두 선택해 판매합니다. 시작 전에 판매 화면의 필터 설정을 꼭 확인하세요.**

[FP 자동 판매 사용법](../scripts/FP-Auto-Sell-KR.md)

정규판 파일은 `FGA-mod-1.4.1-arm.apk`입니다. 저장소에 공개된 debug 키로 서명하므로 신뢰할 수 있는 소유자 배포본에서만 설치하세요. 이 버전의 새 재소환 경로는 자동 테스트로 확인했으며 실제 게임 실행은 검증 작업에 포함하지 않았습니다.
