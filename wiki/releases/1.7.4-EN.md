# 1.7.4 — Temporary Servant Skill Enhancement & Upstream FGA v3070 Sync

This is stable release **1.7.4 / 3099**. It updates in-place over 1.7.3 without uninstalling. Includes all changes verified in `1.7.4-beta.4~5`.

## Fixed Issues

- **Auto Skill Level stopping on temporary (welfare) Servants** ([#259](https://github.com/puruuun/FGA-Modified/issues/259)) [Guide](../scripts/Auto-Skill-Level-EN.md)
  - For temporary (`仮加入`) Servants, tapping Enhance displays a notice dialog first. Previously, this dialog was treated as an unexpected dialog, closed, and enhancement stopped.
  - Now handled in the same way as original FGA's Servant enhancement:
    - Whenever the **Execute (`実行する`)** button on the right side of the dialog is visible, taps it to continue.
    - On the next enhancement confirmation dialog (current → next level), proceeds after performing the same level check as before.
  - If another dialog appears without the Execute button, closes it and stops that slot as before.

## Changed Behavior

- **Grand Support Bond CE effect** ([#240](https://github.com/puruuun/FGA-Modified/issues/240)) [Guide](../scripts/Support-Grand-CE-EN.md)
  - Uses original FGA's newly created NP charge icon image and aligns matching logic with original FGA.
  - Counts as a match when the selected effect icon meets or exceeds the common minimum similarity.
  - **Added features fine tune** no longer applies to Grand CE slot checking.
  - **Bond CE effect preference** and **Match both free slot & bonus-up (Bond/FP/QP/EXP) slot** are visible and applied only when **Grand Servant** is enabled.
- **Automatic support image extraction after app update** [Guide](../scripts/Original-FGA-Import-EN.md)
  - Opening the app for the first time after updating re-extracts built-in support images into the storage folder.
- **Bond summary display** ([#197](https://github.com/puruuun/FGA-Modified/issues/197))
  - Removed the "Bond level-ups with unconfirmed position/level" line from the exit screen and battle log. The "Missing due to bond level-up popups" line remains.
- **Upstream FGA v3070 sync** ([#223](https://github.com/puruuun/FGA-Modified/pull/223))
  - Added Simplified Chinese, Traditional Chinese, and Vietnamese translations.
  - Preserves Korean and Japanese phrasing adjusted by this modified build.

## Known Limitations

- Because no capture of the temporary Servant notice dialog for Append Skill enhancement was available, it assumes the same button position as normal Skill enhancement.
- Because Grand Support (Grand Duel) quests exist only on JP, verification was done on JP screens only.

## Verification

- Passed all unit tests and Main CI.
- Passed all 11 BlueStacks device QA suites.
- Skill enhancement for temporary Servants was verified in live gameplay on `1.7.4-beta.5`.
