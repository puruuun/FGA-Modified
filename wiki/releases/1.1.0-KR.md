# FGA(mod) 1.1.0

기존 정규판 1.0.1 이후의 베타 개발 결과와 판독 개선을 포함하는 정규 릴리스입니다.

## 변경 사항

- **서번트 번호로 서포트 이미지 생성**: 더 많은 옵션 → 추가기능에서 도감 번호를 입력하면 공개 재림·영의 초상화를 조회해 FGA 인식 이미지로 저장합니다. 폴더에 `No.번호 서번트 이름`을 표시하고, 이전 번호 폴더와 선호 서번트 선택도 유지합니다.
- **서포트 스코어 판독 개선**: 일본판의 작은 그랜드 스코어 숫자를 보완했습니다. 클래스 +62와 그랜드 +16을 모두 요구할 때는 두 값이 모두 표시돼야 통과합니다. 클래스 +62만 요구하면 +62 단독 표시와 +62/+16 표시 모두 확인합니다.
- **인연포인트 판독 개선**: 기본 획득량과 괄호 안 보너스를 분리하고 좁은 숫자를 재판독해 누락을 줄였습니다. MAX 및 NEXT 숫자를 획득량과 구분합니다.
- **한섭 티포트·스톰포드 오류 수정**: 실제 블루스택 설정창 제목 표본을 추가했습니다. 두 아이템 상태와 닫기를 확인한 뒤에만 출발합니다.
- **파티 확인 화면에서 바로 시작**: 한국·일본 서버 모두 FGA 재생 시 파티 선택과 아이템 설정을 거쳐 퀘스트를 시작합니다. 직접 열어 둔 아이템 설정창은 먼저 닫고 재생하세요.
- **중단 안내 간소화**: 티포트·스톰포드 오류 뒤의 게임 화면·추가 옵션 안내를 제거했습니다.

## 설치·업데이트

- 버전: **1.1.0 / 3082**
- APK: **FGA-mod-1.1.0-arm.apk**
- 앱 이름: **FGA(mod)**
- 앱 ID: `io.github.fate_grand_automata.cardcount`
- Android 7 이상, ARM 32/64비트 지원

기존 정규판과 같은 패키지·서명으로 업데이트 설치합니다. Obtainium 정규판 설정에서 업데이트할 수 있습니다. FGA(beta)는 별도 앱이며 저장 폴더·설정이 자동으로 옮겨지지는 않습니다.

## 검증

- 앱·설정·스크립트·자동화 라이브러리 자동 테스트 **359개 통과**.
- 티포트·스톰포드 한국·일본 UI 영역 표본 **13개**, 요소를 가린 검사 **36개** 통과.
- 개선본의 인게임 검수는 사용자가 직접 완료했습니다. 모든 기기·서버에서의 동작을 보장하는 검수 범위는 아닙니다.
