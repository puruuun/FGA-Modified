# 1.8.0 — 로그 수집, 계정 대시보드, Chaldea 자동 반영, 홈 화면 위젯

정규판 **1.8.0 / 3101**입니다. 1.7.5 위에 앱을 지우지 않고 업데이트 설치할 수 있습니다. 1.8.0-beta.1~48의 변경을 모두 포함합니다.

## 새 기능

- **로그 수집** (Android 10 이상, KR·공식 JP)
  - 게임 서버의 응답을 기기 안에서 읽어, 스크립트 실행별 획득량(아이템·QP·마스터 EXP·서번트별 인연·과일과 사용한 아이템)을 서버 기준으로 기록합니다.
  - 스크립트 밖에서 생긴 변화(선물함·상점·소환·강화·미션 등)도 출처별로 기록합니다.
  - KR 전투 스크립트는 로그 수집 중에 인연 숫자를 응답에서 가져옵니다. 재료 개수와 인연 MAX 정지는 기존 화면 판독을 그대로 씁니다.
  - 연결 방식은 셋 중 하나를 고릅니다. **FGA VPN**(기본), AdGuard 등 **외부 앱 프록시**(AdGuard 프록시 자동 전환 지원), **루트**(다른 VPN과 함께 사용 가능).
  - KR은 FGA 인증서를 CA 인증서로 설치해 사용합니다. JP는 루트 권한으로 FGA가 인증서를 자동 설치합니다.
  - 기본값은 꺼짐이며, 처음 켤 때 사용 전 안내에 동의해야 합니다. 모은 데이터는 기기 밖으로 보내지 않습니다. [설명](../scripts/Gains-Tracker-KR.md) · [외부 앱 프록시](../scripts/Capture-AdGuard-KR.md) · [루트](../scripts/Capture-Root-KR.md)
- **계정 대시보드와 메인 계정 카드**
  - 메인 화면 위쪽에 계정별 AP와 가득 차는 시각을 보여 주고, 누르면 읽기 전용 대시보드가 열립니다.
  - 프로필, 재화·AP, 보관 현황, 서번트 도감, 아이템, 마술예장, 최근 활동, 클래스 스코어, 소환 기록, 내 서포트·관위 편성을 확인합니다. [설명](../scripts/Modified-Features-KR.md)
- **프렌드 관리**: 로그 수집으로 받은 친구 목록에서 일반·이벤트·관위 편성의 서번트와 예장을 모아 보고, 이름·서번트·예장·레벨·미접속 기간으로 거릅니다. [설명](../scripts/Friend-Manager-KR.md)
- **Chaldea 자동 반영**: 로그 수집으로 모은 계정 데이터를 Shizuku 또는 루트로 Chaldea의 `userdata.json`에 자동으로 써 넣습니다. 기본값은 꺼짐입니다. [설명](../scripts/Chaldea-Sync-KR.md)
- **Chaldea 파일 내보내기**: 계정 데이터를 Chaldea에서 가져올 수 있는 파일로 저장합니다. [설명](../scripts/Gains-Tracker-KR.md)
- **홈 화면 위젯**: FGA 서비스를 시작·중지하는 1x1 위젯과, 수집한 계정의 AP를 보여 주는 계정 정보 위젯을 추가했습니다. 위젯에서 로그 수집도 켜고 끌 수 있습니다. [설명](../scripts/Widgets-KR.md)
- **아오코 카드 변화 감지**: 전투 설정에서 켜면, 변환 아이콘이 붙은 커맨드 카드를 Arts로 취급합니다. 기본값은 꺼짐입니다. [설명](../scripts/Card-Priority-KR.md)
- **서번트 조건 모드 세 번째 대상**: 두 번째 조건을 쓰는 중이면 세 번째 대상과 그 커맨드·카드 우선순위를 추가할 수 있습니다. [설명](../scripts/Card-Count-Start-KR.md)
- **연속 출격 전 미션 팝업 지우기**: 쌓인 미션 달성 팝업이 웨이브·턴 표시를 가리지 않도록, 연속 출격 전에 팝업 자리를 정한 시간 동안 연타합니다. 기본값은 꺼짐입니다. [설명](../scripts/Mission-Popup-Clear-KR.md)
- **다크 모드 설정**: 더 많은 옵션 → 고급에서 시스템 설정 따름·라이트·다크를 고릅니다.
- **선호 서번트·개념예장 선택창에서 이미지 받기**: 선택창의 **이미지 받기**로 서포트 이미지 검색·저장을 바로 열고, 저장한 폴더를 체크합니다. [설명](../scripts/Servant-Number-Portraits-KR.md)
- **선호 서번트로 서포트 클래스 자동 선택**: 선호 서번트를 한 명만 고르면 그 클래스 탭이 서포트 클래스로 선택됩니다. [설명](../scripts/Servant-Number-Portraits-KR.md)
- **기본 서포트 이미지 추출과 로그 아이콘 데이터 다운로드**를 저장소 탭에 나눠 두었습니다. [설명](../scripts/Default-Support-Images-KR.md)
- **설치 안내 페이지**와 **영어·일본어 설명서**를 추가했습니다.

## 바뀐 기능

- **영주 사용**: `영주/令呪` 글자를 찾지 않고, 16:9·와이드 화면별 영주 버튼의 고정 위치를 바로 누릅니다. [설명](../scripts/Command-Spell-Tap-KR.md)
- **JP 서포트 스코어**: 어두운 줄, `+`를 `4`로 읽은 경우, 일부만 읽힌 경우에도 `+62/+16`을 인식합니다. [설명](../scripts/Support-Score-62-KR.md)
- **원본 FGA v3071 동기화**: 그랜드 서포트의 인연 예장 아이콘을 0.60 기준으로 판정합니다. [설명](../scripts/Support-Grand-CE-KR.md)
- **스킬·어펜드 스킬 자동 강화**: 결정 뒤 통신 오류 창이 뜨면 `다시 시도`를 누르고, 4번 반복되면 멈춥니다. [설명](../scripts/Auto-Skill-Level-KR.md)
- **화면 캡처 다시 받기**: 화면을 껐다 켠 뒤 재생 버튼을 누르면 화면 캡처 허용 창을 다시 띄웁니다. 서비스를 다시 켤 필요가 없습니다.
- **드롭 화면 재료 개수 세기**: 로그 수집을 켜지 않아도 그대로 동작합니다.
- **오토 스킬 폴더**: 폴더를 하나의 상자로 보여 주고, 넓은 화면에서는 두 열로 표시합니다. 실행 창 목록도 같은 상자로 묶습니다. [설명](../scripts/Battle-Config-Folders-KR.md)
- **전투 기록 로그**: 날짜·프로필·출처·획득 자원 필터와 보관 개수(50/100/200)를 추가했고, 로그 수집으로 기록한 전투에 열쇠 아이콘을 붙입니다. [설명](../scripts/Battle-Log-KR.md)
- **서포트 이미지 검색**: Atlas 데이터 버전에 맞춰 목록을 갱신해, 새 서번트·개념예장을 바로 검색할 수 있습니다. KR 미실장 서번트의 한국어 이름과 별명 사전을 넓혔습니다. [설명](../scripts/Servant-Number-Portraits-KR.md)
- **원본 FGA 데이터 가져오기**: 같은 스크립트가 여러 개면 앱에 부족한 개수만큼 가져옵니다. [설명](../scripts/Original-FGA-Import-KR.md)
- **더 많은 옵션 재배치**: 전투 관련 스위치를 **배틀** 탭으로, 업데이트 확인·주간 퀘 추적 설정을 **고급** 탭으로 옮겼고, 배터리 최적화 바로가기를 추가했습니다.
- 실행 창에서 스톰포드·티포트 체크를 한 줄에 나란히 표시합니다.

## 고친 문제

- 업데이트 직후 첫 실행에서 앱이 한 번 꺼질 수 있던 문제 ([#360](https://github.com/puruuun/FGA-Modified/issues/360))
- 실행 창 목록의 스크롤바가 폴더 상자 테두리를 가리던 문제 ([#480](https://github.com/puruuun/FGA-Modified/issues/480))
- 백업에서 로그 수집 인증서 파일을 제외하도록 했습니다 ([#457](https://github.com/puruuun/FGA-Modified/issues/457)).
- 설정 가져오기에서 잘못된 파일을 거르고, Android 7에서 파일 이동이 실패하던 문제를 고쳤습니다 ([#441](https://github.com/puruuun/FGA-Modified/issues/441), [#442](https://github.com/puruuun/FGA-Modified/issues/442)).

## 알려진 한계

- 로그 수집은 Android 10 이상에서만 쓸 수 있고, JP는 루트 기기가 필요합니다. 게임 업데이트로 동작하지 않을 수 있으며, 그때는 로그 수집을 끄면 기존처럼 사용할 수 있습니다.
- 외부 앱 프록시 방식에서 FGA가 종료되어 있으면 FGO가 접속하지 못합니다. FGA를 다시 켜거나 프록시 앱의 프록시 설정을 끄세요(AdGuard 프록시 자동 전환을 쓰면 수집 중일 때만 해당).
- 루트 방식은 커널이 앱별 통신 규칙(iptables owner)을 지원해야 합니다. 지원하지 않는 기기에서는 시작 단계에서 안내합니다.
- 듀얼 앱·복제 앱 등 여러 게임 인스턴스의 동시 실행과 BetterFGO는 로그 수집 대상이 아닙니다.
- **분할 화면 터치:** 화면을 나눠 쓸 때 FGA가 실행 중이면 다른 앱의 터치가 끊길 수 있습니다([#119](https://github.com/puruuun/FGA-Modified/issues/119), [#120](https://github.com/puruuun/FGA-Modified/issues/120)).
