# FGA(mod) 1.4.0

Includes FP summon auto-sell and support ascension distinction added since stable release 1.2.1.

## FP Summon Auto-Sell

**Every visible unlocked servant, EXP card and Fou card on the sell screen will be selected and sold. Check the sell-screen filter before starting.**

The app also displays this warning in large, bold red text. Because it does not restrict targets by type, rarity, or `NEW!`, configure your in-game sell screen filters and locks first.

- Turning on **Enable auto-sell** on the FP launcher screen repeats: Servant box full → sell → return to the original FP banner → resume summoning. Off by default.
- Never taps locked, unselectable, temporary, Grand Servant, `PARTY`, already selected, or empty slots. In live selling, slots whose lock state is uncertain are also skipped.
- **Dry-run mode is beta-only.** The stable build hides the dry-run switch and description and always performs live selling regardless of any saved dry-run setting. If live-sale conditions for KR/JP and lock templates are not satisfied, it stops without selling.
- At the end of the list, proceeds through Confirm → Final Confirm → Convert → Close. If still full after selling, repeats selling; stops when 0 selectable slots remain.
- Banner return uses the title remembered at start and searches left up to 10 times. The re-summon confirmation flow from 1.4.0 was reverted to the original FGA path (same as initial summon) in [1.4.1](1.4.1-EN.md).

[Usage and safety rules](../scripts/FP-Auto-Sell-EN.md)

## Support Ascension Distinction (includes 1.3.0 feature)

Create **Servant + NP name (re-ascension)** images in **Support Image Maker** and select them under **Battle Configs → Support → Preferred**. Use this to distinguish Servants whose Noble Phantasm differs across ascensions. Saved with a JP/KR server prefix, and multiple images can be added under the same name.

Please recreate older images that contain only the NP name. Ascensions with identical name, NP, and card cannot be distinguished. [Ascension distinction guide](../scripts/Ascension-Select-EN.md)

## Verification Scope & Installation

- The owner verified the full KR and JP FP auto-sell dry-run flow on `beta.10`.
- The first live KR sale was verified through selling 92 slots and returning to the banner. A subsequent issue where it stopped at the FP usage confirmation dialog was fixed in `beta.11`. **This confirmation dialog fix itself has not been verified in-game yet.**
- Ascension distinction was verified up to static-screen device QA; live game verification remains.
- The stable APK filename is `FGA-mod-1.4.0-arm.apk`. Because it is signed with the debug key published in the repository, install only from trusted owner distributions.
