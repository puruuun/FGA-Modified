# 1.7.1 — バトル設定フォルダー・ターン制限撤退・敵配置ターゲット指定・署名キー更新

正式版 **1.7.1 / 3096** です。1.7.0 の上から削除せずに上書きアップデートできます。`1.7.1-beta.1~15` の変更をすべて含みます。

## 署名キーの更新

- 本バージョンから APK を**個人署名キー**で署名します。これまではリポジトリに公開されているデバッグキーを使用していました。
- APK 署名 v3 のキーローテーション方式を使用しているため、1.7.0 の上から**アプリを削除せずにそのままアップデート**できます。設定も維持されます。
- 新しい証明書の SHA-256: `563754b164de0d4209191f728ebb26644d53b0fbc0a47d5c8eb6a327b5dbe8f8`
- **Android 9 以降**では、アップデート後はこのキーで署名された APK のみインストールできます。公開キーで第三者が作成した APK で上書きすることはできません。
- **Android 7〜8** は新しいキーを読み取れないためこの保護を受けられませんが、インストールとアップデート自体はそのまま行えます。
- APK は GitHub Releases および Obtainium からのみ入手してください。

## 新機能

- **バトル設定フォルダー**
  - バトル設定をフォルダーにまとめて、一覧やランチャーで開閉できます。
  - 選択モードの「**フォルダへ移動**」で移動でき、エクスポート・インポート時にフォルダーも一緒に保存されます。[説明](../scripts/Battle-Config-Folders-JA.md)
- **ターン制限撤退**
  - **撤退して再開** の 1 つの設定で、全滅時撤退と N ターン到達時撤退の両方を設定します。グローバルの「撤退を有効にする」は廃止しました。
  - N 回連続で撤退したときに停止させることができます（`1–99` 回）。
  - 終了画面に `N 回撤退しました(全滅 a 回、ターン制限 b 回)` が表示されます。[説明](../scripts/Turn-Limit-Retreat-JA.md)
- **敵配置ごとのターゲット指定**
  - 6 体配置（`t4`〜`t9`）とレイド配置（`tR`、下 1 行目 `tA`〜`tC`、下 2 行目 `tD`〜`tF`）を指定できます。`t1`〜`t3` は従来どおりです。
  - スキルメーカー左上のオレンジ色の **ターゲット設定** ボタンから 3体 / 6体 / レイド 画面を開いて選択します。[説明](../scripts/Enemy-Layout-Targets-JA.md)
- **カードの優先順位 ウェーブ・ターン別方式**
  - 方式（相性/サーヴァント）とサーヴァント優先順位の使用をウェーブ・ターン項目ごとに設定できます。概要表示も項目ごとの方式に合わせて表示されます。[説明](../scripts/Card-Priority-JA.md)
- **KR 未実装サーヴァントの韓国語検索**
  - サポート画像検索で、韓国サーバーに未実装のサーヴァントを韓国語名で検索できます。[説明](../scripts/Servant-Number-Portraits-JA.md)

## 変更された機能

- **サーヴァントカード確認の自動判定**
  - 「サーヴァントカードアイコン確認をスキップ」オプションを廃止しました。バトル設定を確認し、必要なときだけ自動でチェックをオンにします（サーヴァント方式、サーヴァント優先、ブレイブチェイン、NP 一致シャッフル、ハクノシャッフル、カード枚数開始）。
  - バトル設定画面に判定結果が 1 行で表示されます。
  - 「サポートを自分のサーヴァントと同様に扱う」を **「サポートアイコン確認をスキップ」** に改名しました（その他の設定 → バトル）。
- **攻撃順の直接指定**: 枠を **未選択**（`p`）にするとカードの優先順位に従って埋めます。[説明](../scripts/Direct-Cards-JA.md)
- **スキル自動強化**: 10/10/10 になってサーヴァントの選択が解除されると停止します。[説明](../scripts/Auto-Skill-Level-JA.md)
- **ウィークリーミッション（JP）**: `千手千眼` クエスト名を文字で読み取れない場合、名前画像で確認します。
- **翻訳**: グランドサポートの「**通常礼装＆報酬アップ(絆/FP/QP/EXP)礼装の両方に一致**」オプションを韓国語で表示します。
- オリジナル FGA の Play ストア・寄付・Wiki 関連ファイルと未使用リンクを整理しました。

## 既知の制限

- **Chaldea 取り込み**はまだ `t1`〜`t3` のみ生成します。6 体・レイドクエストは「**エネミーターゲット情報を無視**」をオンにして取り込んでください（[#162](https://github.com/puruuun/FGA-Modified/issues/162)）。
- レイド下 2 行目の左・中央（`tD`・`tE`）の位置は推定値です。ずれる場合はお知らせください。
- **分割画面タッチ**: 画面分割で使用中に FGA が実行されていると、他のアプリのタッチが途切れることがあります（[#119](https://github.com/puruuun/FGA-Modified/issues/119)、[#120](https://github.com/puruuun/FGA-Modified/issues/120)）。
