# 1.6.2 — 서포트 가져오기·판독·퀘스트 시작 보완

정규판 **1.6.2 / 3089**입니다. 1.6.1 이후 개발 베타의 개선과 아래 수정을 포함합니다. 기존 수정판 패키지와 서명을 유지합니다.

- **칼데아 서포트 가져오기(beta.8–9)**: 체크는 기본 꺼짐입니다. 프렌드가 정확히 1명인 편성의 서번트·장착 예장·스킬·어펜드·보구 조건을 미리 보고 확인한 뒤 적용합니다. 저장 이미지·내장 이미지·Atlas 다운로드 순서로 찾고 내장 이름을 바꾸지 않습니다. [설명](../scripts/Chaldea-Import-KR.md).
- **서포트 점수(beta.1–4)**: 그랜드 +16의 2340 화면 대응과 일본판 +62/+16 판독을 보강했습니다. 숫자 영역 분리, 잘림·충돌 거부와 해상도별 템플릿을 적용하며 애매한 값은 인정하지 않습니다. 한국판 기존 경로를 유지합니다.
- **인연 판독(beta.5–6, beta.9)**: 합의 실패 뒤 다수결과 같은 화면의 기본값 확인을 보완합니다. 마지막 두 non-Unknown 판독이 같아야 합산하며 MAX의 연속 화면 조건은 유지합니다. 조건을 만족한 만장일치·공통 기본값 경로도 포함합니다. [설명](../scripts/Bond-Tracking-KR.md).
- **주간 루트(beta.7, beta.9)**: 목록 스크롤 막대와 정지 프레임으로 양끝을 판단합니다. 실제 태블릿 양끝 캡처를 추가했고, 지도는 세로로만 끌어 목표 원점에 접근하며 실제 이동 비율을 보정합니다. [설명](../scripts/Weekly-Mission-Route-KR.md).
- **어펜드 강화(beta.4, beta.9 및 이번 정규판)**: 태블릿 9→10의 다음 숫자 영역, 2→3 판독을 보완했고 KR·JP의 1→2부터 9→10까지 새 와이드 표본과 BlueStacks 7→8을 검증했습니다. 합의와 다음=현재+1 조건을 유지하며 잠긴 어펜드를 해방하지 않습니다. [설명](../scripts/Auto-Skill-Level-KR.md).
- **서번트 변경 시 재림 구분 초기화**: 선호 서번트 집합이 바뀔 때 보구 이름 선택을 없음으로 바꿉니다. 동일한 선택을 확인할 때는 유지합니다. 칼데아 가져오기에도 적용합니다. [설명](../scripts/Ascension-Select-KR.md).
- **보구 Lv.1 이상 제거**: 최소 레벨 목록은 Lv.2–5입니다. 저장된 1은 판독 꺼짐으로 읽고, 칼데아 프렌드 Lv.1도 판독을 끄되 저장 최소값은 유지합니다. [설명](../scripts/Support-NP-Level-KR.md).
- **파티 확인이 생략되는 퀘스트**: 서포트 선택 뒤 3초 안에 파티 화면이 확인되지 않으면 파티·아이템 제어와 Start 탭을 건너뜁니다. 확인한 버튼의 변경·복구 실패는 계속 안전하게 중단합니다. [설명](../scripts/Quest-Items-KR.md).

소유자는 beta.9에서 칼데아 가져오기·태블릿 2→3·트라움 탐색·인연·점수를 확인했습니다. 이번 정규판의 추가 수정은 저장 화면 기반 기기 QA와 단위 테스트로 검증합니다. 실제 강화와 전투 실행은 자동 검증에서 수행하지 않습니다. PR 검토·병합 후 기획자가 main에서 다시 빌드하여 배포합니다.
