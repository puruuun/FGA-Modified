# 1.6.2 — Support Import, Reading & Quest Start Improvements

This is stable release **1.6.2 / 3089**. It includes beta improvements since 1.6.1 and the fixes below. Retains the existing modified build package ID and signing.

- **Chaldea support import (`beta.8–9`)**: Checkbox is off by default. Previews and confirms Servant, equipped CE, Skill, Append, and NP conditions for a formation with exactly 1 friend before applying. Searches in order—saved images, built-in images, Atlas download—without changing built-in names. [Guide](../scripts/Chaldea-Import-EN.md).
- **Support score (`beta.1–4`)**: Improved Grand `+16` support on 2340-width screens and JP `+62/+16` reading. Applies digit-region separation, truncation/collision rejection, and per-resolution templates, rejecting ambiguous values. Preserves the existing KR path.
- **Bond reading (`beta.5–6`, `beta.9`)**: Supplements failed consensus with majority vote and same-screen default confirmation. Requires the last two non-Unknown readings to match before summing, while retaining the consecutive-screen rule for MAX. Also covers unanimous and common-default paths when conditions are met. [Guide](../scripts/Bond-Tracking-EN.md).
- **Weekly route (`beta.7`, `beta.9`)**: Detects both ends of the list using the scrollbar and static frames. Added real-tablet end-of-list captures, and map dragging moves vertically only to approach target origins while calibrating actual movement ratios. [Guide](../scripts/Weekly-Mission-Route-EN.md).
- **Append enhancement (`beta.4`, `beta.9`, and this stable release)**: Improved tablet 9→10 next-digit region and 2→3 reading, and verified new wide samples from 1→2 through 9→10 on KR/JP plus BlueStacks 7→8. Retains consensus and `next = current + 1` checks and never unlocks locked appends. [Guide](../scripts/Auto-Skill-Level-EN.md).
- **Reset ascension distinction when Servant changes**: Clears the NP-name selection to none when the preferred Servants set changes. Preserved when confirming the same selection. Also applies to Chaldea import. [Guide](../scripts/Ascension-Select-EN.md).
- **Removed NP Lv.1+**: The minimum level list is `Lv.2–5`. A saved `1` is read as checking disabled, and Chaldea friend `Lv.1` also turns checking off while keeping the saved minimum value. [Guide](../scripts/Support-NP-Level-EN.md).
- **Quests skipping party confirmation**: If the party screen is not confirmed within 3 seconds after support selection, skips party/item control and tapping Start. Failures to change or restore confirmed buttons still stop safely. [Guide](../scripts/Quest-Items-EN.md).

The owner verified Chaldea import, tablet 2→3, Traum probe, bond, and scores on `beta.9`. Additional fixes in this stable release are verified by stored-screen device QA and unit tests. Live enhancement and battle execution are not performed in automated verification. After PR review and merge, the planner rebuilds from `main` and distributes.
