# 1.6.4 — Upstream FGA v3065 Sync (Expanded Support Screen Region & Server Auto-Detect Error)

This is stable release **1.6.4 / 3091**. Retains the existing modified build package ID and signing.

- **Expanded support screen recognition region on non-standard resolutions**: Incorporates upstream FGA v3065 changes expanding the recognition region (`notFoundRegion`) for the "no supports found" notice on the support screen so it is recognized reliably even on non-standard resolutions.
- **Guidance message when server "Auto-detect" fails**: Improved so that when **Game Server** is set to **Auto-detect** and the running FGO app cannot be detected, an explicit guidance message is shown instead of assuming the NA server, with Korean and Japanese translations added.
- **Build tools & internal updates**: Incorporates the upstream FGA v3063–v3065 sync (expanded CN server package list and Gradle 9.8.2 update).
