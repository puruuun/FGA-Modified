# FGA(mod) 1.2.1

This is a stable release incorporating beta improvements (`1.2.0-beta.1` ~ `1.2.1-beta.5`) since stable release 1.1.0.

## Changes

- **Expanded support image search & save**: Under **More options → Additional features → Search and save support images**, search and save Servants and Craft Essences by collection number or partial official name. Names use the official name for the FGA language setting first, falling back to the Japanese name if unavailable.
- **Search by ascension and hidden names**: Find Servants by ascension costume names and hidden names in addition to their base name (e.g., `"Mélusine"` → No.312, No.390).
- **Automatic image server selection**: Removed the server selection option. Uses the first image found in `JP → KR → NA` order. KR- and NA-exclusive CEs can also be saved.
- **KR campaign CE support**: Searches no longer fail when encountering campaign CEs that use long collection numbers.
- **Stabilized legacy folder migration**: When moving numbered folders, verifies whether files actually moved even if a storage error occurs.
- **Reading improvements**: Reads small bond point digits on JP, outlined support score digits on KR, and white NP `Lv.` indicators on KR.
- **Save support score diagnostics**: Enabling **More options → Advanced → Save support score diagnostics** saves the score region image and decision evidence (JSON) under `diagnostics/support-score/` in the FGA storage folder each time a support is checked. Off by default. Saves up to 500 candidates per run. Never captures screens containing friend names or friend codes—only the score region and surrounding margin. Please attach this folder when reporting reading issues.
- **+16 condition is JP server only**: Grand score (`+62/+16` compound display) currently exists only on the JP server. Leaving +16 enabled on other servers causes endless refreshes because the condition can never be met, so the +16 condition is ignored on servers without Grand score. Shows a notice once per run and displays a "Currently JP server only" note under the +16 switch on the support settings screen. The switch itself can still be toggled.
- **Obtainium beta channel discontinued**: Obtainium provides stable releases only.

## Installation & Updates

- Version: **1.2.1 / 3083**
- APK: **FGA-mod-1.2.1-arm.apk** (accompanied by SHA-256 file `FGA-mod-1.2.1-arm.apk.sha256`)
- App name: **FGA(mod)**
- App ID: `io.github.fate_grand_automata.cardcount`
- Supports Android 7+, ARM 32/64-bit

Installs as an update over existing stable 1.1.0 with the same package ID and signing key. Can be updated via the Obtainium stable configuration.

**Do not install APKs downloaded from anywhere other than GitHub Releases and Obtainium.** Because the stable build is signed with the published signing key, APKs obtained elsewhere cannot be verified against tampering.

`FGA(beta)` is a separate app, and its storage folder and settings are not transferred automatically.
