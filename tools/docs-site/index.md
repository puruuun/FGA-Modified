# FGA(mod) 사용 설명서

이 사이트는 **FGA(mod)** 사용 설명서입니다. FGA(mod)는 *Fate/Grand Order*의 반복 주회를 도와주는 Android 앱 [Fate/Grand Automata](https://github.com/Fate-Grand-Automata/FGA)의 수정판입니다.

- 화면을 읽고 탭만 대신합니다. 게임 데이터나 통신은 건드리지 않습니다.
- Android 7 이상에서 동작하고, 루트 권한이 필요 없습니다.

!!! note "테스트 범위"
    KR(한국)·JP(일본) 서버에서만 테스트했습니다. 다른 서버의 동작은 확인하지 않았습니다.

## 설치

| 종류 | 받는 곳 |
|---|---|
| **정규판** | [최신 정규판 (GitHub Releases)](https://github.com/puruuun/FGA-Modified/releases/latest) |
| 개발 베타 | [전체 릴리스 목록](https://github.com/puruuun/FGA-Modified/releases)에서 `beta` 표시가 붙은 항목 |

- 개발 베타는 정규판과 **다른 앱**(`io.github.fate_grand_automata.beta`)으로 설치됩니다. 정규판의 설정은 옮겨지지 않습니다.
- GitHub Releases와 Obtainium 외의 곳에서 받은 APK는 설치하지 마세요.

위쪽 **기능 설명서** 탭에 기능별 사용법이 있습니다. 새 기능이 추가되면 설명서도 이 사이트에 자동으로 추가됩니다.
