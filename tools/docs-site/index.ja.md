# FGA(mod) ユーザーマニュアル

このサイトは **FGA(mod)** のユーザーマニュアルです。FGA(mod) は *Fate/Grand Order* の周回を補助する Android アプリ [Fate/Grand Automata](https://github.com/Fate-Grand-Automata/FGA) の修正版です。

- 画面を読み取り、タップ操作のみを代行します。ゲームデータや通信内容には一切手を触れません。
- Android 7 以降で動作し、root 権限は不要です。

!!! note "テスト範囲"
    KR（韓国）・JP（日本）サーバーに限定してテストしています。他のサーバーでの動作は確認していません。

## インストール

| 種類 | 入手先 |
|---|---|
| **正式版** | [最新の正式版 (GitHub Releases)](https://github.com/puruuun/FGA-Modified/releases/latest) |
| 開発ベータ版 | [リリース一覧](https://github.com/puruuun/FGA-Modified/releases) の `beta` が付いたバージョン |

- 開発ベータ版は正式版とは**別のアプリ**（`io.github.fate_grand_automata.beta`）としてインストールされます。正式版の設定は引き継がれません。
- GitHub Releases および Obtainium 以外から入手した APK はインストールしないでください。
- 詳しいインストール手順と初期権限の設定は[インストール案内](scripts/Installation-JA.md)をご確認ください。
