# FGA(mod) User Manual

This site is the user manual for **FGA(mod)**, a modified edition of [Fate/Grand Automata](https://github.com/Fate-Grand-Automata/FGA) that helps automate *Fate/Grand Order* farming.

- It only reads the screen and performs taps. It never modifies game data or network traffic.
- Runs on Android 7 and later, without requiring root access.

!!! note "Testing scope"
    Testing is limited to the KR (Korean) and JP (Japanese) servers. Behavior on other servers has not been verified.

## Installation

| Build | Download |
|---|---|
| **Stable** | [Latest stable release (GitHub Releases)](https://github.com/puruuun/FGA-Modified/releases/latest) |
| Development beta | Entries marked `beta` in the [all releases list](https://github.com/puruuun/FGA-Modified/releases) |

- Development betas install as a **separate app** (`io.github.fate_grand_automata.beta`). Settings from the stable build are not migrated automatically.
- Do not install APKs downloaded from anywhere other than GitHub Releases and Obtainium.
- See the [Installation Guide](scripts/Installation-EN.md) for installation and initial permissions, [Log Collection Setup](scripts/Log-Collection-Setup-EN.md) to enable log collection, and [Import Original FGA Data](scripts/Original-FGA-Import-EN.md) to migrate from original FGA.
