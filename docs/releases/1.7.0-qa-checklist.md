# 1.7.0 정규판 최종 QA 체크리스트

기준: `1.7.0-beta.12` / `1007012` (`main` `2e971be3`). 직전 정규판 `1.6.7` / `3094`.

범위는 1.6.7 이후 들어온 기능과 수정 전체입니다. 1.6.8 베타(스킬 레벨 판독)도 1.7.0에 포함됩니다. 각 항목의 근거는 `docs/qa/1.6.8-beta.*`, `docs/qa/1.7.0-beta.*` 검증 기록입니다.

## 표기와 진행 방법

**기기:**
- **B21** = 블루스택 21:9 (2560×1080)
- **B16** = 블루스택 16:9
- **T** = 태블릿 HA29GCWH (분할 화면, 16:10)

**서버:** JP, KR

- 체크는 `[x]`로 바꿉니다. 실패한 항목에는 기기·서버·시각과 함께 `map.log`, `SkillLevel` 로그나 캡처 경로를 적어 주세요.
- **★ 항목은 꼭 확인하세요.** 이번 베타 동안 한 번도 실기에서 확인되지 않았거나, 마지막 베타에서 바뀐 것입니다. 나머지는 이미 베타에서 확인했거나 저장 화면 QA로 덮이므로 가볍게 다시 보면 됩니다.
- 에이전트는 게임을 조작하지 않습니다. 실기 항목은 모두 소유자가 실행합니다.

## 0. 설치·업데이트

- [ ] ★ **업데이트 설치와 설정 유지 (T 또는 B):** 1.6.7 정규판이 깔린 상태에서 1.7.0 베타 또는 정규 APK를 업데이트로 설치합니다.
  - 기존 전투 설정, 커맨드, 서포트 설정이 그대로 남아야 합니다.
  - 카드 개수 조건이 새 조건 줄 UI에 맞게 표시돼야 합니다. 1.6.7에서 쓰던 카드 수와 색 최소 수가 줄로 나와야 합니다.
- [ ] **첫 실행 앱 언어:** 기기 언어에 맞는 앱 언어로 시작해야 합니다. 한국어 기기면 한국어입니다.
- [ ] ★ **정규 APK에서 베타 전용 항목 숨김:** 정규 APK에는 스킬 강화의 **레벨 판독만 확인 (강화하지 않음)** 체크박스가 보이지 않아야 합니다.

## 1. 게임 영역 (더 보기 → 추가기능 → 게임 영역)

- [ ] ★ **T, KR — 스크린샷 자동 맞춤:**
  1. 메인 화면을 팝업 없이 띄웁니다.
  2. **사용자 지정**을 고르면 그 안에 **스크린샷으로 자동 맞춤** 버튼이 있어야 합니다.
  3. 버튼을 누르면 결과가 왼쪽 약 1048, 게임 너비 약 1991로 나와야 합니다.
  4. 저장하면 "자동 맞춤 MM-dd HH:mm" 프리셋으로 바뀌고, 미리보기의 초록 테두리가 게임 그림 가장자리와 맞아야 합니다.
- [ ] ★ **T, JP — 스크린샷 자동 맞춤:** 같은 순서로 확인합니다. 서버 설정은 자동 감지로 둡니다.
- [ ] ★ **B21, JP·KR — 스크린샷 자동 맞춤:** 결과가 전체 화면에 가깝게(여백 0~1) 나와야 합니다.
- [ ] ★ **자동 맞춤 실패 안내:** 메인 화면이 아닌 곳, 팝업이 열린 상태, 스크립트 실행 중에 누르면 저장 없이 사유가 나와야 합니다.
- [ ] **T — 미리보기:**
  - 스위치를 켜면 빨간 테두리(사용자 영역)와 초록 테두리(인식 영역)가 보이고, 좌표를 바꾸면 바로 갱신돼야 합니다.
  - 스크립트를 시작하면 테두리가 사라지고, 실행 중에는 다시 켤 수 없어야 합니다.
- [ ] **프리셋:** 추가, 선택, 삭제가 되고, 앱을 다시 열어도 유지돼야 합니다.
- [ ] **T — 원본 스크립트 동작:** 자동 맞춤으로 저장한 프리셋에서 원본 FGA 스크립트와 수정판 스크립트가 모두 정상이어야 합니다. 예: 전투 1회, 스킬 레벨 읽기.

## 2. 주간 미션 경로

beta.10에서 B21 JP, B21 KR, T JP의 탐색 시험이 246/246으로 통과했습니다.

- [ ] ★ **T, KR — 탐색 시험 전체:** `map.log` 한 파일에 전체 실행이 남아야 합니다. 이 조합은 아직 실행하지 않았습니다.
- [ ] ★ **T, JP·KR — 자동 맞춤 프리셋으로 탐색 시험:** 1번 항목에서 저장한 프리셋으로 탐색 시험을 다시 돌립니다.
- [ ] **실제 주간 실행 (B21 또는 T, 1회):**
  1. 미션 선택 체크박스로 몇 개만 고르고 실행합니다.
  2. 고른 미션만 돌고, 보물창고 초급이 마지막에 메인 → 게이트 → 요일 순서로 방문돼야 합니다.
- [ ] **경로 설정 UI:**
  - 수동 미션에는 체크박스가 없어야 합니다.
  - 체크를 끈 미션은 회색으로 남아야 합니다.
  - 빈 경로에서는 실행되지 않아야 합니다.
  - **주간 미션 경로 활성화**를 끄면 시작 창 버튼이 숨겨져야 합니다.
- [ ] **목록 끝 정지:** 주간 목록 스크롤이 위·아래 끝에서 멈춰야 합니다.

## 3. FP 소환 자동 판매

- [ ] ★ **"뒤에서 1번째" (맨 마지막) 설정:** 하쿠노 배너와 일반 FP 배너가 함께 있을 때, 판매 후 복귀해서 같은 배너에서 소환이 이어져야 합니다.
- [ ] ★ **"뒤에서 2번째" 설정:** 같은 상황에서 판매 후 복귀해 소환이 이어져야 합니다.
- [ ] ★ **잘못된 위치 설정:** 소환하지 않고 "FP 배너 위치 설정을 확인하세요"로 멈춰야 합니다.
- [ ] **판매 목록 끝:** 판매 목록이 아래 끝에서 멈춰야 합니다.
- [ ] **FP 결과 화면:** FP 결과 화면에서 다른 스크립트를 재생해도 FP가 시작되지 않아야 합니다.

## 4. 스킬·어펜드 자동 강화

체크 모드(**레벨 판독만 확인**)는 베타 APK에서만 됩니다.

- [ ] ★ **어펜드 체크 모드 (KR·JP 각각 16:9와 wide, 강화하지 않음):**
  - `WrongScreen` 없이 시작해야 합니다.
  - 특히 2번, 4번 칸의 값과 종료 요약이 실제 레벨과 맞아야 합니다.
- [ ] ★ **스킬 체크 모드, KR 21:9 9→10:** 종료창에 `dialog=9(inferred)`가 나와야 하고, 8→9는 계속 `match`여야 합니다.
- [ ] **재료 부족 칸:** 확인창 없이 끝나고 다음 칸으로 넘어가야 합니다.
- [ ] **실제 강화 1칸 (재료 여유가 있을 때, 선택 사항):** 목표 레벨에서 멈춰야 합니다.

## 5. 전투

- [ ] ★ **커맨드 시작 조건 줄 UI:**
  - 줄 추가와 삭제가 되고, 줄이 1개면 ✕가 숨겨져야 합니다.
  - 색 칩을 누르면 쓰지 않은 색만 나와야 합니다.
  - AND/OR 토글은 줄이 2개 이상일 때만 보여야 합니다.
- [ ] ★ **커맨드 시작 시점:** 아래 조합마다, 실제로 시작한 턴이 요약 문구와 맞아야 합니다.
  - 전체만
  - 색만(AND)
  - 색 OR 조합
  - 전체 + 색
  - 두 번째 대상
- [ ] **대기 알림:** 전체 줄이 없으면 최소 카드 수가 `-`로 표시돼야 합니다.
- [ ] **카드 우선순위:**
  - 항목을 10개까지 추가할 수 있어야 합니다.
  - 구분 기준 웨이브/턴을 바꾸면 표시가 `웨이브 n`/`턴 n`으로 바뀌어야 합니다.
  - 서번트 방식에서는 서번트 목록이 나오고, 다른 세 설정이 회색이 돼야 합니다.
- [ ] **서번트 방식 클릭 순서:** 실제 클릭 순서가 목록과 같아야 합니다. 전투 로그로 확인합니다.
- [ ] **카드 조건 시작 + 턴 기준:** 둘을 함께 쓰면 시작한 턴이 `턴 1`이어야 합니다.
- [ ] **공격 순서 직접 지정:** 같은 색 카드가 두 장 이상이면 상성상 약점 카드가 먼저 골라져야 합니다.
- [ ] **하쿠노 셔플:**
  - 편집기에서 만든 커맨드가 `aH{…}`로 저장되고 실행돼야 합니다.
  - 직접 입력한 `ah{…}`, `a{…}`는 입력 오류로 거부돼야 합니다.
  - 색 조건(예: `1b2|1q2`)을 만족하면 셔플을 멈춰야 합니다.
  - NP 부족 창이 닫혀야 합니다.
  - 대화상자 문구(최소/최대 셔플 횟수, N 장 이상)가 맞아야 합니다.
- [ ] **인연 레벨 10 이상 정지:** 결과창에 칸 표시가 없어도, 인연 레벨이 10 이상으로 오른 캐릭터가 있으면 MAX 정지가 동작해야 합니다.
