상태: **정규 APK·자동 검증·출시 문서 준비 완료. 소유자의 태그·GitHub Release 게시 대기.** 정규 APK는 설치하지 않았고 게임을 조작하지 않았다.

## 대상

- 정규판 `1.4.1` / `3085`, `io.github.fate_grand_automata.cardcount`, 앱 이름 `FGA(mod)`.
- 검증 베타 `1.4.1-beta.1` / `1004101`, `io.github.fate_grand_automata.beta`, 앱 이름 `FGA(beta)`. 보고서: `docs/releases/beta/FGA-beta-1.4.1-beta.1-validation.md`.
- 제품 코드와 버전 값은 같은 커밋 `b73bfa8b33ca30b1866f4c3b5c81294d60669f4c`에 있다. 정규판과 베타의 앱 코드는 같고 빌드 정책(시험 모드 숨김)만 다르다.
- 1.4.0 이후 변경: 0007 §20 D-48(재소환을 원본 FGA 경로로), D-49(UI 안내 문구 3개 삭제).

## 변경

- FP 자동 판매 뒤 재소환이 처음 소환과 똑같은 원본 FGA 탭 경로를 쓴다. 재소환 확인창 워터마크 검사와 `ResummonConfirmFailed` 정지는 없어졌다. 판매 뒤 가득 참 처리, 배너 복귀 확인, 정규판의 시험 모드 숨김은 1.4.0과 같다.
- 서포트 이미지 검색·저장 창 설명과 클래스 스코어 +16 판독 아래 문구 두 개를 지웠다. +16 판독 동작은 같다.

- 서포트 재림 구분(ascension select) 기능: 소유자가 실제 게임에서 직접 써 보고 문제없음을 확인했다.
