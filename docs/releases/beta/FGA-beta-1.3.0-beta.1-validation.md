## 선택한 값과 근거

- **임계값 `NP_NAME_SIMILARITY = 0.85` (D-6).** 맞는 보구는 0.9999 이상, 틀린 보구는 최고 0.588이었습니다. 0.85는 두 값 사이의 넓은 틈에 있어 0.80까지 내릴 필요가 없습니다.
- **띠 `noblePhantasmBand`(D-1):** 행 기준 1440p x 500, 폭 1044(`nameRegion`의 오른쪽 끝까지), 세로는 `nameRegion`과 같음. 측정: 그랜드 행 보구 패널 왼쪽 772, 카드 아이콘 왼쪽 897, `Lv.` 왼쪽 1507(1440p 화면 x, 행 x = 76 기준 상대 위치 821 / 1431).
- **그랜드 아이콘 x = 821:** 측정값(행 1·2 모두 720p에서 x 449 = 1440p 897).
- **일반 행 아이콘 x = 528:** **측정하지 않은 추정값입니다.** 설계의 패널 이동량(1920 폭 기준 220px = 1440p 293px)으로 그랜드 값에서 뺐습니다. 일반 행 화면으로 확인해야 합니다(아래 요청 목록).
- **세로 여백 = 10(1440p):** 처음 6으로 잡았는데, 720p 측정에서 카드 아이콘이 `Lv.`보다 약 4px 위로 올라와 있어 6으로는 아이콘 윗부분이 잘립니다. 10(720p 5px)으로 바꿨습니다.
- **가로 배율 검색 (D-7):** 추가하지 않았습니다. 이번 fixture는 모두 그랜드 행이고 같은 레이아웃이라 배율 차이 사례가 없었습니다. 일반 행 화면에서 불일치가 보이면 그때 추가합니다.

## 확인된 사항 (설계 외)

- **보구 이름이 같은 다른 서번트가 함께 맞습니다.** 妖精騎士ランスロット도 같은 "今は知らず、無垢なる湖光" Arts 보구입니다. 그래서 설정에서 서번트 선호와 함께 고르는 것이 필요합니다(사용 안내에 적었습니다).
- `Lv.` 위치는 보구 이름 길이에 따라 행마다 다릅니다(예: ビーマ 行의 `Lv.`는 메리·멜뤼진 행보다 왼쪽). 그래서 이미지 메이커는 고정 좌표 대신 행마다 `Lv.`를 찾습니다. 오프라인 자르기에서 이 차이 때문에 한 번 잘못 잘라 버렸고, 그 템플릿은 저장소에서 뺐습니다.

## 소유자 테스트 절차 (퀘스트 시작 전 정지)

1. 서포트 선택 화면에서 왼쪽 아래 재생 버튼 → Support Image Maker 실행.
2. 이름 지정 화면의 **보구 이름 (재림 구분)** 칸에 그림이 보이는지 확인. 맞는 것만 체크하고 이름을 씁니다(예: `メリュジーヌ 今は知らず`).
3. 배틀 설정 → 서포트 → 선호 → **서번트 선호** 아래 **재림 구분 (보구 이름)** 에서 같은 이름을 고릅니다. 서번트 선호도 메리·멜뤼진으로 맞춥니다.
4. 선호 서포트로 실행하고, 로그 `FGA.SupportNp`에서 맞는 행 `matched: true`를 확인합니다.
5. 퀘스트 시작 화면이 나오면 **정지**합니다(Quest Start 누르지 않기).
