# FGA 1.4.0-beta.4 검증 보고서

상태: 스크롤 후 별 수를 읽지 못해 아무것도 선택하지 않던 결함 수정, 진단 로그 추가. 전체 단위 테스트, 기기 QA 전 스위트, Main CI 통과. BlueStacks에 업데이트 설치.

- 베타: `1.4.0-beta.4` / `1004004`. 정규판 `1.2.1` / `3083` 유지. `FpSellPolicy.DEFAULT_DRY_RUN = true` 유지.
- 근거: 설계 0007 §11 (D-22, D-23). 소유자 보고: 일섭 BlueStacks, 1~4★ 서번트 켬·경험치 끔·NEW!만 켬·시험 모드 켬에서 첫 화면 7칸만 고르고, 스크롤 후에는 NEW! 1★이 많이 보여도 선택 0.

## 원인

프레임 46(`docs/reference-images/Jp/fp-sell/46.png`, 소유자 1920×1080 원본을 1280×720으로 줄임)을 운영 판독기로 읽었습니다(기기 QA `page` 뷰). 막는 필드는 **`stars`** 입니다.

|---|---|---|---|---|---|---|---|
| 맨 윗줄 7칸 | (격자 위 필터) | - | - | - | - | - | 평가 안 함(`gridTop`) |
| 2줄 1~7열 | Servant | 1:0.0 / 2:0.0 | null(0) | 0.90~0.95 true | Unlocked / false | false | **거절** |

| 4줄 1~7열 | Servant | 1:0.0 / 2:0.0 | null(0) | 0.88~0.90 true | Unlocked / false | false | **거절** |

- 별 줄 템플릿(`fp_sell_rarity1~4*.png`, 60×14)은 KR 카드 그림 위에서 잘라 **별 뒤의 그림 픽셀을 함께 담고** 있어, 그림이 다른 칸에서는 점수가 0.0이 됩니다. 별 수를 못 읽으면 `Cell.category == null`이라 `FpSellPolicy.select`가 거절합니다. 잠금·선택·종류·NEW!는 모두 정상이었습니다.
- "스크롤 후에만" 생기는 이유: 스크롤 위치와는 무관하고 **칸 그림** 때문입니다. 첫 화면은 4★ 칸이었고 4★ 템플릿이 그 그림에서 맞은 것으로 추정합니다(첫 화면 원본은 없음). 1★ 칸은 KR 27번 한 칸 외에는 어떤 서버에서도 검증된 적이 없었습니다(기존 fpSell 기대값의 별 수는 전부 KR).
- 의심 항목 점검: 격자 위·아래 필터는 맨 윗줄만 걸렀고, NEW! 탐색 띠·라벨 매칭·`isSevenColumns`·스와이프 루프는 문제가 아니었습니다. 부차 결함으로 NEW! 점수가 줄마다 0.866~0.949로 흔들려 기준 0.88에 걸리는 칸이 있었습니다.

## 수정

- **D-22 별 수**: 별 한 개(12×12, `En/fp_sell_rarity_star.png`)를 오른쪽부터 5칸에서 찾아 점수를 냅니다. 별 칸 0.55 이상, 마지막 별 다음 칸 0.40 이하(4★의 다섯째 칸은 0.50 이하), 이후 칸은 별이 아니어야 하며 아니면 `null`(선택 안 함)입니다. 기존 별 줄 템플릿이 확실히 읽으면(0.9, 2위와 0.08 차) 그대로 따르고, 못 읽은 서번트 칸에만 새 방식을 씁니다. 경험치 카드는 기존 그대로입니다. 프레임 46의 별 칸 점수: 첫 칸 0.77~0.94, 다음 칸 0.0~0.40.
- **NEW! 기준** 0.88 → 0.85(0.80~0.85 판별 불가 유지). 실제 표시 0.858 이상, 표시 없는 칸은 검색 하한 0.75 미만.
- **격자 위 가장자리(NEW! 표시가 잘릴 수 있는 칸)는 보수적으로 처리**합니다: 읽지 않고 선택하지 않습니다(기존 필터 유지). 프레임 46의 맨 윗줄 7칸이 그렇습니다. 맞는 칸은 스크롤 후 다른 위치에서 다시 읽힙니다. NEW! 표시를 다른 방식으로 읽어 되살리는 길은 택하지 않았습니다(잘린 표시는 읽을 수 없기 때문).
- 안전 규칙은 그대로입니다: 잠금·선택 불가·Grand·PARTY·서번트/경험치가 아닌 칸은 선택하지 않고, 잠금 불확실 칸은 실제 판매에서 선택하지 않으며(시험 모드만 허용), 칸을 다시 누르지 않습니다. `FpSellPolicy.select`는 바꾸지 않았습니다.
- **로그**: 태그 `FpSell`(`ScriptLog.FpSell` → `ScriptMessages` → Timber, 베타 빌드에서도 INFO 출력). 평가한 칸마다 한 줄(쪽, 줄·열, kind, 별 수와 점수, NEW 판독과 점수, 잠금, 제외, 선택, 판정 또는 거절 이유), 쪽마다 요약과 스와이프 결과, 시작 옵션, 정지 단계와 이유, 시험 모드 완료. `FpSellPolicy.decision`이 거절 이유를 말하고 `select`와 일치함을 표로 검증합니다.
- 버전 1.4.0-beta.4 / 1004004.
