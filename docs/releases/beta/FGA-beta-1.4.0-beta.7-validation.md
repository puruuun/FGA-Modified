# FGA 1.4.0-beta.7 검증 보고서

전체 단위 테스트·오프라인 기기 QA·Main CI 통과. APK 확인 및 BlueStacks 업데이트 설치 완료.
버전 `1.4.0-beta.7` / `1004007`, 패키지 `io.github.fate_grand_automata.beta`. 안정판 `1.2.1` / `3083`은 유지했다.
0007 §15 D-33~D-36을 적용했다.

## 변경 및 근거

- 임시 가입 카드에는 자물쇠가 없어 beta.6에서 19회 재탭하고 426으로 집계했다. JP `仮加入` 띠와 `仮加入サーヴァント` 본문을 최종 407칸 프레임에서 추출해 제외에 추가했다. KR 임시 가입 문구는 아직 원본이 없어 새 템플릿을 만들지 않았다.
- 목록 내 행·열을 스와이프 요청 거리와 다음 화면의 행 위상으로 추적한다. 겹친 다음 쪽에서 여전히 미선택인 이전 탭은 `tap-rejected`로 기록하고 선택 수와 잠금 불명확 수에서 한 번 빼며 다시 누르지 않는다. 같은 화면 위치도 연속으로 누르지 않는다. 탭 직후 확인 대기는 추가하지 않았다.
- 화면 전체의 0.995 비교를 없앴다. 행 y 목록이 ±12px(1440p) 이내로 두 번 연속 같거나 새 탭 없는 쪽이 5회 연속이면 종료한다. 겹침 스크롤·관성 억제·999칸 상한은 유지했다.
- 두 모드 모두 결정 후 최종 확인창과 양쪽 버튼을 검증한다. 시험 모드는 왼쪽 취소만 누르고 판매 화면 복귀를 확인한다. 실제 판매만 변환→완료 닫기로 간다. 선택 수 0이면 결정을 누르지 않는다.
- 판매 화면 닫기→공방→MENU→소환→제목 비교 및 왼쪽 최대 10회 탐색→FP 버튼 재소환을 진행한다. 시험 모드는 두 번째 가득 참 경고에서 판매 흐름·배너 복귀·재소환 확인 안내로 종료한다. 두 번째 경고가 없으면 성공 안내 대신 흐름 실패로 정지한다.
- 흐름의 버튼은 해당 템플릿을 찾은 영역만 누른다. 시험 모드 기본 켬, 실제 판매 허용/잠금 규칙은 유지했다. 수동 중단에도 `final-summary pages/taps/rejected/selected`를 남긴다.
- en/ko 안내와 위키를 최종 취소 방식으로 갱신했다. 오래된 일본어 3문구는 삭제해 최신 영어 원문으로 폴백한다.

## 단위 테스트

JDK 21.0.12.101, ANDROID_HOME 환경변수만 사용했다.

```text
./gradlew :app:testCiUnitTest :prefs:testCiUnitTest :scripts:test :libautomata:test :app:compileCiKotlin
BUILD SUCCESSFUL
```

app 177 + prefs 24 + scripts 270 = **471개 통과**, 실패·오류·skip 0. libautomata는 테스트 소스 없음.
거부 카드 영구 재탭 금지·수 보정, 요청 560px/실제 470px 겹침 식별, 같은 화면 위치 보호, ±12px 바운스 2회 종료, idle 5회 상한/리셋을 검사했다.
