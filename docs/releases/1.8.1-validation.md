# FGA(mod) 1.8.1 검증

- **버전:** 정규 **1.8.1 / 3102**
- **패키지:** `io.github.fate_grand_automata.cardcount`
- **범위:** 1.8.0 이후 `main`의 변경(1.8.1-beta.1~2와 #519).
  - 바뀐 기능: 긴 보구 이름의 서포트 보구 레벨(#495, JP), 스킬·어펜드 자동 강화의 아이콘 재선택 생략(#504), 마스터 스킬 메뉴 대기시간 설정(#496), 로그인 프렌드 포인트 기록(#511), Chaldea 내보내기 정리(#494)

- **기준 코드:** 베타 검증 `main` `c88e1432`(1.8.1-beta.2). 정규판 후보는 `main` `381d8cec`입니다.
  - 두 커밋 사이에 들어간 앱 코드는 #519(PR #520) 하나입니다.
  - 그 밖에는 테스트(PR #517), 문서, 그리고 PR #514(Rust 전환 준비용 `ISupportScoreReader`)의 병합과 되돌림(PR #518)입니다. 되돌린 뒤 `git diff 0585800b -- app/src scripts/src prefs/src libautomata/src`에 #519와 테스트 외의 차이는 없습니다.
- **베타를 건너뛴 것:** #519는 자체 베타 없이 정규판에 들어갑니다(소유자 결정, 2026-11-18). 저장된 로그 파일을 읽는 부분만 바뀌고, 검증자 두 명이 1.8.0 형식 파일이 이전과 같은 글자로 읽히고 쓰이는 것을 확인했습니다.

## 알려 둘 점

- 1.8.0 이하 버전에는 다른 FGA 앱의 루트 수집을 확인하는 기능이 없습니다. 1.8.1이 수집 중일 때 구버전이 루트 수집을 시작하면 최대 60초 겹친 뒤 1.8.1 쪽이 안내와 함께 멈춥니다.
- **로그인** 출처가 기록된 뒤 1.8.0 이하로 되돌리면 그 버전은 `outside-log.json`을 `outside-log.corrupt-<uuid>.json`으로 옮기고 빈 목록으로 시작합니다.
- 일본 서버 루트 설정을 끄면 다른 FGA 앱의 인증서도 사라지는 문제(#505)는 고치지 않기로 했습니다.
