## 변경 및 검증

1. 선호 서번트 집합 변경 시 재림 구분(NP 이름)을 공통 prefs 쓰기 경계에서 초기화합니다. 같은 집합의 순서만 바뀌면 유지합니다. 화면 선택·가져오기·collector·commit·삭제 경로를 단위 테스트했습니다.
2. 보구 최소 레벨 목록은 2–5입니다. 가져온 Lv.1은 체크를 끄고 저장 최소값을 유지하며, Lv.5는 켜고 5를 저장합니다. 모든 설정의 저장값 1은 getter/flow에서 체크 꺼짐으로 읽습니다. 재활성화 시 유효 기본값 5를 사용합니다. 영어·한국어 미리보기도 갱신했습니다.
3. KR/JP 서포트 선택 후 파티 화면을 최대 3초(300ms 간격) 확인합니다. 미확인 시 파티 선택·아이템·Start를 건너뛰고 `quest items: party screen not confirmed, skipped`를 기록합니다. 처음부터 Unknown이면 prepare는 반환하며, 확인된 토글 변경 실패는 계속 중단합니다. 우회·다른 서버 동작을 유지합니다. 화면 없음/지연 등장/정상 확인/실패 토글을 fake로 검증했습니다.
4. 어펜드 전용 임계값 0.62/0.63을 추가하고 배경 오독을 만드는 0.60을 제외했습니다. 일반 Skill 프로필은 그대로입니다. 현재 숫자 크롭 폭 64를 유지하며 x=-204→-206으로 이동했습니다. JP/KR 와이드에서 9 NCC 개선을 확인했습니다. 합의·신뢰도·다음=현재+1·9 fallback 안전 조건은 유지합니다.

프레임 19장의 수정 전후 및 **모든 프로필 원문·신뢰도**는 [판독 표](1.6.2-append-readings.md), [전체 JSON](1.6.2-append-readings.json)에 있습니다. 18개 업로드는 재표본화 자료, BlueStacks 창 캡처는 chrome 제거 자료로 표시했습니다. 생성 스크립트는 `tools/device-qa/normalize_append_0019.py`입니다.
