# FGA(mod) 1.5.0 검증 리포트

상태: **정규 APK·자동 검증·출시 문서 준비 완료. 소유자의 태그·GitHub Release 게시 대기.** 정규 APK는 설치하지 않았고 게임을 조작하지 않았다.

## 대상

- 정규판 `1.5.0` / `3086`, `io.github.fate_grand_automata.cardcount`, 앱 이름 `FGA(mod)`.
- 앱 코드는 베타 `1.5.0-beta.4` / `1005004`(`e1cbcd5d`)와 같다. 베타 값은 그대로 두었고 새 베타는 만들지 않았다. 버전 커밋은 `1d3ce395`.
- 1.4.1 이후 변경: 스킬·어펜드 스킬 자동 강화(0008) 추가. 사용법은 `wiki/scripts/Auto-Skill-Level-KR.md`.

## 변경

- 서번트를 고른 스킬 강화 / 어펜드 스킬 강화 화면에서 칸마다 목표 레벨까지 강화한다. KR·JP 전용.
- 설정 창은 열 때마다 모든 칸이 끔(0)이며 목표를 저장하지 않는다. 목표를 넘기지 않고, 잠긴 어펜드는 해방하지 않고 건너뛴다.
- 확인창에서 현재·다음 레벨을 모두 읽고 다음 = 현재 + 1일 때만 결정한다. 강화·취소 뒤 대기 0.4초.
- 이 기능은 빌드 종류로 막지 않으므로 정규판에서도 동작한다. 설명서와 README의 "베타 전용" 표기를 지웠다.
