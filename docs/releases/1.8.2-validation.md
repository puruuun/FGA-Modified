# FGA(mod) 1.8.2 검증

- **버전:** 정규 **1.8.2 / 3103**
- **패키지:** `io.github.fate_grand_automata.cardcount`
- **범위:** 1.8.1 이후 `main`의 변경(1.8.2-beta.1~20과 #750). 바뀐 기능과 고친 문제는 [릴리스 노트](../../wiki/releases/1.8.2-KR.md)에 있다.
- **기준 코드:** 베타 검증 `main` `af4153f6`(1.8.2-beta.20). 정규판은 릴리스 PR [#751](https://github.com/puruuun/FGA-Modified/pull/751)을 병합한 `main` `07fd3e4f`이다.
  - 두 커밋 사이에 들어간 앱 변경은 #750 하나다: 일본어 문자열 한 줄(퀘스트 기록 검색 안내문의 「戦争」을 「章」으로)과 일본어 매뉴얼의 같은 표현. 코드 변경은 없다.
  - 그 밖에는 beta.20 검증 기록(#749)과 릴리스 PR(버전, 릴리스 노트, README)이다.
- **베타를 건너뛴 것:** #750은 자체 베타 없이 정규판에 들어간다(소유자 결정, 2026-11-26).
- **beta.18:** PR #723을 뺀 실험 빌드로 `main`에 없다. 번호만 건너뛰었다.

## 자동 검증

- **전체 단위 테스트:** PR #745 head(`030564cd`, beta.20의 코드)에서 4,412개(app 2,203, prefs 71, scripts 2,138), 실패 0. 이후 PR(#748, #750, #751)은 `Main CI`의 `test-and-build`가 통과했다.
- **CI:** 1.8.2에 들어간 모든 PR의 `Main CI gate`가 성공했다. 코드가 바뀐 PR은 `engine-apk` 작업이 정규판 형태 APK를 디버그 서명으로 만들어 `apk_check.py stable`을 통과시켰다.
- **검증 에이전트:** 위험 변경은 모두 검증자를 거쳤다. 자동화 로직, 수집, 저장 데이터 변경은 서로 다른 모델의 검증자 2명, 빌드와 CI 변경은 1명이다. 화면 배치와 문구는 플래너가 읽었다. 반려와 보완 내용은 각 PR의 "Planner record" 댓글과 `docs/qa/1.8.2-beta.*-validation.md`에 있다.
- **Rust 단위의 `main` 병합**(PR #663, #688, #697, #725)은 검증자 2명, 기기 QA, 소유자 승인을 거쳤다.

## 실기기 확인 (소유자, 2026-11-26)

- **설치:** 태블릿 HA29GCWH에 beta.19와 beta.20, MuMu에 beta.20을 업데이트로 설치했다.
- **소유자 QA:** 태블릿에서 KR과 JP의 실제 게임으로 최종 점검을 했고 문제를 찾지 못했다. 확인한 것:
  - 서포트 목록 필터: 조건에 맞는 친구가 있을 때와 없을 때(0명). 0명일 때 게임이 멈추지 않는다 (#741).
  - 체인 우선순위를 켠 실제 전투.
  - 대시보드의 퀘스트 기록과 상점 블록.
- **서포트 스코어 엔진의 실사용 진단** (Rust 플래너가 태블릿의 진단 기록을 읽음): 엔진이 읽은 줄 누적 44개, 틀린 값 0, 기존 판독기로 넘어간 경우 0. KR은 beta.19의 3줄(`+62`)로 표본이 작다.
- 베타별 기록: [`docs/qa/1.8.2-beta.19-validation.md`](../qa/1.8.2-beta.19-validation.md), [`docs/qa/1.8.2-beta.20-validation.md`](../qa/1.8.2-beta.20-validation.md)와 그 이전 기록.

## 확인하지 않은 것

- 체인 우선순위의 21:9 화면 보구 타입 판독. 캡처가 없다. 원본 FGA에서 온 기능이다.
- KR의 관위 조건(관위 서번트, 그랜드 스코어 +16, 인연예장 효과): KR 응답에 관위 항목이 아직 없다. KR에 들어오면 실측한다.
- KR 실더·룰러의 클래스 스코어 +62: 게임에 아직 열리지 않았다. 필터는 응답의 해방 클래스 목록을 읽으므로 열리면 코드 변경 없이 맞게 된다.
- 하단 띠 위치(#657)는 태블릿과 MuMu에서만 측정했다.
- 블루스택에서의 설치와 기기 QA.

## 알려 둘 점

- 네이티브 판독에 시간 제한이 없다 (#673). 지금까지 어떤 실행에서도 멈춘 적이 없다.
- 저장된 브레이브 체인·카드 재배치 목록이 카드 우선순위 항목 수보다 길면 화면에서 저장할 때 잘린다. 가져온 설정이나 직접 고친 설정에서만 생긴다.
- `PickerDownloadTest`가 전체 실행에서 가끔 실패한다 (#746). 계정 상태의 두 읽기 경로가 배열이 아닌 표를 다르게 다룬다 (#747).
- APK가 1.8.1의 94,339,070 B에서 156,005,186 B로 커졌다. 서포트 스코어 판독 라이브러리와 모델이 들어갔다.
