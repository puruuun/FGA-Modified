## 오프라인 템플릿 점수

소유자 캡처(`자동퇴각` 폴더)를 `FgoGameAreaManager`와 같은 방식으로 게임 영역만 잘라 720p 그레이스케일로 만든 뒤, 코드가 쓰는 영역에서 `TM_CCOEFF_NORMED` 최고 점수를 구했습니다. 기본 유사도는 0.80입니다. 확인 스크립트는 `build/orchestration/check_retreat_templates.py`(커밋하지 않음).

설계와 다르게 나온 두 가지:

1. 확인창은 반투명이라 뒤의 메뉴 버튼이 그대로 비칩니다. 그레이스케일 정규화 상관은 밝기 변화에 둔감해 `retreat_button`이 확인창에서도 0.96~0.97로 맞습니다. 이슈의 조건 (a)(확인창에서 퇴각 버튼이 사라짐)는 쓸 수 없습니다.
2. 기존 `Images.Ok`(JP 決定, KR 확인)와 `OkKR`(결정)은 이 확인 버튼에서 0.28 이하입니다. 다른 화면에서 자른 글자 크기라 맞지 않습니다.

그래서 확인창의 확인/決定 버튼 글자를 새 템플릿 `retreat_confirm.png`(Kr, Jp)로 잘랐고, 확인창 검증은 이 템플릿 하나로 합니다. 메뉴 프레임에서는 0.14 이하, 확인창에서는 1.000이라 구분이 확실합니다. 모든 서버의 닫기 버튼 점수는 기존 `Images.Close`가 철수 창에서 0.99 이상입니다.

## 소유자 실기기 확인 (KR, JP, BlueStacks 와이드)

퇴각은 AP를 소모하므로 N은 작게 잡고 한 번에 몇 번만 확인하세요.

- [ ] 일반 퇴각: N = 4로 3턴까지 평소처럼 진행하고 4턴 시작에서 스킬과 카드 없이 퇴각한 뒤 퀘스트가 다시 시작되는지
- [ ] 카드 개수 대기 턴이 1번 있을 때 게임 TURN 5에서 퇴각하는지
- [ ] "3회 연속 퇴각 시 정지"를 켜면 3번째 퇴각 뒤 정지하고, 끄면 계속 진행하는지
- [ ] 퇴각 뒤 맨 위 퀘스트가 다시 선택되고 AP 회복과 서포트 선택이 이어지는지
- [ ] 종료 화면에 "턴 제한 퇴각 N회"가 표시되고, 퇴각이 주회 수와 주회 제한에 더해지지 않는지
- [ ] 퇴각을 여러 번 한 뒤에도 배틀 메뉴의 "스킬 사용 확인" 설정이 그대로인지
- [ ] 한국 서버와 일본 서버 모두에서 위 항목 확인, 다른 서버에서는 설정이 꺼진 채로 표시되는지
- [ ] 주간 미션 경로에서는 퇴각하지 않는지
