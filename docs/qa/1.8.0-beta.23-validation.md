## beta.22 이후 바뀐 것
- #314 위젯 다듬기 (PR #315)
  - 여러 계정 스타일에서 데이터 경과 표시("2시간 전")를 없앰. 버튼이 찌그러지지 않음
  - 위젯 선택 창 미리보기를 바로잡음. 1×1은 버튼만 보이고, 계정 위젯은 계정 정보와 버튼이 보임
    - 코드와 APK의 연결은 정상이었음. 런처가 예전 리소스 ID로 미리보기를 기억한 것으로 추정
    - 미리보기 파일 이름을 바꿔 새 ID를 받게 함
  - "계정 AP"를 "계정 정보"로 바꿈. 선택 창 설명 두 줄을 지움
- #304 새 위젯 "계정 정보 + 최근 로그" (PR #316)
  - 기본 3×2, 크기 조절 가능
  - 윗줄은 계정 정보 위젯과 같음
  - 아랫줄은 최근 로그 카드
    - 섞는 대상: 전투 로그, 스크립트 밖 기록, 진행 중 구간. 순서는 로그 화면과 같음
    - 카드를 누르면 그 기록이 선택된 로그 화면이 열림
  - 로그는 읽기만 하고, 읽기에 실패하면 "로그 없음"을 표시
  - 첫 결과는 폰 4×2에 카드 3장이 들어가 제목이 두 글자만 보여서 돌려보냄
  - 고친 결과: 카드 최소 폭 96 dp, 130 dp보다 좁으면 계정 이름 숨김
    - 폰 3×2와 4×2는 2장, 태블릿 560 dp는 5장
- 구현: Codex 사용 한도로 #314와 #304는 Sonnet 5.5가 구현

## 확인한 것
- 전체 단위 테스트(f51dc170): app 1015, prefs 48, scripts 1062, 실패 0
- 기기 QA: 돌리지 않음
  - 위젯 코드와 읽기 전용 로그 알림만 바뀌었고, 판독·템플릿·좌표·전투 흐름 코드는 바뀌지 않음
  - 전체 기기 QA는 beta.22에서 돌림
- Robolectric 스크린샷(다크·라이트)을 직접 확인
  - 여러 계정 스타일 최소 높이에서 버튼이 둥글고 경과 표시가 없음
  - 1×1·계정 위젯 미리보기가 맞음
  - 최근 로그 카드의 제목이 폰 3×2·4×2와 태블릿에서 읽힘
