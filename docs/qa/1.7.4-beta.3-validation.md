# 1.7.4-beta.3 검증 기록

## 변경
- 버전: 베타 `1.7.4-beta.3` / `1007403`. 정규판은 1.7.2 / 3097 그대로이고, 다음 정규판 이름은 1.7.3입니다.
- 이슈와 PR: [#191](https://github.com/puruuun/FGA-Modified/issues/191), PR [#192](https://github.com/puruuun/FGA-Modified/pull/192)(`38a588bf`).
- 구현: Codex가 사용 한도에 걸려 Sonnet 5.5(medium)가 구현했습니다.

### 로그 화면
- 폭 600dp 이상에서는 화면을 둘로 나눕니다. 왼쪽 약 40%에 목록, 오른쪽에 선택한 기록의 상세가 나옵니다.
- 처음에는 가장 최근 기록이 선택됩니다. 선택한 기록을 지우면 남은 기록 중 가장 최근 것이 선택되고, 남은 기록이 없으면 빈 화면이 나옵니다.
- 600dp 미만에서는 예전처럼 기록을 누르면 상세 화면이 열립니다.

### 기록 카드
- 두 줄로 줄였습니다.
  - 1줄: 이름과 날짜
  - 2줄: "N회 · 평균 T턴"과 종료 사유
- 종료 사유가 반복 문구와 같으면 숨깁니다.

### 배경
- 화면과 상세 배경을 테마 배경색으로, 카드를 카드색으로 칠했습니다. 블루스택에서 보이던 흰 사각형을 없애려는 변경입니다.

### 인연 합계 (종료 화면과 로그 공통)
- "기본값과 보너스를 합산합니다…" 문구를 지웠습니다.
- 미확정 레벨업 줄은 "위치·레벨 미확정 레벨업 퀘스트: n회"로 줄였습니다.
