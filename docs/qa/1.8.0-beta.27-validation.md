## beta.26 이후 바뀐 것
- #338 위젯 테스트 안정화 (PR #340, Sonnet 구현)
  - 테스트가 실제 시간을 기다리지 않도록 바꿈
  - 앱 코드는 갱신 scope 두 곳을 `val`에서 `var`로 바꾼 것뿐이고 동작은 같음
- #341 인증서와 Chaldea 내보내기 저장 위치 변경 (PR #342, Sonnet 구현)
  - 저장 위치: `FGA 폴더/capture/`. Download에는 더 이상 저장하지 않음
  - 인증서 파일 이름: `fga-capture-ca.crt`
  - 3단계 저장: 고정 이름으로 덮어쓰기 → 날짜·시간 이름으로 재시도 → 저장 위치 선택 창
  - 인증서가 있으면 "인증서 파일 다시 저장"이 같은 인증서를 다시 내보냄. "새 인증서 만들기"는 확인 창을 거침
  - 계기: 새 MuMu(Android 15)에서 "인증서를 만들지 못했습니다" 발생. Download에 `.cer.crt`로 저장되어 사본이 쌓였고, 파일만 지워진 뒤 남은 목록 때문에 저장이 거부됨
- #343 검증에서 나온 문제 6건 수정 (PR #344, Codex 구현)
  - 로그 수집 VPN이 켜져 있으면 새 인증서를 만들 수 없음. 버튼 연타도 막음
  - 인증서 파일 두 개를 임시 파일로 쓴 뒤 한꺼번에 교체. 어긋난 쌍은 쓰지 않음
  - Chaldea 저장이 2단계에서 새 파일을 남기고, 쓰기에 실패하면 선택 창으로 넘어감
  - 선택 창으로 저장한 Chaldea 파일을 계정별로 기억해 교체·삭제에 포함
  - 폴더 권한이 끊긴 상태의 삭제는 실패로 알림. 앱 안의 데이터는 삭제함
  - 선택 창으로 저장한 뒤 폴더 이름과 파일 이름을 함께 표시
