## beta.23 이후 바뀐 것
- "계정 정보 + 최근 로그"(3×2) 위젯을 다시 뺌 (오너 결정, PR #318)
  - #304의 두 커밋을 되돌림
  - 위젯·레이아웃·provider·매니페스트·전투 로그 파일이 #304 이전(548b0c68)과 같음
- #319 프렌드 관리에 친구의 관위 서번트 표시 (PR #320, Codex 구현)
  - 서포트 칸마다 `grandSvt` 값을 읽어 관위 여부를 저장. 서버 구분 없이 읽으므로 한국 서버에 관위가 생기면 그대로 표시됨
  - 화면: 서번트 이름 옆 "관위" 표시, 필터의 "관위 서번트만" 켜기/끄기(칩과 초기화 포함)
  - 기기 안 `capture/diagnostics/friend-fields.json`에는 친구·칸 필드 이름과 `grandSvt` 값별 개수만 기록. 이름·ID·친구 코드는 기록하지 않음

## 확인한 것
- 전체 단위 테스트(55cb8afd): app 992, prefs 48, scripts 1067, 실패 0
- 기기 QA: 돌리지 않음. 캡처 해석, 프렌드 관리 화면, 위젯 제거만 바뀌었고 판독·템플릿·좌표·전투 흐름 코드는 바뀌지 않음
- 관위 구조: MuMu 일본 계정 상태를 root로 읽어 구조만 확인. 계정 데이터는 저장소에 넣지 않음
  - 본인 서포트 칸 39개 중 4개가 `grandSvt` = 1. 관위는 일반 클래스 칸에 붙는 표시이고 따로 생기는 칸이 아님
  - 그 4칸의 서번트가 `userSvtGrand`(11개)에 있음
- 관위 표시와 필터 화면은 Robolectric 스크린샷으로 확인

## 확인하지 않은 것
- 친구 데이터에 `grandSvt`가 실제로 들어오는지
  - 일본 계정으로 친구 목록을 연 뒤 `friend-fields.json`을 읽어 확인할 예정
- 실기기에서 관위 표시와 필터, 3×2 위젯이 선택 창에서 사라졌는지
- 태블릿 설치
