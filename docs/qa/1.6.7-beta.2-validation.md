## 소유자 게임 확인 예정

소유자가 **다음 기능 수정과 함께 나중에** 실제 게임에서 확인합니다. 이번 검증은 저장 화면과 테스트 앱만 사용하며 게임은 조작하지 않습니다.

1. 다음 퀘스트 개방 안내가 나오는 강화 퀘스트가 닫기 뒤 계속 진행하는지.
2. 스톰포드 소진 뒤 다음 퀘스트 탭에서 멈추고 마지막 전투를 한 번만 집계하는지.
3. 서포트 → 파티 → 아이템 → 시작이 새 대기 순서로 진행하는지.

PR은 병합하지 않습니다. Beta APK는 소유자가 이번 작업에 명시한 예외에 따라 PR head에서 빌드하며, 계획 담당자가 병합 뒤 `main`에서 다시 빌드합니다. Stable 승격과 GitHub Release는 수행하지 않습니다.
