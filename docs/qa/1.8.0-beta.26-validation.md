## beta.25 이후 바뀐 것
- #332 계정 대시보드 (PR #335, Codex가 시작하고 Sonnet이 마무리)
  - 카드 순서: 프로필, 재화, 보관 현황, 서번트, 아이템, 서포트 편성, 관위 편성, 마술예장, 최근 활동
  - 840dp 이상에서는 이 순서대로 더 짧은 열에 카드를 채움
  - 서포트·관위 편성 카드의 데이터 기준 시각, 스킬, 어펜드를 뺌
  - 편성 행: 서번트 아이콘, 이름(관위 배지), `Lv · 보N · 클래스`, 그리고 예장을 한 줄로 `이름 · Lv · 최대`
  - 관위 편성은 예장 1·3을 한 줄씩 쓰고 그 아래에 인연 효과를 씀
  - 카드 폭이 400dp 미만이면 예장 줄을 서번트 정보 아래로 내림
  - 첫 검토에서 고칠 점 두 가지를 되돌려 보냄: 예장 이름과 레벨 사이 빈칸, 예장 칸이 좁아 이름이 두세 글자로 잘림. 수정 후 다시 확인함
- #333 프렌드 필터 (PR #337, Codex가 시작하고 Sonnet이 마무리)
  - 서번트를 여러 개 선택할 수 있음. 고른 서번트 중 하나라도 맞으면 표시
  - 스킬 1~3, 어펜드 1~5 칸마다 `전체 / 10 / 10 아님`을 고름. 정한 칸이 모두 맞아야 표시
  - 열리지 않은 어펜드는 `10 아님`으로 침
  - PR 생성과 CI 실행은 자동 권한 검사에서 막혀서, 오너 승인을 받고 플래너가 대신 함
- #334 로그 출처 필터 (PR #336, Codex가 시작하고 Sonnet이 마무리)
  - 출처: 스크립트, 선물함, 상점, 소환, 복권, 강화, AP 회복, 직접 퀘스트, 미션, 기타
  - 전투 기록과 FGA 전투 외 스크립트 중의 변화는 "스크립트"로 표시
  - 예전 기록은 원래 출처를 유지함
  - 한국어 표기 변경: 룰렛 → 복권, 수동 퀘스트 → 직접 퀘스트

## 확인한 것
- 전체 단위 테스트(abd80768): 2258건, 실패 0
- 기기 QA: 돌리지 않음. 화면 표시와 로그 출처 표시만 바뀌었고, 판독·템플릿·좌표·전투 흐름 코드는 바뀌지 않음
- #334의 기록 쪽 변경을 한 줄씩 확인함
  - 전투 스크립트가 스크립트 밖 로그를 멈추는 동작은 이전과 같음
  - 전투 외 스크립트는 표시만 붙이고, 스크립트가 끝나는 모든 경로에서 표시가 꺼짐
- PR마다 Robolectric 스크린샷을 직접 확인함
  - 대시보드: 360, 840, 1280dp
  - 프렌드 필터: 360x800, 1280x800
  - 로그 필터와 기록 상세: 360x800, 1280x800. 커밋된 스크린샷이 옛 문구로 남아 있어서 플래너가 다시 찍음

## 확인하지 않은 것
- 실기기에서 가로 대시보드 배치와 실제 데이터의 긴 예장 이름
- 실기기에서 FGA 전투 외 스크립트(복권, 선물함 등)를 돌린 뒤 로그에 "스크립트" 출처로 기록되는지
- 대시보드 관위 편성의 자리 번호(`grandGraphId - 10000`)가 게임 화면과 맞는지 (beta.25부터 남은 항목)
- 친구 데이터에 `grandSvt`가 실제로 들어오는지(`capture/diagnostics/friend-fields.json`)
