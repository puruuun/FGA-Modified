## #286 동작
- 개념예장 자동 강화에서 추천 선택 창의 実行(실행)을 누르고 1초 기다린 뒤, 경고 창의 오른쪽 버튼을 **한 번** 확인합니다.
  - 경고 창은 필터에 ★4·★5·강화한 예장이 포함됐을 때 뜹니다.
  - 확인 그림은 기존 결정 버튼 그림입니다(JP 決定, KR 확인·결정).
- 버튼이 보이면 누르고 1초 기다린 뒤 強化する를 누릅니다. 안 보이면 예전처럼 바로 強化する를 누릅니다.
- 새 위치는 `filterWarningConfirmRegion = Region(300, 1085, 260, 90).xFromCenter()`이고, 누르는 위치는 `Location(400, 1130)`입니다. 가운데 창이라 16:9와 21:9에서 같은 위치를 씁니다.
