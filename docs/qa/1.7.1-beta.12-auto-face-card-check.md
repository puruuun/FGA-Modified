# 1.7.1-beta.12 서번트 카드 확인 자동 판단 (#157)

## 변경

- **서번트 카드 확인 자동 판단:** 더보기 → 배틀의 "서번트 카드 아이콘 확인 생략" 옵션을 없앴습니다. 스크립트를 시작할 때 전투 설정을 보고 확인을 켤지 정합니다(`FaceCardCheckPolicy`).
  - 판단 범위는 카드 수 모드의 두 번째 프로필(활성일 때)과 모든 웨이브·턴 항목입니다.
  - 아래 조건 가운데 하나라도 맞으면 확인을 켜고, 하나도 맞지 않으면 생략합니다.
    1. 서번트 방식 항목이 있음
    2. 상성 항목에서 서번트 우선순위를 켬
    3. 상성 항목에서 브레이브 체인을 "보구와 같이" 또는 "피하기"로 지정
    4. "보구와 맞는 카드 없음" 셔플
    5. 스킬 명령에 하쿠노 셔플이 있음
    6. 카드 수 시작 모드
- **결과 표시:**
  - 시작할 때 로그에 한 줄을 남깁니다. 예: `face-card check: on (brave chains, entry 2)`
  - 전투 설정 화면의 카드 우선순위 요약 아래에 같은 판단을 읽기 전용으로 표시합니다. 예: "서번트 카드 확인: 자동 — 켜짐 (브레이브 체인 W2)"
- **하쿠노 셔플:** 이제 하쿠노 셔플이 있으면 확인이 켜지므로, "확인 생략 때문에 멈춤" 종료 이유(`ShuffleUntilFaceCheckDisabled`)를 없앴습니다.
- **이름 변경(한국어):** "서포트를 자신의 서번트처럼 취급합니다"를 "서포트 아이콘 확인 생략"으로 바꾸고 설명도 새로 썼습니다. 위치(더보기 → 배틀)와 동작은 그대로입니다.
- **예전 설정:** 예전 키 `skip_servant_face_card_check`는 앱 전역 값이었고 전투 설정 내보내기에 들어가지 않았으므로, 가져오기에는 영향이 없습니다.

## 오너 확인 사항

1. 서포트와 명령만 쓴 단순 주회 설정의 전투 설정 화면에 "서번트 카드 확인: 자동 — 생략"이 나오는지, 그리고 전투가 평소대로 진행되는지.
2. 브레이브 체인, 서번트 우선순위, 서번트 방식 중 하나를 쓰는 설정에서 "켜짐 (이유)"가 나오고, 그 기능이 동작하는지.
3. 하쿠노 셔플이 들어간 명령이 확인 생략 때문에 멈추지 않고 실행되는지.
4. 더보기 → 배틀에 "서포트 아이콘 확인 생략"이 새 이름과 설명으로 보이는지.
