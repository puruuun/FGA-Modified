# 1.7.1-beta.14 적 타겟 선택 화면 (#160)

## 변경

- **메인 화면 버튼:** 스킬 메이커 왼쪽 위 버튼을 주황색(`#E65100`) 버튼으로 바꿨습니다. 글씨는 흰색 "타겟 설정"으로 고정했고, 현재 타겟("적: t2", "적: 없음")은 더 이상 버튼에 표시하지 않습니다.
- **선택 화면:** 회색 배경의 대화상자 대신, 스킬 대상 선택 화면처럼 따로 열리는 "적 타겟 선택" 화면(`SkillMakerNav.EnemyTarget`)이 나옵니다.
  - 가운데에 전투 화면 모양으로 타겟 버튼을 놓았습니다. 6타겟 배치의 두 줄 간격은 16dp입니다.
  - 아래에는 "3타겟 / 6타겟 / 레이드" 전환 버튼이 있습니다. 각진 모양이고 체크 표시가 없습니다.
  - 현재 타겟은 파란색으로 강조됩니다.
  - 타겟을 누르면 명령에 추가되고 메인 화면으로 돌아갑니다. 뒤로 가기를 누르면 아무것도 바꾸지 않고 돌아갑니다.
- **그대로인 것:** 타겟 코드, 명령 형식, 게임에서 누르는 좌표는 바뀌지 않았습니다.
- **매뉴얼:** `wiki/scripts/Enemy-Layout-Targets-KR.md`의 "스킬 메이커에서 쓰기" 절을 고쳤습니다.
- **미리보기 도구:** #151 브랜치에 있던 Roborazzi 화면 캡처 도구에서 하니스와 빌드 설정만 가져왔습니다. `ScreenshotHarness.kt`에는 `folder`와 `locale` 인자를 추가했습니다. 캡처 테스트는 `:app:recordRoborazziCi`로만 돌고, Main CI(`:app:testCiUnitTest`)에서는 제외됩니다.

## 오너 확인 사항

1. 스킬 메이커 왼쪽 위에 주황색 "타겟 설정" 버튼이 보이는지.
2. 버튼을 누르면 따로 열리는 화면이 나오고, 3타겟·6타겟·레이드 전환과 현재 타겟 강조가 잘 되는지.
3. 타겟을 누르면 명령에 들어가고 메인 화면으로 돌아오는지. 뒤로 가기를 누르면 아무것도 바뀌지 않는지.
4. beta.13의 확인 사항(6타겟 `t4`~`t9`, 레이드 `tR`·`t10`~`t12`, 임시 추정값인 `t11`)을 이 버전으로 이어서 확인해 주세요.
