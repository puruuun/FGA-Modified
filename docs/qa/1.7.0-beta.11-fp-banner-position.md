# 1.7.0-beta.11 FP 배너 위치 검증 기록

이슈 #114. 배너 제목 비교를 없애고, 소환 화면이 첫 번째 배너로 열린 뒤 설정한 횟수만큼 왼쪽 화살표를 누릅니다.

## 자동 테스트
- 전체 단위 테스트: scripts 724, prefs 38, app 215 (모두 통과, 실패 0)
- `FpBannerReturnTest`: 위치 1/2에서 왼쪽 정확히 1회/2회, 화살표마다 AFTER_ARROW 대기, 이동 뒤 FP 라벨 또는 소환 버튼이 없으면 `FpBannerNotAtPosition`으로 정지하고 소환 탭 없음, `verifySummon`은 저장된 제목 없이 동작.
- `:app:compileCiAndroidTestKotlin` 컴파일 통과. 제목 비교용 `bannerTitle` 기기 QA 케이스(`docs/reference-images/cases/fpSell.json`)는 제거함.

## 소유자 확인 항목 (기기 QA 미실시)
1. Hakuno 배너와 일반 FP 배너가 함께 있을 때, "뒤에서 1번째(맨 마지막)" 설정으로 판매 후 복귀해 소환이 이어지는지.
2. 같은 상황에서 "뒤에서 2번째" 설정으로 판매 후 복귀해 소환이 이어지는지.
3. 잘못된 위치로 설정하면 소환하지 않고 "FP 배너 위치 설정을 확인하세요" 메시지로 멈추는지.
