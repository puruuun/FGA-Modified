# 1.6.8-beta.5 검증

- 대상: `1.6.8-beta.5 / 1006805`, 이슈 #35·#36. Stable은 `1.6.7 / 3094` 유지.
- 안내 띠 문구·색상 검사를 제거하고, FP 자동 판별은 배너 화면으로 제한했습니다.
- 칸 처리: 자물쇠 → 선택·안정 대기 → 패널 판독 → 해방 버튼·패널 잠금 검사 → 일반 모드 패널 판단 → 탭 직전 해방 버튼 재검사 → 강화 → 확인창 대기.
- 확인창이 없으면 최대 레벨 버튼에 따라 Max/CannotEnhance로 끝냅니다. 일반 모드는 직전 결정으로 목표에 도달한 Reached를 유지하고, 확인 모드는 `no-dialog`와 `max`/`no-response`를 기록합니다.
- FP 결과 화면은 기본 Battle로 분류됩니다. `AutoBattle.loop()`는 일치하는 화면 처리기가 없으면 탭 없이 0.5초 간격으로 다시 검사합니다. 시작 시 `isInBattle=false`여서 전투 중 사망·웨이브 전환 탭도 실행하지 않습니다.
