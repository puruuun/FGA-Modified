# 1.7.0-beta.10 주간 경로 지도 가장자리 기하 (이슈 #111)

지도 그림 맞추기를 없애고 모든 장을 가장자리 기하와 측정 드래그로 찾습니다. 구현자는 기기·adb를 쓰지 않았습니다.

## 자동 시험

- 시뮬레이션(`WeeklyMapSimulationTest`): 지점 290개 × 시작 위치 3종(위·가운데·아래) × 화면 폭 8종. 허용 목록은 비어 있습니다.
  - 드래그마다 이동 비율은 0.66~1.00(시드 고정), 측정값은 실제 이동 ±2px, 줌은 실제 최소 배율.
  - 폭별 결과(경우 수 / 실패): 1152 870/0, 1280 870/0, 1440 870/0, 1560 870/0, 1600 870/0, 1680 870/0, 1707 870/0, 1760 870/0.
  - 측정 단계 최대 5회(한도 16), 드래그 총 최대 49회(끝으로 밀기 포함), 믿는 원점과 실제 원점의 최대 차이 5.6px.
  - 측정 한 번 실패하면 끝으로 돌아가 다시 시도해 성공하는 경우, 두 번 실패하면 `map movement did not converge`로 끝나는 경우, 폭으로 제한되지 않는 지도는 `map not recognized`인 경우를 시험.
- 전체 단위 시험(`:app:testCiUnitTest :prefs:testCiUnitTest :scripts:test :libautomata:test`): scripts 721, app 215, prefs 38, 실패 0. `:app:compileCiAndroidTestKotlin` 통과.
- 장비 시험 `weeklyRoute`: 지도 그림 맞추기 사례 14개(JP 06~09·11·19·20, KR 28·29, 다른 지도 거부 4개, 와이드 03)를 삭제했습니다. 해당 시험이 그림 맞추기에만 의존하기 때문입니다. 판·보물창고·닫기·스크롤바 사례는 그대로입니다. 기기에서는 실행하지 않았습니다.
