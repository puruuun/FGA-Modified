# 1.7.1-beta.5 스킬 자동 강화: 10/10/10 선택 해제 정지 (#141, PR #142)

1.7.1-beta.5는 퇴각 대기 시간 조정(#139, PR #140)과 이 수정을 함께 담은 빌드입니다. 버전은 더 올리지 않았습니다.

## 변경

- 스킬 모드에서 결정 뒤 복귀를 기다리는 동안(0.5초 간격) 안내 문구 O, `서번트 재선택` 버튼 X, 확인창 X가 **두 번 연속** 보이면 그 칸을 `Deselected`로 끝내고 실행을 멈춥니다. 종료창 이유: "모든 스킬이 10레벨에 도달하여 선택이 해제되었습니다." (EN·JA 문자열 포함)
- 기존 연출 이탈/3회 규칙을 그대로 따르며, 다른 결과가 끼면 횟수를 0으로 되돌립니다. 목표·레벨 조건 없음. 어펜드 모드는 기존과 같습니다.
- 새 템플릿·좌표 없음. 위키 `Auto-Skill-Level-KR.md` 5단계와 종료 메시지 표를 고쳤습니다.
- 구현: Sonnet 5.5 medium(Codex 사용 한도, 2026-11-04 16:28까지).

## 계획자 검토

- 스펙 일치: 위 조건, Back/Timeout 의미 유지, `runAll` 중단, 버전 파일 미변경.
- 테스트: 흐름(마지막 칸·첫 칸 해제, 이후 칸 미선택, Back/Timeout 회귀), 기기 판정(1회 뒤 복귀, 2회 연속, 중간 리셋, 연출 이탈 전 미집계, 어펜드 미판정).
- 화면 형태: 좌표 변경 없음. 기존 고정 이미지 JP-01(서번트 미선택 스킬 화면)은 label=Skill, reselect=false. 결과 화면 고정 이미지(16:9·2560, KR·JP)는 모두 label=none이라 결과 화면에서는 판정되지 않습니다.
