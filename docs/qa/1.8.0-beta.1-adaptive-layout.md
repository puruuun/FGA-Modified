# 1.8.0-beta.1 큰 화면 레이아웃 스위치 (#151)

## 배경

- **요청:** 태블릿(Y700 16:10 가로)과 BlueStacks처럼 넓은 화면에서 설정 화면이 끝에서 끝까지 늘어나는 문제입니다([#151](https://github.com/puruuun/FGA-Modified/issues/151)).
- **11월 1일:** 폭 제한과 두 칸 배치를 구현하고 스크린샷까지 확인했지만, 오너가 보류했습니다.
- **2026-11-04 재개:** 오너가 추가기능 탭의 스위치로 켜고 끌 수 있게 해 달라고 했습니다. 꺼짐이면 지금과 같고, 켜짐이면 큰 화면에 맞춥니다. 작업 흐름은 오너가 승인했고, 요구사항은 #151 마지막 댓글에 있습니다.

## 변경

- **스위치:** 더 많은 옵션 → 추가기능 → **큰 화면 레이아웃**. 기본값은 꺼짐입니다. 문자열은 영어·한국어·일본어입니다.
- **꺼짐:** 모든 화면이 1.7.3-beta.1과 같습니다. 폭 제한이 없고 한 칸입니다.
- **켜짐:**
  - 설정 화면 12개의 폭을 최대 840dp로 제한하고 가운데에 놓습니다.
  - 전투 설정은 폭 600dp 이상에서 두 칸입니다.
    - 왼쪽: 이름·메모, 커맨드, 요약
    - 오른쪽: 서포트, 커맨드 시작, 카드 셔플
  - 폭 600dp 미만(폰 세로)은 켜도 꺼도 같습니다.
- **적용 구조:**
  - 앱 최상단(`FgaApp`)에서 설정값을 한 번 전달하고, 폭 제한과 두 칸 배치를 처리하는 공통 함수(`CappedWidth`, `AdaptiveColumns`)만 이 값을 읽습니다.
  - 스위치를 바꾸면 다시 시작하지 않아도 바로 반영됩니다.
- **바뀌지 않은 것:** 자동화 로직, 전투 설정 저장값, 대화창, 전투 종료 화면은 그대로입니다.
- **매뉴얼:** `wiki/scripts/Modified-Features-KR.md`에 "큰 화면 레이아웃" 절을 추가했습니다.

## 구현과 리뷰

- **구현:** Codex가 사용 한도에 걸려 있어 Sonnet 5.5(medium)가 구현했습니다(`0e930c96`).
  - 지금 `main`에서 새 브랜치를 만들고, 예전 레이아웃 커밋(`7768b674`)을 옮겨 왔습니다.
  - `main`에 새로 생긴 전투 설정 폴더와 자동 얼굴 카드 확인은 유지했습니다.
  - 스크린샷 도구는 이미 `main`에 있어서 다시 넣지 않았습니다.
- **PR:** [#174](https://github.com/puruuun/FGA-Modified/pull/174). 플래너 리뷰 댓글을 남겼습니다.
  - 공백을 무시하고 보면, 화면 대부분의 변경은 감싸는 함수 한 줄뿐입니다.
  - 전투 설정은 카드를 함수로 나눴고, 한 칸일 때 순서는 같습니다. 더 많은 옵션은 상태를 밖으로 뺐습니다.
- **스크린샷:** 72장입니다. 화면 4개(전투 설정, 전투 설정 목록, 카드 우선순위, 더 많은 옵션)를 폭 360·600·840·1280dp, 꺼짐·켜짐, 영어·한국어로 찍었고, 전투 설정은 다크 모드도 찍었습니다.
  - 플래너가 비교 이미지(로컬 `build/screenshots-151-switch/`)로 확인했고, 오너가 레이아웃을 승인했습니다(2026-11-04).
  - 스크린샷 테스트는 Main CI에서 돌리지 않습니다.
- **플래너 커밋:** `bc0b8952`, 1.8.0-beta.1(1008001)로 버전을 올렸습니다.
- **CI:** PR의 Main CI와 PR Build(두 커밋 모두), `main`(push)의 Main CI가 성공했습니다.
- **브랜치:** fast-forward로 병합한 뒤 `feat/adaptive-layout-switch`를 삭제했습니다. 예전 `feat/adaptive-layout`도 승인된 계획대로 삭제했습니다. 예전 커밋 해시는 #151 댓글에 남아 있습니다.
