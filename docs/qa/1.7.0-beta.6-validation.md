# 1.7.0-beta.6 검증 기록

## #90 주간 목록·FP 판매 목록 끝 상자 축소

서포트 선택 화면(`SupportScreenLocations`, 서포트 임계값)은 그대로입니다. 주간 목록과 FP 판매 목록의 끝 상자와 임계값만 바꿨습니다.

### 상자 (1440p)

끝 위치 범위에 가로 ±4 px, 세로 ±3 px(720p)를 더했습니다. 템플릿은 28x11(720p)입니다.

| 화면 | 16:9 | 와이드 (중앙 기준) |
|---|---|---|
| 주간 위 | x -82(오른쪽 끝), y 178, 74x38 | x +1430, y 178, 72x42 |
| 주간 아래 | x -82, y 1152, 74x34 | x +1430, y 1152, 72x34 |
| FP 아래 | x -554, y 1330, 72x34 | x +956, y 1330, 72x34 |

- 와이드 상자는 오른쪽 끝 기준이 아니라 **화면 중앙 기준**입니다. 와이드의 안전 영역 안쪽으로 들어가지 않습니다.
- 위쪽 끝이 x -35에 있던 프레임(`Jp/wide-2560/24.webp`, `Jp/wide-21x9/01.webp`)은 가로세로비가 2.33:1이고, 나머지 실기기 캡처(2560x1080)는 2.37:1이라서 오른쪽 끝에서 잰 위치가 13 px 다릅니다. 중앙에서 잰 위치는 두 비율 모두 719 ± 0.5 px(FP는 482 ± 0.5 px)로 같아서, 상자를 넓히지 않고 기준점을 중앙으로 바꿨습니다.
- 이전 점수 파일의 2560x1080 캡처는 1680x720으로 찌그러뜨려 재었습니다. 새 파일(`1.7.0-beta.6-scroll-scores.json`)은 원래 비율(1707x720)로 잽니다.

### 임계값과 측정

기존 120프레임과 `Kr/scroll-end` 고정 프레임 6장을 실제 상자로 다시 잰 결과입니다(`1.7.0-beta.6-scroll-scores.json`).

| 화면 | 끝 최소 | 끝 아님 최대 | 임계값 |
|---|---|---|---|
| 주간 위 16:9 / 와이드 | 0.834 / 0.821 | 0.230 / 0.008 | **0.60** (이전 0.721) |
| 주간 아래 16:9 / 와이드 | 0.817 / 0.832 | 0.381 / -0.173 | **0.60** |
| FP 아래 16:9 / 와이드 | 0.905 / 0.913 | 0.532 / 0.157 | **0.72** (이전 0.728) |

16:9 값은 기획 측정과 일치하고, 와이드 끝 아님 점수는 중앙 기준 상자라서 더 낮습니다(끝 최소는 같음). 이전 상자의 최악 간격 0.193이 0.37 이상으로 늘었습니다.
