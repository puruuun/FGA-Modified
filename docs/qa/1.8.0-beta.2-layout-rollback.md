# 1.8.0-beta.2 큰 화면 레이아웃 되돌리기, 전투 설정 두 칸만 유지 (#177)

## 배경

- **1.8.0-beta.1:** 추가기능 탭에 "큰 화면 레이아웃" 스위치를 넣었습니다(#151). 켜면 설정 화면 12개의 폭을 840dp로 제한하고, 전투 설정은 두 칸으로 배치했습니다.
- **2026-11-04 오너 결정:**
  - 처음에는 스위치 없이 자동으로 바뀌고 넓은 화면에서 전투 설정 목록과 상세를 나란히 보는 안을 진행했습니다([#175](https://github.com/puruuun/FGA-Modified/issues/175), PR [#176](https://github.com/puruuun/FGA-Modified/pull/176)).
  - 1.8.0-beta.1을 실기기에서 본 뒤 중단했습니다. #176은 병합하지 않고 닫았고, #175는 "계획하지 않음"으로 닫았습니다.
  - 사용자가 다시 익혀야 하는 UI 변화는 넣지 않기로 했습니다. 모든 화면을 1.7.x로 되돌리고, 전투 설정 두 칸 배치 하나만 남깁니다([#177](https://github.com/puruuun/FGA-Modified/issues/177)).

## 변경

- **되돌린 것:** 아래는 모두 1.7.3-beta.1 시점(`8861a44e`)과 차이가 없습니다.
  - 전투 설정 목록, 카드 우선순위, 미세 조정, 추가기능 조정, 시작 화면, 더 많은 옵션, 라이선스, 주간 미션 설정, 선호 서포트, 스팸 화면
  - `FgaApp`, 추가기능 탭, 설정값(`PrefsCore`), 문자열(영어·한국어·일본어)
  - 이에 따라 "큰 화면 레이아웃" 스위치와 그 설정값이 없어졌습니다.
- **남긴 것:** 전투 설정 화면(설정 파일 수정)은 1.8.0-beta.1과 같습니다.
  - 폭 600dp 이상이면 두 칸입니다. 왼쪽은 이름·메모, 커맨드, 요약이고, 오른쪽은 서포트, 커맨드 시작 조건, 카드 셔플입니다. 최대 1280dp로 가운데에 놓습니다.
  - 600dp 미만은 원래의 한 칸입니다.
  - 설정 없이 항상 자동이며, 폰 가로도 600dp 이상이면 두 칸입니다.
- **매뉴얼:** `wiki/scripts/Modified-Features-KR.md`의 "큰 화면 레이아웃" 절을 "전투 설정 두 칸 배치"로 다시 썼습니다.
