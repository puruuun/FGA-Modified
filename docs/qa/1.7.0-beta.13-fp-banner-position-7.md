# 1.7.0-beta.13: FP 배너 위치 1~7 (#121)

## 변경
- FP 배너 위치를 뒤에서 1~7번째로 확장했습니다(기본 1). 범위는 `FpBannerReturn.POSITIONS` 한 곳에 있고 UI 스테퍼도 같은 값을 씁니다.
- 라디오 두 개를 숫자 스테퍼로 바꿨습니다. 저장 키 `fpBannerPosition`(Int)은 그대로여서 기존 값이 이어집니다.
- 범위 밖 값은 1~7로 보정합니다. 스크립트 흐름과 정지 사유(`FpBannerNotAtPosition`)는 그대로입니다.

## 테스트
- `FpBannerReturnTest`: 위치 1, 2, 7은 왼쪽 1, 2, 7번과 같은 횟수의 AFTER_ARROW 대기, 0은 1로, 8은 7로 보정. 전체 수치는 `1.7.0-beta.13-validation.md`에 기록했습니다(scripts 738, app 215, prefs 39 통과).

## 소유자 확인
- 위치 1, 2, 3 이상(해당 배너 구성이 있을 때)에서 판매 후 같은 배너로 돌아와 소환이 이어지는지.
- 잘못된 값이면 소환하지 않고 멈추는지.
