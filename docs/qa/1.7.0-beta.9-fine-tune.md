## 소유자 확인 항목

1. 고급 탭에서 "미세 조정" 위에 "추가 기능 미세 조정"이 보이고, 7개 구역(Hakuno 셔플·카드 우선순위 없음)이 열린다.
2. 대기 배율은 50~300%, 유사도 보정은 -0.05~+0.05로 움직이고, 퀘스트 구역에 ms 항목 두 개가 있다.
3. 구역별 "기본값으로"와 "전체 기본값으로"가 값을 되돌린다.
4. 기본값 상태에서 기존 동작(주간, FP 매각, 스킬 레벨, 예장 강화, 아이템 제어, 인연, 서포트)이 그대로다.
5. 값을 바꾼 뒤 다음 실행부터만 적용되고, 한국어·영어 문구가 올바르다.
