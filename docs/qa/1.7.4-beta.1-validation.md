## 오너 확인 항목
- [ ] **메인 화면:** 오토 스킬 → **로그** → 더 많은 옵션 순서인지 확인. 로그를 누르면 "추후 추가될 기능입니다." 화면이 열리는지 확인.
- [ ] **언어:** 더 많은 옵션 → **고급** 맨 위의 언어 선택으로 언어를 바꾸면 앱 전체에 바로 적용되고, 앱을 다시 켜도 유지되는지 확인.
- [ ] **폭 제한:** 블루스택 2560×1080에서 메인·전투 설정 목록·더 많은 옵션 등의 내용이 가운데 1280dp 폭으로 보이는지 확인. 서비스 시작 버튼과 "+" 버튼은 창 가장자리에 남는 것이 정상입니다.
- [ ] **Chaldea 1웨이브:** 제보 링크(冠位研鑽戦〔アーチャー〕 Ⅶ, `questId=94150847`)로 가져오기 → 턴 목록에서 "공격 1 뒤"가 **턴**으로 선택돼 있는지 확인. 적용 결과가 `cdefg25,bah1kj1t24`인지 확인.
- [ ] **Chaldea 여러 웨이브:** 3웨이브 퀘스트에서 공격이 3번이면 모두 웨이브로 선택돼 있는지 확인. 4번 이상이면 경고가 뜨고 직접 고를 수 있는지 확인.
