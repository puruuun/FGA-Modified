# 1.7.1-beta.8 카드 우선순위 웨이브·턴별 방식과 서번트 우선순위 (#147)

## 변경

카드 우선순위의 **방식**(상성/서번트)과 **서번트 우선순위 사용**을 웨이브·턴 항목마다 따로 정합니다. 브레이브 체인, 카드 재배열과 같은 방식입니다.

- **설정 화면:**
  - 맨 위에 구분 기준을 두고, 그 아래 웨이브·턴 탭(선택·추가)을 둡니다.
  - 각 페이지에는 우선순위 목록이 있고, 그 아래 설정 카드가 방식 → 서번트 우선순위 사용 → 브레이브 체인 → 카드 재배열 순서로 놓입니다.
  - 서번트 방식인 페이지는 그 페이지의 아래 세 항목만 흐리게 표시하고 끕니다.
  - 새 페이지는 앞 페이지의 방식과 스위치를 이어받습니다.
- **전투:** 카드를 고를 때마다 그 웨이브·턴 항목의 방식, 서번트 우선순위, 브레이브 체인, 재배열을 씁니다. 직접 지정의 '미선택' 슬롯과 카드 수 기준 모드의 1·2번 프로필도 같은 규칙을 따릅니다.
- **요약:**
  - 전투 설정 화면의 요약이 항목마다 그 방식의 목록을 보여 줍니다(`WB, WA…` 또는 `1B, 1A…`).
  - 서번트 우선순위가 켜진 줄에는 "서번트 우선"이 붙습니다.
  - 화면에서 돌아오면 바로 반영됩니다.
- **기존 설정:**
  - 새 설정 `card_priority_styles`, `use_servant_priorities`가 비어 있으면 예전 단일 값을 모든 항목에 씁니다. 그래서 업데이트 전과 똑같이 동작합니다.
  - 예전 키는 지우지 않았습니다.
- **위키:** `Card-Priority-KR.md`를 고쳤습니다.

## 오너 확인 사항

1. 카드 우선순위 화면이 이 순서로 놓였는지: 구분 기준 → 웨이브 탭 → 페이지 안 설정 카드(방식 → 서번트 우선순위 → 브레이브 체인 → 카드 재배열).
2. 페이지 방식을 서번트로 바꾸면 목록이 1B…로 바뀌고 아래 세 항목이 흐려지는지.
3. W1 상성, W2 서번트처럼 섞어 저장한 뒤 돌아갔을 때 요약에 `W1: WB…`, `W2: 1B…`로 나오는지.
4. 기존에 만든 전투 설정이 업데이트 후에도 같은 방식과 서번트 우선순위로 열리는지.
5. 실제 전투에서 웨이브마다 정한 방식대로 카드를 고르는지.
