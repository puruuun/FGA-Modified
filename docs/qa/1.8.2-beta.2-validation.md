  - 구현: Sonnet 5.5. UI·문자열만 바뀌어 플래너가 검토

## 확인한 것

- 전체 단위 테스트(버전 커밋 dfd5373c): app 1599, prefs 61, scripts 1540, 실패 0. PR의 Main CI 통과
- 기기 QA 묶음은 돌리지 않음. 바뀐 곳(로그 화면)을 다루는 묶음이 없음
- MuMu에서 이 APK의 로그 화면을 실제 기록으로 열어 봄(게임은 열지 않음). 필터 창에서 날짜별을 고르고 적용
  - 각 줄의 첫 줄에 날짜, 계정 이름, 서버가 함께 나옴(예: "11월 18일 (수) 蕨 JP")
  - 둘째 줄에 출처만 나옴: "스크립트 · 로그인", "로그인", "전투", "소환", "상점 · 소환 · 강화 · 전투 · 미션", "전투 · 상점", "상점 · 강화"
  - 11월 16일 KR 줄의 "전투"는 기록별 보기에서 "직접 퀘스트"로 나오는 스크립트 밖 전투. 직접 퀘스트가 따로 나오지 않고 "전투"로 합쳐짐
  - "전투 0"과 횟수 표시가 없음

## 확인하지 않은 것

- 세로 휴대폰 화면의 날짜별 목록(긴 계정 이름의 말줄임 포함). Robolectric 테스트와 스크린샷으로만 확인함
- 진행 중인 날의 "진행 중" 표시와 출처가 없는 날(둘째 줄 없음). 이 기기의 기록에는 없어서 단위 테스트로만 확인함
- beta.1에서 넘어온 항목: #577 실제 04:00 이후 첫 로그인에서 기간이 닫히는지, 날짜별 보기의 전투 상세 이동과 출처별 내역 펼침
