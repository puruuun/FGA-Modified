# 1.7.1-beta.13 6마리·레이드 적 타겟 (#155)

## 변경

- **새 타겟 코드:** 스킬 명령에 적이 6마리인 배치와 레이드 배치용 타겟 코드를 추가했습니다. `t1`~`t3`의 위치와 동작은 그대로입니다.

  | 배치 | 코드 | 1440p 좌표 (16:9 기준) |
  | --- | --- | --- |
  | 6마리 윗줄 | `t4` `t5` `t6` | (460, 80) (860, 80) (1260, 80) |
  | 6마리 아랫줄 | `t7` `t8` `t9` | (260, 276) (660, 276) (1060, 276) |
  | 레이드 보스 | `tR` | (780, 96) |
  | 레이드 아래 적 | `t10` `t11` `t12` | (200, 297) (757, 297) (1313, 297) |

  - 와이드 화면에서는 새 배치의 x에 155를 더합니다. 일반 `t1`~`t3`은 예전처럼 183을 더합니다.
  - `t11`(757, 297)은 캡처가 없어 양옆 위치로 계산한 **임시 추정값**입니다.
- **명령 해석:** `t` 뒤에 `1`과 `0`·`1`·`2`가 오면 `t10`·`t11`·`t12`로 읽습니다. 그 밖의 `t1…`은 예전처럼 `t1`입니다. 예: `t14`는 `t1` 다음 NP 4. 없는 코드(`t0`, `tX`)는 해석 오류로 멈춥니다.
- **스킬 메이커:** 적 타겟 대화상자에 3마리 / 6마리 / 레이드 배치 선택을 넣었습니다.
- **매뉴얼:** `wiki/scripts/Enemy-Layout-Targets-KR.md`를 추가했습니다.
- **그대로인 것:** 자동 타겟 선택과 Chaldea 가져오기는 일반 3마리 배치만 다룹니다.
