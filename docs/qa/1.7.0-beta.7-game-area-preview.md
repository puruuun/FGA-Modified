## 소유자 태블릿 확인 (아직 미실시)

플래너가 병합 후 beta.7에서 확인한다. 이 작업에서는 기기 QA·adb·APK 빌드를 실행하지 않았다.

- [ ] 분할 화면에서 접근성 서비스를 켜면 빨간·초록 테두리와 크기·비율이 보인다. 서비스 OFF에서는 스위치와 안내를 확인한다.
- [ ] 좌표 버튼을 누르거나 길게 누르면 테두리가 즉시 갱신된다. 다른 모드로 바꾸면 사라진다.
- [ ] 초록 테두리가 제목 표시줄·파란 여백을 제외한 실제 게임 이미지와 맞는다.
- [ ] 스크립트를 시작하면 첫 화면 판별 전에 테두리가 사라지고, 실행 중 다시 켤 수 없다.
- [ ] 스위치 OFF·설정 화면 이탈·Activity 정지·접근성 서비스 해제 시 제거되고, 재진입 시 OFF다.
