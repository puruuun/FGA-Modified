#186 기록 기능의 세부 사항입니다.
- 기록하는 내용: 설정 이름, 날짜, 종료 사유, 반복, 사과, 턴, 시간, 예장, 철수. 재료와 인연은 해당 기능을 켰을 때만 기록합니다.
- 최근 200건만 남깁니다.
- 기록을 하나씩 지우거나 전체를 지울 수 있고, 지우기 전에 확인합니다.
- 일시정지 상태 화면과 0회로 끝난 경우는 기록하지 않습니다.
- 상세 화면은 종료 화면과 같은 구성 요소를 씁니다.

- PR마다 플래너 검토 댓글을 남겼습니다.
- #188은 #189 병합 뒤 `main`을 브랜치에 병합하는 방식으로 갱신했습니다. 강제 푸시는 하지 않았습니다. 이후 CI가 다시 성공했습니다.
- 두 PR 모두 Main CI와 PR Build가 성공했습니다. fast-forward로 병합했고 브랜치는 삭제했습니다.

## 오너 확인 항목
1.7.4-beta.1의 확인 항목은 그대로 유효합니다. 다만 Chaldea 항목은 아래 내용으로 바뀝니다.
- [ ] **Chaldea 1웨이브:** 제보 링크(冠位研鑽戦 Ⅶ)를 가져올 때 선택 창 없이 바로 `cdefg25,bah1kj1t24`가 들어가는지 확인합니다.
- [ ] **Chaldea 여러 웨이브:** 3웨이브 퀘스트에서 공격이 3번이면 선택 창 없이 모두 웨이브로 들어가는지, 4번 이상이면 경고와 함께 선택 창이 뜨는지 확인합니다.
- [ ] **로그 기록:** 전투 설정으로 몇 판 돌린 뒤 종료하고, 메인 → 로그 맨 위에 그 기록이 있는지 확인합니다. 설정 이름, 날짜, 반복 횟수, 평균 턴, 종료 사유가 보여야 합니다.
- [ ] **로그 상세:** 기록을 눌러 종료 화면과 같은 내용이 나오는지 확인합니다. 재료 카운트나 인연 추적을 켰다면 그 내역도 보여야 합니다.
- [ ] **로그 제외:** 시작하자마자 0회로 정지하거나 일시정지 상태 보기만 한 경우에는 기록이 생기지 않는지 확인합니다.
- [ ] **로그 삭제:** 개별 삭제와 전체 삭제가 확인 창 뒤에 동작하는지 확인합니다.
- [ ] **날짜 표시:** 한국어 기기에서 날짜가 기기 형식으로 나오는지 확인합니다. 테스트 환경에서는 영어 형식으로 보였습니다.
