# 1.7.1-beta.11 오토 스킬 폴더 (#153)

## 변경

오토 스킬(배틀 설정)을 폴더 한 단계로 묶습니다. 목록 화면과 런처 모두 폴더를 접고 펼 수 있습니다. 정리 기능일 뿐이며, 전투 로직(`scripts/`)은 바뀌지 않았습니다.

- **저장:** 설정마다 `battle_config_folder` 키를 둡니다(빈 값이면 폴더 없음). `.fga` 내보내기·불러오기와 설정 복사에서 폴더가 같이 따라갑니다. 예전 파일은 폴더 없이 들어옵니다.
- **목록 화면:**
  - 서버 탭과 서버 구역마다 폴더를 먼저, 폴더 없는 설정을 그다음에 이름순으로 보여 줍니다.
  - 화면을 열면 폴더는 모두 접혀 있고, 펼침 상태는 저장하지 않습니다.
  - 선택 모드에 「폴더로 이동」이 있습니다: 기존 폴더 / 새 폴더… / 폴더에서 빼기.
  - 폴더 이름은 앞뒤 공백을 지우고, 빈 이름은 막고, 30자까지 받습니다. 대소문자만 다른 이름은 기존 폴더를 그대로 씁니다.
- **런처:**
  - 선택한 설정을 목록 인덱스 대신 설정 ID로 기억합니다.
  - 선택된 설정이 든 폴더만 펼쳐서 열고, 그 설정으로 스크롤합니다.
  - 그 폴더를 접으면 폴더 줄에 "폴더 · 설정"으로 표시합니다.
- **버전:** 새 기능이라 규칙대로라면 1.8.0이지만, 오너 결정(2026-11-02)으로 1.7.1에 넣었습니다.
