## 주간 경로 (#53)

좌측 버튼 점수만으로 공지=Home, 터미널=Map, 닫기=List를 분류합니다. 모호한 점수는 Unknown입니다. 문턱 0.88, 차이 0.05를 유지했습니다. 새 캡처의 글자 끝이 검색 영역 밖이라 1440p 너비를 330→380으로 늘렸습니다. 로컬 OpenCV 확인 점수는 이벤트 게이트 Close 0.978, 오케아노스 Terminal 0.969입니다.

삭제: `weekly_gate_title.png`, `weekly_daily_title.png`의 JP·KR 4개 파일, 해당 Images 항목, gateHeader 영역, `listScreen`, GateList·DailyList 상태. En 사본은 없었습니다.

테스트는 좌측 버튼별 분류·모호한 점수, 다른 퀘스트 뒤 Home 확인→게이트→요일→보물창고 순서, 빈 경로의 Empty 결정, 수동 선택 키 무시를 포함합니다. 요일 목록은 Close와 `weekly_daily_quest` 앵커로 확인하고, 전투 후에도 같은 조건을 씁니다. 판을 누르는 조건은 노란색+초급 이름이며 표시 AP는 로그용입니다.

초상화와 상태에 최소 12px 여백을 둡니다. `(273,486)`의 `군도`는 가림 영역이며 드래그 필요=true, 보이는 부분 fallback=false입니다. 기존 드래그·fallback·도달 불가 종료 로직은 유지합니다. 제공된 게이트·지도 캡처를 720p 회귀 fixture로 추가했습니다.

## FP 판매 (#54)

5·6·7열 프레임으로 진입을 기다리고 서번트 탭은 진입 시 한 번 확인합니다(안 보이면 탭 후 재확인). 7열·청록 선택 프레임·가득 참의 서번트 문구·복귀 배너 제목/FP/소환 버튼 검사는 유지합니다. 자물쇠만 잠금 판정에 쓰며 excluded 플래그와 페이지별 제목 검사는 제거했습니다.

삭제한 Images 항목(총 17종, 에셋 28개): FpSellHeading, FpSellHeadingWide, FpSellLockedText, FpSellLockedTextAlt, FpSellUnselectable, FpSellGrandServant, FpSellParty, FpSellTemporary, FpSellTemporaryServant, FpSellConfirm, FpSellConvertHeading, FpSellCancel, FpSellConvert, FpSellDone, FpSellClose, FpSellScreenClose, FpSellShop.

실제 판매: Confirm→1초→Convert→1초→완료 팝업 Close→4초. 기존의 별도 판매 화면 Close는 보존하고 4초 후 MENU로 진행합니다. 공방 제목 확인·재시도는 없습니다. 시험 모드는 Confirm 직후 SellDryRunDone, 선택 0장은 최종 단계와 복귀 없이 InventoryFullNothingToSell로 정지합니다. 기존 두 Close를 구분해 유지한 해석이며 소유자의 실제 게임 확인이 필요합니다.

## 내장 지원 서번트 (#51)

명시적 15종 ID·JP 번호를 Atlas JP와 대조해 서번트 24/24, 예장 23/23 연결, 미연결 0입니다. 생성기 2회 실행 결과 동일합니다. 잘못된 번호·누락 ID·파일명 ID 불일치·누락 폴더도 거부했습니다. 한국어 이름 4개와 서번트 연결표를 추가했고 기존 CE 로직은 유지했습니다.

**U-올가마리 코스튬은 보류했습니다.** 지정 상수(128→158, x=3/y=47, 125×44)로 Atlas `f_40001000.png`를 재현한 크기는 기존과 같지만 평균 절대 차이는 RGB **8.601030**, RGBA **6.450773**입니다. 불투명 이미지라 알파 차이는 원인이 아닙니다. 사양의 중단 조건에 따라 `f_40001300.png`를 추가하지 않았으며 기존 4개 파일은 그대로입니다. `tools/chaldea/make_support_portrait.py --check`가 이를 재현하고 불일치 시 에셋 쓰기를 차단합니다. 이 항목은 완료가 아닙니다.
