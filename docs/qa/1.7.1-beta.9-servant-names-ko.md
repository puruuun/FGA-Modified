# 1.7.1-beta.9 KR 미실장 서번트 한국어 이름 검색 (#149)

## 변경

서포트 이미지 검색·저장에서 **한국 서버에 아직 실장되지 않은 서번트도 한국어 이름으로 찾을 수 있습니다.**

- **사전:** 앱에 한국어 이름 사전 `app/src/main/assets/servant-names-ko.json`을 넣었습니다.
  - Atlas 서번트 내부 ID 기준이며, 44명을 담았습니다(No.438~483).
  - 출처는 나무위키 서번트 문서입니다. 재림에 따라 이름이 바뀌는 서번트는 "영기재림별 적용 그림" 캡션의 재림별 이름을 모두 넣었습니다(예: 448 → 옥토끼 / 료기 시키 / 옥토끼 카구야). 470은 오너 결정으로 진명 `우르드`를 추가했습니다.
  - 새 서번트가 나오면 오너가 직접 사전을 고칩니다. 사전 파일만 바꿔도 assets 변경이므로 PR로 올립니다.
- **검색:**
  - 서번트 이름 검색에서 **KR 카탈로그에 해당 ID가 없을 때만** 사전 이름을 별칭으로 붙입니다.
  - KR에 실장되면 Atlas 공식 이름만 쓰고 사전은 무시합니다.
  - 매칭 규칙(완전 일치 → 앞부분 일치 → 포함)은 그대로입니다. 예: `히폴` → 히폴리테, `카구야` → No.448.
- **바뀌지 않은 것:**
  - 표시 이름, 도감 번호, 이미지, 저장 폴더 이름. JP 전용 서번트는 일본어 공식 이름을 씁니다.
  - 번호 검색과 개념예장 검색.
- **안전장치:**
  - 사전 파일이 없거나 깨져도 검색은 실패하지 않습니다. 사전 없이 검색하고 로그만 남깁니다.
  - 앱 언어가 한국어가 아니고 KR 카탈로그를 받지 못하면, 검색을 실패시키지 않고 사전을 모든 항목에 적용합니다.
- **넣지 않은 것 (오너 결정):** 발음 추정(가나→한글) 매칭과 영어 이름 별칭은 넣지 않았습니다.
- **위키:** `Servant-Number-Portraits-KR.md`에 설명을 추가했습니다.

## 조사 근거 (2026-11-01)

- JP 플레이어블 서번트 471명 중 44명이 KR에 없습니다.
- Atlas에는 한국어 번역이 없습니다. API 언어는 `jp`·`en` 두 가지이고, `basic_servant_lang_ko`는 404입니다.
- Chaldea 커뮤니티 번역(`svt_names.KR`)은 44명 중 14명만 있고, 최신 서번트는 없습니다.
- 앱이 나무위키를 실시간으로 읽는 방식은 쓰지 않았습니다. 공식 API가 없고 봇 차단이 있기 때문입니다. 플래너가 앱 안 브라우저로 클래스별 목록과 서번트 문서를 읽어 사전을 정리했습니다.

4. 이미 KR에 있는 서번트(예: `네로`)의 검색 결과가 전과 같은지.
