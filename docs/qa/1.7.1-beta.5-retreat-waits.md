# 1.7.1-beta.5 퇴각 대기 시간 조정 (#139)

## 변경

beta.4 확인에서 턴 제한 퇴각의 대기 시간 두 곳이 게임 전환 속도보다 짧았습니다.

- 확인(OK)을 누른 뒤 "퀘스트에서 철수했습니다" 창의 닫기 버튼을 찾기 전 대기를 0.5초에서 **1초**로 늘렸습니다. 확인을 한 번 더 누르는 재시도 경로도 같습니다.
- 닫기를 누른 뒤 주회 흐름으로 돌아가기 전 대기를 5초에서 **6초**로 늘렸습니다. 퀘스트 목록이 느리게 뜹니다.
- 닫기 버튼을 찾는 최대 15초, 메뉴와 퇴각 버튼의 0.5초 대기는 그대로입니다. 전멸 퇴각(`Withdraw.kt`)은 건드리지 않았습니다.
- `TurnLimitRetreat.kt`, `TurnLimitRetreatTest.kt`(추적 값 갱신), 위키 `Turn-Limit-Retreat-KR.md`를 고쳤습니다.

## 테스트

전체 단위 테스트 결과는 PR에 기록합니다. 기존 `TurnLimitRetreatTest`의 전체 순서와 재시도 순서 검증이 새 대기 시간(`wait:1s`, `wait:6s`)을 확인합니다.

## 소유자 확인 사항

1. BlueStacks에서 N턴 퇴각 시 확인 후 닫기 버튼을 놓치지 않고 누르는지.
2. 닫기 후 퀘스트 목록이 완전히 뜬 뒤 다음 주회가 시작되는지.
