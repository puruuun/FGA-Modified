## beta.1 이후 바뀐 것
- #496 마스터 스킬 메뉴 대기시간 설정 (PR #502)
  - 미세 조정 → 딜레이에 항목 추가. 기본 1500ms(기존 고정값과 같음), 범위 300~3000ms, 100ms 단위. 범위를 벗어난 저장값은 읽을 때 범위 안으로 맞춤
  - 마스터 스킬과 오더 체인지에 적용. 령주 메뉴 대기와 다른 대기는 그대로
  - 구현: Sonnet 5.5(medium). 검증 두 개: Sonnet, Haiku 모두 통과
- #504 스킬·어펜드 자동 강화에서 스킬 아이콘 재선택 생략 (PR #506)
  - 선택된 칸은 아이콘 바깥에 하늘색 빛이 있음. 칸 중심에서 60px(720p) 떨어진 네 변의 평균 (파랑 − 빨강)이 60 이상이면 빛으로 봄. 실측은 선택된 칸 92 이상, 나머지 27 이하(KR·JP, 16:9·21:9)
  - 그 칸의 네 변이 모두 빛이고 다른 칸은 어느 변도 빛이 아닐 때만 "선택됨". 그 외에는 기존처럼 누름
  - 칸마다 첫 강화 전에는 항상 누름. 기존 안전장치는 순서와 내용 그대로
  - 구현: Sonnet 5.5(medium). 검증 두 개: Sonnet, Haiku 모두 통과
- #493 루트 수집의 앱별 규칙 이름과 다른 FGA 앱 감지 (PR #503)
  - 체인 `FGA_CAP_<앱 UID>`, 감시 파일 `fga_cap_watchdog_<앱 UID>.*`. 정리는 자기 이름만 지움
  - 시작 전, 규칙 적용 직후, 60초 점검에서 다른 FGA 앱의 살아 있는 루트 수집을 확인. 있으면 규칙을 적용하지 않거나 자기 수집을 멈추고 안내
  - 감시 프로그램이 없는 남은 체인은 약 2초 간격으로 두 번 확인한 뒤 지움
  - 60초 점검이 자기 포트로 가는 REDIRECT 규칙까지 확인하고, 재적용할 때 감시 프로그램도 다시 시작
  - 구현: Sonnet 5.5(medium), 두 번에 걸쳐 완료. 검증 두 개(Sonnet, Haiku): 1차 둘 다 반려, 2차 둘 다 통과
- #357, #364 Chaldea 직접 동기화 보강 (PR #510)
  - 번들 해시가 비어 있으면 거부. 스위치를 끌 때 권한 요청 대기를 항상 해제. 켜는 도중 실패하면 되돌리고 실패 상태 표시
  - 쓰다 중단된 파일의 복구를 Chaldea가 닫힐 때까지 계속 확인(쓰기 패스, 세션 종료 처리, 수동 동기화 뒤). 대기는 복구 실패 횟수에 넣지 않음
  - 스위치를 끄면 대기 중인 루트 확인 프로세스를 종료
  - 구현: Sonnet 5.5(medium), 두 번에 걸쳐 완료. 검증 두 개: 1차 Sonnet 통과·Haiku 반려, 2차 둘 다 통과
- #511 로그인 때 받는 프렌드포인트를 로그에 기록 (PR #512)
  - 로그인 응답의 `addFriendPoint`, `addFollowFriendPoint`, `addRecommendSupportFriendPoint` 합이 0보다 크면 스크립트 밖 변화에 "로그인" 출처로 기록
  - 로그인 응답을 기준점으로만 쓰는 기존 처리는 그대로. 계정을 새로 받은 로그인일 때만 기록
  - 구현: Sonnet 5.5(medium), 두 번에 걸쳐 완료. 검증 두 개: 1차 Haiku 통과·Sonnet 반려(실패한 로그인 응답에서 이전 지급량이 다시 기록되는 결함을 재현), 2차 둘 다 통과
- #495·#496 후속 테스트 (PR #508): 보구 레벨 숫자 칸의 12px 허용값과 마스터 스킬 대기시간 범위 제한을 고정하는 테스트. 구현: Haiku 5.5(medium). 테스트·문서만 바뀌어 플래너가 검토
- 설명서: 로그 수집 시작 설정 문서 추가와 기존 문서 정리(7d9d8432, 다른 세션), 사이드바 메뉴 추가(PR #516), 루트 수집 문서의 체인 이름 정정(29dadec6)

## 알아 둘 점
- #493: 1.8.0 이하 버전에는 감지 기능이 없어서, 새 버전이 수집 중일 때 구버전이 수집을 시작하면 최대 60초 겹친 뒤 새 버전이 안내와 함께 멈춤
