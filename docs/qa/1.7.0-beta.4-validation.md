지원 선택과 같은 작은 끝 박스 구조를 쓰되 주간·FP 값을 따로 측정했습니다. 끝 모양 crop의 `TM_CCOEFF_NORMED` 점수는 주간 위 끝 0.6828~1.0000 / 비끝 최대 0.1112, 아래 끝 0.9584~1.0000 / 비끝 최대 0.4828입니다. 위 끝 모양의 화면별 차이보다 **밝기와 테두리 대비**의 구분이 명확해 이 방식을 선택했고 새 템플릿 에셋은 추가하지 않았습니다.

- 주간: 끝 중앙 평균 250~254, 비끝 최대 150. 끝 문턱은 중앙 ≥220 및 양옆 대비 ≥30입니다. 레일 박스에서 중심/양옆 대비가 20 이상인 행 비율은 레일 있음 0.917~1.000, 없음 0.000~0.250이므로 문턱을 0.60으로 정했습니다.
- FP: 와이드 아래 끝 중앙 250.2·대비 87.4, 16:9 비끝 중앙 약 22·대비 -46.9, 와이드 비끝 중앙 약 13·대비 -36.9입니다. 끝 문턱은 중앙 ≥225 및 대비 ≥40입니다. 대비 25 이상인 레일 행 비율은 있음 1.000 / 없음 0.000이며 문턱은 0.70입니다.
- 세 유휴 아래 끝 캡처는 모두 즉시 Down 종료, 소유자 위 끝 캡처는 즉시 Up 종료입니다. 16:9 중간 화면은 레일만 읽습니다. 새 PNG fixture는 실제 판독 박스만 남기고 나머지를 가렸습니다. 기존 unreadable 2개 QA 케이스도 보존해 새 판독에서 레일 없음으로 기록합니다.

주간의 전체 레일 위치 계산, 프레임 픽셀 복사·정지 판정·끝 불신 규칙을 제거했습니다. 아래→위 검색 순서, 마지막 화면 검색, 예상 목록 이탈 방지와 방향별 14회 한도는 유지합니다. FP는 페이지 선택 후 아래 끝이면 `scrollbar-end`, 레일이 없으면 `no-scrollbar`로 끝냅니다. 행 정지는 종료 이유에서만 제거하며 `stationary`·`pageStationary` 기반 거부 탭 추론, 새 탭 없는 5페이지 종료와 500페이지 한도는 유지합니다.
