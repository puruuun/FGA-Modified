# 1.7.0-beta.4 검증

대상: 1.7.0-beta.4 / 1007004. #66 문구 변경과 #68 대문자 `H` 구문을 포함합니다. 정규판은 1.6.7 / 3094 유지하며, #68에서는 버전을 올리지 않았습니다.

| 변경 | 단위 테스트 app / prefs / scripts | Main CI |

| #68 | 214 / 28 / 617 통과 (총 859) | PR 생성 후 확인 |

두 변경 모두 `:app:compileDebugKotlin`과 `:app:testCiUnitTest :prefs:testCiUnitTest :scripts:test :libautomata:test`를 통과했습니다. 실패·오류·건너뜀은 0이며 libautomata에는 테스트 소스가 없습니다. 기기 QA와 로컬 APK 빌드는 실행하지 않았고 게임을 조작하지 않았습니다.

#68은 아홉 서번트 스킬 × 최소값 3종 × 색 조건 2종 × 중단 옵션 2종의 108가지 조합을 파싱·저장·재파싱해 같은 액션인지 검사합니다. 구형 `a{…}`·오타 `ah{…}`·잘못된 `H`는 거부하고, `ah`·`a1`·`c[Ch2A]`는 기존 의미를 유지합니다. 편집기 목록의 저장·재열기·되돌리기, 전투 실행 순서와 뒤따르는 공격도 새 구문으로 검증했습니다.
