## 소유자 확인 항목

1. 조건 줄 추가·삭제: 추가는 쓰지 않은 첫 색으로 1장, 줄이 1개면 ✕ 숨김.
2. 색 변경: 칩을 눌러 미사용 색만 표시, 값이 새 색으로 이동하고 이전 색은 삭제.
3. AND/OR 토글: 줄 2개 이상일 때만 표시.
4. beta.9 설정 표시: 업데이트 후 기존 카드 수와 색 최소 수가 줄로 정확히 나타남.
5. 전투 중 시작: 전체만, 색만(AND), 색 OR 조합, 전체 + 색 AND/OR, 두 번째 대상 각각에서 시작 시점이 요약 문구와 일치.
6. 대기 알림: 전체 줄이 없을 때 최소 카드 수가 `-`로 표시.
