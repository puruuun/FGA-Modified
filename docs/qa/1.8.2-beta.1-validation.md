## 1.8.1 이후 바뀐 것

모두 로그 기능입니다. 화면 판독, 탭, 스크립트 흐름은 바뀌지 않았습니다.

- #575 로그 필터 초기화와 출처 여러 개 선택 (PR #579)
  - 필터 창에 초기화 버튼. 목록 위의 해제 버튼은 없앰
  - 출처를 여러 개 고르면 그중 하나라도 맞는 기록을 보여 줌(OR)
  - 구현: Sonnet 5.5. UI·문자열만 바뀌어 플래너가 검토
- #577 스크립트 밖 변화 기간을 04:00 이후 첫 로그인에서 닫음 (PR #578)
  - 게임 날짜는 한국·일본 시각(UTC+9)에서 4시간을 뺀 날짜. 기기 시간대와 언어에 영향받지 않음
  - 열린 기간이 시작된 게임 날짜와 로그인 시각의 게임 날짜가 다르면, 로그인 처리 전에 그 기간을 닫음. 닫힌 기간의 끝 시각은 로그인 시각
  - 구현: Sonnet 5.5. 검증 두 개(Sonnet, Haiku). 지적 사항(`GregorianCalendar` 사용, 윤일과 열린 기간이 없는 경우 테스트)을 반영한 뒤 병합
- #576 날짜별 보기 (PR #580, #581, #582, #583)
  - 왼쪽은 (게임 날짜, 계정)마다 한 줄. 날짜는 04:00 기준이고 기록은 시작 시각의 날짜로 묶음
  - 오른쪽은 그날 그 계정의 전체 변동, 출처별 내역(스크립트 밖 출처와 각 전투), 실행한 스크립트
  - 기록별·날짜별은 필터 창의 "보기"에서 고름. 적용을 눌러야 바뀌고, 취소·초기화는 보기를 바꾸지 않음
  - 계정 변동과 실행한 스크립트에는 회색 상자가 없음. 왼쪽 줄은 날짜 / 계정·서버·전투 수의 두 줄
  - 구현: Sonnet 5.5 (네 번). UI·문자열만 바뀌어 플래너가 검토
