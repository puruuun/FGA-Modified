## beta.24 이후 바뀐 것
- #322 프렌드 관리의 관위 편성과 필터 개편 (PR #325)
  - 편성 종류: 일반 / 이벤트 / 관위
  - 관위 편성은 예장 1·3을 두 줄로, 인연 예장 효과를 "인연: NP 차지 / 기본 효과 / 없음" 라벨로 표시
  - 필터 추가: 친구 이름 검색, 서번트 레벨 이상/이하, 예장 여러 개 선택, 예장 최대 돌파 여부, 최종 로그인 기간
- 필터 창을 모든 화면 너비에서 한 줄로 배치 (PR #327, 오너 요청)
- #324 위젯 버그 두 가지 (PR #326, Codex가 시작하고 Sonnet이 마무리)
  - FGA가 다른 화면에 있을 때 위젯으로 시작하면 메인 화면으로 이동한 뒤 서비스를 한 번 시작. 온보딩 중이거나 이미 실행 중이면 요청을 버림
  - 계정 1개 카드를 탭하면 그 계정의 대시보드를 엶. ▲/▼로 계정을 바꾼 뒤에도 같음
- #323 계정 대시보드에 내 서포트 편성과 관위 편성 표시 (PR #328, Sonnet 구현)
  - 서포트 편성: 일반/이벤트, 편성 번호, 클래스별 행
  - 관위 편성: 관위 데이터가 없는 계정(현재 KR)에서는 카드를 숨김
- #329 필터 창 개편 (PR #330, Sonnet 구현)
  - 폭 600dp 이상(휴대폰 가로 포함): 오른쪽 360dp 사이드 패널. 목록이 옆에 보이고 조건을 바꾸면 바로 반영. 이름 입력은 250ms 뒤에 반영
  - 폭 600dp 미만: 위에서 내려오는 패널을 유지하고 "N칸 보기"로 적용
  - 로그인 기간: 숫자 직접 입력(0~99), −/+, 단위(분/시간/일) 드롭다운
  - 서번트 레벨은 한 덩어리로 정리. 고른 서번트와 예장은 패널 안에 지울 수 있는 칩으로 표시
