# 1.7.1-beta.7 연속 퇴각 정지 횟수 설정 (#144)

## 변경

"3회 연속 퇴각 시 정지"의 횟수 3이 고정값이었습니다. 이제 전투 설정마다 1~99 중에서 정할 수 있습니다.

- 새 설정 `turn_limit_retreat_streak_count`(기본값 3)를 추가했습니다. 전투 설정을 내보내고 가져올 때 함께 저장됩니다. 이미 체크박스를 켜 둔 설정은 계속 3회에서 멈춥니다.
- 퇴각 후 재시작 창의 체크박스 옆에 숫자 조절기(1~99)를 두었습니다. 체크박스와 스위치가 켜져 있을 때만 조절할 수 있습니다. 라벨은 "N회 연속 퇴각 시 정지"입니다.
- `checkStreak()`는 설정한 횟수(최소 1)로 판단합니다. 전멸 퇴각과 턴 제한 퇴각을 함께 세고, 정상 클리어한 주회만 연속 횟수를 0으로 되돌리는 동작은 그대로입니다.
- 종료 이유 `TurnLimitRetreatStreak`가 횟수를 담고, 메시지는 "퇴각이 N회 연속 발생해 정지했습니다."입니다. 영어·일본어 문구도 맞췄습니다.
- 위키 `Turn-Limit-Retreat-KR.md`를 고쳤습니다.

## 테스트

`TurnLimitRetreatTest`에 횟수 1, 횟수 5, 체크박스 꺼짐, 0 이하 값 보정, 클리어 후 초기화와 종료 이유의 횟수를 확인하는 테스트를 더했고, `AddedFeatureTuningPrefsTest`에 기본값 3 확인을 더했습니다. 전체 결과는 PR에 기록합니다.

## 소유자 확인 사항

beta.6은 다른 기능과 함께 빌드합니다. 이 PR만으로 APK를 만들지 않습니다.

1. 퇴각 후 재시작 창에서 체크박스를 끄면 조절기가 비활성화되는지.
2. 횟수를 바꾼 뒤 저장하고 다시 열었을 때 값이 유지되는지.
