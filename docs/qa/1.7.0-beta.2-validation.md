### Grand·CE·하쿠노

- Grand JP 와이드 y720=179: NP **0.739172**, 기본 **0.220356** → NP 수락·기본 거부·무시 수락. 부분 행 579: NP **0.203713**, 기본 **0.844201** → NP 거부. 이 점수를 실제 판정과 같은 crop에서 읽어 `FGA.SupportCe`에 기록합니다.
- CE 새 실행 템플릿: JP 16:9/와이드 **0.99998**, KR 와이드 **0.99977–0.99999**. 재선택: JP 16:9 **0.99996**·와이드 **0.99918**, KR 16:9 **0.99996**·와이드 **0.9049–0.99843**. 기존 KR 서번트 화면의 부재 점수는 실행 ≤**0.3551**, 재선택 ≤**0.4519**이며 감지는 `ServantLevel` 유지.
- **KR 16:9 실행 창의 가리지 않은 원본은 제공되지 않았습니다.** 그 비율의 팝업은 부재 사례로 검증했고, 실제 실행 창은 소유자 확인 항목입니다. 결과를 합성해서 양성으로 기록하지 않았습니다.
- 하쿠노 Close: `Region(-160, 1060, 320, 130).xFromCenter()`, 기존 `Kr/close.png`. 정규화 fixture 점수는 와이드 **0.99479**, 16:9 **0.99480**, 일반 전투 부재 **0.18963**. 매칭 영역은 두 비율 모두 중심 기준 x=-112, y=1088, 218×72. 원 이슈의 원본 측정값은 와이드 0.986·16:9 0.994입니다.
