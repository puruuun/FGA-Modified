## beta.2 이후 바뀐 것

UI만 바뀜. 화면 읽기, 터치, 저장 데이터, 로그 수집 동작은 바뀌지 않음.

- 앱 색 F (#595, PR #597, #598): 회색 바탕과 글자, 누르는 요소만 남색, 최대값만 금색, 경고만 빨간색. 꺼진 스위치의 테두리가 보이게 함
- 표준 Material 3 버튼과 선택 요소 (#596, PR #599): 제목줄 버튼은 아이콘 있는 외곽선 버튼, 웨이브·스팸 번호는 탭, 서포트 스킬 10 칸은 체크 표시 없는 금색
- 계정 대시보드 개편 (#594)
  - PR #602: 넓은 화면은 왼쪽 메뉴(계정 정보와 섹션 목록), 좁은 화면은 위쪽 탭. 처음에는 개요가 열림. 개요에 AP·성정석·QP, 사과, 재화, 보관, 최근 기록, 계정 정보
  - PR #604: 아이템 섹션. 이름 검색, 휘석·마석·비석과 피스·모뉴먼트의 클래스별 표(10개 미만은 빨간색), 강화 재료 12종 뒤 "더 보기"
  - PR #603: 서번트 섹션. 넓은 화면은 표, 좁은 화면은 서번트당 세 줄. 클래스 칩은 게임 순서. 스킬·어펜드 10은 금색, 열지 않은 어펜드는 "–". 좁은 화면의 "계정 대시보드" 제목을 한 줄로
  - PR #606: 개요 사과 순서 테스트가 실행 순서에 따라 실패하던 것을 읽기 순서 비교로 고침(테스트만)
- 구현: Sonnet 5.5 (각 PR). 검토와 병합은 플래너. #606은 플래너가 직접 고침

## 확인한 것

- 전체 단위 테스트(버전 커밋 fd2a87cf): app 1717, prefs, scripts, libautomata 모두 실패 0. PR의 Main CI 통과
- 기기 QA 묶음은 돌리지 않음. 바뀐 곳(앱 UI)을 다루는 묶음이 없음
- MuMu에서 이 APK의 앱 화면만 열어 봄(게임은 열지 않음)
  - 메인: 빌드 칩이 옅은 남색에 정보 아이콘, "서비스 시작"·"로그 수집 시작" 버튼이 남색
  - 로그 수집 설정: 꺼진 스위치는 테두리와 회색 손잡이로 보이고, 켜진 스위치는 남색. 연결 방식의 선택된 칩은 옅은 남색
  - 계정 대시보드(KR 계정, 세로 360dp)
    - 제목 "계정 대시보드"가 한 줄. 계정 정보 아래에 탭(개요, 서번트 302, 아이템, 편성, 도감·소환, 선물함 173), 처음에 개요가 열림
    - 개요: 사과 네 종류와 재화(마나 프리즘, 레어 프리즘, 성정편, 청동색 묘목, 호부, 스톰 포드, 티포트)가 실제 아이콘과 이름으로 나옴. 보관 막대가 서번트·기타 두 색으로 나옴
    - 서번트: 실제 얼굴 그림, 세 줄 행, 금색 10과 "–", 클래스 칩이 세이버부터 게임 순서
    - 아이템: 검색란, 강화 재료 2열과 "더 보기 (58종)", 휘석·마석·비석과 피스·모뉴먼트 표가 7열로 잘리지 않고 나옴
  - 대시보드를 보려고 "로그 수집 사용"을 잠시 켰다가 확인 뒤 다시 끔(원래 상태). 수집 자체는 켜지 않음
  - 계정 정보가 보이는 화면 캡처는 저장소에 넣지 않음
