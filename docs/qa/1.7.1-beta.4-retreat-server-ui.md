# 1.7.1-beta.4 퇴각 설정 서버 검사 제거 (#137)

## 원인

beta.3의 "퇴각 후 재시작" 창은 `IPreferences.gameServer`로 서버를 판단했습니다. 이 값은 스크립트를 시작할 때만 설정되는 메모리 값이라, 앱을 켠 뒤 스크립트를 한 번도 실행하기 전에는 항상 NA입니다. 그래서 KR/JP에서도 N 입력이 0으로 잠기고, 저장하면 N이 0으로 덮어써졌습니다.

## 수정

- 설정 창에서 서버 검사를 모두 없앴습니다. N은 0~99로 항상 입력할 수 있고(스위치가 켜져 있을 때), 저장은 고른 값 그대로 기록합니다.
- 설명은 항상 기본 문구이고, 설정 줄은 저장된 값만으로 꺼짐 / 전멸 시 퇴각 / N턴 도달 시 퇴각을 표시합니다.
- 서버 안내 문구(`p_battle_config_turn_limit_retreat_unsupported`)를 모든 언어에서 삭제했습니다.
- 스크립트는 그대로입니다. 실행 중 KR/JP만 N을 쓰고, 다른 서버는 N을 무시한 채 전투를 계속합니다. 전멸 퇴각은 모든 서버에서 스위치를 따릅니다.
- 위키 `Turn-Limit-Retreat-KR.md`의 "서버" 설명을 갱신했습니다.

## 테스트

설정 창에는 단위 테스트할 로직이 남지 않았습니다. 스크립트 쪽 기존 `TurnLimitRetreatTest`가 다른 서버의 N 무시(이미지 미로드 포함)와 KR/JP의 N턴 퇴각을 이미 검증합니다. 전체 단위 테스트 결과는 PR에 기록합니다.

## 소유자 확인 사항

1. KR/JP에서 설정 창에 N을 입력해 저장하고, 다시 열어도 값이 유지되는지.
2. KR/JP에서 N턴에 도달하면 퇴각하는지.
3. 다른 서버에서는 N을 넘겨도 전투를 계속하는지.
4. beta.3에서 업데이트하면 저장된 N이 이미 0으로 덮어써져 있으므로 N을 다시 입력해야 합니다.
