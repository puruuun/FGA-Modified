# 1.7.2-beta.1 서포트 카드 구분 (#167)

## 배경

- **제보:** 카드 우선순위를 웨이브별로 다르게 정했는데 가끔 다른 웨이브 순서로 카드를 고름(dcinside 제보, 골든 BB 본인 + 골든 BB 서포트 + 테노치티틀란).
- **원인:**
  - 웨이브 판정과 정렬은 정상이었습니다. 카드를 서번트별로 나누는 단계에서 서포트 카드를 잘못 나눴습니다.
  - 카드의 `SUPPORT` 표시 판정 이미지(`support.png`, `+SU`, 2021년)는 지금 카드 표시와 맞지 않습니다. 지금 카드 표시에는 `+`가 없습니다. 실제 화면에서 가려지지 않은 표시도 0.5 안팎이었고, 기준은 0.8입니다.
  - 표시를 놓친 서포트 카드는 본인 서번트 얼굴 중 가장 비슷한 쪽으로 갔습니다. 제보 파티에서는 1번이 0.63, 테노치티틀란이 0.66이라 그때그때 결과가 달라졌습니다.
  - 버프 아이콘이 표시 앞부분(`SU`)을 가리는 것도 상황을 더 나쁘게 했습니다.
- **분석 기록:** [#167](https://github.com/puruuun/FGA-Modified/issues/167) 댓글 두 개(측정값과 확정 사양)

## 측정 (BlueStacks JP, 2560x1080, 흑백 TM_CCOEFF_NORMED)

| 판정 이미지 | 본인 카드 최고 | 서포트, 표시 다 보임 | 서포트, `SU` 가려짐 |
|---|---|---|---|
| 기존 `+SU` | 0.48 | 0.51~0.54 | 0.43 |
| `PORT` | 0.42 | 0.96~1.00 | 0.85 |
| **`ORT` (채택)** | 0.45 | 0.96~1.00 | 0.90~0.92 |

- 카드가 위아래로 흔들리는 캡처 4장에서 차이는 0.03 이하였습니다.
- 메인 화면 서포트 판정(`servant_check_support.png`)은 정상이었습니다. 서포트 자리 0.94, 본인 자리 0.02와 0.14입니다.
- 같은 캐스터 알트리아를 본인과 서포트로 넣었을 때, 상세 창 얼굴 크롭이 픽셀까지 같았습니다(1.00). 서포트 상세 창도 본인 창과 모양이 같습니다.

## 변경 (오너 승인 사양)

1. **카드 표시 판정:** `support.png`(En·Jp)를 실제 캡처에서 자른 `ORT` 크롭으로 바꿨습니다. 판정 기준은 0.7입니다.
2. **서포트 얼굴 저장:** 서포트가 나오면 상세 창을 열어 얼굴을 저장합니다. 같은 서포트가 계속 나오면 한 번만 저장합니다.
3. **같은 얼굴 판정:** 서포트 얼굴이 본인 서번트 얼굴과 0.99 이상 일치하면 이번 실행에서는 서포트 얼굴을 쓰지 않습니다. 이때는 지금처럼 표시로만 구분합니다.
4. **표시가 없는 카드:** 필드에 있는 서번트 얼굴 중 점수가 가장 높은 쪽(0.5 이상)에 배정합니다. 3번에서 허용되면 서포트 얼굴도 후보입니다.
5. **"서포트 아이콘 확인 생략" 옵션 삭제:** UI, 설정 값, 문자열에서 지웠고, 매뉴얼(`wiki/scripts/Card-Priority-KR.md`)도 고쳤습니다.

## 1.7.2-beta.2: 서포트 얼굴 비교 멈춤 수정 (2026-11-03)

- **증상:** 오너가 BlueStacks에서 캐스터 알트리아를 본인과 서포트로 넣고 돌렸습니다. 서포트 상세 창 얼굴 확인까지 마친 뒤 FGA가 더 이상 동작하지 않았습니다.
- **원인:**
  - 같은 얼굴 판정의 `matchScore`가 `findMatches(…, 0.0)`을 `maxOfOrNull`로 끝까지 읽었습니다.
  - `DroidCvPattern.findMatches`는 찾은 자리를 0.0으로 채우고 `score >= similarity`인 동안 계속 찾습니다. 그래서 기준이 0.0이면 끝나지 않습니다.
  - 서포트가 있는 전투에서는 서포트 얼굴을 저장하면 항상 멈췄습니다.
- **리뷰 누락:** 플래너 리뷰는 순수 판단 로직만 확인했고, 이미지 매칭 시퀀스가 끝나는지는 보지 않았습니다.
- **수정:**
  - 가장 높은 점수인 첫 결과만 읽습니다(`FaceCardGrouping.bestScore`).
  - 끝없이 이어지는 시퀀스로 단위 테스트를 추가했습니다.
  - 나머지 `findMatches` 사용처를 다시 확인했습니다. 표시 판정은 0.7, 얼굴 비교는 0.5 기준이라 문제가 없습니다.
- **PR과 CI:**
  - 플래너가 [#169](https://github.com/puruuun/FGA-Modified/pull/169)로 고쳤습니다(`d78d1a58`).
  - 로컬 전체 단위 테스트가 통과했습니다. PR의 Main CI와 PR Build, `main`(push)의 Main CI도 성공했습니다.
- **베타 APK:** `build/release-assets/FGA-beta-1.7.2-beta.2-arm.apk`
  - versionName `1.7.2-beta.2`, versionCode `1007202`
  - SHA-256 `f52e682dfa8f47d6453fc944e43ed219bc7f9170871449592224409758e4bfa8`
  - 서명은 v3 오너 키와 v2입니다. zipalign(16 KB)을 통과했습니다.
- **BlueStacks:** beta.1 위에 업데이트했습니다. 처음 설치 날짜가 그대로입니다.
- **기기 QA:** 바뀐 부분을 다루는 스위트가 없어 돌리지 않았습니다. 판독 코드는 beta.1의 전체 기기 QA 뒤로 바뀌지 않았습니다.

## 오너 확인 사항

1. **서포트가 있는 파티로 서번트 방식 카드 우선순위 주회:** 웨이브마다 서포트 카드가 맞게 골라지는지 확인해 주세요. 버프가 여러 개 붙어 표시가 가려진 경우도 봐 주세요.
2. **같은 서번트를 본인과 서포트로 쓰는 파티:** 본인 카드와 서포트 카드가 섞이지 않는지 확인해 주세요. 예: 캐스터 알트리아 2명.
3. **시작할 때 서포트 상세 창:** 서포트 상세 창이 한 번 열렸다 닫히는지 확인해 주세요. 같은 서포트로 다음 주회를 돌 때는 다시 열지 않습니다.
4. **더 보기 → 배틀:** "서포트 아이콘 확인 생략" 항목이 없어졌는지 확인해 주세요.
