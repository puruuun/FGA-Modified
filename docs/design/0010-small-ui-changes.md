# 0010 작은 UI 변경 (2026-10-20 소유자 요청)

- 상태: 설계
- 버전: 1.6.0-beta.3에 함께 포함

## D-1. 정규판 앱 아이콘을 Quick으로
- 지금은 베타가 Quick 아이콘(`app/src/main/res/mipmap-*`), 정규판(`ci` 빌드)이 Arts 아이콘(`app/src/ci/res/mipmap-*`)을 씁니다.
- 정규판도 **베타와 같은 Quick 아이콘**을 씁니다. `ci` 전용 아이콘 리소스를 지워 main 아이콘을 쓰게 하는 것이 가장 단순합니다. 앱 이름(`FGA(mod)` / `FGA(beta)`)은 그대로입니다.
- 확인: Stable APK의 aapt `application-icon`이 main 아이콘을 가리키는지 봅니다.

## D-2. 인연 추적 설정을 실행 창으로
- 지금 인연 추적(`BondPrefsCore`: 추적, 최대 시 정지, 대상 칸)은 전투 설정 편집 화면(`BondGroup.kt`) 안에 있습니다.
- 이것을 **전투 실행 창**으로 옮깁니다. 스톰포드·티포트 체크박스(`BattleLauncher.kt` "아이템 자동 사용")처럼, 시작할 때 고르게 합니다.
  - 체크박스: "인연 추적", "최대 인연이면 정지", 대상 칸 선택
  - 값은 지금처럼 **전투 설정별로 저장**합니다. 실행 창에서 바꾼 값은 확인할 때 그 전투 설정에 저장됩니다(티포트와 같은 방식).
- 전투 설정 편집 화면의 인연 항목은 지웁니다. 저장 키는 바꾸지 않아 기존 값이 유지됩니다.
- 설명서(`wiki/scripts/Bond-Tracking-KR.md`)의 위치 안내를 고칩니다.
