# 0011 추가기능 스위치 정리와 정규 1.6.0 (2026-10-21 소유자 요청)

- 상태: 완료 (e0ea34c7, 정규·베타 APK 검증 및 베타 설치 완료)
- 버전: 정규 **1.6.0 / 3087**, 베타 **1.6.0-beta.13 / 1006013** (같은 커밋)
- 정규 1.6.0에는 0009 주간 미션 루트(beta.12까지)와 이 문서의 변경이 들어갑니다.

## D-1. 티포트·스톰포드 자동 설정: 기본값 켜짐
- 지금은 `QuestItemControlPrefsCore.ignore`(`ignore_teapot_storm_pod_usage`)의 기본값이 `true`라서, 추가기능의 "티포트·스톰포드 자동 설정 사용"이 **기본 꺼짐**입니다.
- 기본값을 **켜짐**으로 바꿉니다(`ignore` 기본값 `false`).
  - 사용자가 직접 바꾼 적이 있으면 저장된 값을 그대로 씁니다. 저장된 적이 없을 때만 새 기본값이 적용됩니다.
- 설명 문구에서 "기본값은 꺼짐"을 "기본값은 켜짐"으로 고칩니다(en, ko).
- 실행 창의 체크박스(스톰포드·티포트) 자체는 지금처럼 **체크해야 사용**합니다.

## D-2. 인연 추적 기능 스위치 (추가기능)
- 더 많은 옵션 → 추가기능에 **"인연 추적 기능 사용"** 스위치를 추가합니다. 기본값은 **켜짐**입니다.
  - 새 전역 설정: 예) `bond_tracking_feature_enabled`, 기본값 `true`.
- 스위치가 꺼져 있으면
  - 전투 실행 창의 인연 항목(인연 추적, 최대 인연이면 정지, 대상 칸)이 **보이지 않습니다**.
  - 스크립트도 인연 추적과 최대 인연 정지를 하지 않습니다(`BondTracker.enabled = false`). 전투 설정에 저장된 값은 지우지 않습니다.
- 스위치가 켜져 있으면 지금과 같습니다. 실행 창에서 **체크해야 사용**합니다(기본 체크 해제, 지금 저장 값 유지).

## D-3. 꺼진 기능은 실행 창에서 숨김
- 추가기능에서 꺼진 기능은 전투 실행 창에서 회색으로 잠그지 말고 **아예 숨깁니다**.
  - 티포트·스톰포드: `ignoreQuestItemUsage`가 참이면 "아이템 자동 사용" 블록 전체(제목, 체크박스 2개, 안내 문구, 구분선)를 숨깁니다. "추가기능에서 켜면…" 안내 문구(`p_quest_item_usage_ignored`)는 쓰지 않으므로 지웁니다.
  - 인연 추적: D-2 그대로.
- 서버가 지원하지 않아 쓸 수 없는 경우(`p_quest_item_usage_servers`)는 지금처럼 안내합니다.

## D-4. 서포트 판독 진단 저장을 추가기능으로
- 정체: 이 포크에서 만든 **서포트 점수 판독**(클래스 점수, NP·어펜드 판독 등)이 서포트를 확인할 때마다 점수 이미지와 판독 근거를 FGA 저장 폴더의 `diagnostics/`에 저장하는 개발·검수용 기능입니다. 원본 FGA에는 없습니다. 기본값은 꺼짐입니다.
- 위치를 더 많은 옵션 → **고급**에서 → **추가기능**으로 옮깁니다. 설정 키와 기본값(꺼짐)은 그대로입니다.

## D-5. 정규판에서 탐색 시험 모드 숨김
- 정규판(`ci`/`release` 빌드)에서는 주간 미션 칸의 **탐색 시험** 토글과 범위·건너뛰기 옵션을 숨깁니다. FP 판매 시험 모드처럼 빌드 종류로 나눕니다(`provideFpSellStableBuild`와 같은 기준).
- 베타에서는 그대로 보입니다.
- 정규판에서는 주간 루트의 진단 PNG도 지금처럼 저장하지 않습니다(`WeeklyPanelDiagnostics`는 베타 전용). 단, 루트가 멈출 때의 진단(D-38)은 베타 전용으로 둡니다.

## 검증
- 단위 테스트
  - 티포트 기본값: 저장 값이 없으면 켜짐, 저장된 `true`/`false`는 그대로입니다.
  - 인연 스위치가 꺼지면 `BondTracker.enabled`는 거짓입니다.
- 정규 APK에서 탐색 시험 UI가 없고, 베타 APK에는 있는지 확인합니다(빌드 종류 단위 테스트 또는 기기 QA).
