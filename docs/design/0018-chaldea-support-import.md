# 0018 칼데아 불러오기: 서포트 설정 함께 가져오기 (2026-10-23 소유자 요청)

- 상태: 구현 (검증 기록: `docs/qa/1.6.2-beta.8-validation.md`)
- 버전: 1.6.2-beta.8 / 1006208
- 관련: Chaldea 공유 링크로 커맨드 입력(`util/chaldea/`), 서포트 이미지 검색·저장(`util/portraits/`)

## 목표
칼데아 공유 링크로 커맨드를 가져올 때, 링크에 들어 있는 **프렌드(서포트) 서번트와 그 장착 개념예장, 레벨 조건**을 전투 설정의 서포트 설정에 함께 넣습니다. 판독 이미지가 없으면 자동으로 받습니다.

## 링크에 있는 정보 (실제 링크로 확인)
`team.onFieldSvts` / `team.backupSvts`의 각 항목:
- `supportType`: `"friend"`면 서포트, `"none"`이면 자기 서번트
- `svtId`(내부 ID), `limitCount`(재림), `tdLv`(보구), `skillLvs[3]`, `appendLvs[5]`
- `ceId`(내부 ID), `ceLimitBreak`(최대 돌파), `grandSvt`
- 내부 ID는 서버와 무관합니다. JP와 KR이 같습니다.

## D-1. 서포트 찾기
- 6자리 가운데 `supportType == "friend"`인 항목이 정확히 1개일 때만 가져옵니다.
- 0개거나 2개 이상이면 서포트 부분은 건너뛰고 안내합니다. 커맨드 가져오기는 지금처럼 진행합니다.

## D-2. 내부 ID → 도감 번호
- 서포트 이미지 검색·저장이 쓰는 Atlas 목록(`AtlasSupportRepository` / `SupportImageCatalog`의 내부 ID ↔ 도감 번호 ↔ 이름)을 그대로 씁니다. 번호 우선순위와 지역 전용 규칙(JP 우선, `KR.No.`/`NA.No.`)도 그 기능과 같습니다.

## D-3. 판독 이미지 폴더 찾기 (B 방식, 소유자 결정)
순서대로 찾습니다.
1. 저장 폴더의 `support/servant/No.번호 …` 또는 `support/ce/No.번호 …`(기존 `ServantPortraitMetadata.number/resolve` 규칙)
2. **내장 이미지 연결표**(D-4)로 원본 FGA 내장 폴더(`Merlin`, `Kaleidoscope.png` 등)
3. 둘 다 없으면 **서포트 이미지 검색·저장 기능으로 그 번호를 자동 생성·저장**한 뒤 그 폴더
- 다운로드는 사용자가 확인한 뒤에만 합니다(D-6 미리보기). 네트워크가 필요하고, 실패하면 그 항목만 건너뛰고 안내합니다.
- 내장 폴더와 파일 이름은 **바꾸지 않습니다**(원본 FGA 호환, 기존 선택, 업스트림 병합 보호).

## D-4. 내장 이미지 연결표

생성 스크립트: `tools/chaldea/generate_builtin_ids.py`. [개념예장 28개 전체 검토표](0018-builtin-ce-table.md).
현재 파일을 검사하면 내부 ID가 있는 `f_<ID><face>.png`는 9개 서번트 폴더에만 있습니다. 나머지 15개는 이름으로 추측하지 않고 미연결로 남깁니다. 예장은 Atlas NA 이름 완전 일치·단일 결과 11개만 연결하고 17개는 미연결입니다. 원래 이미지의 이름과 내용은 유지합니다.
- 서번트 24개: 폴더 안 파일 `f_<내부ID><얼굴번호>.png`(예: `Arcueid/f_23005000.png`)에서 내부 ID를 얻어 Atlas로 도감 번호를 찾습니다. 생성 스크립트로 만들고 결과를 확인합니다.
- 개념예장 28개: 파일 이름이 영어 이름뿐입니다. Atlas NA 이름과 맞춘 연결표를 한 번 만들고, 28개 전부 사람이 확인할 수 있도록 표로 문서에 남깁니다. 정확히 하나로 맞지 않는 항목은 연결하지 않습니다.
- 연결표는 앱 리소스(예: `assets/Support/builtin-ids.json`)에 두고 단위 테스트로 누락·중복을 검사합니다.
- 원본 FGA가 내장 이미지를 추가하거나 바꾸면, 연결표에 없는 내장 폴더는 그냥 연결이 없는 상태로 둡니다(오류 아님).

## D-5. 설정 반영
가져오기를 켠 경우 그 전투 설정의 서포트 설정을 아래처럼 바꿉니다.

| 설정 | 값 |
|---|---|
| 선택 방식 | Preferred |
| 선호 서번트 | D-3의 서번트 폴더 하나로 **교체** |
| 선호 개념예장 | 장착 예장이 있으면 D-3의 예장 폴더 하나로 교체, 없으면 비움 |
| 개념예장 최대 돌파 | `ceLimitBreak` |
| 보구 레벨 판독 | 켜고, 최소 레벨 = `tdLv` |
| 스킬 1–3 최대 | 각 `skillLvs == 10` |
| 어펜드 판독 | `appendLvs`에 10이 하나라도 있으면 켜고, 칸별로 `== 10`이면 10, 아니면 x |
| 서포트 클래스 | 서번트 클래스로 설정(FGA `SupportClass`에 대응하는 값, 없으면 그대로) |
| 그랜드 서번트 / 스코어 / 친구만 / 그 밖의 설정 | 바꾸지 않음 |

## D-6. 화면
- 칼데아 불러오기 창에 **"서포트 설정도 가져오기"** 체크를 둡니다. 기본은 꺼짐입니다.
- 변환 뒤 **미리보기**를 보여 줍니다. 서번트·예장 번호와 이름, 찾은 폴더(내장/저장/다운로드 필요), 바뀔 설정 목록이 나옵니다. 사용자가 확인하면 그때 다운로드하고 적용합니다.
- 취소하면 아무것도 바꾸지 않습니다. 커맨드만 가져오는 기존 흐름은 그대로입니다.
- 선택 목록 화면에서 내장 폴더 옆에 번호를 같이 보여 주는 것(`No.150 Merlin`)은 이번 범위에 넣지 않습니다.

## 검증
- 단위 테스트:
  - 실제 공유 링크 2개(테스트에 이미 있음) 각각에 대해 friend 0개와 1개 처리
  - 설정 매핑 표 전 항목
  - 폴더 찾기 3단계 순서
  - 연결표 누락·중복
  - 네트워크 실패
  - 취소 시 무변경
- 문서: `wiki/scripts/Chaldea-Import-KR.md`에 서포트 가져오기를 추가하고, 내장 예장 연결표를 문서에 넣습니다.
- 실기기: 소유자가 칼데아 링크로 가져온 뒤 서포트 선택을 1회 돌려 봅니다.
